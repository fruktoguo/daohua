# 黑白单彩极简折面美术规范

本规范定义了一套**冷峻、硬朗、具压迫感、暗黑修仙妖煞风格的 2D 扁平折面视觉系统**。适用于怪物、BOSS、元素生灵、角色立绘与战斗资产的 AI 提示词组装与视觉验收。

在进行任何设计、审核或提示词撰写前，请查阅 [art-direction-bible.md](references/art-direction-bible.md) 与 [prompt-assembly-guide.md](references/prompt-assembly-guide.md)。

---

## 1. 核心美学哲学与暗黑调性

- **少而精的折面**：采用大色块折角与锐利硬边切角，构建冷酷、凶煞、充满张力的形体结构。
- **暗黑压迫感与恐怖张力**：
  - 拒绝一切温和呆萌、泡泡圆角的宠物感。
  - 强调骨骼感、棱角张力、锐利目光与妖异能量核，呈现修仙世界中凶残、诡谲、煞气逼人的妖魔与异灵形态。
- **背景强制为纯黑色（#000000）**：
  - 画面背景**必须严格为纯黑实色**，与外层的暖骨白纸板描边形成极高反差。
- **三层视觉尺度**：
  1. **宏观**：极具压迫感的主体轮廓、重心与姿态轴线。
  2. **中观**：3~5 块高价值的黑/白/彩闭合结构面，交代骨架、面具、外甲与能量源。
  3. **微观**：至多 1~2 个微小识别符号（如冷冽的菱形凶光眼）。

## 2. 视觉预算与色彩语义规范

每个单位严格遵循三色层级分配，背景统一为纯黑色：

| 颜色角色 | 面积预算 | 视觉职责 | 规则与约束 |
|---|---|---|---|
| **纯黑背景** | **画布底色** | 纯色实底 `#000000` | 绝不使用灰色、彩色或渐变背景，凸显纸板外描边。 |
| **近黑主体** | **60% ~ 80%** | 主体肉身、重甲、煞气质心 | 连续的主体深色质量；提供骨架间的负空间与压迫感。 |
| **骨白结构** | **12% ~ 28%** | 骨刺、面具面盘、獠牙、外甲壳与接触利爪 | 封闭大面，通常 1~3 块；具有骨骼硬度和导向感。 |
| **单饱和强调色** | **5% ~ 14%** | 妖核、幽冥灵火、煞气回路、魔纹动力链 | 单一高饱和主色（如血赤、妖紫、幽蓝、碧绿、玄金）。 |

### 强制间隙规则（呼吸槽）
- 独立的白色骨骼面与彩色能量面之间**必须保留近黑色隔离槽（呼吸槽）**。
- 仅当两者在物理/逻辑上构成同一块复合结构（如骨架内嵌核心）且交界分明时才允许贴合。

## 3. 结构分类与质量几何

### 承重与运动模式
- **G（贴地多足）**：四足或多点伏地，着重刻画压低扑杀、沉重底盘或后蹬弹跳。
- **V（直立双足）**：双足挺拔立立，如人立巨魔、狂暴猿魔、虎首人身妖王，着重刻画高大压迫感与战斗前迎面。
- **W（悬浮推进）**：浮空小精灵/飞灵/气煞，着重刻画飘逸聚拢的流线、精灵灵火与下垂灵须。
- **L（线性低伏）**：蛇形、长轴脊椎匍匐，强调中轴扭动与利爪。
- **R（放射聚拢）**：浮空核心环绕少数不对称气焰或触角。
- **X（节段多足）**：甲壳分段与尖刺武器端。

### 质量几何形态
- **C（紧凑重装）**：宽肩厚体重心低，力量感集中。
- **D（穹顶重甲）**：上方大壳/驼峰隆起，坚不可摧。
- **T（高挑立轴）**：高大威严、双足站立或树冠立轴。
- **F（扁平流线）**：横向开阔，极速冲锋。
- **W（精灵小体）**：轻盈浮空、聚拢灵体，具有精灵/小异灵特征。

## 4. 标准 AI 提示词组装流水线（纯黑背景与暗黑调性）

生成提示词时严格拆分为两部分：

### A. 固定公共段（纯黑背景）
```text
请精确生成一张已完成的 2D 游戏精灵图，主体为 [ENTITY_NAME]。使用暗黑奇幻切割形视觉语言：纯黑实色背景（#000000）、近黑连续主体块面（60%~80%）、少量宽大骨白结构面（12%~28%）、单一高饱和强调色（5%~14%）。使用带克制倒角的硬边平面形状、实色填充；禁止纹理、禁止渐变、禁止柔光阴影、禁止发光、禁止模糊、禁止 3D 渲染、禁止文字、禁止水印。整个实体必须完整可见、居中，并在 96px 下清晰可读。使用明确的朝右、近正交的侧向为主纸片卡视角，带轻微四分之三体积感。在实体外侧加一圈细暖骨白纸板描边，描边与实体之间以一道极窄墨黑凹槽分隔。背景必须是纯黑实色。
```

### B. 实体定制段（凶煞暗黑）
```text
架构与姿态：
[ENTITY_NAME] 是一个 [SUPPORT_MODE] 的暗黑系实体，质量几何为 [MASS_GEOMETRY]。姿态：[SPECIFIC_STANCE_AND_AXIS]。设计一条连续的近黑威胁感剪影，解决 [SILHOUETTE_PROBLEM]。

骨白结构面：
添加 [1-3] 块锐利的闭合骨白色面：[PLANE_1，承担 SKELETAL_MASK/CLAWS 职责]；[PLANE_2，承担 ARMOR/RIDGE 职责]。用一个锐利菱形标记表现寒冽的 [EYE_COLOR] 眼睛。禁止柔软圆润的卡通特征。

强调色拓扑：
将 [ACCENT_COLOR] 以 [ACCENT_TOPOLOGY] 形状布置在 [ACCENT_LOCATION]。它承担 [DEMONIC_CORE/ENERGY_CHAIN] 职责，起点为 [START]，终点为 [END]。在骨白结构面与强调色能量之间保留近黑呼吸槽。禁止给 [FORBIDDEN_AREAS] 上色。

规避：
规避吉祥物化特征、柔软蓬松的圆润感、杂乱的细密尖刺、多种强调色，以及非黑背景。
```

## 5. 验收红线清单

1. **纯黑背景**：背景完全为纯黑实色（#000000），外层暖骨白纸板描边边缘锐利反差强烈。
2. **暗黑压迫感**：造型冷酷硬朗，杜绝圆润呆萌与宠物化。
3. **96px 极简辨识度**：缩至小图标依然清晰辨认出轮廓 + 骨白大面 + 单色核心。
4. **姿态准确**：双足站立者（如直立虎魔、立立猿魔）必须呈现挺拔双足立姿；元素小精灵必须呈现浮空灵动体态。
