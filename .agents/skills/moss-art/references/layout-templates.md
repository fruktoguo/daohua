# MOSS-Image 空间布局（Layout）标准模板库

MOSS-Image 原生支持空间布局控制（Layout to Image）。在 1024×1024 正方形画布下，坐标系为中心原点绝对像素坐标（`bbox_coord_space: "abs_centralized"`），格式为 `[y_min, x_min, y_max, x_max]`（`bbox_format: "yxyx"`）。

---

## 一、坐标换算原理 (1024×1024 画布)

- 画布中心为 `(0, 0)`。
- X 轴向右为正（范围 `-512` ~ `+512`）。
- Y 轴向下为正（范围 `-512` ~ `+512`）。
- 左上角：`(-512, -512)`，右下角：`(+512, +512)`。

---

## 二、常用网格布局模板

### 1. 2×2 四宫格布局（适合副手4件套、四灵宝物等）

四分天下，四角居中分布，四周和中央留有间隔：

```json
[
  {
    "name": "左上 Top-Left",
    "bbox": [-450, -450, -60, -60]
  },
  {
    "name": "右上 Top-Right",
    "bbox": [-450, 60, -60, 450]
  },
  {
    "name": "左下 Bottom-Left",
    "bbox": [60, -450, 450, -60]
  },
  {
    "name": "右下 Bottom-Right",
    "bbox": [60, 60, 450, 450]
  }
]
```

### 2. 1×3 横向三件套布局（适合防具三件套：巾/甲/裤）

```json
[
  {
    "name": "左侧 头部/巾",
    "bbox": [-240, -460, 240, -180]
  },
  {
    "name": "中间 上衣/甲",
    "bbox": [-240, -140, 240, 140]
  },
  {
    "name": "右侧 下装/裤",
    "bbox": [-240, 180, 240, 460]
  }
]
```

### 3. 2×4 八宫格布局（适合生活工具7件套、丹药组）

```json
[
  {"name": "第1行第1个", "bbox": [-450, -460, -60, -260]},
  {"name": "第1行第2个", "bbox": [-450, -210, -60, -10]},
  {"name": "第1行第3个", "bbox": [-450, 40, -60, 240]},
  {"name": "第1行第4个", "bbox": [-450, 290, -60, 490]},
  {"name": "第2行第1个", "bbox": [60, -460, 450, -260]},
  {"name": "第2行第2个", "bbox": [60, -210, 450, -10]},
  {"name": "第2行第3个", "bbox": [60, 40, 450, 240]},
  {"name": "第2行第4个", "bbox": [60, 290, 450, 490]}
]
```

### 4. 1:1 单体居中布局（适合首领立绘、高价值法宝）

```json
[
  {
    "name": "正中单体",
    "bbox": [-420, -420, 420, 420]
  }
]
```
