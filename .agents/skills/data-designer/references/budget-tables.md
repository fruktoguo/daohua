## 5. 装备两段式配置与预算正向审计速查

- **区间一：基础 14 属性百分比加成 (`BaseStatRatios`)**：直接填写百分比（1% = 1.0 点预算）。
- **区间二：额外固定值与特殊机制 (`FlatAndSpecialStats`)**：固定值（物理加生命，法系加灵力）与特殊机制（刀系额外威胁值等）显式直接配置。
- **部位预算权重（6 件套总和 6.0× 严格守恒）**：
  - 武器：**1.4×**（T1=40点 / T2=56点）
  - 衣服：**1.4×**（T1=40点 / T2=56点）
  - 头 / 腿 / 鞋 / 饰：**0.8×**（各扣一点，T1=22点 / T2=32点）
- **正向审计对比**：$\text{实际预算 } B_{\text{actual}} = \sum (\text{各属性预算}) \quad \text{vs} \quad \text{部位基准预算 } B_S$。
- **强化成长**：每级强化增量 = 白板基础属性 / 50.0（每级 +2%，满级 +20 达到 +40% 稳定成长）。
