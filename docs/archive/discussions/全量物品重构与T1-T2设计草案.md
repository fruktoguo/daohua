# 全量物品重构与 T1-T2 基础物品设计草案

> 本文档用于实时记录与沉淀开发者与 Agent 共同重写设计全量物品的过程草案。
> **时效状态（2026-09 复核）**：大部分已落地——19 种原料 / 6 种加工材料 / 28 件装备 / 7-5-1-2 配方规则均已进入 `config/game-data` 配表；唯引气丹配方以 总纲 定稿「凝血草 × 3」为准，本文「草木精华 + 破碎灵核」方案已废弃。
> **核心规约**：
> 1. 全面采用【品阶 (Tier · 1~12阶)】与【品质 (Quality · 8阶宇宙观)】双轨制（废除冗余数字等级）。
> 2. **加工材料消耗量同品阶绝对一致**：基准为 5 个，**武器 (1.4×) = 7 个**，**衣服 (1.4×) = 7 个**，**头/腿/鞋/饰 (1.0×) = 各 5 个**。
> 3. **T2 进阶装备升阶熔炼规则**：**打造每件 T2 装备均需要消耗 2 件对应的 T1 装备作为基底**。
> 4. **特殊/怪物辅助材料严格只需 1 个**（数量恒等于 1）。
> 5. **草木精华 / 伴灵精华专用于丹药**，装备完全不消耗精华。

1. **完整技能书 (`item.tome.<ability_id>`)**：
   - **首次使用**：解锁并学会该技能，**获得 0 经验**。
   - **学会后再次使用**：为该技能增加 **10,000 点经验**。
