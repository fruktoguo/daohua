# 道化太初 — 剧情与设定总览

> 本文档是《道化太初》（当前工程代号 `daohua`）的剧情、设定与地图设计真源。
> 状态：v0.1 草案。与 `../design/总纲.md`（系统设计总纲）互补：本文档只负责「世界与故事」。

## 1. 定位

《道化太初》是《道劫余生》之前的故事。两者共享同一个世界：太初时代是万法未立、炁序初显的世道；《道劫余生》所在的时代，同一片大地已被旧物、旧地、旧人层层覆盖。

**叙事红线（最重要的一条）：**

> 游戏内一切文案、任务、NPC 对白，不得提及「道劫」「旧灾」「劫难」「天穹残宫」「封天井」「旧阵崩坏」等任何未来语汇。
> 《道化太初》是一部表面完全独立的故事。它与《道劫余生》的关系只存在于本文档与玩家自行发现的蛛丝马迹里。

## 2. 创作原则

延续《道劫余生》的叙事美学：

1. 不设总答案，不给完整故事。
2. 所有事件只从侧面进入，只给后果、残留、误读、传闻、口供、遗物和现场痕迹。
3. 没有任何单个 NPC 掌握全貌。
4. 每张地图只提供自己的伤痕、习惯、规矩和活法，不负责替世界观做总解释。
5. 同一事件允许互相冲突的说法，不强制裁定真假。
6. 章节收束不做总结，只把人推到下一个缺口前。
7. 「井」「碑」「台」「柱」「谷」「天」是本作反复出现的意象，出现时不做解释。

与《道劫余生》的差异：太初时代天色更亮、人烟更稀、万物初生——同一套碎片化叙事，但底色从「劫后」变成「初醒」。绝望不是本作基调，**「刚学会的事开始变味」**才是。

## 3. 时间线

```text
【道化太初】太初之世
  炁序初显；万法未立；云来集初成聚落
  玩家一代人：采药、引炁、立碑、守谷、见天、下井
      ↓（漫长岁月，本文档不描述，也不在游戏内提及）
【道劫余生】乱世边地
  旧阵崩坏、旧碑断折、旧矿废弃、旧宫残破、旧井被封
  云来镇：同一片土地上长大的边地小镇
```

两个时代之间发生了什么，**两个游戏都不讲**。玩家只能通过两边地点的亲缘关系自行拼出「这片地一直有事」。

## 4. 暗线对照表（内部设定，严禁进入游戏文案）

下表只用于创作者对齐，不构成任何对外文本。

| 道化太初（前传） | 道劫余生（正传） | 关系 | 强度 |
| --- | --- | --- | --- |
| 云来集 | 云来镇 | 同一聚落更早的样子，集→镇 | 强（同名可见） |
| 北井（集北老井） | 北井（镇内异动之井） | 同一口井 | 强（同名可见） |
| 守井人（无名） | 天穹宫主（无名） | 同一类人：守在井边，来历不明，话不说满 | 强（角色暗线） |
| 观星客（云顶活人） | 观星残影（残宫残响） | 观星者的生与残 | 强（角色暗线） |
| 古台立碑（碑新立） | 断碑遗迹（碑已断） | 同一块碑，从立到断 | 强（地点暗线） |
| 玄铁矿洞（矿在采） | 玄铁矿洞（旧矿已废） | 同一矿脉 | 中（同名可见） |
| 青竹林 | 青竹林 | 同一片竹林 | 中（同名可见） |
| 暮影谷（谷中初异） | 噬魂兽谷（漏口） | 同一道谷，异变之始与之后 | 中（性质对应） |
| 灵脊岭·守岭人 | 灵脊岭·守岭老修 | 同一道岭，同一类守门人 | 中（同名可见） |
| 初阵（云来集阵基） | 旧阵（崩坏之源） | 最早立起的阵，后来被称为旧阵 | 中（概念对应） |
| 天铁（云顶坠星） | 星铁雨、星陨金 | 天上第一次掉下来的铁 | 中（概念对应） |
| 云顶观星台 | 天穹残宫 | 高处遗存的生前形态 | 弱（位置对应） |
| 沈娘（脚店掌柜） | 沈七娘（落脚掌柜） | 姓氏传承或巧合，不解释 | 弱（姓氏彩蛋） |
| 兰婆（药师） | 兰药师（救命派） | 同上 | 弱（姓氏彩蛋） |
| 老洛（猎户） | 洛猎户（荒野活路） | 同上 | 弱（姓氏彩蛋） |
| 游执事（压话头） | 清玄执事（控信息者） | 职能相同，人不同代 | 弱（职能对应） |

**彩蛋强度说明**：
- 强：正传玩家一眼能认出的同名/同物线索，前传玩家只觉得是自然设定。
- 中：需要两边都玩过才能对上。
- 弱：只有深挖者才能察觉的呼应。

**统一口径**：前传文案永远只解释「这个东西在这个时代是什么」，不解释「它后来怎么样了」。

## 5. 术语

| 术语 | 定义 | 备注 |
| --- | --- | --- |
| 炁 | 天地初凝的先天之气，万物含之 | 正传称之为「灵气」；前传用古称，不做说明 |
| 引炁 | 将外界之炁引入自身 | 即现有玩法的「引气入体」，显示名建议改为「引炁入体」 |
| 炁序 | 炁运转的秩序；无人能说清其规律 | 全作最大悬念，不给答案 |
| 天铁 | 天上落下的铁，罕见 | 见第五章 |
| 初阵 | 云来集最早立起的防护阵基 | 正传「旧阵」的前身，前传文案只称「阵基」 |
| 行令 | 通过试炼后获得的通行凭证 | 沿用正传概念，前传更早出现 |
| 漏 | 异炁从地底渗出的现象 | 前传只描述现象，不解释成因 |
