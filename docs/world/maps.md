# 道化太初 — 地图设计

> **主线基准确认**：游戏当前主线运行与配表以 **青云仙山 (`map.qingyun-mountains`) 的 8 个核心地理节点**（云溪村、漱玉溪、百草谷、落霞桃林、清石水滩、望云茶肆、青云山门、云巅草庐，详见 `config/game-data/maps/qingyun_mountain.json`）为**权威稳定基准**。
> 本文档记录该 8 节点主线拓扑与世界观剧情设定，后续扩展设想（如北井、灵脊岭、云顶观星台等）作为未来世界演进储备。
> **配置与强类型 ID 规约**：底层地图配置与领域代码保持强类型 ID（如 `map.qingyun-mountains`、`node.yunxi-village` 等），确保配置指纹与领域引用绝对一致。

## 2. 剧情节点扩展草案（未实现）

以下为历史剧情扩展提案，并非当前地图目录。其“保留”“现有内容承接”仅表示对旧提案的承接，不证明当前配置存在这些节点、NPC、行动或建筑。开发时须重新对照以上两张地图与真实配置，不为旧提案补兼容 ID。

### 2.1 云来集（现有「青云山门」节点改造）

- **对外描述**：几十户人家的小集子，木栅口、脚店、老井、阵基。山门样的木栅口是集子的正门。
- **现有内容承接**：
  - 守山弟子（保留）：记来往的人，讲集里规矩。
  - 「青云山门」建筑 → 改为「云来集木栅口」（建筑 ID `building.qingyun-gate` 可保留，显示名建议改）。
  - 「防护阵基」描述 → 改为「集口的阵基，木柱上的纹夜里会隐隐发亮」（这是全作「阵纹」的第一处亮相）。
- **新增 NPC**：游执事（集内走动，任务交付人）、沈娘（脚店，可作挂机/恢复场景）。
- **玩法**：任务交付、购买基础物品、领支线。
- **暗线**：阵基木纹 = 正传「旧阵」的起点。文案只写「会画纹的人立的」。

### 2.2 青岚药谷（保留）

- **对外描述**：低阶灵草沿溪谷生长，清晨的谷里浮着白气（炁）。采药人林伯常驻。
- **现有内容承接**：采集草药行动（`explore.gather-herbs`）主要产地；林伯 NPC 保留。
- **新增细节**：林伯教玩家认炁；谷里偶尔能采到「炁凝的露」——炼丹材料（对应现有物品可后续扩展）。
- **暗线**：谷底也有一条暗纹（第三章玩家在此可发现第二处旧纹线索，与古台/兽身/井壁同系，文案不点破）。

### 2.3 落霞西岭（保留）

- **对外描述**：山势开阔，常有聚炁兽徘徊，适合练手。猎户老洛常在这一带。
- **现有内容承接**：历练聚气兽行动（`combat.hunt-qi-beast`）。
- **新增细节**：老洛 NPC；西岭入夜后「炁会变燥」，入夜前行事不同（可做昼夜差异后续玩法）。
- **暗线**：此处的兽是「正常兽」——与暮影谷的异兽形成对照组。

### 2.4 玄铁矿洞（现有「玄岩矿脉」改名建议）

- **对外描述**：裸露的山体里可见玄铁纹路，矿工在采。矿道深处壁上有光。
- **草案来源**：旧提案的「玄岩矿脉」改为「玄铁矿洞」；`node.stone-vein` 不在当前地图配置中，不能当作现有节点引用。
- **现有内容承接**：「废弃矿架」建筑 → 改为「矿架」（还在用，尚未废弃）；「后续开放采矿行动」→ 剧情第二章主场景，可先开放「下矿寻人」任务链。
- **新增细节**：矿道深处的微光、矿工带回的发光的石头（第二章剧情道具）。
- **暗线**：矿光石与天铁同源（第五章汇合）。

### 2.5 青竹林（新增节点）

- **对外描述**：运材路穿过的竹林，竹高而密。路常出事。
- **剧情职能**：第二章支线（翻车痕迹，裂口不似野兽）。
- **玩法建议**：采集竹材（炼丹燃料）/低阶战斗；后续可在林中发现「兽道」通向兽谷。

### 2.6 古台（保留，重设）

- **对外描述**：山腰一处老石台，比集子更老，台上立着无名旧石。第三章起，石上刻字成碑。
- **草案承接**：`node.ancient-terrace` 不在当前地图配置中；古台为未来剧情候选，拟承接「立碑」剧情。
- **新增细节**：台基下的旧纹（第三章发现）；碑文八字「炁有归处，人留门路」（终章前全作唯一完整文字谜面）。
- **暗线**：旧石 = 正传「断碑」的前身。文案只写「台上立着旧石，无人记得何时在此」。

### 2.7 暮影关（保留）与暮影谷

- **对外描述**：通往暮影谷的狭窄关口。谷中妖物成群，且行为反常。暮影哨塔立于此。
- **现有内容承接**：清剿暮影谷行动（`combat.sweep-twilight-valley`）；哨塔建筑保留，描述改为「谷鸣后新立起的哨塔」。
- **新增细节**：谷主（每十场的首领）身上有纹——与古台旧纹同系；老洛在此伤退。
- **暗线**：暮影谷 = 正传「噬魂兽谷」的前身。文案只写「谷里的兽开始不一样了」。

### 2.8 灵脊岭（新增节点）

- **对外描述**：连接暮影关与云顶的高岭。两片巨岩夹成一道窄缝，守岭人常年守在缝前。
- **新增 NPC**：守岭人。
- **玩法建议**：第四章后开放；窄缝不可通过（地图边界）；守岭人发放行令（后续凭证系统的第一块）。
- **暗线**：与正传「灵脊岭」同名同职能——文案只写「那边是别的东西的地方」。

### 2.9 云顶观星台（新增节点）

- **对外描述**：山脉最高处。一间石屋，一个常年看天的人（观星客）。
- **新增 NPC**：观星客。
- **玩法建议**：第五章后开放；观星长期任务（记录天象，产出天铁相关材料）。
- **暗线**：正传「天穹残宫」的位置前身。文案只写「高处看得见天」。

### 2.10 流云集（保留）

- **对外描述**：山中散修交换物资的集市，灵市功能所在。
- **现有内容承接**：灵市牙人 NPC、交易棚建筑保留。
- **暗线**：此世最早的「市场」——正传灵市的前身。文案不改。

### 2.11 北井（新增节点，集内）

- **对外描述**：云来集北边一口老井。井水清冽，打水的人不多看井底。夜里井里有声音，每个人听见的不一样。
- **新增 NPC**：守井人（常驻井沿）。
- **玩法建议**：序章起可见但不可交互（有「夜里别去」的规矩限制）；终章开放下井剧情。
- **暗线**：正传「北井」与「封天井」的双重前身。文案只写井本身。

## 3. 行动目录对齐（显示名建议）

| 现有显示名 | 建议显示名 | 理由 |
| --- | --- | --- |
| 引气入体 | 引炁入体 | 「炁」是本作核心用字 |
| 炼制引气丹 | 炼制引炁丹 | 同上 |
| 历练聚气兽 | 历练聚炁兽 | 同上 |
| 采集草药 | 采集灵草（或保留） | 可保留；「草药」口语更贴集民 |
| 清剿暮影谷 | 守谷（可选） | 「清剿」偏军事，集民口语可选「守谷」 |
| 赶路 | 赶路（保留） | — |

> 本节名称为剧情显示名建议，旧行动 ID 不构成接口要求。实现时以当前行动目录为起点，同步修改所有调用点，不保留旧协议或存档兼容路径。

## 4. 场景美术建议（延续正传画风）

- 画风：水墨钢笔淡彩，灰调底色 + 局部重点色。太初之世比正传亮一档：天更透、雾更白、炁的痕迹（白雾/微光）是各图共同的重点色。
- 每章重点色：
  - 序章：晨白（炁雾）
  - 第一章：泉青（灵泉变味后的水色）
  - 第二章：矿金（矿道微光）
  - 第三章：碑灰（旧石与刻痕）
  - 第四章：谷绿转暗（兽谷）
  - 第五章：天银（坠星与天铁）
  - 终章：井冷白（井底隙光）
- 构图纪律：同正传——16:9、不出现魔法阵光效、不出现日式 RPG UI 元素、不过度戏剧化透视。

## 5. 实现优先级建议

1. **P0（纯文案，零代码风险）**：显示名与描述的「炁」字化改造；现有节点描述的太初化重写（青岚药谷、澄心灵泉、落霞西岭、暮影关、流云集、古台）。
2. **P1（新增节点，需改 WorldCatalog + 测试）**：青竹林、灵脊岭、云顶观星台、北井；对应 NPC 与行动可用节点调整。
3. **P2（任务链，需新增剧情数据）**：七章主线任务簇、支线任务簇、碑文/井底等关键场景。
4. **P3（长期）**：昼夜差异、观星长期任务、守界人身份系统。
