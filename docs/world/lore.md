# 道化太初 — 世界观设定

> 内部设定文档。游戏内文案只使用「对外口径」一栏的内容；「内部设定」仅供创作者理解，不得直白出现在文案中。
> **落地状态定性**：本文描述的地域格局（云来集、青岚药谷、玄铁矿洞、北井等）与人物为**剧情设定储备/草案**，不等于已上线内容；当前运行配表仅含青云仙山与星陨异境两张地图（见 [README「当前已配表内容速览」](./README.md#6-当前已配表内容速览)），落地与否一律以 `config/game-data` 为准。

## 1. 时代：太初之世

天刚分清浊不久（这是此世人对自身时代的说法，是否正确无人能证）。大地上的炁浓得能看见——清晨山谷里浮动的白气、矿脉深处渗出的微光、老树根下凝成露珠的异香。万物皆含炁，但**没有人知道炁的规矩**。

这个时代没有宗门，没有传承，没有一部写得完的功法。会修行的人屈指可数，而且各自的路子都不一样——有人从吐纳入手，有人靠丹石入道，有人是在矿下埋了三天后自己醒过来的。修行在这个时代不是「拜入门派学艺」，而是**每个人都独自在摸一条看不见的线**。

世界状态：

- 人烟稀少，聚落零星，山与山之间隔着大片无人敢走的野地。
- 没有文字记载的修行史；最老的传说只有两三辈人那么远。
- 炁本身在缓慢变化：有些地方炁越来越活（灵泉、药谷），有些地方炁越来越燥（兽谷、矿底）。没有人知道这是不是正常。

**对外口径**：这片天地很大，炁很浓，人很少，规矩还没被写出来。
**内部设定**：这正是「一切开始之前」的状态。所有后来被称为「旧」的东西，此刻都是新的、小的、刚发生的。

## 2. 炁

- 炁是天地初凝的先天之气，无色而有迹：浓处可见白雾，燥处可灼肌肤，静处可凝露。
- 人人皆可引炁——此世没有「灵根」一说，因为还没有人发明「测灵根」这件事。能不能引炁、引多少、会不会出事，全凭个人体质与运气。
- 引炁入体是此世最接近「修行」的行为。初引者如饮烈酒：通体发热，心神清明，随后是极深的疲惫。
- 炁会「认地」：同一道山谷，朝阳坡的炁和背阴坡的炁不同；同一口泉，晴天的水和雨后的水不同。老采药人靠这个认路。
- **禁忌（此世之人的共识，无人能解释原因）**：不要在井下、碑前、谷底引炁。具体为什么，各地说法不一——有人说是「下面太潮」，有人说是「下面有主」，有人什么都不说。

**对外口径**：如上。
**内部设定**：禁忌的几处，正是正传「旧阵」「漏口」「封天井」所在的位置。此世之人以为自己在遵守乡俗，其实是在回避同一样东西。

## 3. 地域格局

太初之世没有国界。以云来集为中心，可活动的区域大致分五层：

| 层次 | 区域 | 特征 |
| --- | --- | --- |
| 集内 | 云来集 | 落脚、交易、规矩；唯一能睡安稳觉的地方 |
| 近郊 | 青岚药谷、落霞西岭 | 采药、历练；白天安全，入夜后说不准 |
| 远线 | 玄铁矿洞、青竹林 | 有活路也有事故；矿洞深处不能久留 |
| 边界 | 暮影关、灵脊岭 | 再往外就是「没人回来过」的地方 |
| 高处 | 云顶观星台 | 看得见天的地方；只有观星客常住 |

## 4. 势力与人群

太初之世没有宗门，只有几类人：

- **集民**：云来集的常住者。种地、打铁、卖货、养娃。他们知道集外有事，但只要事不进集，就不算事。
- **走山客**：来往各聚落贩货的脚商。消息最灵通，话最不可信。
- **采药人**：靠药谷吃饭的人。认炁认地，是最早的「实践派」。
- **猎户**：在兽谷外围讨生活的人。身上都有伤，话都很少。
- **野修**：自己摸出引炁路子的人，散居山野。多数沉默寡言，少数疯疯癫癫——引炁引岔了，人也就不对了。
- **守界人**：守井、守岭、守碑、守台的人。他们大多说不清自己为什么守，只知道「该有人守着」。

**对外口径**：如上。
**内部设定**：守界人是此世最接近「正传角色原型」的人群——守井人、守岭人、观星客都属于这一类。

## 5. 云来集

云来集是此世少有的「能让人落脚」的聚落：几十户人家，一间脚店，一口老井，一座山门样的木栅口，外加一片刚立起不久的阵基。

- **名字由来（对外传说）**：老人们说，很久以前有片云落在这里，落地就成了集。云往哪飘，集就往哪长。
- **北井**：集北边一口老井，井水清冽，但打水的人从不往井底多看。夜里路过北井的人，都说井里好像有声音——每个人说的声音都不一样：有人说像水声，有人说像风声，有人说像有人在下面数数。
- **阵基**：集口立着几根刻了纹的木柱，是集里请「会画纹的人」立起来的，说是能挡山风野物。夜里阵基的木纹会隐隐发亮，没人知道为什么。
- **脚店**：沈娘的店。过路人的歇脚处，也是云来集消息最多的地方。

**对外口径**：一个靠山吃饭的小集子，规矩不多，够活。
**内部设定**：云来集是正传云来镇的雏形；北井是正传北井；阵基是正传「旧阵」的起点；木柱上那些纹，是此世最早的阵纹。

## 6. 人物

### 6.1 守井人（无名）

- 住在北井边搭的棚子里，白天不见人，夜里坐在井沿上。
- 没有人知道他什么时候来的、从哪里来的。问他，他就说「一直在这」。
- 他不种地、不打铁、不采药，也不见他和谁做生意——但集里的人从不赶他走，因为「井边有人守着，心里踏实」。
- 他话极少，偶尔说一句，都是怪话。比如：
  - 「井不是用来打水的。」
  - 「有些门不是锁，是留的。」
  - 「你听见的不是水声。」
- 他对玩家（引炁者）的态度与对常人不同：不亲近，也不回避，像是「认得这一类人」。

**对外口径**：井边一个说不清来历的老人。
**内部设定**：正传天穹宫主的原型。两个时代，同一种「守在井边」的姿态，同一种不解释。前传不说明他是谁，正传不说明他曾经是谁。

### 6.2 观星客（无名）

- 住云顶观星台。此世唯一一个常年抬头看天的人。
- 他说天上有东西在动——不是云，不是鸟，「比山还大的东西，慢慢地走」。
- 没人信他，但也没人敢反驳他，因为他是此世唯一能说出「明天什么时辰会起风」的人。
- 他记星象不用纸笔，全记在脑子里。有人问他记这些做什么，他说：「等它掉下来的时候，得知道它原来在哪。」

**对外口径**：云顶一个看天的怪人。
**内部设定**：正传「观星残影」的生前。前传他是活人，正传他只剩残影——中间发生了什么，两作都不讲。

### 6.3 游执事

- 云来集实际管事的人。集里的大小事都经他手，但他说得最少。
- 玩家每次查到一点东西，游执事都会把话头压下去：「先活下来。」「先会跑。」「先把自己练明白。」
- 他认得守井人，但从不说破；他知道阵基的纹是谁画的，也不说。

**对外口径**：集里的管事人，话少，管用。
**内部设定**：职能对应正传清玄——控信息者。两作都不让他把话说满。

### 6.4 沈娘

- 脚店掌柜。收留过路的、受伤的、走投无路的。
- 她的规矩只有一条：「在店里，先吃饭，后问事。」
- 她看得出玩家在引炁，但她不管：「引炁是好事，别在井边引就行。」

**对外口径**：脚店掌柜，热心，规矩大。
**内部设定**：正传沈七娘的姓氏彩蛋。

### 6.5 兰婆

- 集里唯一的药师。认药、认炁、认病。
- 她对「炁变」最有发言权——但她从不把话说绝：「泉变了就是变了，我说不清为什么，我只能告诉你变了之后什么能喝什么不能喝。」
- 名言：「先救活的，再问为什么。」

**对外口径**：药师，务实。
**内部设定**：正传兰药师的姓氏彩蛋，职能也对应。

### 6.6 林伯（沿用现行玩法的 NPC 设定；配表 `npcs` 字段补齐中）

- 青岚药谷的采药人。熟悉药谷每一条路，知道哪片坡的草壮。
- 他对玩家说的最多的话是：「采药先认炁，认炁先认地。」

### 6.7 老洛

- 落霞西岭的猎户，常年在兽谷外围活动。
- 身上伤疤多，话少。唯一主动开口的话题是兽：「兽会学人。你杀过它同伴，它下次就认得你。」

**对外口径**：猎户。
**内部设定**：正传洛猎户的姓氏彩蛋。

### 6.8 守岭人

- 灵脊岭上唯一的人。守着一道两片巨岩夹成的窄缝。
- 他不让任何人过缝，也不解释为什么：「这边是人的地方，那边是别的东西的地方。就这一句，你听不听是另一回事。」

**对外口径**：守岭的怪人。
**内部设定**：正传守岭老修的前身，同一道岭，同一道窄门。

### 6.9 守山弟子（沿用现行玩法的 NPC 设定；配表 `npcs` 字段补齐中）

- 云来集木栅口的年轻人。负责记来往的人。
- 会提醒新来的人：「集里有规矩，北井夜里别去，西岭入夜前回来。」

### 6.10 静修道人（沿用现行玩法的 NPC 设定；配表 `npcs` 字段补齐中）

- 澄心灵泉边的静坐者。常年闭眼，外界少有回应。
- 偶尔有人听见他自言自语，听不清在说什么。集里人说他在「听泉」。

### 6.11 灵市牙人（沿用现行玩法的 NPC 设定；配表 `npcs` 字段补齐中）

- 流云集（山中散修换物处）的牙人。替往来的人整理挂牌与交割。
- 他经手的东西里偶尔会有「不该有的东西」——矿里带出来的、谷里捡的。他不问来路，也不问去处。

## 8. 境界与修行（对齐现有玩法）

此世没有完整的境界体系，只有模糊的「段」：

| 段 | 表现 | 对应玩法 |
| --- | --- | --- |
| 未入门 | 会采药、会认炁，但引炁不稳 | 采集草药行动 |
| 引炁 | 能将炁引入体内运转周天 | 引炁入体行动（显示名建议改） |
| 炼炁 | 炁已入骨，举手投足有异于常人 | 战斗行动解锁（历练聚气兽） |
| 凝炁 | 炁能离体（此世极少人达到） | 后续规划；正传「练气」的前身概念 |

**对外口径**：修行没有路数，全看个人。
**内部设定**：此世修行体系的粗胚，正是正传成熟境界体系的前身。剧情对白与世界观任务文案不直白宣扬后世成型的宗门术语。

> **系统等阶与叙事解耦说明**：‘未入门 / 引炁 / 炼炁 / 凝炁’属于**主线剧情、NPC 对话与世界观叙事的沉浸式口径**；玩家角色内视面板、境界徽章（`RealmBadge`）、装备穿戴门槛与战斗数值底座统一采用全 12 等阶（T1~T12）修仙口径（锚点小境界：T1 凡胎、T2 叩天门、T3 半步筑基……，详见 [`数值量化模型集.md`](../design/总纲/11-数值量化模型集.md)），系统逻辑与剧情口径清晰解耦。
