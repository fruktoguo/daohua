# 临时设计讨论目录说明

本目录用于存放开发讨论过程中的**临时草稿、脑暴记录与设计推演草案**。

## 维护规范与定位

1. **临时讨论草稿**：本目录下的文档用于快速记录与沉淀开发者与 Agent 之间的对话结论、未定稿架构方案与临时设计脑暴。
2. **非正式真源**：本目录下的内容定稿后，会整理沉淀为 `docs/backend/`、`docs/design/` 或 `docs/frontend/` 中的正式规范文档。
3. **Git 规则**：根据 `AGENTS.md` 规则 15，本目录下的临时文档属于纯文档修改，**严禁自动提交 Git**，仅保持在工作区方便实时双向编辑与查看。
4. **命名规范**：本目录下的子文件采用**中文文件名**，直观清晰地表达讨论主题。
