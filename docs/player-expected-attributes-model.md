# 太虚仙途 · 境界阶位体系与基准玩家期望属性量化模型

本文档定义《太虚仙途》三级境界体系（大境界 $\to$ 位阶 $\to$ 小境界）、一体化境位徽章三框架构（大境界牌匾框、位阶棱形框、小境界灵气胶囊框）、属性两级管线结算模型、装备标准化权重预算公式，以及全周期基准玩家期望属性矩阵。

## 1. 境界三级阶梯架构 (大境界 · 位阶 · 小境界)

境界体系严格划分为三级概念：
- **大境界 (Major Realm)**：宏观修仙大纪元（凡俗、练气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫、飞升）。
- **位阶 (Rank / Phase)**：大境界内部的质变位阶。
  - **凡俗期**（前 18 级）分为三大位阶：**凡武**（Lv 1~6，位阶棱形标识：**`[武]`**）、**通玄**（Lv 7~12，位阶棱形标识：**`[玄]`**）、**天人**（Lv 13~18，位阶棱形标识：**`[天]`**）。
  - **修仙各大境界**（每 12 级一大境）分为四大位阶：**初**（1~3 层，**`[初]`**）、**中**（4~6 层，**`[中]`**）、**后**（7~9 层，**`[后]`**）、**极**（10~12 层，**`[极]`**）。
- **小境界 (Minor Realm / Level)**：具体的等级层级，凡俗期为 18 阶专属名号，修仙期为一层~九层、巅峰、大圆满、半步下阶。
- **一体化境位徽章结构 (三框组合)**：
  - **外层主框 (Master Frame)**：包裹大中小三层境界，鼠标悬浮（Hover）全局显示具体小境界等级（例如：`当前小境界：Lv.28 (练气 · 极 · 练气巅峰)`）。
  - **大境界框**：道家玉简/牌匾铭牌设计（如 `[凡俗]`、`[练气]`、`[筑基]`、`[金丹]`）。
  - **位阶框**：古典旋转棱形徽章（如 `◇武◇`、`◇玄◇`、`◇天◇`、`◇初◇`、`◇中◇`、`◇后◇`、`◇极◇`）。
  - **小境界框**：流光灵气椭圆胶囊（如 `(凡胎)`、`(练气一层)`、`(练气巅峰)`、`(半步筑基)`）。

## 2. 属性全链路两级管线数学模型

$$\mathbf{最终面板属性} = \underbrace{\left( \text{基准底座} + \text{境界额外基础值} + \text{特殊装备基础值} + \text{丹药固定值} \right)}_{\text{基础值加算池 (Base Flat Pool)}} \times \underbrace{(1 + \text{六维\%})}_{\text{六维乘区}} \times \underbrace{(1 + \text{装备\%})}_{\text{装备乘区}} \times \underbrace{(1 + \text{Buff\%})}_{\text{Buff乘区}}$$

### 2.1 统一基准底座 (Baseline，全部为 double)
- `HP` = 100.0, `MP` = 50.0
- `HpRegen` = 2.0 / 5s (每 5 秒回复 2.0 生命值)
- `MpRegen` = 1.0 / 5s (每 5 秒回复 1.0 灵力值)
- `PhysAtk` = 10.0, `SpellAtk` = 5.0, `Armor` = 10.0, `MagicRes` = 0.0
- `Accuracy` = 1.0, `Evasion` = 1.0, `Crit` = 1.0, `CritAvoid` = 1.0, `BreakPower` = 1.0, `ParryResolve` = 1.0
- `全部百分比属性` = 0.0 点 (0.0%)

### 2.2 六维累计经验与独立乘区
- 六维经验永久累加不清空，达到等级 $L$ 所需总经验：$\text{Exp}(L) = 100.0 \times (L - 1)^3$。
- 六维提供第一独立乘区 $(1 + \text{RootPercent})$：
  - 体魄：每级 $+1\%$ 生命、$+1\%$ 护甲、$+1\%$ 生命回复
  - 经脉：每级 $+1\%$ 灵力、$+1\%$ 法抗、$+1\%$ 灵力回复
  - 根骨：每级 $+1\%$ 生命、$+1\%$ 灵力、$+1\%$ 拆招(化解)
  - 力道：每级 $+1\%$ 物攻、$+1\%$ 暴击、$+1\%$ 破招
  - 神识：每级 $+2\%$ 术法攻击 (×2)、$+1\%$ 命中
  - 身法：每级 $+1\%$ 闪避、$+1\%$ 免爆、$+1\%$ 拆招(化解)

## 3. 装备标准化权重预算与指数强化模型

### 3.1 装备百分比权重配置公式
$$\text{装备属性加成}_i = \text{等级装备基准预算}(L) \times \text{装备强度 Intensity} \times \left( \frac{\text{属性权重 Weight}_i}{\sum \text{所有属性权重}} \right) \times (1.05)^{\text{强化等级}}$$

- **装备基准预算 $\text{Budget}(L)$**：系统在等级 $L$ 分配的装备总百分比当量。
- **装备强度 Intensity**：普通 80%、良品 100%、上品 120%、极品 150%。
- **特殊加成（Special Flat/Affix）**：特殊基础值加成不吃强度缩放，直接加算入基础值池。
- **强化指数增幅**：每级 $+5\%$ 指数放大：$\text{EnhanceMultiplier} = 1.05^{\text{level}}$。

## 5. 怪物自动对齐与平衡应用

基于此基准矩阵，所有副本、野外怪物的生成直接套用：
- **普通小怪 (Minion)**：对齐当前推荐等级玩家属性的 $1.0\times$ 生命、$0.8\times$ 攻击、$0.6\times$ 护甲。
- **精英妖修 (Elite)**：对齐 $3.0\times \sim 3.6\times$ 生命、$1.1\times \sim 1.2\times$ 攻击、$1.0\times$ 护甲。
- **首领妖王 (Boss)**：对齐 $10.0\times \sim 14.0\times$ 生命、$1.3\times \sim 1.5\times$ 攻击、$1.2\times \sim 1.5\times$ 护甲。
