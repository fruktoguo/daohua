# TASK-20261031-02 坊市买卖盘口自身订单行显示取消

## 1. 任务背景与核心目标

当前坊市交易中，玩家查看标的盘口深度（求购订单 / 正在售卖列表）时存在明显的交互割裂：
1. **盘口中自身订单无法直接撤回**：当玩家在某个价格档位挂有求购或出售订单时，盘口深度列表仅将该价格与其他挂单聚合展示，操作列要么是空白（非最优档），要么在最优档展示荒谬的“一键与自身挂单成交”快捷交易按钮；
2. **撤单链路繁琐割裂**：玩家若要撤回已挂订单，必须手动切出当前标的详情、点击切换到顶部的「我的订单」Tab，在全部标的订单流中翻找该笔订单后点击「×」取消，再重新切回「浏览」Tab 重新查找标的，严重影响市场交易盯盘与改单体验。

**核心目标**：
1. **盘口直观标明自身订单价格**：在标的深度盘口（求购/出售列表）中，若当前价格档位存在玩家自身的活动挂单，为该行赋予专属标识样式（`.market-level--own`）；
2. **价格行直接提供「取消」操作**：在该价格行的操作列直接渲染【取消】按钮（文案统一使用 `t('common.cancel')` 即「取消」），点击即可向服务端发送 `market.cancel` 指令就地撤回订单；
3. **修复自交易荒谬按钮**：当玩家自身订单处于最优档（买一/卖一）时，原本显示的「卖出」/「买入」快捷交易按钮自动替换为【取消】按钮，杜绝玩家误触自交易无效请求；
4. **即时撤单与状态联动**：撤单提交后弹出系统通知并于 120ms 内强制全量刷新盘口与个人挂单数据，确保界面秒级同步；
5. **主题样式与 i18n 完备**：提供清晰精致的警示红微光撤单按钮与行级金光强调，适配深色与浅色高对比度主题，并通过 i18n 词典与模板双向门禁。

## 2. 详细技术方案

1. **盘口深度组件扩展（`MarketBookPanel.tsx`）**：
   - 扩展 `MarketBookPanelProps`：增加 `orders?: readonly MarketOrder[]` 与 `onCancelOrder?: (orderId: string) => void`；
   - 利用 `useMemo` 分别按求购（`side === 'bid'` 对应订单 `order.side === 'buy'`）和出售（`side === 'ask'` 对应订单 `order.side === 'sell'`）基于标的 `itemId`、`enhancementLevel` 建立 `price -> MarketOrder` 快速索引表；
   - 在 `MarketRows` 渲染各价格档位时，检查当前单价 `level.price` 是否命中自身订单：
     - 若命中：操作列渲染 `<button className="market-level-trade-btn market-level-cancel-btn" ...>{t('common.cancel')}</button>`，点击触发 `onCancelOrder(ownOrder.orderId)`，外层行容器附加 `market-level--own` 类；
     - 若未命中：维持既有行为（仅 `index === 0` 且有 `onQuickTrade` 时展示快捷买卖按钮，其余行操作列留白）。
2. **市场宿主页面接入（`MarketPage.tsx`）**：
   - 引入 `gameClient` 与 `useGameStore.setNotice`；
   - 实现 `handleCancelOrder` 回调：发送 `market.cancel` 指令、弹出提示并延迟 120ms 触发 `refresh(true)`；
   - 在渲染 `<MarketBookPanel />` 处向其透传 `orders` 与 `onCancelOrder={handleCancelOrder}`。
3. **样式与交互（`styles.css` & `theme.css`）**：
   - 为 `.market-level-cancel-btn` 配置警示朱红/赤霞边框与微光背景，悬浮时高亮；
   - 为 `.market-level--own` 配置微弱金色背景高亮与呼吸感边框；
   - 在 `theme.css` 中适配浅色主题高对比度色彩。
4. **国际化（`market.zh.ts` & `template.csv`）**：
   - 增加 `cancelOwnOrderAria: '撤销自身挂单（单价 {price}）'`，执行 `export-i18n-csv.mjs` 同步更新并运行门禁。
