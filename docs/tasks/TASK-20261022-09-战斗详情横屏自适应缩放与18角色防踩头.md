# TASK-20261022-09 战斗详情横屏自适应缩放与18角色防踩头优化

## 任务背景与核心痛点

- **用户反馈**：在分辨率较低（如笔记本 1366x768、1920x1080 @ 125%/150%/175% 缩放）的设备上，当战斗详情页面出现多个角色（例如 5 个角色，横向 3 个时），其他行/槽位的角色会“踩在其他角色的头上”（立绘、名字、血条、行动条发生严重垂直重叠遮挡）。
- **核心目标**：横屏模式下，无论任何屏幕缩放比例或窗口高度，战斗详情必须保证能**同时清晰完整显示 18 个角色**（己方 3x3 九宫格 + 敌方 3x3 九宫格，共 18 人），绝不出现上下行互相遮挡/踩头。
- **手段**：动态自适应计算或通过场内容器/卡片总显示比例（scale / CSS 动态变量），使 3x3 阵型根据战场实际可用宽高自适应收缩，保持 3:4 比例且完好排布。

## 关键技术点与不变量

1. **双层防重叠架构**：外层 `.arena-actor` 严格按 `calc(var(--actor-base-width) * var(--arena-scale))` 与 `calc(var(--actor-base-height) * var(--arena-scale))` 参与 CSS Grid 布局，使自身布局盒真实收敛；内层 `.arena-actor-card` 固定基准尺寸并施加 `scale(var(--arena-scale))`，保证文本、血条、立绘、行动条、Buff 与伤害跳字保持完美几何比例且文字极度清晰。
2. **数学防踩头定理**：动态缩放算法 `computeArenaFormationScale` 取两轴严格约束 `ideal = min(1.05, (slotH - 2)/206, (slotW - 2)/96)`，确保角色高度永远严格小于槽位高度，相邻两排绝对存在安全正净空，即使 18 角色同时出战也绝不发生任何重叠。
3. **紧凑高度空间让渡**：新增 `@media (min-width: 761px) and (max-height: 760px/640px)` 紧凑高度响应式，在低高度或高缩放下适度压缩底部托盘与边距，向战场让渡 50~70px 垂直高度。
