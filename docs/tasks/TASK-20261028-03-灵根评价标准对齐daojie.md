## 2. 缺陷取证

用户实例分布 `金96 / 木94 / 水92 / 火90 / 土15`（总值 387，最低 15）。

旧实现 `frontend/src/game/linggenEvaluation.ts` 五系分支条件为
`总值 ≥ 200 && 最低 ≥ 40` 才给「五行杂灵根」，否则一律「废灵根」。
该实例最低 15 < 40，直接落入 `fiveWaste` → **废灵根 / 五灵根 · 废品**。

实测断言（旧实现）：

| 分布 | 总值 | 最低 | 旧输出 |
| :--- | ---: | ---: | :--- |
| 96/94/92/90/**15** | 387 | 15 | 废灵根 · 废品 |
| 96/94/92/90/**0** | 372 | 90 | 四象天灵根 · 天品 |
| 95/92/90/91/**39** | 407 | 39 | 废灵根 · 废品 |
| 95/92/90/91/**40** | 408 | 40 | 五行杂灵根 · 杂品 |

两条缺陷：

1. **单系绝对门槛 `最低 ≥ 40` 是硬断层**：一条十几点的残系即可把四象天灵根降为废灵根，评价随总点数增长非单调（多一条弱根反而降级，强根越多惩罚越重）。
2. **旧表无「总值高但分布极散」的档位**：旧体系五系只按「是否皆强 / 总值+最低」二分，缺乏按总值梯度分档的评价，无法表达「四强一残」这类高总值形态。

## 3. 目标口径（完全对齐 daojie-yusheng）

真源：`D:\Project\Vibe\daojie-yusheng\packages\client\src\utils\spiritual-roots.ts` →
`describeSpiritualRoots`（`packages/client/src/constants/ui/i18n.generated.ts` 的 `root.*` 词条族）。

判定按有效系条数分支，**同一分支内一律先判纯度档、再按总值梯度分档**，取消单系绝对门槛：

| 条数 | 判定顺序 |
| :---: | :--- |
| 1 | ≥90 **天灵根**（满百同档）→ ≥80 真灵根 → ≥35 偏枯单灵根 → 废灵根 |
| 2 | 皆 ≥90 天品 → 皆 ≥80 上品 → 离散 ≤8 且次强 ≥50 均衡 → 总值 ≤40 近废 → ≤80 杂驳 → 常规 |
| 3 | 皆 ≥90 天品 → 皆 ≥75 上品 → 离散 ≤10 且末位 ≥45 均衡 → 总值 ≤60 近废 → ≤120 杂驳 → 常规 |
| 4 | 皆 ≥90 天品 → 皆 ≥70 上品 → 总值 ≤90 近废 → ≤160 杂驳 → 常规 |
| 5 | 全 100 **仙灵根**（仙品）→ 皆 ≥90 天品 → 皆 ≥80 极上 → 离散 ≤10 且末位 ≥55 均衡 → 总值 ≤45 近废 → ≤120 杂驳 → ≤220 普通 → ≤320 上品 → 极品 |

其中「离散」= 最高系 − 最低系；「次强 / 末位」= 排序后倒数第二 / 最后一位。

用户实例 `96/94/92/90/15` 在新口径下：五系、非同强、离散 81 > 10、总值 387 > 320 → **极品五行灵根 / 五灵根 · 极品**。

### 3.1 保真项与用户裁定

- **完全保真**：全部判定条件、阈值、印章（`meta`）、档位顺序、离散度公式与评语语义。
- **裁定一（用户，2026-10-28）**：单系不细分满值档——「超过 90 都叫天灵根，没必要整那么复杂」。
  daojie 原表的 `100 先天道胎灵根`（极境资质）与 `≥95 极品天灵根`（极品）两档**归并入 `≥90 天灵根`（天品）**，满值语义只保留在评语；
  此举同时修复了与本项目 TASK-20261023-02 §3.1「单系满百不再用先天道胎/极品等自造词」裁定的冲突。
- **裁定二（用户，2026-10-28）**：五系全满百定名 **「仙灵根」**，印章「五灵根 · 仙品」（daojie 原文为「神灵根 / 神品」）。
- **微调**：daojie 的双系天品名与单系天品名同为 `{names}天灵根`，会产出与顶级档位同名的歧义称号；本项目沿用既有 `{elements}双天灵根` 消歧，其余名称对齐。
- **书面语风格**：评语沿用本项目 TASK-20261023-02 §3.6 确立的沉浸式 25~40 字风格（daojie 评语为简述式），语义逐档一一对应。
- **结算零影响**：`evaluateSpiritualRoots` 仍为纯展示函数；升级需求乘区 `1 + 0.5 × (有效条数 − 1)` 与 daojie `resolveHeavenGateCultivationMultiplier` 完全一致，本次不动。
