## 需求背景与核心问题定位

1. **Hover 气泡未显示与具体属性缺失**：
   - 原因一：`ItemTooltipTarget` 过去使用了 `displayContents`，导致 `FloatingPopover` 的 `anchorRef` 处于 `display: contents` 无几何盒状态，触发器尺寸计算为 0，气泡无法正常定位展示。
   - 原因二：装备类产出物（`equipment.*`）未在 `ItemTooltipTarget` 中自动关联 `CombatEquipmentDefinition`，且 `resolveItemMetadata` 未对装备 ID 进行兜底，导致装备无属性展示。
   - 原因三：丹药与消耗品的修炼/采集/炼丹增益倍率（`cultivationMultiplier`, `gatheringMultiplier`, `alchemyMultiplier`, `durationSeconds`）未在 `describeItemEffects` 中解析格式化。
2. **行动卡片排序混乱（低等级在后、高等级在前）**：
   - 过去工艺与行动过滤直接沿用配置文件中的未排序数组，导致不同阶位装备与丹药呈现混乱顺序。
   - 解决方案：在 `filteredActions` 中统一按真实等级（Level）升序严格排序（`levelA - levelB`，相同按 ID 稳定排列），确保低等级在前、高等级在后。
3. **丹药与材料全部呈现蓝色的品质异常**：
   - 过去 `ITEM_META_CORES` 中将一阶丹药（引气丹、止血散、顺气丸）和二阶材料错误标注为 `rarity: 'spirit'`（青碧/蓝色）与 `mystic`（湛蓝），导致所有丹药与材料统一发蓝。
   - 解决方案：严格按修仙品阶规范校准：
     - 一阶（Lv.1）：凡品 `mundane`（质朴灰/白）
     - 二阶（Lv.18）：黄阶 `yellow`（灵动翠绿）
     - 三阶（Lv.30）：玄阶 `mystic`（深邃湛蓝）
     - 四阶（Lv.42）：地阶 `earth`（紫气氤氲）
     - 五阶（Lv.54）：天阶 `heaven`（金乌流光）
