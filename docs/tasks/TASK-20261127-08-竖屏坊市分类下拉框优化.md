## 一、需求与实现边界

1. **业务痛点**：竖屏/窄屏模式下，坊市浏览页（`MarketBrowseGrid`）的各级横向分类芯片与 `OptionToggle`（一级品类、材料子分类、装备/功法/消耗品/材料多维筛选）多行堆叠占屏过多，导致下方 `.market-browse-grid` 物品网格仅剩约一行可视区域。
2. **改造方案**：
   - 保持桌面横屏（`> 960px` 且横屏）原有横向芯片 + `OptionToggle` 交互不变；
   - 在竖屏或窄屏模式（`(orientation: portrait), (max-width: 960px)`）下，将坊市所有分类维度（一级品类、材料子分类，以及稀有度/类型/部位/分类/门类/伤害/形式）统一收拢为紧凑原生下拉框（复用 `.filter-grade-field` / `.filter-grade-select` 样式与 `FilterDimension` 统一抽象）；
   - 工具栏收紧为「搜索框 + 持有/在售/求购/参考价角标切换」单行紧凑排布，并适度压缩竖屏 `.market-header` 留白，把纵向视区最大化让渡给物品网格。
