## 需求原文

> 优化文本描述
> 我希望是类似这种的，带有图标和高亮的
> 也就是
> 甘露的整体描述为
> 对生命值百分比最低的玩家施加 图标 8% 术法攻击 + 1 层 的 甘露（这个是 buff 所以高亮）
> 然后这个 8% 会随着技能等级提升而改变数值，就和其他的一样
> 我希望，所有的技能都是这种风格的，没有很绕很无关的描述，给碎罡也改一下改成这样

## 需求分析

1. 现有 `describeAbility` 对 Buff 技能逐项罗列「施加增益 / 持续 / 重复施加只保留最高层数 / 层数公式」，形成长句；与伤害技能（连环等）的图标胶囊短句风格不一致。
2. 目标风格：主描述只保留「目标 + 核心构成 + 高亮 Buff 名」，数值用 `[[ ]]` 胶囊并自动带属性图标；Buff 的具体效果与持续时间移入词条行，避免正文堆叠。
3. 甘露主描述固定为：`对生命值百分比最低的队友施加 [[8%术法攻击 + 1层]] 的 [[甘露]]`；层数百分比随等级成长显示（Lv2 为 8.2%），与伤害倍率同口径。
4. 碎罡主描述改为：`对自身施加 [[碎罡]]（双抗 [[80%]]）、[[煞力]]（[[1 + 30%双抗]] 层）、[[罡锋]]（每 [[5]] 点已损气血 1 层）`；双抗比例与已损气血阈值同样按等级成长显示。
5. 碎罡/甘露/嘲讽的 Buff 效果、持续时间移入词条行；破阵子等主动增益保持「直接效果 + 高亮数值」的短句。
6. 不改变任何服务端结算与配表数值，仅调整展示层。
