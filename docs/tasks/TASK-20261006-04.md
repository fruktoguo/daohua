# TASK-20261006-04 顶栏主行动卡片右上角常驻「停止」按钮

## 需求

- 提出时间：2026-10-06 16:09:04
- 需求原文：给顶部行动栏的主行动（当前正在进行的行动）在右上角增加一个常驻按钮，作用是直接停止这个行动，不必进入详情或展开任务行动列表；其他地方不做更改，原停止按钮保留；按钮文案只写「停止」。

## 分析

- 顶部行动栏 = `frontend/src/App.tsx` 的 `QueueCenter`（`qc-current` 当前行动卡 + `qc-upcoming` 后续预览 + `qc-controls` 循环/自动移动/队列展开）。
- 主行动卡由 `QueueCurrentStage` → `CurrentActionCard` 渲染（`queue.entries[0]`）。
- 现有三条停止路径全部经 `ConfirmDialog` 二次确认后发送 `action.remove { actionInstanceId }`：
  - 队列展开下拉 `×` → `pendingRemoval` → `removeConfirm*`；
  - CombatArena 生活/赶路卡内按钮与战斗相位独立按钮 → `pendingStopEntryId` → `stopConfirm*`。
- 新按钮沿用 `QueueCenter` 已有 `pendingRemoval` 确认链路（对队首条目语义等价：移除队首 = 停止当前行动），防误触，且不新增弹窗流程。

## 实现要点

- `app.zh.ts` `queue` 域新增 `stop / stopAria / stopTitle` 词条（按钮文案「停止」）。
- `CurrentActionCard` 新增 `onStop` 回调，`.qc-current` 末尾渲染 `qc-stop danger` 按钮，`align-self: flex-start` 落位右上角；离场过渡卡（departing）不渲染。
- `QueueCurrentStage` 透传 `onStop`；`QueueCenter` 绑定 `setPendingRemoval(current)`。
- `styles.css` 新增 `.qc-stop` 紧凑按钮样式（小字号、顶部对齐、防收缩）。
