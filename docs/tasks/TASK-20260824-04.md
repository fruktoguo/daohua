## 需求背景与核心意图

用户明确要求：
> “单独写一个配置编辑器,可以直接查看并编辑保存当前游戏的全部配置文件。除了数值类型,其他的都应该有下拉框选项,而非手动输入,所有配置文件都应该有单独的解析”

### 核心规约与交付目标：
1. **独立配置编辑器 Web GUI (`tools/config-editor`)**：
   - 基于 React 19 + TypeScript + Tailwind CSS 极速响应架构。
   - 内置 Vite Node.js 文件中间件插件，直接读写磁盘 `config/game-data` 下的 25+ 个配置文件。
   - 自动生成变更快照备份 (`config/game-data/.backup/`)。
2. **全量非数值字段下拉化（无手动输入）**：
   - 枚举下拉单选/多选（`CombatStyle`, `DamageCategory`, `Element`, `ItemKind`, `ItemCategory`, `EquipmentSlot`, `UnitRank`, `ActionType`, `ActionExecutionKind`, `CombatAbilityEffectType`, `CombatAbilityTargetType` 等）。
   - 跨表外键 ID 引用下拉搜索选择器（`abilityId`, `itemId`, `enemyId`, `actionId`, `encounterId`, `nodeId`）。
   - 属性名下拉选择字典配置器（14 维属性及特殊机制属性）。
   - 布尔值下拉选择器（是/否/默认未指定）。
3. **9 大游戏配置文件全部拥有专属独立解析与编辑表单**：
   - `manifest.json`: 数据结构版本、内容发行版本、全量数据要素看板。
   - `actions.json` (及 `actions/` 子文件): 行动分类过滤、配方耗产、可用节点多选与遭遇关联。
   - `items.json` (及 `items/` 子文件): 道具品阶/类型过滤、消耗品与 Buff 效果列表。
   - `abilities.json` (及 `abilities/` 子文件): 流派/元素/伤害大类过滤、数值成长、Dot 与控制几率。
   - `equipment.json` (及 `equipment/` 子文件): 部位/品阶过滤、三段式 BaseStatRatios/FlatStats 字典配置与数值预算。
   - `monsters.json` (及 `monsters/` 子文件): 品质/流派过滤、攻防抗性矩阵、技能装配与掉落表。
   - `encounters.json` (及 `encounters/` 子文件): 刷怪池权重、首领/精英多选、波次狂暴与通关掉落。
   - `maps.json` (及 `maps/` 子文件): 大地图元数据、区域节点配置、可用行动/遭遇多选与路径网络连线。
   - `expected-attributes.json`: 四大乘区理论公式卡片、T1~T12 境界矩阵与双流派战斗仿真看板。
4. **一键启动与校验集成**：
   - `scripts/config-editor.sh` 一键启动服务。
   - 内置前端实时死链检测器与 `.NET` 领域层 `DataTool` 校验调用。
