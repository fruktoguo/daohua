## 1. 需求背景与核心理解

用户对传音与聊天系统可发送分享的内容类型提出深度优化需求：
1. **文案规范对齐**：原物品与装备操作菜单中的「分享到传音」，统一变更为「发送到聊天」，并保持全局各界面文案口径一致（包括插入提示「已插入聊天输入框」等）；
2. **扩展发送富文本类型**：在当前已有的【物品】（`{{item:...}}`）与【订单】（`{{order:...}}`）超链接基础上，新增两类核心富文本行内标记：
   - **队伍链接（Party Link）**：支持将当前小队一键生成富文本标记（包含队伍 ID、队名、目标类型、目标地点、身家门槛、成员数与槽位数），发送到聊天后渲染为修仙风格队伍胶囊，悬浮可查看完整队伍配置，点击可直接加入队伍或查看队伍；
   - **地点链接（Location Link）**：支持将大世界地点一键生成富文本标记（包含地点节点 ID 与地点名称），发送到聊天后渲染为碧翠修仙地标胶囊，悬浮可查看地点所属区域、产出资源概览与栖息生灵，点击可自动无缝切换至大地图并视口漫游平移聚焦至该地点。
3. **交互操作入口落地**：
   - 队伍面板（`SocialPage.tsx` 中的队伍详情）：提供一键「发送到聊天」按钮；
   - 地图面板（`WorldMapPanel.tsx` 中的地点侧边栏）：提供一键「发送到聊天」按钮；
   - 背包与装备：文案统一修正为「发送到聊天」。

## 2. 方案设计与技术边界

### 2.1 行内标记语法扩充（轻量、自包含、向前兼容）
- 队伍标记：`{{party:partyId:name:activityKind:nodeId:minValuation:memberCount:maxSlots}}`
  - 示例：`{{party:uuid-1234:九霄诛仙队:combat:node.cloud-peak:10000:3:5}}`
  - 容错支持：字段缺失时降级回退，保证零白屏。
- 地点标记：`{{location:nodeId:name}}` 与 `{{location:nodeId}}`（同时支持 `{{map:nodeId}}` 别名）
  - 示例：`{{location:node.cloud-peak:碧云峰}}`
  - 容错支持：若未传名称则由前端从大地图 catalog 自动解析地点名称。

### 2.2 渲染层组件
- `ChatPartyReference`：
  - 队伍胶囊组件，展示小队名称、目标徽标与容量；
  - 悬浮展示详细信息卡片；
  - 点击响应：未入队者发起加入申请，已入队者快捷跳转小队面板。
- `ChatLocationReference`：
  - 地点胶囊组件，展示地标图标与地点名称；
  - 悬浮展示产出与妖兽简介；
  - 点击响应：一键跳转探索大地图并高亮聚焦该地点。

### 2.3 地图聚焦与联动调度
- 在 `uiStore` 中增加 `mapFocusNodeId` 与 `setMapFocusNodeId`，供聊天地点点击时设置目标；
- `WorldMapPanel` 响应 `mapFocusNodeId`，自动切换选中节点并触发视口平移居中。
