## 1. 需求背景与目标

### 1.1 需求说明
调整装备强化行动的基础成功率 $P_{\text{base}}$：
原设定中 $+1 \sim +10$ 采用查表，$+11 \sim +20$ 采用 $0.3 \times 0.95^{(t-11)}$ 指数衰减（$+20$ 时基础成功率衰减至 $18.91\%$）。
现根据数值调优要求，将全阶强化基础成功率统一调整为：
- **+1**：50%
- **+2**：45%
- **+3**：45%
- **+4**：40%
- **+5**：40%
- **+6**：40%
- **+7**：35%
- **+8**：35%
- **+9**：35%
- **+10**：35%
- **+11 ~ +20**：统一均为 30%

## 2. 详细设计

### 2.1 成功率查表化
将原基础成功率数组由 10 项扩展为完整的 20 项：
```csharp
private static readonly double[] SuccessTable =
[
    0.50, 0.45, 0.45, 0.40, 0.40, 0.40, 0.35, 0.35, 0.35, 0.35,
    0.30, 0.30, 0.30, 0.30, 0.30, 0.30, 0.30, 0.30, 0.30, 0.30
];
```
在 `BaseSuccessRate(int targetLevel)` 中：
若 $1 \le t \le 20$，直接取 `SuccessTable[t - 1]`；若超出 20（容错兜底），取 `0.30`，经 `Math.Clamp(rate, 0.01, 0.5)` 保护。

### 2.2 前端镜像对齐
在 `frontend/src/game/combatConstants.ts` 中：
更新 `ENHANCE_BASE_SUCCESS_RATES` 常量为 20 项数组，`enhanceSuccessRate` 直接查表取值，移除指数衰减分支。
