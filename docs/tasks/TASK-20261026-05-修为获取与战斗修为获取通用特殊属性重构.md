# TASK-20261026-05 修为获取与战斗修为获取通用特殊属性重构

## 任务背景与目标

1. **用户核心需求**：
   - 用户反馈内功《炼精化气诀》参悟等级提升后，其标注的核心效果“修为获取 +20%”数值完全没有任何提升。
   - 经排查，原实现中内功修为增幅为特异字段 `cultivationExpBonusPoints`，未进入角色通用属性系统，也未接入任何等级成长公式，且打坐引气入体（`cultivation.draw-qi`）未接入该增幅。
   - 用户决定将其彻底重构为**通用的特殊属性**：
     - 新增两个通用特殊属性：**「修为获取」(`cultivationExpBonusPoints`)** 与 **「战斗修为获取」(`combatExpBonusPoints`)**；
     - 面板展示归入特殊属性栏，和其他特殊属性一样：**为 0 时不显示，非 0 才显示**；
     - 内功《炼精化气诀》（及《焚血功》）统一改为通过标准的 `passive` 常驻面板被动来修改这些属性；
     - 由此天然获得内功参悟等级的线性成长（`passiveScale = 1 + 0.05 * (Lv - 1)`），升级时修为增加数值动态提升，且未来装备、丹药、Buff、宗门阵法等均可无缝复用。

2. **设计预期与边界**：
   - **「修为获取」(`cultivationExpBonusPoints`)**：全路径通用修为点数（100 点 = 100%）。生效范围：战斗击杀、打坐引气入体、历练冥想等全部修为收益路径。
   - **「战斗修为获取」(`combatExpBonusPoints`)**：战斗专精修为点数（100 点 = 100%）。生效范围：仅战斗遭遇击杀怪物/战报结算生效。
   - **最终结算公式**：
     - 战斗击杀修为：$\text{Exp}_{\text{combat}} = \text{BaseExp} \times \big(1 + \frac{\text{cultivationExpBonusPoints} + \text{combatExpBonusPoints}}{100}\big)$
     - 打坐/非战斗修行修为：$\text{Exp}_{\text{timed}} = \text{BaseExp} \times \big(1 + \frac{\text{cultivationExpBonusPoints}}{100}\big)$
   - **内功配置变更**：
     - 《炼精化气诀》：移除顶层 `cultivationExpBonusPoints: 20`，改为 `passive: { "cultivationExpBonusPoints": 20 }`。
     - 《焚血功》：移除顶层 `cultivationExpBonusPoints: -10`，改为 `passive: { "combatExpBonusPoints": -10, ... }`（弃道从武，战狂代价）。
