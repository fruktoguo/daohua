## 2. 需求背景与核心目标

根据《道化太初》的通用大世界设计哲学（`docs/design/generic-map-and-encounter-system.md`）及 T1-T2 全量物品与怪物生态草案（`docs/临时设计讨论/全量物品重构与T1-T2设计草案.md`）：
1. **世界节点网络化**：地点（`WorldNode`）必须是有机连接的网络拓扑，具备地理逻辑、赶路时长与探索梯度。
2. **拒绝割裂刷怪本**：每个世界节点聚合「生活采集 + 历练遇怪 + 修炼环境 + NPC交互 + 阵法建筑」，生态特色鲜明。
3. **T1【凡俗仙山 · 青云境】（极其祥和，俗世仙山）**：
   - 山脚是炊烟袅袅的凡俗山村（云溪村）、清澈溪涧与药谷，山道有茶肆与石滩。
   - **草庐设在「云巅绝顶」**，居高临下俯瞰俗世红尘与茫茫云海，仙风道骨，凡人仰望。
   - **行动命名直白纯粹**：如 `收集晨露`、`挖掘乌铁矿`、`采摘凝血草`、`采伐桃木`、`引气入体`。
   - 历练为山林驱兽与同门切磋（野兔、木灵、小灵猴、守山石偶、护山灵兽）。
4. **T2【异象险途 · 叩仙门】（光怪陆离，怪异诡谲）**：
   - 叩响仙门，正式踏入真正的修仙界。修仙界并非童话，而是充满天地异象、星煞侵蚀、古修残蜕与异化妖魔的诡异世界。
   - 包含伴生异花（伴灵花）、绝壁怪松（引灵松）、煞气伴生铜矿（赤铜）。
   - 历练怪物极具怪异感（裂齿妖狼、星屑火鸦、掠灵邪修、残刃尸煞、坠魔祭司、坠星兽）。
