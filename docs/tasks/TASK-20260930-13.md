## 风险与裁定

| 风险 | 裁定 |
| --- | --- |
| 面板并入主端口后，生产 SPA 兜底可能把面板页面吐出来 | 前端用 `import.meta.env.DEV` 门控路由，生产产物不含面板入口 |
| 写操作 + 局域网可达构成后门 | 一次性令牌（`Ops:Token` / 启动随机生成并打印）+ 全部写操作二次确认 |
| 重写后页面由 Vite 提供，局域网设备打不开（Vite 固定绑回环） | 用户裁定并入主端口，接受面板仅本机可访问 |
| 存储/调度视图缺现成查询 | 新增仓储只读查询（outbox 分布、section 版本分布、表体量、留存计数） |

## 方案

见设计真源 [`docs/backend/ops-panel.md`](../backend/ops-panel.md)，要点：

1. **服务端**：`OpsPanel` 扩展为只读 14 项视图 + 4 项令牌保护写操作；`Ops:Port`/`ListenAddress` 与 `UseOpsGate` 端口门禁退役；页面嵌入资源退役。
2. **前端**：新增 `frontend/src/ops/`，`main.tsx` 按路径分流；复用游戏全局样式与 `ConfirmDialog`/`Modal`/`FloatingPopover` 等公共组件；左侧竖排导航 + 顶部状态条的信息架构。
3. **接线**：Vite 新增 `/ops/api` 代理；`dev.sh` 改为探测 `/ops/api/overview` 并更新横幅；生产三重拦截。
4. **文档**：`docs/frontend/common-components.md` 登记新增可复用组件。
