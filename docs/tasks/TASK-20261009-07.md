## 需求

战斗详情（竞技场）中，在每个参战角色蓝条（灵力条）下方加一个实时变化的数字，表示该单位的累积威胁值。

## 定位结论

- 威胁值链路已全程就绪：领域层 `ActionParticipation`/`CombatActionRules` 维护各单位累积威胁（敌方按全队威胁轮盘选目标、我方按有效威胁最高者选敌），`ProtocolSnapshotMapper` 每帧常驻下发 `playerThreat`、`enemies[].threat`、`allies[].threat`，前端 `snapshot.ts` 与 `types.ts` 已解析为强类型字段——唯缺上屏。
- 落点：`frontend/src/components/CombatArena.tsx` 的 `ArenaActor` 卡片，`arena-vitals` 内灵力 `ArenaResource`（tone="mp"）之后渲染威胁行；三方调用点（玩家自卡 ×2、盟友、敌人）分别接入 `expedition.playerThreat` / `ally.threat` / `entry.threat`。斗法镜像无威胁语义，传 null 不渲染。
- 「实时变化」由快照帧驱动：该字段逐帧下发，React 直接绑定渲染即随每次快照推送刷新。

## 改动面

1. `CombatArena.tsx`：`EnemyDisplayState`/`AllyDisplayState` 增 `threat` 字段；`ArenaActor` 增 `threat?: number | null` prop，在蓝条下渲染「威」徽 + `UnitNumber` 数值行；四个调用点接线。
2. `frontend/src/styles/expedition.css`：新增 `.arena-threat` 紧凑样式（crimson 敌意色调，tabular-nums）。
3. `frontend/src/i18n/domains/combat.zh.ts`：`combat.arena` 新增 `threatLabel`/`threatAria` 词条。
