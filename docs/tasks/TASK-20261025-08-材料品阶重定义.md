# TASK-20261025-08-材料品阶重定义（凡品普通／稀有阶梯）

## 1. 需求与实现边界

- **任务提出时间**：2026-10-25 21:10:00
- **需求分析完成时间**：2026-10-25 21:14:00
- **任务分类**：数值设计 / 配表体系 / 材料经济 / 图鉴与坊市
- **用户目标**：按「产出概率决定品阶」重建全部材料品阶：
  1. 低概率掉落 → 稀有材料；
  2. 采集直出与怪物超高爆率 → 普通材料；
  3. 普通材料全部为凡品（`tier: 1`）；
  4. 全部常规物品与装备制造**只能消耗普通材料**；
  5. 凡品以上一律稀有材料（`tier >= 2` 即稀有）；
  6. 随境界提高，稀有材料品级逐阶抬升。
- **实现边界**：仅改动材料配表 `tier`、6 条行动的显式 `level`、前端静态元数据与品阶门禁测试、总纲文档；不改掉率数值、不改材料价格、不改怪物配表、不改装备与丹方配方内容、不改协议与运行时结算。

## 2. 品阶判定口径

- **稀有判定唯一来源**：`tier >= 2`。服务端 `StaticGameCatalogMapper.ReadInt(item,"tier",1)`、前端 `marketFilters.matchesMaterialRarity` 与 `resolveInstrumentTier` 均已按此口径工作，本次不改判定代码，只改数据。
- **品阶 ↔ 境界**：`ConvertTierToLevel`（前端 `convertTierToLevel`）——T1→1 级、T2→18 级、T3→30 级，每阶 +12 级。稀有材料品级 = 产出源等阶 + 1：T1 怪物（Lv1~16）掉黄品 T2，T2 怪物（Lv20~24）掉玄品 T3。
- **概率分档**：现有掉落概率集合为 `{1.0, 0.5, 0.1, 0.05, 0.02, 0.01, 0.005, 0.001}`，以 **50%** 为凡品/稀有分界（对齐总纲 08「普通异材=50%/100% 出产」「珍稀异材=1% 或 10% 专属」的既有措辞）。秘籍/残卷 `dropChance: 0.001~0.01` 属独立爆率体系，不参与材料品阶。

## 4. 连带改动

### 4.1 六条行动补显式 `level: 18`

材料降阶后，行动解锁等级若继续由「产物 tier 推导」会从 18 级退化到 1 级，破坏关卡进度与两条既有测试：

- `config/game-data/actions/gathering.json`：`explore.gather-banling-flower`、`explore.chop-yinlingsong`、`explore.mine-crimson-copper`；
- `config/game-data/actions/crafting.json`：`craft.refine-copper`、`craft.refine-spirit-pine-crystal`、`craft.extract-banling-essence`。

**口径统一**：配表显式 `level` 为最高优先级。`CraftingRecipeRules.ResolveRequiredRealmLevel` 原先忽略 `ActionDefinition.Level`（仅装配期经验结算 `GameDataCatalog.ResolveActionCatalog` 与前端 `resolveActionLevel` 认它），导致「界面显示 18 级、服务端却放行 1 级玩家」的口径分叉；本次在服务端解析函数补齐同一优先级，三处（服务端解锁判定、服务端经验结算、前端行动等级展示）完全一致。

### 4.2 前端静态元数据 `frontend/src/game/ids.ts`

- `ITEM_META_CORES`：26 条材料 `rarity`/`level`/`tone` 与配表 tier 对齐（`tier:1`→`mundane`/1/`gray`；`tier:2`→`yellow`/2/`green`；`tier:3`→`mystic`/3/`violet`）。`tone` 仅用于战斗与快照图标配色，不承担稀有度边框语义。
- `ACTION_DEFINITION_CORES`：同 6 条行动补 `level: 18`，与服务端配表一致（该常量是离线/无网络兜底路径的行动定义）。

### 4.3 品阶门禁测试 `frontend/src/game/materialTier.test.mjs`（新增）

跨 `items` / `monsters` / `actions` 三域联合校验 5 条不变量：

1. 每项材料必须显式声明 `tier`（禁止缺省值兜底）；
2. 采集直出与 ≥50% 高爆率战利品必须 `tier: 1`；
3. <50% 低概率掉落必须 `tier >= 2`，且等于产出源等阶 + 1；
4. 任何制造配方（`type: alchemy`/`enhancement` 行动的 `inputs`）不得出现稀有材料；
5. 凡品材料必须存在正产出来源（采集 / 高爆率掉落 / 凡品加工）。

配套调整 `codexCalculations.test.mjs` 解锁用例：凡品材料一律 1 级解锁，稀有材料按品阶门槛（T2→18、T3→30）解锁，技艺分派路径改用同构材料定义验证（配表已无凡品技艺门槛材料）。

## 6. 影响与风险

- **稀有材料暂无制造去向**：7 种稀有材料当前零常规配方消耗，唯一消耗点是 `building.demon-seal-array`（煞骨×100 + 妖核×1）。阵成后造价因稀有度抬升显著提高，属有意设计（高阶建筑吃稀有材料），需在后续版本补稀有材料的制造与建筑用途。
- **封魔阵造价**：煞骨 2,000 灵石/件 ×100 = 20 万灵石，妖核 20,000 灵石/件 ×1，均按 1% 爆率从 T2 elite/BOSS 获取；当前阶段属长期积累目标。
- **图鉴解锁面收窄**：材料整体降阶后，图鉴默认解锁数量从 20 增至 27（31 条材料 - 7 条稀有之外全部凡品），稀有材料的解锁门槛改为 18/30 级。
