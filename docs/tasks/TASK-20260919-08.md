# TASK-20260919-08 · 战场单位详情弹窗重构：复用内视斗法属性面板，角色/敌怪统一口径

- 提出时间：2026-09-19 21:03:09
- 完成时间：2026-09-19 21:10:00
- 状态：✅ 实现完成，待验收

## 需求

用户反馈斗法战场中单击角色/敌怪展开的属性弹窗（`CharacterAttributeModal`）存在严重口径漂移：

1. 角色与敌怪面板字段、分组、排序完全不一致；
2. 角色面板错误地展示了六维根基等级（体魄/经脉/根骨/力道/神识/身法）——六维属于内视「根基」Tab 语义，不属于战斗属性；
3. 角色面板战斗属性为手写的一套 `combat.attr.*`/`combat.special.*` 散乱行，未复用内视「斗法」Tab 的属性体系。

要求：弹窗按分区组织，首先复用内视斗法的属性体系；角色与敌怪走同一组件同一字段口径。

## 方案

### 新增共享组件

1. `frontend/src/components/CombatAttributePanel.tsx`（新增）：
   - `CombatAttributePanelModel`：斗法面板归一化展示模型（生息/攻防/博弈/特殊比例/增免伤比例对，全量 double 原始值）；
   - `resolvePlayerCombatAttributeModel(attributes, loadout, basePool)`：玩家模型解析，逐行搬移内视斗法 Tab 既有推导（attributes 实时值优先，缺省回退 basePool × 六维加成估算）；
   - `resolveEnemyCombatAttributeModel(definition)`：敌怪模型解析，由遭遇配表 `CombatantDefinition` 映射（category=spell 或 style=five-elements 记术法攻击，否则物理攻击；暴击/免暴点 = 比例 ×100，与玩家 `criticalRating ?? criticalChance*100` 兜底同口径；破招/化解配表未下发记 0）；
   - `CombatAttributePanel`：渲染内视斗法同款三组胶囊分区（基础战斗属性/特殊战斗属性/增免伤与五行属性，复用 `.insight-sub-tabs` 二级导航 Tab 切换）+ 可选「当前运转丹药与神通加持」Buff 分区，词条统一 `insight.combat.*`。

### 改造点

2. `frontend/src/components/InsightPage.tsx`：斗法 Tab 改为 `<CombatAttributePanel model buffs />`，属性推导收敛到共享解析函数；头部快捷气血/灵力改读模型值。
3. `frontend/src/components/CombatArena.tsx`：`CharacterAttributeModal` 移除手写 `AttributeRow`/`baseRows`/`specialRows` 体系与六维行，改为头部（立绘+道号+阵营徽章）+ `<CombatAttributePanel>`；敌怪 Buff 无下发源保持空数组。
4. `frontend/src/i18n/domains/combat.zh.ts`：删除失效键 `combat.attrs.base|special|effects`、`combat.special.*` 整块、`combat.attr.*` 中仅旧弹窗使用的 `power/accuracy/evasion/armor/magicRes/metalRes/woodRes/waterRes/fireRes/earthRes/attackInterval/maxDamage`（`hp/mp/seconds` 与六维名仍被遭遇面板/地图/账本复用，保留）。
5. `frontend/src/styles.css`：删除失效样式 `.character-attribute-section*`、`.character-buff-list*`，保留头部与徽章样式。
6. `docs/frontend/common-components.md`：登记 `CombatAttributePanel` 统一模板。

## 取舍说明

- 敌怪五行抗性等点数型字段当前配表全为 0，且与斗法「增免伤%」组语义不同，不在面板展示——与玩家侧自身五行抗性同样未入斗法口径，保持一致。
- 敌怪「攻击间隔」「控制抗性/吸血/汲蓝」等旧弹窗字段不属于斗法展示体系，统一移除；出手间隔已由角色卡片行动条可视化承载。
- 玩家掉落率/稀有度等产出加成属经济属性而非斗法面板口径，一并移除（内视斗法本就不展示）。
