## 2. 美术设计真源与风格规范

- **色彩预算**：
  - 纯黑背景 (`#000000`)
  - 近黑连续主体块面 (60% ~ 80%)
  - 骨白结构面 (12% ~ 28%)

  - 骨白与强调色之间保留近黑呼吸槽。
- **图标尺寸**：64x64 WebP。
- **立绘尺寸**：256x256 WebP / SVG。
