# TASK-20261109-11 聊天点击角色查看角色详情

## 1. 任务背景与核心需求

### 1.1 业务目标与需求背景
在传音/聊天界面中，玩家互相交流时希望能像主流 MMO 游戏一样，直接点击发言修士的名字/道号，即可唤起该修士的「角色信息卡（PlayerCardModal）」，查阅其形象、角色序号、境界、修为进度、战斗属性、穿戴装备、功法配置及百艺等详情，增强社交互动感与装备展示乐趣。

### 1.2 核心逻辑预期
1. **前端交互与无缝触发**：
   - 聊天行头部道号（`.chat-sender-name`）升级为可交互按钮，鼠标 Hover 时呈现高亮/微下划线反馈并提示「点击查看修士详情」；
   - 点击时调用 `useSocialStore.getState().requestPlayerCard(message.senderId)`；
   - 触发既有的全局 `PlayerCardModal`，复用成熟的角色信息卡弹窗，优雅呈现修士的全部公开属性与装配。
2. **服务端权限边界解耦与放行**：
   - 目前 `SocialRuntime.cs` 中的 `BuildPlayerCardAsync` 硬编码限制为「仅本人、同队或同一大地图节点附近修士」，若为跨节点、世界频道或未组队聊天，服务端会拦截返回 `error="forbidden"`；
   - 角色信息卡（`PlayerCardDto`）本身仅包含角色的公开展示数据（道号、形象、境界、六维等级、装备强化、功法神通、自动战斗消耗品栏、基础攻防属性等），不包含任何私密资产、背包仓储或鉴权凭据；
   - 因此放行全域已注册玩家的 `PlayerCardRequest` 检视权限（仅目标玩家不存在时返回 `error="not-found"`），使聊天室、排行榜、附近与队伍场景均可正常公开查阅修士名片。
3. **设计文档对齐**：
   - 同步修订 `docs/design/总纲/21-同道与组队系统.md` 中关于角色信息卡授权边界的描述。
