# TASK-20260923-01 · 储物袋面板分组展示

- 提出时间：2026-09-23 00:03:58
- 状态：✅ 实现完成，待验收

## 需求

用户要求储物袋（背包）面板不用顶部 Tab，而是在同一滚动视图中按小标题分段陈列物品，一段排完后另起新段。固定五组：

1. 重要 —— 货币、特殊物品等
2. 消耗品 —— 战斗消耗与持续消耗品全部归入
3. 装备法宝
4. 功法
5. 材料

## 方案

- `frontend/src/game/ids.ts` 新增 `InventoryGroupKey` / `INVENTORY_GROUP_ORDER` / `resolveInventoryGroup(itemId, items, equipment)`：以物品目录 `ItemDefinition.kind`/`category` 键与装备目录命中为准，`itemId` 前缀（`equipment.*`/`item.tome.*`/`item.fragment.*`/`currency.*`）作目录未加载兜底；空组不渲染，组内保持服务端资产顺序。
- `InventoryPanel`（RightSidebar.tsx）按组渲染小标题 + 原 `inventory-grid` 瓦片网格。
- 词条收拢 `app.inventoryPanel.group.*`；样式新增 `.inventory-group*`（沿用 abilities 分区小标题视觉语言）。
