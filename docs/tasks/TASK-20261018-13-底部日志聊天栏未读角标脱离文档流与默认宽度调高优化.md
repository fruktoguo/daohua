## 需求背景与核心痛点
底部战报与传音日志聊天面板（`GameLogPanel`）拥有 8 个频道分组选项卡（综合、世界、附近、系统、战斗、好友、宗门、队伍）。
在既有实现中：
1. **角标占据布局流撑宽按钮**：未读计数角标（`.log-tab-badge`）直接作为 flex 流内子元素排列于标签文字右侧（`display: inline-flex; gap: 4px`）。当某个频道收到新消息产生未读时，角标突然挂载，导致该 Tab 按钮宽度瞬间被撑大 16px~28px，并推挤整行其它选项卡，造成整个 Tab 栏剧烈变宽、横向挤压甚至触发不必要的横向滚动条；
2. **切换已读时宽度骤缩回弹**：当玩家点击进入该 Tab 时，未读数清零，角标被移除，按钮宽度突然变窄，导致整行再次发生跳变抖动；
3. **按钮初始宽度过于紧凑**：默认无角标时，两字 Tab 仅依靠 `padding: 2px 8px` 包裹，视觉宽度仅约 40px，缺乏统一沉稳的呼吸感。

---

## 解决方案与技术方案
1. **角标绝对定位脱离文档流 (Position Absolute)**：
   - 将未读角标 `.log-tab-badge` 改造为 `position: absolute; top: -3px; right: -2px; z-index: 2;`；
   - 角标完全脱离流式布局，不占据任何普通流宽度，彻底消除未读消息产生或清零时对 Tab 按钮尺寸和整行布局的任何撑宽与抖动；
   - 保持角标入场弹性微动画（`log-badge-pop`），提升视觉精致度。
2. **默认宽度适度调高/加宽并统一规整**：
   - 为 `.log-tabs .log-tab-btn` 设置稳定适宜的默认基准宽度 `min-width: 54px`，文字水平居中（`justify-content: center`）；
   - 在未读角标不存在时，8 个 Tab 保持宽度均匀规整，布局整齐舒展；
   - 在右上角挂载角标时，左右留白充分容纳角标投影，完全不遮挡居中文字内容。
3. **顶边距安全防护与交互手感增强**：
   - 为 `.log-tabs` 增加 `padding-top: 4px;`，为右上角微外挂浮层预留充足呼吸空间，杜绝横向滚动容器切断顶部发光阴影；
   - 为 Tab 按钮补充细腻的 hover 悬停高光与 active 激活态微边框过渡，提升交互反馈品质。
4. **统一规范同步**：
   - 同步登记更新 `docs/frontend/common-components.md` 关于 Tab 徽章定位的最佳实践说明。
