# TASK-20260923-02 普攻/吟唱统一动作时间线模型修正

## 需求来源

用户指出当前实现把「法术系填充技能（掌心雷）的 2s 吟唱时长」错误建模成了「法术系单位的普攻间隔 = 2s」，导致木灵等术法怪面板攻击间隔显示 2s。正确设计：

- **普通攻击（全单位统一）**：基准 1.0s，吃行动速度（ATR）与攻击速度双乘区；伤害 = 100% 物理攻击力（AD）物理伤害，法系单位完全相同。
- **掌心雷**：普通技能槽位的 0CD 填充技，吟唱 2.0s 只吃行动速度不吃攻击速度；装配后因 0CD 永远可放而自然完全顶替普攻。
- **单动作时间线**：每次出手要么是普攻（占 1s×系数），要么是放技能（占该技能吟唱时长），不存在并行双轨。
- 不存在「灵爆」技能/概念；文档中「法术普攻 = 灵爆 2.0s」为错误设定，需同步修正。

## 现状偏差

- `GameDataCatalog.ParseMonsterDefinitions`：spell 怪 `interval = 2 × actionFactor`，普攻伤害取 AP、`BasicAttackRatio = 0.6 × skillIntensity`。
- `PlayerAttributeResolver`：`spellStyle → baseInterval = 2`、`BasicAttackRatio = 0.6 × skillIntensity`；`ToCombatant` 普攻取 SpellAttack。
- 怪物技能调度：血量比例一次性触发（UsedSkillMask），掌心雷只放一次；放技能不占用动作时长。
- 玩家侧：吟唱与普攻双轨并行，吟唱期间普攻照打。

## 实施要点

1. 普攻统一：interval = 1.0s ×(1-ATR)×(1-攻速)，倍率 100%→200% AD，物理伤害；删除全部 spell 分支。
2. 战斗引擎单时间线：出手边界先结算待完成动作，再决策下一动作（可放技能→吟唱占位；否则普攻占位）。
3. 怪物技能槽语义：触发门槛（triggerHpRatio）+ 冷却循环（cooldownMilliseconds），移除 UsedSkillMask 一次性语义；0CD 填充技每次出手循环施放。
4. 玩家吟唱期间压制普攻 tick（唱完才重新起普攻前摇）。
5. 快照/协议字段同步（待结算吟唱、技能冷却），前端展示口径核对。
6. 文档：`combat-benchmark-model.md` 灵爆/法术普攻表述修正，`generic-map-and-encounter-system.md` 等相关口径同步。
