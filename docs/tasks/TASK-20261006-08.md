# TASK-20261006-08 内功心法体系设计：以六维经验分配为核心的首批内功配表

## 需求

- 提出时间：2026-10-06 20:33:57
- 需求原文：当前只有术法没有内功。内功定位是调整经验获取——经验分修为经验与六维经验两部分，内功通过提升某一维度、降低某一维度达成个性化养成。先看现有术法的名字与设计风格，共同探讨设计方案。

## 现状勘察（设计讨论依据）

- 功法门类已有落地：`discipline` 字段划分 `internal`（0 号内功位专属）/`spell`（术法位），槽位双向互斥服务端已校验（`LoadoutCommand`）。
- 现有 3 门「伪内功」过渡归类（嘲讽/清平乐/破阵子），DESIGN.md 第四篇明示其为过渡态、真正心法数值载体待落地——本任务即落地载体。
- 六维根骨：`CoreAspectKind` = 体魄 Stamina / 经脉 Meridians / 力道 Attack / 根骨 Bone / 身法 Agility / 神识 Consciousness；等级 = `floor(cbrt(exp/100))+1`，初始 72900 exp = 10 级。
- 六维→战斗属性映射（`PlayerAttributeResolver`）：气血=体魄+根骨、灵力=经脉+根骨、护甲/回血=体魄、法抗/回蓝=经脉、物攻/暴击/破招=力道、闪避/免爆=身法、化解=根骨+身法、法攻=神识×2、命中=神识。
- 分配机制现状（`CombatActionRules.DistributeRootExp`）：击杀 `experience` 总量守恒，未装内功六维各得 1/6；已装内功按其 `rootAttribute` 归属集合均分——单维归属即 100% 全灌一维、其余归零。现语义只有「全修/单修」两极端，不支持「主升+副修+削弱」的细粒度配比。
- 六维经验唯一来源是怪物击杀；修为池另有 `CreditExperience`（瓶颈截断+底蕴 1:1 兑换放大至 3 倍）。
- 学习路径：秘籍物品命名约定 `item.tome.X` ↔ `ability.X`（习得+10000 参悟经验）、`item.fragment.X`（复读 +500，需先习得）；内功纯被动不施放则参悟经验只能靠秘籍注入，需决议参悟等级是否影响调整幅度。
- 文档口径过时待修：`docs/backend/game-data.md` §7 的 `rootAttribute` 枚举值（stamina/intelligence/attack/defense/swordsmanship/talisman）与真实枚举（stamina/meridians/attack/bone/agility/consciousness）不符。

## 已定决议（用户确认）

- **分配模型**：非守恒增减率——`rootExpMultipliers` 逐维乘率（缺省 1.0、可 0 献祭），`share_i = experience × mult_i × eff/6`，总效率可偏离 100%。
- **内功形态**：纯被动常驻，不进入施放序列；可携带 `passive` 常驻面板效果（首批配小数值）。嘲讽/清平乐/破阵子三门伪内功落地时改回 `spell`。
- **参悟等级**：`rootExpEfficiencyPerLevel` 每级提升六维总量效率（`eff = 1 + perLevel×(Lv−1)`）。
- **跨池转换**：做，简单实现——`cultivationExpBonusPoints` 直接增减修为获取（独立乘区乘 `amp`），不做池间转换结算。
- **投放**：本轮不做掉落/发放，用户后续自行配置；仅预留 `item.tome.X`/`item.fragment.X` 秘籍物品。
- **命名**：T1 凡俗=武侠拳谱名（吐纳功/蛮牛劲/铁布衫/飞燕功/清心诀），T2 练气=真修功法名（焚血功/小周天功/存神诀/炼精化气诀）。
