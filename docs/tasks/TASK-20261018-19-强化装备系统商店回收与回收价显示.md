# TASK-20261018-19 · 强化装备系统商店回收与回收价显示

## 任务背景与核心目标

根据设计总纲《04-装备标准化预算与锻造升阶体系.md》§4.6 及用户诉求：
1. **解决装备商店显示「不可回收」问题**：当前悬浮副卡「市场价格」中对所有装备及强化变体均显示「不可回收」，前端未能感知装备的基准售价与强化等级回收价，需对齐总纲模型闭环展示；
2. **支持不同强化等级装备被系统商店回收**：服务端 `item.sell` 与 `item.discard` 当前缺少 `variant` 参数支持，且一刀切拦截装备处置；需扩展命令支持装备及变体行出售与丢弃，并按照受保强化 50% 额外造价折旧公式计算入账灵石；
3. **穿戴与备件所有权精细化判定**：将装备处置的已穿戴拦截收窄至同级已占用量（对齐 `market.place` 防线），放行背包内多余未穿戴备件；
4. **前端交互与弹窗打通**：`InventoryItemCell` 放行装备回收与变体处置，动态计算对应等级回收单价与灵石总额，命令附带 `variant` 保证资产扣减精确无误。

## 核心设计与计算模型

### 1. 装备白板回收基础售价 $V_0$
根据制造翻倍铁律（原料成本 $\times 2.0$）：
$$V_0 = 2.0 \times \sum (\text{原材料单价 } P_i \times \text{配方投入数量 } Q_i)$$
配方投入若含低阶装备，递归展开至基础材料。

### 2. 强化等级回收单价 $\text{SellPrice}(+N)$
总纲 §4.6.2 闭式常数查表（$\alpha = 0.50$）：
$$\text{SellPrice}(+N) = \text{round}\left( V_0 \times (1 + \beta_N) + F_N \right)$$
