## 1. 任务背景与核心目标

用户明确阐释了《道化太初》角色的核心设计哲学：
**角色本身的状态是完全常驻的（Unified Living Entity）**。玩家角色无论处于移动、采集、制造、战斗，还是后续的切磋 PvP 或秘境探索，在底层与设计逻辑上永远是**这同一个常驻实体**；角色的生命值、灵力值、Buff、境界属性、伤病状态在时间轴上完全连续存在并互相影响，彻底打破传统 RPG 将各系统玩法完全隔离的做法。

本任务旨在建立一份**权威、详尽、系统化且具备架构落地指导意义的《道化太初·角色核心设计文档》（Character Core Design Document）**，涵盖：
1. **角色核心设计哲学与顶层定位**：统一常驻实体原理、环境作用力模型、确定性时空连续性；
2. **角色多维体征与数据模型**：精气神基础体征（气血/灵力/高精度余量）、修炼境界与底蕴、武道装配（心法/神通/六大装备部位/技艺工具）、随身储物与大世界空间坐标；
3. **状态连续性与跨玩法流转模型**：状态全局穿透与继承、Buff/Debuff 实体级统一时间轴衰减、脱战继承与 1 HP 濒死复苏机制、秘境与 PvP 真实入场机制；
4. **行动队列与身体状态互锁机制**：前置状态准入、动作阻断（Blocked）、持续消耗品分摊与自动使用槽位（300s 动作时间池）；
5. **技术架构与系统实现映射**：`PlayerState` 聚合根、`SimulationEngine` 确定性状态演进、`PlayerShardHost` + `YuoFiber` 单写者并发所有权、网络增量同步（`PlayerPatchDto`）；
6. **设计红线与未来扩展准则**：禁止影子角色、禁止跨玩法免费重置、保证全量 `double` 精度。
