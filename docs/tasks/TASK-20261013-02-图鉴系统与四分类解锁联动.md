## 需求背景与核心定位
用户提出增加「图鉴」顶级 Tab 页面。图鉴的核心作用为：用于解锁建筑和制造配方，后续承载万象图鉴与百科收集。
经讨论与确认，图鉴系统包含四大分类，其解锁规则与交互联动如下：

1. **制造配方（Crafting）**：
   - 涵盖四大技艺制造：炼丹 (Alchemy)、炼器 (Forging)、阵法 (Formation)、符箓 (Talisman)。
   - 按 T 级所需境界等级自动解锁图鉴：T1 默认 1 级解锁；T2 需 18 级（凡俗 [天] 叩仙门）解锁。
   - 交互联动：未解锁对应图鉴前，在前端制造面板（CraftingPage）中**彻底隐藏**对应制造项；服务端 `action.enqueue` 同步校验等级，未达解锁等级拦截入队。
   - 图鉴展示：展示全部配方，未解锁暗墨加锁，Hover 悬浮卡内注明「解锁条件：境界达到 18 级自动领悟」。
2. **建筑图谱（Buildings）**：
   - 节点公共建筑（采葛营帐、携行丹灶、聚灵蒲团、淬火铁砧、护阵石龛、养脉泉眼等）。
   - 按配表 `requiredRealmLevel` 境界等级解锁图鉴。
   - 交互联动：未解锁图鉴的建筑，**不出现在地图附近面板的建造候选列表**（原灰显改为隐藏）。服务端 `building.build` 维持等级校验。
   - 图鉴展示：展示全部建筑，未解锁虚影暗淡，Hover 悬浮卡内注明「解锁条件：境界达到 X 级自动解锁图鉴」。
3. **技能神通（Abilities）**：
   - 功法神通图鉴。
   - 解锁规则：学会对应技能即解锁对应图鉴（检查已学技能列表 `learnedAbilityIds`）。
   - 交互联动：暂时只做纯收集展示，无额外交互效果。Hover 悬浮卡内注明「解锁条件：研读对应秘籍领悟」。
4. **大世界怪物（Monsters）**：
   - 妖兽志图鉴。
   - 解锁规则：击败对应妖兽即解锁对应图鉴。
   - 领域状态扩展：在玩家进度中落地 `DefeatedMonsterIds` 击败怪物 ID 集合，讨伐击胜时自动记录并下发快照。
   - 交互联动：暂时只做纯收集展示。未击败显示迷雾暗影，已击败显示全彩。Hover 悬浮卡内注明「解锁条件：在野外讨伐并击败该妖兽」。
