## 2. 需求理解与实现边界

### 2.1 业务目标
为游戏中所有物品（包含材料、消耗品、装备、道具等）构建全自动、高性能的动态来源反向检索系统。当玩家在任何界面 Hover 物品时，在现有多副气泡（装备属性、丹药Buff、功法参悟、坊市行情等）体系中，并排呈现一个独立的「获取途径/来源」副气泡悬浮窗（Aside Card），清晰指引物品从何处获取。

### 2.2 核心逻辑预期
1. **全量反查覆盖维度**：
   - **妖兽击杀（Monster Drops）**：自动检索全量战斗遭遇（`encounters`）中的所有出没怪物，提取产出该物品的妖兽名称、生命层次（普通/精英/Boss）、掉落概率（百分比格式化）与掉落区间。
   - **技艺制造（Crafting & Life Actions）**：自动检索全量行动目录（`actions`），识别产出该物品的配方，展示配方名称、所属生活技艺门类（炼丹/炼器/符箓/阵法/生活采集等）、所需技艺等级或境界要求，以及单轮产出数量。
   - **开袋开启（Storage Bag / Pack Opening）**：检索储物袋/礼包（如「破损的储物袋」）开启概率与掉落池，列出产出概率（必得/概率暴击）与数量范围。
2. **特殊资源处理（灵石、功德等通用货币）**：
   - 灵石（`currency.spirit-stone`）与功德（`item.gongde`）由于掉落怪物泛滥（几乎全境怪均掉落），机械罗列会导致副卡片极度垂地溢出且缺乏可读性。
   - 专门进行聚合提炼：结构化概括出妖兽讨伐（全图怪物普遍产出）、储物袋开启（破损储物袋固定与暴击区间）、坊市商贸（交易与回收变现）、天地历练等四大核心产出通道。
   - 其它掉落怪较多（$\ge 6$ 只）的常规材料，按怪物品阶与爆率降序展示前 5 只核心妖兽，并在尾部注明「等 N 只妖兽」，保持紧凑优雅。
3. **独立悬浮窗体系接入**：
   - 完全复用现有的 `FloatingPopover` 双列均衡与自适应缩放机制，以 `FloatingAsideCard`（碧玉翡翠色调 `jade`、徽标 `[来源]`、标题 `获取途径`）呈现。
   - 全局注入 `resolveItemTooltipAsideCards`，令背包、装备栏、图鉴、坊市、商店、掉落物、行动详情等全场景悬停天然同步受益。
4. **性能保障**：
   - 配表数据（`encounters`, `actions`）在前端维护模块级惰性反向倒排索引，初次查询或配表变更时构建，单次 Hover 查询复杂度 $O(1)$，保证密集网格 Hover 零卡顿。
