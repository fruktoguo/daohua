# TASK-20261015-04 生态生灵悬浮详情统一与附近修士详情查看

## 任务背景与核心需求

用户反馈了两项体验优化与交互需求：
1. **当前地图怪物悬浮卡统一**：地图下方 Tab（附近面板）中的怪物 hover 浮层当前只有少量攻防属性、缺少掉落物和收益明细，应当与大地图地点生灵浮层保持一致，以最详尽的信息卡为基准，全局统一生灵悬浮展示（包含生命层次徽记、境界等阶副标、刷新节奏提示、击杀收益、掉落物图元瓦片及完整战斗六维属性）。
2. **附近修士卡片交互与详情查看**：
   - 地图人物 Tab 下的「附近玩家」卡片当前缺乏角色形象、境界和身家等关键修仙要素展示；
   - 增加点击事件，点击附近玩家（及同队成员）弹出详尽的角色信息卡（`PlayerCardModal`）；
   - 详情信息卡中完整展示：角色形象立绘、道号名称、境界牌匾、身家估值、六维根骨经验进度、完整战斗属性（气血/灵力/双攻/双防等）、各项生活技艺等级以及全身装配（战斗装备与技艺工具）。

## 架构方案设计

### 1. 生态生灵悬浮卡统一 (`MonsterInfoCard` / `MonsterTooltipTarget`)
- **现状梳理**：
  - `NearbyPanel.tsx` 现有 `MonsterCard` 使用内联 `FloatingInfoCard`，仅包含 `statLevel/statRank/statMaxHp/statMaxDamage/statArmor`，无掉落物与收益；
  - `WorldMapPanel.tsx` 的 `MapMonsterPill` 包含奖励收益、掉落物胶囊（`ItemDropReference`）以及生命/灵力/双攻/双防六维基础战斗属性；
  - `CombatEcologyPanel.tsx` 的 `EcologyMonsterTile` 包含六维属性、攻速间隔、掉落物与施展功法。
- **重构方案**：
  - 提取公共生灵悬浮详情构建逻辑 `buildMonsterInfoCardContent` / 统一组件，或在 `NearbyPanel.tsx` 补齐与 `WorldMapPanel.tsx` 一致的详尽规格：
    - 徽记：`rankLabel`（普通生灵/精英强敌/关底领主）及品质色调（gold/purple/danger）；
    - 副标：`t('combat.map.monsterSubtitle', { realm: minorName, level, tier })`；
    - 词条行：刷怪节奏 `intervalHint`（逢 N 场出没）、击杀修为收益 `monsterReward`、掉落物列表 `monsterDrops`（使用公共组件 `ItemDropReference` 渲染复合胶囊，展示概率与数量区间）；
    - 战斗属性网格：气血、灵力、物攻、法攻、护甲、法抗（有完整定义时展示，回退时展示已知攻防与护甲）；
  - 全局生灵悬浮均以最详尽信息为准，彻底消除不同页面同一怪物的体验断层。

### 2. 附近修士卡片升级与详情弹窗 (`NearbyPanel.tsx` + `SocialRuntime.cs` + `PlayerCardModal.tsx`)
- **附近玩家卡片信息补全**：
  - 服务端协议 `NearbyPlayerDto` 扩展可选字段：`realmLevel`（境界等级）、`valuation`（身家估值）；
  - `OnlinePresenceRegistry.cs` 登记在线玩家时携带/关联境界与身家（或经 `BuildStateAsync` 按节点投影时填充），下发前端；
  - `NearbyPanel.tsx` 中附近玩家卡片展示：
    - 左侧：`CharacterAvatar` 形象立绘；
    - 中部：玩家道号 `displayName`、境界牌匾/小标签（如「炼气一层」）、身家（金色调 `valuation` 格式化数值）；
    - 右侧：交互按钮（加好友、组队）；
    - 卡片本体：支持点击触发 `gameClient.requestPlayerCard(player.playerId)` 查看详情。
- **角色信息卡详情扩展 (`PlayerCardDto` & `PlayerCardModal.tsx`)**：
  - `PlayerCardDto` 扩展字段：
    - `attributes` (`CombatAttributesDto`：完整战斗属性面板)；
    - `techniqueLevels` (`IReadOnlyDictionary<string, int>`：七大生活技艺当前等级)；
  - 服务端 `SocialRuntime.BuildPlayerCardAsync`：
    - 放宽查询授权：支持查询本人、同队成员以及同节点附近玩家（或所有有效修士公开名片）；
    - 解算目标玩家的战斗属性（`PlayerAttributeResolver.Resolve(state, _gameData)`）与技艺等级（`TechniqueCatalog.LevelFor`）；
  - 前端 `PlayerCardModal.tsx`：
    - 弹窗名片英雄卡片（`.player-card-hero`）按用户指定结构重构：
      1. **上下两部分划分**：上部占 80%，下部占 20%；
      2. **上部 80% 区域（左右 40% / 60%）**：
         - 左侧 40%：角色形象（`CharacterAvatar`，居中充满、大气饱满）；
         - 右侧 60%：上方为玩家道号（**横向居中**加粗展示），中部为身家（**横向居中**金色高亮展示）；
      3. **下部 20% 区域**：横向居中展开屏幕左上角同款三段式牌匾（`RealmBadge`，大境界框 + 棱形徽章 + 小境界胶囊）；
      4. **身份标识与代码净化**：若是玩家本人，右上角展示 45 度绿色/金色缎带斜角标（「自己」）；彻底移除原有的 `第 13c49fce 号修士`（UUID 底层代码）；
    - 名片卡片下方紧接着渲染：
      1. **战斗属性面板**：气血、灵力、物攻、法攻、护甲、法抗、命中、闪避、暴击等战斗六维/核心属性；
      2. **生活技艺等级面板**：采药、伐木、采矿、炼丹、炼器、制符、阵法等生活技艺的当前等级胶囊。
