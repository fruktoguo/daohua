# TASK-20261003-09 · 本地库坊市系统挂售种子：系统身份为全部可回收物品挂 1 亿份卖单（半价）

- 提出时间：2026-10-03 16:57:36
- 分类：本地开发工具 / 数据种子 / 坊市
- 状态：✅ 已完成（2026-10-03 18:41，54 品种半价货架生效，旧官商货架经用户裁定清理）

## 需求原文

> 调整本地数据库：让系统身份给市场的所有物品添加1亿份挂售，价格为出售价格的一半。

## 需求澄清结论

1. 「系统身份」= 本地库新建一个不可登录的系统账号 + 玩家（固定 UUID 幂等），作为坊市货架卖方。
2. 「市场的所有物品」= `config/game-data/items/*.json` 中 `sellPrice > 0` 的非货币物品（54 个）。
   - `currency.spirit-stone`（灵石）为货币本身，排除（与 `item.sell` 系统回收拒绝 `currency.*` 同口径）。
   - 装备无回收价目（`PartyValuationService`：装备配表无回收价目），无「出售价格」可取半，排除。
3. 「1 亿份」= 每物品卖单 `quantity = 100000000`；「出售价格的一半」= `price = sellPrice / 2`。
4. 仅作用于本地回环库（`daohua-local-db`），不涉及生产数据。

## 技术方案

- 新增 `scripts/seed-market-system-listings.sh`（对齐 `migrate-local-db.sh` 的 psql 执行约定与 `--dry-run`）：
  - node 解析配表 → 生成幂等 SQL → `docker exec psql` 单事务执行（无 docker 时回退本机 psql）。
- 系统身份固定 UUID：账号 `f0000000-0000-4000-8000-000000000001`、玩家 `f0000000-0000-4000-8000-000000000002`，
  `login_normalized = system-market@daohua.internal`，随机口令哈希不可登录，道号「系统坊市」。
- 每物品一条 CTE 语句，完整对齐 `PostgresMarketRepository.CommitPlacementAsync` 的落库事实链，
  保证后续成交（`ApplyFillAsync` 要求活动冻结记录）、撤单/到期退款（`CloseOrderCoreAsync`）路径与正常挂单完全一致：
  1. `market.orders`：side=sell、price=sellPrice/2、quantity=1e8、status=active、
     sequence=分区 max+1、幂等键 `system-seed:{assetId}`、有效期 now()+3650 天；
  2. `economy.player_asset_balances`：先注入 1e8 库存（upsert 累加）再冻结扣减至 0；
  3. `economy.transactions` + `transaction_lines`：`system-grant:{assetId}`（+1e8，type=system-grant）
     与 `market-order:system-seed:{assetId}`（-1e8，type=market，request_hash 复刻 `ComputeMarketRequestHash`）；
  4. `economy.reservations`：side=sell、quantity=1e8、reserved_value=0、status=active。
- 幂等性：订单 UUID/流水 UUID/幂等键全部按 assetId 确定性生成，`ON CONFLICT DO NOTHING`；
  重复执行只为缺失品种补挂，已成交/已撤销订单不自动重挂。
- 生效方式：坊市盘口为内存投影（`MarketRuntime` 启动时 `LoadActiveOrdersAsync` 重建），
  落库后重启后端（dev-hot 守护自动拉起）即上架。
