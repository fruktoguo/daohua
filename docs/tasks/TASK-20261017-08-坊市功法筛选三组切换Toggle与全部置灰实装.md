## 2. 需求背景与核心目标

### 2.1 现状与痛点
- 当前坊市（Marketplace）中一级分类选为「功法」时，二级分类仅提供简单的「全部功法 / 秘籍全本 / 招式残卷」三个互斥子 Tab。
- 随着内功心法、五行法术与近战物理功法体系的扩充（共 20 门功法、40 种秘籍全本与残卷标的），玩家无法快速过滤出「只要内功心法」、「只要物理招式」或「只要全本秘籍」等复合维度的标的，选购效率较低。

### 2.2 核心目标与交互规范
1. **三组左右二选一可切换的 Toggle**：
   - 组 1：**术法**（`spell`） vs **内功**（`internal`）
   - 组 2：**物理**（`physical`） vs **法术**（`spell`）
   - 组 3：**全本**（`tome`） vs **残卷**（`fragment`）
2. **最左侧「全部」开关**：
   - 处于激活/勾选态时：所有三组 Toggle 视觉上置灰（`opacity: 0.45` 哑光微光），**但不改变三组 Toggle 当前已经勾选的选项**；网格列表展示全部功法标的。
   - 取消激活/非勾选态时：三组 Toggle 解除置灰，网格列表按三组 Toggle 当前选中的组合进行 `AND` 联合精准过滤。
   - 交互顺畅度提升：在置灰状态下点击任意 Toggle 选项，自动取消「全部」激活状态并选中所点击项，无阻碍平滑过渡。
3. **状态持久化与无损恢复**：
   - 筛选状态（全部开关状态、三组 Toggle 选定值）统一收拢至 `useMarketStore`，切换界面与详情页往返无损记忆。
4. **i18n 词条闭环**：
   - 词条纳入 `market.zh.ts` 与 `template.csv`。
