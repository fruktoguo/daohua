# TASK-20261014-05 物品悬浮坊市行情卡

- 提出时间：2026-10-14 15:38:40
- 完成时间：2026-10-14 17:20:00
- 状态：✅ 已完成
## 需求

物品悬浮气泡（hoverinfo）新增「市场价格」模块：悬浮任何可交易物品时展示该标的当前坊市行情——

- 标题「市场价格」+ 物品名称；
- 最低在售价 与 总在售数量；
- 最高收购价 与 总收购数量；
- 今日成交量、本周成交量；
- 无盘口数据一侧价格显示 `-`。

服务端持续维护一张覆盖全部可交易物品的行情统计表，读取路径必须廉价（禁止每次悬浮实时扫描订单/成交流水）。

## 方案

- **存储**：新增 `market.item_stats`（asset_id + variant 主键）：`best_ask_price`/`ask_quantity`/`best_bid_price`/`bid_quantity` 盘口聚合 + `day_volume`/`day_key`/`week_volume`/`week_key`（UTC 自然日与 ISO 周一开始）+ `updated_at`。行情列随挂单/撤单/到期/成交事务在同一 Serializable 事务内维护：盘口列整簿重算（索引覆盖扫描，单品种行数小），成交列按键惰性换日累加；读侧按 `day_key`/`week_key` 过期掩零，不写库也能跨日归位。schema v32→v33，迁移 `migrations/0033_v32_to_v33.sql`。
- **读取**：`PostgresMarketRepository.LoadItemStatsAsync` + `GET /api/v1/market/stats` 全量小表读取（单行/品种，数百行规模），新增 `MarketItemStatsDto`。
- **前端**：`gameStore.marketStats` 全局缓存（键 `itemId|level`）；`gameClient` 在 HelloAck 连上后启动 15s 前台轮询、断连即停；`ItemDisplay.resolveItemTooltipAsideCards` 追加 `resolveMarketStatsAsideCard` 副卡（仅可交易标的：item.isTradable 或装备变体簿，按 enhancementLevel 命中 "+N" 变体行情）；`market.zh.ts` 新增 `market.price.*` 词条。
- **文档**：`docs/backend/commercial-persistence-architecture.md` 市场表清单补 item_stats 与维护语义；`docs/frontend/common-components.md` 悬浮卡清单补行情副卡。
- **测试**：`tests/Server.Tests/MarketItemStatsTests.cs`——挂单/成交/撤单/跨日回绕的真实 Postgres 断言。
