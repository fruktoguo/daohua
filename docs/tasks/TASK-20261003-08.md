- 提出时间：2026-10-03 16:10:00

- 状态：✅ 已完成（待 UI 目检）

## 需求原文

> 给任务队列展开的最下面，增加几个操作按钮，目前的话，要，暂停和移除全部，暂停不需要确认，移除全部需要二次确认

## 需求澄清结论

1. 「任务队列展开」= 顶栏 `QueueCenter` 展开下拉（`.queue-dropdown`）；「最下面」= 下拉列表底部的整排操作区。
2. 「暂停」= 队列级暂停/继续切换开关（暂停态再按即恢复），点击直接生效不弹确认。
3. 「移除全部」= 一键清空全部队列项，复用 `ConfirmDialog` 二次确认（danger 样式）。

## 设计语义（已落 `docs/design/总纲/02-角色核心与常驻实体设计.md` §2.4.4）

- **暂停（`queuePaused`）**：`PlayerSettingsState` 队列停泊开关，与 `LoopEnabled`/`AutoTravelEnabled` 同族，随 settings 分段持久化与下发。暂停时行动队列整体冻结——计时进度、战斗/搜寻/复活/斗法相位、旅行推进、斗法撮合全部不消费墙钟；队列结构与进度原样保留，恢复后按原进度继续。墙钟资源窗口照常结算（自然回复、Buff 到期、自动使用冷却、暂存物品、道龄、48h 离线截断），与 Blocked「时间照走、行动停走」语义同族。在线与离线补算语义一致。
- **移除全部（`queue.clear`）**：先补算到当前时刻；队首若为斗法按弃战判负（`ApplyDuelForfeit`，与单项移除同语义）；全部实例经统一队列变更管线新 `Clear` 种类归档行动账本、死亡远征恢复最低气血、单次版本提交；`destroyEncounters` 清理队首战斗实体。

## 实现方案

### 协议契约（两端共用）

- `queue.configure` 载荷新增可选布尔 `paused`（与 `loopEnabled`/`autoTravelEnabled` 同校验规则，三键至少一）。
- 新命令 `queue.clear`，载荷仅 `requestId`；空队列返回 `QUEUE_EMPTY`。
- settings 分段 wire 自动携带 `queuePaused`（`PlayerSettingsStateDocument` 新字段，缺省 false 可解码）。
- 存档 schema v7→v8：`SectionCodec.CurrentSchemaVersion`、`PostgresSchema.Version`、前端 `SNAPSHOT_SCHEMA_VERSION`、`check-frontend-contracts.mjs` fixture 同步；`migrations/0007_v7_to_v8.sql` 仅标签推进。

### 后端（domain-dev 子代理）

- `PlayerSettingsState.QueuePaused` + `PlayerAggregate.SetQueuePaused`（`Touch(Settings)`）。
- `PlayerActionQueueMutationKind.Clear` + `PlayerActionQueueRules.Prepare/ApplyStructure` Clear 分支 + `PlayerAggregate.ClearActions()`。
- 引擎拦截：OOP `AdvanceToCore` 跳过行动消费循环；ECS `PrepareQueue` 置 `Waiting`；`SimulationSchedule` 不计行动边界。
- `EcsPlayerRuntimeAdapter`：`queue.configure` 扩展 `paused`、新增 `queue.clear`、`ShouldPersistReceipt` 登记。
- SectionCodec `SettingsDocument` 加 `QueuePaused`；`PlayerStateDocument` 导出/恢复/缓存链同步。
- 后端测试：Domain.Tests（Clear 变更语义、暂停不推进行动）、Ecs.Tests/Server.Tests（命令路径镜像现有队列命令测试）。

### 前端（frontend-dev 子代理）

- `QueueState.paused` + `mapQueue`/settings-delta 合并 `queuePaused` + 初始快照默认 false。
- `useSmoothProgressRef`：paused 时按非 running 冻结插值（覆盖计时/旅行/远征相位全部进度条）。
- `QueueCenter` 下拉底部 `.queue-footer` 操作行：暂停/继续 toggle 按钮 + 移除全部（danger → `ConfirmDialog`）。
- 当前行动卡与下拉激活条目显示「已暂停」徽标。
- i18n `app.queue.*` 新键；`SNAPSHOT_SCHEMA_VERSION` → 8；契约 fixture `schemaVersion` → 8。
