## 需求

用户要求优化斗法属性面板显示：

1. 将「伤害增减」整组放到「特殊」Tab 的最下面；
2. 所有等于默认值的属性不再显示，只显示非默认属性；暴击伤害例外必须保持显示；伤害增减条目同样适用；
3. 「详情」页点击角色/敌怪头像弹出的属性面板同步修改。

## 方案

- `CombatAttributePanel` 为内视斗法 Tab 与 `CharacterAttributeModal`（详情页点击单位头像呼出）共用组件，改一处即两处同步。
- 「伤害增减」独立 Tab 移除，8 个增减伤对条目以 `insight-pill-group` 分组（沿用原 `groupElements` 词条作标题）收在「特殊」Tab 最下面；全默认时整组隐藏。
- 默认值口径：点数类修饰属性默认 0、乘区因子类默认 ×1（100%）；原始数值属性默认 0。判定带 1e-9 容差吸收浮点残差。
- 增减伤对按「增伤/减伤」成对展示，两侧均默认才隐藏，单边非零整对显示。
- 条目渲染由固定 JSX 行改为数据驱动（词条按 `insight.combat.{key}` / `{key}Tooltip` 约定派生），行内全默认时整行不渲染。

## 边界

- 仅前端展示层；不改协议字段与数值口径（TASK-20261007-05 的点数通道重构进行中，字段切换由其完成，本任务结构调整与新模型兼容）。
- i18n：`groupElements` 词条保留作分组标题，无新增词条。
