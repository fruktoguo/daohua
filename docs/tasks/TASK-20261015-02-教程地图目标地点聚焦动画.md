## 需求背景与痛点

在新手引导流程中，涉及多处需要玩家打开大地图并点击指定目标地点的步骤（如从云溪村前往云巅草庐、从云巅草庐返回云溪村，以及玩家不在出生节点时的回村引导）。
在移动端、小屏幕设备或玩家显示比例（Zoom 缩放）偏大时，大地图视口无法一次性完整展示当前地点与较远的目标地点。若视角未处于合适位置，目标地点容易落在屏幕可视区外部，导致玩家无法直接看到高亮指引框与目标节点，无法完成点击交互，造成新手引导卡阻。

### 用户需求

> 当前的教程，点击地图，如果显示比例比较偏大，会导致没法直接看到目标地点，在教程引导里面的点击目标地点的步骤，加个动画，打开地图后先让当前地点居中，然后视角平滑平移切换到目标地点居中，这样就肯定点得到了。

## 技术方案设计

1. **步骤配置增强（`frontend/src/tutorial/steps.ts`）**：
   - 在 `TutorialUiStep` 接口中新增可选字段 `mapFocusNodeId?: string`。
   - 为引导中涉及点击地图目标节点的步骤声明目标节点 ID：
     - `AWAY_PREFIX_HOME`（回村前缀链子步 1）：`mapFocusNodeId: HOME_NODE_ID`（云溪村）
     - 里程碑 3（前往云巅草庐子步 0）：`mapFocusNodeId: 'node.cloud-peak'`（云巅草庐）
     - 里程碑 5（返回云溪村子步 0）：`mapFocusNodeId: HOME_NODE_ID`（云溪村）

2. **全局 UI 引导状态打通（`frontend/src/uiStore.ts`）**：
   - 在 `UiStore` 中新增 `tutorialMapFocusNodeId: string | null` 与 `setTutorialMapFocusNodeId`。
   - `TutorialOverlay.tsx` 在当前引导子步骤变化或退出引导时，将当前 `uiStep.mapFocusNodeId ?? null` 同步至 `useUiStore`。

3. **大地图运镜动画与交互中断（`frontend/src/components/WorldMapPanel.tsx`）**：
   - 监听 `tutorialMapFocusNodeId` 与地图可见性状态。
   - 待地图舞台（`stage`）宽高真实渲染就绪后，计算当前地点世界坐标与目标节点世界坐标在当前缩放比例下的视口平移值（`startPan` 与 `targetPan`）。
   - 执行镜头运镜动画：
     - 第一阶段（0~360ms）：视角立即定格在玩家当前所在地点正中央（当前地点居中），短暂停留给玩家提供起始位置认知；
     - 第二阶段（360~1240ms）：采用经典 `easeInOutCubic` 缓动曲线，视角平滑平移滑行至目标节点居中；
     - 动画结束：目标节点稳稳停留在屏幕中心，处于引导发光光圈内，百分之百可见可点。
   - 交互安全中断机制：若玩家在动画进行期间手动按下鼠标/触摸拖拽地图（`handlePointerDown`）或滚轮缩放（`onWheel`）或点击工具栏，立即调用 `cancelAnimationFrame` 优雅中止动画，控制权实时移交玩家，杜绝冲突。
   - 去重防抖：同一目标节点在同一子步中仅播放一次运镜动画，防止无关重渲染打断玩家漫游。
