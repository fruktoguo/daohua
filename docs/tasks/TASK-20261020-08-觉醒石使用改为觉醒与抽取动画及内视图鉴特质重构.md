## 需求背景与核心设计

1. **觉醒石使用文案“参悟”统一修正为“觉醒”**：
   - 之前觉醒石被当作通用道具处理，在储物袋浮层和确认弹窗中复用了秘籍的“参悟”文案。
   - 现将其修正为明确的修仙专用动作“觉醒”（按钮：觉醒；弹窗标题：觉醒 {name}；确认按钮：确认觉醒）。
2. **觉醒石使用后独立抽取展示界面（弹窗）**：
   - 使用觉醒石（无论 1 个还是批量多个）后，弹出独立的抽取展示弹窗 `AwakenResultModal`。
   - 抽出的特质按长条展示，包含特质名称、品阶边框颜色（白/绿/蓝/紫/金）、数量（如 `×3`）。
   - Hover 时显示完整的特质效果（复用统一的 HoverInfo / 机制浮层）。
   - 多个特质按每秒 5 个（间隔约 200ms）的速度逐个动画弹现。
   - 若特质为首次觉醒（IsNew），右上角展示精致的金色/朱红斜角标 `NEW`。
3. **万象图鉴（CodexPage）增加“特质”分类**：
   - 图鉴顶级 Tab 新增“特质”（trait）。
   - 二级分类按照品阶划分子 Tab（凡品/黄品/玄品/地品/天品，或全部）。
   - 完整展示游戏内所有特质的品阶、消耗、效果与修仙风味。
4. **内视（InsightPage）特质界面深度重构**：
   - 彻底废除旧的独立模态配置弹窗 `TraitConfigModal`，所有配置内联在内视特质面板上直接操作。
   - 顶部：一个容量横条，清晰展示已用点数与容量上限。
   - 中间：【已装备特质】区域，长条展示已装备特质，点击可直接卸下。
   - 下方：【已解锁特质】区域，长条展示所有已觉醒的特质，点击可直接装备。
