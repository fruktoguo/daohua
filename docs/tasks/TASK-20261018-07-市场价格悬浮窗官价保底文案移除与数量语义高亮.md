# TASK-20261018-07 市场价格悬浮窗官价保底文案移除与数量语义高亮

## 1. 任务背景与核心诉求

用户在查看物品悬浮副卡「市场价格」时指出两点体验瑕疵：
1. **系统回收行右侧「官价保底」文案多余**：该四字没有任何业务信息量，纯粹属于占位文本，根据《AGENTS.md》UI 文本简练红线，应彻底移除。
2. **上方盘口数量缺乏高亮与颜色变化**：
   - 目前「在售 1亿」与「求购 0」采用单串文本输出，中文标签与数值混在一起，均为暗淡统一灰度，数字毫无高亮感；
   - 需要对右侧数量进行语义分词，使数值采用专属等宽数字字体、粗体高亮，并与各自盘口方向（在售赤橙、求购碧青）形成协调的色彩联动与状态强弱对比（有量高亮、为0淡化）。

---

## 2. 技术设计方案

### 2.1 结构化重构 (`frontend/src/components/ItemDisplay.tsx`)
- 系统回收行：彻底删除右侧的 `recycleGuaranteed`（「官价保底」）与 `noVendorPrice` 占位标签，保持系统回收价格简洁干净。
- 在售与求购行：
  - 拆分独立为 `daohua-market-aside-stock-chip` 容器；
  - 标签部分 `daohua-market-aside-stock-label`（“在售” / “求购”）；
  - 数值部分 `daohua-market-aside-stock-val`（数值加粗、字体等宽，附带 `--ask` 与 `--bid` 语义修饰及活跃/零量类）。

### 2.2 视觉与样式演进 (`frontend/src/styles/floating-popover.css`)
- 在售数量：
  - 活跃态（`count > 0`）：高亮赤橙色（`#f6bfa8`），带有轻微发光阴影；
  - 零量态（`count == 0`）：弱化暗灰色；
- 求购数量：
  - 活跃态（`count > 0`）：高亮碧青色（`#aae0c2`），带有轻微翡翠发光阴影；
  - 零量态（`count == 0`）：弱化暗灰色；
- 标签文本保持次级调（`rgba(233, 227, 210, 0.55)`），消除以前混成一团的单调感。

### 2.3 i18n 规范收拢 (`market.zh.ts`, `template.csv`)
- 新增 `market.price.askStockLabel: '在售'` 与 `market.price.bidDemandLabel: '求购'`；
- 录入 `frontend/public/locales/template.csv`。
