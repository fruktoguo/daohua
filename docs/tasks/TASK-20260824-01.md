## 2. 需求背景与核心目标

根据用户明确指令：
1. **物品 Hover 浮层展示清理**：
   - 彻底移除物品 Hover 气泡顶部展示的 `来源：xxx`（`subtitle`）。
   - 彻底移除物品 Hover 气泡底部数值统计中的 `产出` 属性（`stats` 中的 `source` 标签项）。

2. **物品与装备材料描述精简为纯背景设定（Lore）**：

   - 所有物品、材料、装备、丹药、消耗品、秘籍与残卷的描述，均统一采用简短凝练、富有修仙意境的纯背景与外观设定描述（如「向阳坡地采伐的百年老木，木质坚致密实，隐泛淡淡纯阳辟邪之意」）。
   - 全面同步更新后端游戏数据配置（`items.json`、`equipment.json`、`GameDataCatalog.cs` 等）与前端多语言词典（`game.zh.ts`、`market.zh.ts`、`ids.ts`、各 fallback 机制等）。
