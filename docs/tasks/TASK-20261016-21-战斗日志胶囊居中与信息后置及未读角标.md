## 需求背景与问题根因分析

1. **怪物悬浮框异常变为椭圆/胶囊形，且日志中怪物名称缺失高亮胶囊**：
   - **根因**：`LogFeed.tsx` 的 `EnemyReference` 在调用 `MonsterTooltipTarget` 时，传入 `className={`log-reference log-reference--${kind}`}`。而 `MonsterTooltipTarget` 直接将其透传给 `FloatingPopover` 的卡片外壳 `className`，而非触发器 `triggerClassName`。导致怪物名称触发器失去胶囊样式，而浮层卡片 `.daohua-floating-card` 继承了 `.log-reference` 的 `border-radius: 9999px`，异常变成巨大的椭圆胶囊。
2. **战斗日志胶囊纵向不居中（明显下沉）**：
   - **根因**：`.log-reference` 与 `.value-capsule` 等行内胶囊设置了 `display: inline-flex; vertical-align: baseline; min-height: 18px;`。在 CSS 规范中，inline-flex 盒子的 baseline 对齐以最后文本基线为准，加上 padding、border 和 min-height 后，盒子视觉中心比行内中文字符中心下沉了 3-4px。
3. **战斗信息文本排版体验欠佳，修饰词前置且为纯文本**：
   - **现有形态**：`你施放 连环，破招暴击 对魔化野兔造成 192.18 点暴击伤害`
   - **重构目标**：伤害统一为 `造成 X 点伤害`，破招、暴击、化解/拆招、闪避等修饰词移至末尾，并用专属修仙微光胶囊高亮呈现，即：`对魔化野兔造成 192.18 点伤害 [破招] [暴击]`。
4. **底部消息日志未读数字角标实装**：
   - **需求**：世界、附近、系统、好友、队伍、宗门及综合分组，在收到未读消息时展示数字角标（如 1、2、99+）。切换至该分组后，未读角标自动清零。战斗分组因高频推进，明确排除在外，不展示未读角标。
