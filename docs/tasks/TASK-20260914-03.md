## 1. 需求与问题背景

用户反馈在打开坊市（Market）的完整列表（一级主 Tab 为「全部」时展示全服 80+ 个可交易物品与装备标的）时，鼠标滚轮在网格列表中滚动出现明显卡顿、跳帧（掉帧至约 20 FPS）。

经过全链路技术剖析，定位到以下四个深层性能瓶颈：

1. **悬浮气泡饥饿式求值 (Eager Evaluation of Popover Content)**：
   - 目前 `MarketBrowseGrid` 中展示 80+ 个标的，每个格子均被 `ItemTooltipTarget` 包裹。
   - `ItemTooltipTarget` 内部在父组件每次 render 时，**无论浮层是否展开（`isOpen === false`），均无条件执行**：`describeItemEffects`、`describeEquipmentEffects`、`resolveItemAsideCards`、`resolveEquipmentAsideCards`、`resolveManualAsideCard`，并立即构建完整的 `FloatingInfoCard` JSX 虚拟 DOM 树（每个格子包含 20+ 个 React 节点，全表累计构建约 2,000 个未展示节点）。
   - `FloatingPopover` 在 `isOpen === false` 时仍无条件执行 `content` 解析，产生严重的垃圾回收（GC Pressure）。

2. **滚动期间的 Hover 事件风暴与强制重排 (Scroll Hover Storm & Reflow)**：
   - 用户在网格上快速滑动滚轮时，鼠标指针静止，卡片高速划过鼠标。
   - 划过的每一个卡片均触发 `mouseenter` 并启动 60ms 定时器；滚轮稍有缓动即达到 60ms 触发 `setOpen(true)`。
   - 气泡展开时触发 `useLayoutEffect` 调用 `getBoundingClientRect()` 并动态挂载 Portal，在滚动动画中引发**强制同步回流 (Layout Thrashing)**，导致瞬间掉帧。

3. **复杂图元全量重绘负担 (CSS Paint Cost & Lack of Viewport Culling)**：
   - 80 个方块包含多层线性渐变、发光外阴影、内阴影、品类丝带 45° 旋转、像素图标滤镜以及伪元素光效。
   - 缺乏现代浏览器原生渲染裁剪（`content-visibility: auto`），导致无论视口内仅有 20 个可见格子，浏览器在滚动每一帧依然对全部 80 个格子的样式树和图层进行全量布局和光栅化。

4. **线性查找与缺乏组件级记忆化 (Linear Scan & Re-render)**：
   - 渲染循环中对每个格子调用 `inventory.find(...)` 进行 O(N) 线性扫描。
   - 未将单个网格单元拆解为 `memo` 组件，背包库存变动或父级轮询时导致 80 个格子全部全量重绘。

## 2. 四层组合优化技术设计

### 方案 1：`FloatingPopover` 与 `ItemTooltipTarget` 懒求值 (Lazy Evaluation)
- 修改 `FloatingPopover.tsx`：仅在 `isOpen && portalRoot` 为真时执行 `content` 求值与 `mergedAsideCards` 构建；未展开时直接返回 `null`，开销彻底降为 0。
- 修改 `ItemTooltipTarget`：将主卡片内容与副气泡解析逻辑抽离为仅在展示时执行的渲染函数。未悬停的 80 个格子只渲染自身方块 `ItemTile`。

### 方案 2：滚动抑制技术 (Scroll Suppression) 消除滚动冲突
- 在 `MarketBrowseGrid.tsx` 的滚动容器上监听滚动事件，滚动发生时给容器添加 `is-scrolling` 类，并在滚动停止 100ms 后解除；
- 在 CSS 中声明 `.market-browse-grid.is-scrolling { pointer-events: none; }`：
  - 滚动过程中鼠标划过不再触发任何 `mouseenter` / `mouseleave` / `setTimeout`；
  - 杜绝滚动期间的气泡误弹和强制回流；
  - 浏览器进入极速纯 GPU 合成滚动通道。
- 将标的网格的 `openDelay` 从 60ms 微调至 150ms，避免极微小的停顿误触发。

### 方案 3：启用现代浏览器原生引擎优化 (`content-visibility: auto`)
- 在 `selection-grid.css` / `styles.css` 中为 `.market-browse-tooltip` 增加：
  ```css
  content-visibility: auto;
  contain-intrinsic-size: var(--item-slot-size) var(--item-slot-size);
  ```
- 浏览器原生跳过视口外 70% 节点的渲染、布局与光栅化，视口内仅维持 20 余个格子的极低开销。
- 滚动容器追加 `contain: paint`，约束重绘边界。

### 方案 4：Map O(1) 索引与单个卡片 `React.memo` 隔离
- 将 `inventory` 预先转换为 `Map<string, number>` 字典映射，查找由 O(N) 降为 O(1)。
- 将每个标的卡片抽离为 `memo(MarketBrowseCardItem)`，按需比对 `itemId`、`selected`、`amount`，彻底杜绝全表 80 格连带重绘。
