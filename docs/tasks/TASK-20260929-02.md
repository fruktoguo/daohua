# TASK-20260929-02 通用待选列表收拢：选择器由全屏模态改为贴槽浮层

- 提出时间：2026-09-29 11:35:22
- 完成时间：
- 状态：🚀 进行中

## 需求

当前物品（`ItemGridPicker`）与功法（`AbilityGridPicker`）选择均为全屏独立模态窗，体验割裂。
改为通用「待选列表」组件：列表可设定「设置目标（锚定槽位）+ 所有列表（候选集）」，
候选瓦片按可用宽度自动判列排布，形态参照参考截图——槽位行保持可见，候选框贴槽浮出，
首格为「移除/空选」。

## 交互裁定（用户确认）

- 弹出形式：**贴槽浮层**——候选框定位在目标槽位附近（上方优先、空间不足自动翻转），
  无全屏遮罩，点击外部 / ESC 关闭，底层界面保持可见可操作。
- 搜索框：**按需出现**——候选数超过阈值（默认 12）时才显示搜索框，短列表不显示。

## 方案

- `FloatingPopover` 新增 `anchorEl` 外部锚点支持：定位、判外点击排除、滚动跟随均以
  外部锚点为准（manual 受控模式复用既有 Portal/翻转/夹持/rAF 重定位管线）。
- 新增 `frontend/src/components/CandidatePicker.tsx` 通用待选列表：
  `anchor`（设置目标）+ `options`（所有列表，`CandidateOption{key,tile,wrapCell,searchText,disabled,ariaLabel}`），
  首格空选、`auto-fill` 自动判列（卡片宽度上限收拢为最多 5 列、网格最多约 4 行滚动）、
  选中即回调并关闭。
- `ItemGridPicker`/`AbilityGridPicker` 收拢为薄适配器：保留物品元数据/装备 tooltip、
  功法 discipline 槽位过滤与参悟等级角标，仅把域对象映射为 `CandidateOption[]`。
- 调用点（App.tsx `AutoUseSlotGroup` + `CombatLoadoutPanel`、`AbilitiesPanel`、`EquipmentPanel`）
  由 `onClick` 事件回传 `e.currentTarget` 作锚点；重复点击同一槽位切换关闭；
  正在设置的槽位加 `is-picking` 高亮。
- 清理孤儿样式：`.item-grid-picker-modal/header/grid/eyebrow` 系列规则随模态退场移除；
  `item-grid-picker-card*/tooltip/empty*` 单元格类继续被候选单元复用而保留。
