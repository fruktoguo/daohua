# TASK-20261005-06 文案风格统一：仙侠韵文 + 游戏化数值两段式

## 背景

用户要求全部玩家可见介绍文案统一为「仙侠韵文首行 + 游戏化具体描述/数值」两段式：诗句或双四字、双五字、单七字等工整句式；技能书完本/残卷需要机制提示（完本可习得、残卷仅增经验且需先习得）。

## 文案规范（本次确立）

### 结构

```
{韵文行}\n{文学散句或功能说明行}
[前端渲染：数值/机制效果行]
```

- 物品悬浮卡：`description`（韵文\n散句）+ `effectLines`（数值）——结构已存在
- 技能悬浮卡：`description`（配表韵文）+ 效果句 + 数值 lines——`describeAbility` 拼接改换行分隔
- 属性 tooltip：对齐六维范本 `力可拔山，势能断岳。\n每点提升 1% 物理攻击…`

### 韵文句式（任选其一，避免连续多条同句式）

- 双四字：`XXXX，XXXX。`（力可拔山，势能断岳）
- 双五字：`XXXXX，XXXXX。`
- 单七字：`XXXXXXX。`（一剑横空贯星斗）

### 风格约束

- 仙侠意象：剑、雷、云、灵、丹、符、罡、太虚、周天等；贴合本体功能
- 韵文行**不出现数值**；数值走散句行或前端效果行
- 忌现代词汇、忌口语、忌连续条目重复同一动词/意象套路
- 原散句可保留微调（文学描述是既有资产）
