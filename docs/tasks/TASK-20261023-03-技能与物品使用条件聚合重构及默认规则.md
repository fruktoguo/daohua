## 1. 需求背景与核心目标

### 1.1 现有架构痛点
1. **观察对象分散割裂**：目前一级下拉将「谁（自身/目标/友方/敌方）」与「单体选择策略（最低生命/最高生命/全体）」扁平混在了一起（如 `ally-lowest-hp`、`enemy-highest-hp` 等），选项冗长且逻辑不自洽。
2. **缺乏实体特征感知**：无法感知目标或场上单位是否为「玩家」、「精英」、「妖王」或「召唤物」，导致无法针对特定强敌或召唤小怪制定战术。
3. **缺乏队伍大盘感知与战斗时钟**：无法根据「友方/敌方总生命百分比/总灵力百分比」施放群体抬血或斩杀，且缺少「战斗时间（秒）」时钟控制。
4. **默认条件缺失与重置体验不足**：目前大部分技能无合理默认触发条件或规则生硬；玩家修改后无法一键「重置为出厂默认条件」。

### 1.2 改造目标
1. **观察对象聚拢为 5 大维度**：
   - `self`（自身）、`target-enemy`（目标）、`ally`（友方）、`enemy`（敌方）、`battle`（战场）。
2. **判断属性分层与扩展**：
   - **单体属性**（自身/目标）：生命/灵力数值与百分比、Buff层数、是玩家 (`is-player`)、是精英 (`is-elite`)、是妖王 (`is-boss`)、是召唤物 (`is-summon`)。
   - **群体大盘与极值**（友方/敌方）：总生命百分比 (`total-hp-percentage`)、总灵力百分比 (`total-mana-percentage`)、最低生命百分比 (`lowest-hp-percentage`)、最高生命百分比 (`highest-hp-percentage`)、存活数量 (`alive-count`)、总数量 (`total-count`)、阵亡数量 (`dead-count`)、有玩家 (`has-player`)、有精英 (`has-elite`)、有妖王 (`has-boss`)、有召唤物 (`has-summon`)。
   - **战场全局**（战场）：战斗时间 (`elapsed-seconds`)。
3. **出厂默认触发条件规约**：
   - **伤害类技能**：默认为 `目标 当前生命 > 1`（攻击活着的目标）。
   - **Buff 类技能**：默认为 施加对象身上该 Buff `状态层数 == 0`（避免重复释放浪费）。
   - **治疗类技能**：默认为 `友方 最低生命百分比 < 75%`（血量较低时急救）。
   - **物品（消耗品）**：不配置默认条件，默认为空 `[]`（受冷却控制，无条件恒可用）。
4. **编辑器支持「重置为默认」**：
   - `CombatTriggerEditor` 增加「重置为默认」功能，从技能或物品出厂默认规则恢复。

## 2. 详细技术方案

### 2.1 领域模型 (`src/Domain/Combat/`)
1. **`CombatantState` 扩展**：
   - 增加 `bool IsSummon { get; set; }`（是否为召唤物）；
   - 增加 `bool IsPlayer => !string.IsNullOrEmpty(Id) && Id.StartsWith("player", StringComparison.Ordinal);`；
   - 增加 `CombatMonsterRank? Rank`（或通过 DefinitionId 映射，指示 Minion/Elite/Boss）。
2. **`SkillTriggerEvaluator` 校验与求值矩阵更新**：
   - `Matches` 签名接收 `double elapsedSeconds`；
   - 扩充依赖词表：`self`, `target-enemy`, `ally`, `enemy`, `battle`；
   - 兼容平滑读取旧值或直接规范化；
   - 增加 `total-hp-percentage`、`total-mana-percentage`、`lowest-hp-percentage`、`highest-hp-percentage` 求值；
   - 增加 `is-player`、`is-elite`、`is-boss`、`is-summon` 及 `has-*` 求值；
   - 增加 `elapsed-seconds` 比较。
3. **配表出厂默认生成 (`GameDataCatalog.cs` / `abilities/*.json`)**：
   - 根据技能 `effectType`（heal / buff / damage）及配表，自动补齐或标准化 `defaultTriggers`；
   - 消耗品保持 `triggers: []` 或 null。

### 2.2 前端模型与组件 (`frontend/src/`)
1. **类型定义 (`types.ts`)**：
   - 更新 `CombatTriggerDependency`、`CombatTriggerCondition`、`CombatTriggerComparator`。
2. **条件编辑器 (`CombatTriggerEditor.tsx`)**：
   - 对象选择器：自身、目标、友方、敌方、战场；
   - 二级判断属性根据对象动态联动；
   - 比较器与阈值根据是否为布尔类型动态切换；
   - 底部操作栏增加「重置为默认」按钮，接收 `defaultTriggers?: CombatTrigger[]` 回调。
3. **文本描述器 (`format.ts`) 与 i18n (`game.zh.ts`, `combat.zh.ts`)**：
   - 补齐所有新增条件、比较器和对象的中文翻译与自然语言拼接模板。
4. **前端模拟器 (`expeditionSimulator.ts`)**：
   - 同步对齐求值器逻辑，确保战斗模拟器确定性。
