# TASK-20260823-06: 通用地图架构、生物（NPC/怪物）与预算遇怪机制设计

## 1. 任务背景与核心需求

用户提出对大地图和遇怪架构的整体设计原则与规约：
1. **去纯战斗地图化，全面转为通用世界地点（Generic World Nodes）**：
   - 游戏不存在孤立的“纯战斗副本”，所有地图均是承载修仙世界行为与生态的通用地点。
   - 地点内聚合两类生物（Creatures）：**NPC**（承载任务、传授技能，当前结构预留行为留空）与 **怪物（Monsters）**（历练遇怪）。
2. **地图配置与展示**：
   - 地图配置该地点可能遭遇的怪物列表与危险度（Danger / Hazard Rating）。
   - 地图 UI 明确向玩家展示该地点的怪物生态、掉落、以及驻留 NPC。
3. **基于质量/战力预算的遇怪生成机制（融合灵狐 Quality 算法）**：
   - 怪物配置 `budgetCost`（单体消耗预算 / 质量点数）。
   - **地图无独立危险度评级字段，危险度本身即为 `[minBudget, maxBudget]` 预算区间**。
   - 地图可独立配置精英遭遇周期（如 `eliteInterval: 5`）与 Boss 遭遇周期（如 `bossInterval: 20`）。
   - 遇怪生成采用预算随机扣减算法（循环抽取并扣减 `remainBudget`，连续 3 次超限则停止）。
