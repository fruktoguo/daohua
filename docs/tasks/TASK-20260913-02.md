## 配套改动

| 文件 | 改动 | 原因 |
| :--- | :--- | :--- |
| `.dockerignore` | 新增 `art` | Dockerfile 本来就只 `COPY frontend/ src/ config/game-data/ vendor/YuoCore/src/`，`art/` 不会进镜像；加进忽略表是为了**减小发送给 daemon 的构建上下文**（约 13MB 美术资源） |
| `.gitattributes` | 新增 `*.png binary`、`*.webp binary` | 原文件只有 `* text=auto eol=lf`。首次纳入二进制美术资源，显式声明为 binary，杜绝被当文本做行尾转换而损坏的可能 |

`art/` **纳入 Git 版本管理**：它是美术源与工程母版，属于代码资产而非运行数据，
不适用 AGENTS.md 里 `data/`（运行数据，不进镜像、不进 Git）的排除规则。
