## 3. 核心风险与缺陷排查汇总

### 3.1 严重级别风险 (Critical P0/P1)
1. **[市场与存储] 市场落盘异常导致不可逆的内存-数据库状态分裂（丢资产/双花）**
   - 定位：`GameHost.cs:L717-L733`、`PostgresStores.cs:L840-L865`
   - 根因：`Coordinator.Place` 先在内存扣减玩家资产并撮合，若后续 `CommitAsync` 发生 CAS 冲突抛出 `MarketLedgerConcurrencyException` 时无捕获与回滚，内存状态永久脱轨。
2. **[存储与持久化] Durable Outbox 缺乏快照合并与 autovacuum 优化，导致表严重膨胀与 WAL 放大**
   - 定位：`PersistenceDispatcher.cs:L71-L121`、`PostgresStores.cs:L231-L241`
   - 根因：未合并同一玩家多条高频快照；Outbox 表频繁 INSERT+DELETE 产生巨量 Dead Tuples 且无针对性 vacuum 配置。
3. **[前端与网络] WebSocket Delta 增量包缺失版本连续性校验，丢包引发幽灵状态**
   - 定位：`gameStore.ts:L293-L296`
   - 根因：仅判断 `patch.version < state.version`，未校验 `patch.version === state.version + 1`，发生断层时盲目合包。
4. **[前端与时间] CombatArena 时钟偏移阈值随自然时间流逝翻转，导致行动条 5s 突变回退至 0%**
   - 定位：`CombatArena.tsx:L206-L211`
   - 根因：`serverTimeUnixMilliseconds - Date.now()` 随挂机时间推移超过 5000ms 门限，导致时间模式瞬间翻转，进度条 Snap-back 抽搐。
5. **[前端与网络] 弱网环境 2000ms 启发式失效导致无限死循环重连，且重连定时器未清理泄露并发 WS**
   - 定位：`gameClient.ts:L150-L164`
   - 根因：依赖高延迟不可靠的时间差判断认证失败；多入口调用导致挂起定时器新建多个并发 WebSocket 连接。
6. **[领域与调度] MaxTransitionsPerAdvance = 2,000,000 极端离线在单 Fiber 连续同步推演阻塞 Shard**
   - 定位：`SystemConstants.cs:L38`、`SimulationEngine.cs:L952-L1364`、`GameHost.cs:L1203-L1247`
   - 根因：大跨度离线推演无步数配额和时间片中断，单次可能独占 CPU 数十秒，造成同 Shard 其他玩家断网卡顿。
7. **[配表与经济] 寻灵香与地火引配置错位导致持续消耗品 6 秒被当成即时药水扣除（消耗暴增 20 倍）**
   - 定位：`config/game-data/items/pills.json:L78-L120`
   - 根因：`durationSeconds` 错填入 `buffs[0]`，解析为 0 耗时持续药水，每次动作完成均扣除 1 个，10 分钟耗光原本挂机 8 小时的存量。
8. **[配表与校验] GameDataCatalog.Validate 漏检普通行动 DurationSeconds <= 0**
   - 定位：`GameDataCatalog.cs:L243`、`SimulationEngine.cs:L1074-L1081`
   - 根因：仅校验 `< 0`，未限制非战斗行动 `> 0`；若为 0 会退化为 1ms 碎片推进，瞬间产生百万次空转。
