- 提出时间：2026-11-10 18:14:11

- 需求：为自动消耗品增加同一物品允许占用的自动使用槽数量配置。配置值缺省或为 `0` 时，同一物品只允许占一个槽；配置正整数时，最多允许占用该数量的槽。
- 特例：定神香与青灵香配置为 `3`。

- 作用边界：只约束槽位重复占用，不改物品效果本身的叠加结算、单槽持续时间、扣件与冷却语义。
