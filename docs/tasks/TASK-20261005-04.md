## daojie 参考实现调研（样式与机制摘要）

`daojie-yusheng` 的新手引导是**两层结构**：

### 1. 步骤式导览层（guided tour 遮罩引导）

- 配置驱动：`constants/ui/guided-tour.ts` 中 `GUIDED_TOUR_FLOWS` 常量数组，共 25 条引导流，分 4 类（核心操作 11 / 战斗引导 3 / 技艺引导 5 / 玩法引导 6）。
- 每条流：`id`、`category`、`storageVersion`（升版本号可让已完成玩家重看）、`autoStart`（仅 `starter-basics` 自动播放）、i18n 标题/摘要 + steps 数组。
- 每步：`targetSelector` + `mobileTargetSelector`（CSS 选择器定位高亮目标）、`placement`（auto/top/right/bottom/left）、`advanceMode`（`next` 按钮推进 | `target-click` 点目标本身推进）、`prepare[]` 预动作。
- `prepare` 预动作三类：`switch-tab`（切面板页签）、`set-layout-collapsed`（展开左右/底部栏）、`click`（模拟点击某 selector），可按 `when: mobile|desktop` 分端执行——保证高亮目标先被渲染出来再量位置。
- 运行时 DOM：fixed 全屏层（z-index 3600），四块半透明遮罩 `rgba(12,10,8,0.58) + blur(1px)` 围住目标外扩 8px 的矩形；高亮框 = 朱红 2px 描边 + 白描 + 外发光 + 投影，带脉冲动画。
- 气泡卡：kicker（流程名红色小字）+ 步骤标题 + 正文 + 进度条（n/m）+ 按钮行（跳过 / 上一步 / 下一步·完成）；箭头是 14px 旋转方块指向目标。
- 定位算法：按 preferred→bottom→top→right→left 顺序尝试空间是否容纳卡片，clamp 到视口；目标 `scrollIntoView`；resize/scroll/MutationObserver 触发重定位。
- 交互：`target-click` 步骤点击高亮目标**真实触发该 UI**（边教边做）；普通步骤点击目标被吞掉并推进；点遮罩触发高亮脉冲提示；Esc 跳过。
- 持久化：`localStorage["mud:guided-tour:v1"]` 记 `completed`/`dismissed` 版本映射。
- 解锁：`guided-tour-unlock.ts` localStorage 集合，默认解锁 5 条基础流，其余随任务推进解锁；百科面板中未解锁流折叠展示「任务解锁」。
- 触发入口：HUD 按钮 → 百科弹窗引导页；`GUIDED_TOUR_START_EVENT` CustomEvent 供任意 UI（如任务面板「开始引导」按钮）请求播放；autoStart 流在 game-shell 可见后约 650ms 自动播放。
- 调试：`window.__guidedTour = { start, reset, status }`。

### 2. 机制百科面板（TutorialPanel）

- 「仙途指引与百科」大弹窗（约 1180px × 68dvh），顶部全文搜索栏（跨引导步骤文案与百科词条，命中 `<mark>` 高亮）。
- 左侧竖排一级分类：核心操作 / 战斗引导 / 技艺引导 / 玩法引导 / 机制百科。
- 引导分类页：已解锁流卡片（分类色标签 + 标题 + 步数 + 摘要 + 「▶ 开始引导」），未解锁折叠区。
- 机制百科：二级 tab + 章节卡片 + 要诀提示卡；内容真源为 `docs/tutorial-mechanics.md`，脚本生成 `tutorial-mechanics.generated.ts`（含境界表虚拟条目直读共享配置）。
- 正文中功能词渲染为胶囊 inline action，hover/点击浮出该功能在 UI 中的路径提示（如「[左上角->坊市]」）。
- 视觉基调：纸面渐变底 + 朱红印章色强调 + 细墨描边 + 4px 硬阴影；移动端页签收窄为竖排文字。

## 与 daohua 的差异点（初步）

- daojie 引导层是**纯 DOM 命令式**实现；daohua 是全 React（React 19 + zustand），引导层宜做成 React 组件 + `uiStore` 联动。
- daojie 的 prepare 动作依赖其自研 `switchTab`/`setLayoutCollapsed` 控制句柄；daohua 对应物为 `useUiStore.setActiveTab` 与各页内 sub-tab 状态。
- daohua 布局不同（左侧主导航 Tab + 中央内容区 + RightSidebar + 底部日志），引导流的 targetSelector 需按现有组件补 `data-tour` 锚点。
- 设计文档 `docs/design/总纲/` 尚无新手引导设计章节，按「文档先行」需先落设计再实现。

## 实现摘要

设计真源 `docs/design/总纲/22-新手引导系统.md`。最终交付形态：

- **七环里程碑**：采集凝血草 → 赠炼丹材料（凝血草×3）→ 炼引气丹 → 赠炼器材料（百炼铁×7、兽骨×1）→ 锻青锋剑 → 旅行云巅草庐 → 引气入体一轮 → 旅行回云溪村 → 讨伐完成一轮 → 终奖 `item.gongde`×1000 + `currency.spirit-stone`×10000。
- **服务端权威**：`PlayerSettingsState.TutorialStep`（settings 分段，schema v14）持久化；推进器 `TutorialRules` 挂在行动轮结算、旅行到达、讨伐波次清空三边界；赠送/终奖经资产增量通道与行动产出同一事务入账；`tutorial.skip` 命令置终态不发奖。
- **前端 React 化**：`TutorialOverlay` 遮罩四块 + 金色高亮框 + 气泡卡（kicker/标题/正文/进度/跳过/上一步/下一步/Esc），button/target/server 三种推进模式，prepare 动作驱动真实 UI（切页签/展开技艺菜单/选子页签）；`data-action-id`、`data-tour` 锚点；完成卡用 `ItemReference` 展示奖励。
- **版本链修复**：`SectionCodec`/`PostgresSchema` 对齐 v14，`0013` 邀请迁移补齐存档标签推进，`SNAPSHOT_SCHEMA_VERSION` 与契约脚本同步 14，测试种子 SQL 补 `invite_code`。
