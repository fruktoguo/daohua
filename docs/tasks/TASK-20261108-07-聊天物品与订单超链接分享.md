## 1. 需求背景与核心理解

用户提出对传音聊天系统的深度交互优化：
1. **物品超链接分享**：所有物品（包含普通消耗品、材料、功法残卷、秘籍以及装备）均可在背包（储物袋）或装备栏一键「分享/发送到聊天」；
2. **装备强化等级透传**：若被分享的是装备，超链接文本与详情展示必须带上其实际强化等级（如 `[赤血剑 +3]`），并在悬浮/点击时以现有修仙风物品详情卡（`ItemTooltipTarget`）完整展示强化后属性与成长倍率；
3. **自身订单超链接分享**：在坊市（市场）个人活跃挂单列表中，自身发布的【求购】或【挂售】订单均可一键「分享/发送到聊天」；
4. **订单方向与数量信息完备**：订单超链接必须明确显示买卖方向（【求购】/【挂售】）、物品名称（带强化等级）、挂单单价与数量（如 `[求购: 凝血草 x50 @5灵石]` 或 `[挂售: 赤血剑 +3 x1 @120灵石]`）；
5. **交互联动（超链接行为）**：
   - 聊天消息正文中超链接具有明显的视觉胶囊样式（颜色、图标、悬浮下划线）；
   - 物品超链接：悬停或点击弹出物品悬浮卡；
   - 订单超链接：悬停或点击展示订单信息卡，并支持点击直达坊市该物品交易盘口；
   - 发送时支持将标记插入聊天输入框，允许玩家附带发言文本（或一键快速发送）。

## 2. 方案设计与技术边界

### 2.1 标记语法与数据协议设计（自包含、轻量、无需破坏历史）
采用正文行内结构化标记（Inline Markup），不破坏现行数据库存储结构与 WebSocket 广播信封，支持文字混排：
- 物品超链接标记：`{{item:itemId:enhancementLevel}}`
  - 示例：`{{item:equipment.sword-01:3}}` -> 渲染为行内 `ItemReference` 胶囊，名称显示为 `赤血剑 +3`，带有强化等级悬浮属性。
- 订单超链接标记：`{{order:orderId:side:itemId:enhancementLevel:price:qty}}`
  - 示例：`{{order:ord-123:buy:item.herb-01:0:5:50}}` -> 渲染为买单徽章胶囊，标明 `求购: 凝血草 x50 @5`，点击可打开坊市。
- 纯文本降级与兜底：若接收端遇到无法识别的标记，降级为友好纯文本展示；富文本标记在解析时具备严格字段数校验与安全防御。

### 2.2 交互入口与触发链路
1. **储物袋 (InventoryItemCell)**：物品左键弹出菜单中新增「分享到传音」操作；
2. **装备栏 (EquipmentPanel)**：已穿戴装备槽点击或浮层菜单中增加「分享到传音」操作；
3. **坊市我的订单 (MarketOwnOrders)**：活跃挂单列表每项右侧增加「分享」按钮；
4. **调度中心 (chatComposerService / chatService)**：
   - 点击分享时，将对应格式的 `{{item:...}}` 或 `{{order:...}}` 插入当前聊天输入框，聚焦输入框并将光标移至末尾，玩家可直接按回车发送或输入补充留言；
   - 若聊天面板未展开或处于收起状态，自动呼出传音面板。

### 2.3 渲染体系 (LogFeed / ChatRow / ChatMessageRenderer)
1. 封装 `ChatMessageContent` 富文本解析器，将包含 `{{item:...}}` 和 `{{order:...}}` 的字符串解析为 React 节点片段；
2. 物品超链接复用 `ItemReference`，传入解析出的 `itemId` 与 `enhancementLevel`；
3. 订单超链接渲染带有方向徽章（碧青 `求购` / 琥珀金 `挂售`）、物品图标与单价数量的复合胶囊，集成悬浮详情并绑定点击跳转坊市盘口逻辑。
