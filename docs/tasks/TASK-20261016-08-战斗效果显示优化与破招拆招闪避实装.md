## 2. 问题根因分析

1. **血条浮起碎裂切片层级跳变盖过文字**：
   - `ArenaResource` 组件中，数值文字徽标 `.arena-resource-badge` 嵌套在 `.arena-resource-track` 内部；而 `.arena-resource-track` 声明了 `transform: skewX(-20deg)` 样式属性，根据 CSS 规范会建立独立的层叠上下文（Stacking Context）。
   - 碎裂血条切片容器 `.arena-resource-shards`（`z-index: 3`）为 `.arena-resource-track` 的兄弟节点，层叠等级直接压过整个 `.arena-resource-track` 及其内部的一切子元素。
   - 当受到大额伤害触发血条切片浮起动画时，`.arena-resource-slice` 在生成瞬间以完全不透明的明亮切片直接覆盖下层的血量数字，且在切片动画结束或被清理时血量数字突兀暴露出，造成明显的层级跳变与文字被遮挡缺陷。
2. **破招、拆招、闪避战斗效果无正确显示**：
   - 领域层 `DeterministicCombatEngine.ResolveHit` 与 `CombatActSystem` 具备完整的破招（`broken`）、拆招（`parried`）、闪避（`!hit`）、暴击（`critical`）对抗逻辑并产生 `CombatEvent`。
   - 但在服务端与协议侧，单人及组队讨伐战斗在推进后，`expedition` 状态载荷未向下携带该步进产生的事件明细（`recentEvents`），斗法回放事件 `DuelScriptEvent` 亦丢弃了 `broken` 和 `parried` 标签。
   - 战斗日志生成器 `AppendCastClause` 对未命中仅记录「对XXX未命中」，未区分闪避，且完全未体现破招与拆招前缀。
   - 前端战场 `ArenaResource` 与 `ArenaActor` 仅在气血发生绝对差值时播放受击与掉血浮字；当发生「闪避」时血量无变化，前端完全没有任何浮字与受击/闪避动作，导致普攻或技能落空时画面毫无反应，「看起来就像卡了一样」；发生破招与拆招时也仅显示普通掉血数字，缺乏关键博弈反馈。

## 3. 实施方案

### 3.1 领域与服务端改造
1. **`src/Domain/Combat/CombatModels.cs` 与 `src/Domain/Combat/DuelModels.cs`**：
   - `CombatExpeditionState` 增加 `RecentEvents` 列表属性，承载当前步进产生的战斗事件。
   - `DuelScriptEvent` 增加 `bool Break = false, bool Parried = false` 字段。
2. **`src/Ecs/Combat/DuelScriptEngine.cs`**：
   - 撮合推演生成 `DuelScriptEvent` 时透传 `combatEvent.Break` 与 `combatEvent.Parried`。
3. **`src/Ecs/Systems/CombatActionRules.cs` 与 `src/Ecs/ActionParticipationSessionEngine.cs`**：
   - 战斗切片推进时将 `combatResult.Events` 存入 `updatedBattle.RecentEvents`。
   - 技能战报子句收集器 `AppendCastClause` 补充 `critical`、`broken`、`parried` 标识，未命中改为「被{target}闪避」，伤害前缀补充「破招」「拆招」与「暴击伤害」。
4. **`src/Server/Clean/ProtocolSnapshotMapper.cs`**：
   - `ToExpeditionDto` 映射 `recentEvents`（`at`、`attackerId`、`targetId`、`damage`、`hit`、`critical`、`broken`、`parried`、`abilityId`）。
   - `ToDuelPlaybackDto` 透传 `broken` 与 `parried`。

### 3.2 前端改造
1. **`frontend/src/game/types.ts` 与 `frontend/src/network/snapshot.ts`**：
   - `ExpeditionProgress` 声明 `recentEvents?: CombatRecentEvent[] | null` 并完成快照解码。
   - `ExpeditionDuelEvent` 声明 `broken?: boolean, parried?: boolean` 并完成快照解码。
2. **`frontend/src/styles/expedition.css`**：
   - 规范化血条层叠上下文：`.arena-resource-track`（`z-index: 1`）、`.arena-resource-shards`（`z-index: 2`）、`.arena-resource-badge`（`z-index: 4`）、`.arena-resource-floats`（`z-index: 5`），消除遮挡跳变。
   - 新增浮字与徽标样式：`.arena-resource-floats em.is-dodge`（水绿）、`.arena-resource-floats em.is-break`（琥珀橙）、`.arena-resource-floats em.is-parry`（银蓝）、`.arena-resource-floats em.is-crit`（道金）、`.arena-float-badge`。
   - 新增单位闪避敏捷身法动画：`@keyframes arena-actor-dodge` / `.arena-actor.is-dodging .arena-avatar-stage`。
3. **`frontend/src/components/CombatArena.tsx`**：
   - 将 `.arena-resource-badge` 移出 `.arena-resource-track`，置于 `.arena-resource-meter` 顶层，彻底解决层级跳变。
   - `ArenaActor` 与 `ArenaResource` 消费单位对应的 `recentEvents` 与斗法回放事件，正确触发「闪避」（含闪避身法动画）、「破招」、「拆招」、「暴击」浮字与受击/闪避反馈。
4. **`frontend/src/i18n/domains/combat.zh.ts`**：
   - 补充 `dodge`、`break`、`parry`、`crit` 词条并同步模板 CSV。
