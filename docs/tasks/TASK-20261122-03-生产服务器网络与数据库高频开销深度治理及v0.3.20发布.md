## 一、问题定位与治理目标

1. **ECS 强化暂存泄漏与 ComputeNode 载荷上限错配**
   - `PlayerActionQueueReportArchiveSystem` 遗漏 `MarkEnhancementCompleted`，导致 ECS 行动出队后 `StagedEnhancements` 记录长期保持 `IsCompleted = false`、前端无法 Ack 清理；
   - 存量角色如 `元真初` 的 `progression` 分段已膨胀至 `588,432` 字节（2,029 条未完成记录），超出 `ComputeContract.MaxPayloadBytesPerSection`（`512 KB`），引发冷挂机任务 `dead`；
   - 修复：补齐 ECS 出队完成标记、在 `CreatePlayer` 对历史孤儿记录自动补标完成并按 `MaxStagedEnhancementRecords = 256` 裁剪已完成记录；将 `ComputeNode` 解压上限对齐 `SectionCodec.MaxRawBytes`（4 MiB）。

2. **在线组队会话 50ms 数据库读写风暴**
   - 后台 `PlayerSimulationHostedService` 贴着 `50ms` 步进时，每轮无条件调用 `ActionParticipationRuntime.AdvanceOnlineAsync` → `ListActiveAsync` 扫库拉取完整 `party_sessions` JSONB，同时每轮对成员调用 `LoadPendingAsync` 与 `GetPartySessionAsync` 导致每秒上百次无效 SQL 与 `section_flush_queue` 写入；
   - 修复：为 `AdvanceOnlineAsync` 增加贴 `NextVisibleBoundaryUtc` 自然边界跳过半途空切片、1 秒子秒空转去抖、`(sessionId, Version)` 检查点与边界缓存、成员空收件箱世代去抖，以及 `ReconcileParticipationOwnedAsync` 会话规格复查节流与复用。

3. **公网 WebSocket 出站高带宽占用**
   - 玩家 `/ws` 通道原未开启 `permessage-deflate` 压缩，且 `ProtocolSnapshotMapper` 对 `progression.ageSeconds` 直接输出精确小数导致同秒多次战斗触发整个 `progression` 分段重复下发；
   - 修复：在玩家 `/ws` 启用 `permessage-deflate`（`ServerMaxWindowBits = 12`），协议投影层将 `ageSeconds` 向下取整为整秒（不改动领域状态）。

4. **宿主机杂项清理与发布验证**
   - 清理旧名残留 `daojie-ccr-auto-update.service` failed 单元；
   - 全量门禁 `verify.sh --full` → 原子化提交推送 → `release-prod.sh --skip-odin` 发布至 `yuohira` → 发布后即时验证 + 多轮稳态监控对比前后指标。
