### 3. 运行时语义对齐修复（本轮排查发现）

| 缺陷 | 根因 | 修复 |
| --- | --- | --- |
| 自然边界死循环（多人推进超 `MaxTransitionsPerAdvance`） | double 剩余预算残留亚 `DateTimeOffset` tick（~1e-7s）残差→`NextBoundaryAt` 量化回落同一时刻→零步长不动点 | `EcsActionPipeline`：`frameTarget>=NextBoundaryAt` 时按 `min(remaining,needed)` 直接消费（去掉量化差值二次限幅）；`CompleteClock` 对 `frameTarget>=windowEnd` 的 ≤1μs 残差归零 |
| 空闲玩家收到快照 delta | 推送条件未对齐 OOP `Simulation.Changed` | `AdvanceAllAsync` 仅 `simulation.Changed==true` 时推快照（日志仍按原语义） |
| `TouchedSections=null` | `HashSet` 差集漏记"已脏段再次触及" | `PlayerIdentityComponent.DirtyMarks` 按段流水号 + `TouchedSectionsSince` 差集（镜像 `PlayerAggregateState.DirtySectionMarks`，不回退） |
| `WireAttributesChanged` 恒 false | `MutatePlayer` 文档往返把 `VersionedList` 计数器重置为恢复基线 → `InputRevision` 恒定 | 修订号续写：`ApplyAggregateState` 直传聚合实例重载（跳过二次文档往返）+ `prev+(post−baseline)` 续写 `RestoreRevisionCounters`/`RestoreVersion`（`InternalsVisibleTo("DaoHua.Ecs")`）；适配器 `_attributeRevisions` 跟踪 |
