# TASK-20261015-08 装备特殊属性显示规范化：威胁增幅与特殊加成统一胶囊格式并对齐内视口径

## 任务背景与用户反馈

1. **用户核心反馈**：
   - 优化装备的属性显示，当前的威胁值提升不太对。
   - 当前威胁提升属性写的是“额外威胁值加百分之多少”（如 `[额外威胁值 +15%]` 单个大胶囊），没有按照通用格式（即上面的属性名称胶囊对应加多少多少，例如 `[物理减伤] +2%`）。
   - 前面的属性名称应和内视（内饰）的特殊属性名称保持一致（内视中为 `威胁增幅`）。
2. **根因排查**：
   - `frontend/src/components/ItemDisplay.tsx` 的 `POINT_STAT_LABELS` 中，`threatBonusPoints` 与 `healingBonusPoints` 配置为了模板型词条 `market.effect.threatBonus`（`额外威胁值 +{n}%`）与 `market.effect.healingBonus`（`额外治疗提升 +{n}%`）。
   - 在 `describeEquipmentEffects` 中判定 `isTemplate = point.label.startsWith('market.effect.')` 为真，导致整句话作为 `label` 塞进了 `PillBonusLabel` 的标题胶囊内部，而数值部分 `value` 置空，破坏了「属性名微胶囊 + 专属色彩下划线数值」的统一排版。
   - `market.stat` 词典中缺少 `threatBonus` 与 `healingBonus`，而内视域 `insight.combat` 中标准词条正是 `威胁增幅` 与 `治疗增幅`。
3. **改造目标**：
   - 补充 `market.stat.threatBonus: '威胁增幅'` 与 `market.stat.healingBonus: '治疗增幅'`，对齐内视属性面板标准术语。
   - 将 `ItemDisplay.tsx` 中 `POINT_STAT_LABELS` 的 `threatBonusPoints` 与 `healingBonusPoints` 迁移至 `market.stat`，不再走模板整句渲染，自动恢复为标准 `[属性名胶囊] +数值%` 格式。
   - 完善 `STAT_TONE_MAP` 对应色系（`threatBonus` / `threatBonusPoints` 为 `crimson`，`healingBonus` / `healingBonusPoints` 为 `violet`）。
   - 自动同步至 `template.csv` 并通过前端构建与各层门禁验证。
