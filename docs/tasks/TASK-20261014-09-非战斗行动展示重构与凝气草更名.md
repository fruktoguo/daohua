# TASK-20261014-09 非战斗行动展示结构重构、速度加成文案与凝气草更名

## 1. 任务背景与核心需求

### 1.1 需求说明
1. **加成展示语义优化**：现在的非战斗行动（如炼丹、采集、挖矿等）耗时加成显示为「炼丹 耗时 -5%」，容易引发玩家误解（实际机制为行动速度提升，如技艺等级每级 +5% 速度）。统一将加成由「耗时减少」改为「速度增加」（如「炼丹 速度 +5%」、「公共建筑 速度 +12%」）。
2. **物品全量更名**：道具「凝血草」更名为「凝气草」，除显示名外所有标识（如 `item.ningxue-grass`、`explore.gather-ningxue-grass`）及配方与数值其他保持不变。
3. **所有非战斗行动展示结构重构**：非战斗行动弹窗（`ActionModal`）统一规范为五大核心栏目：
   - **消耗**：行动所需物品与材料，无消耗显「无」。
   - **产出**：所有产出物品，以及修炼行动的「灵力」产出（修炼灵力归入产出，其他按物品判定），无产出显「无」；若有产出倍率加成在此处呈现。
   - **感悟**：所有经验与修为类收益（基础修为经验、六维根基经验），并且行动若具有归属生活技艺（采集、挖掘、炼丹、炼器等），必须明确注明获得的对应技艺经验（入账点数等于当轮基础耗时秒数，如采摘凝气草 8s 获得「采集技艺经验 ×8」）。
   - **耗时**：单轮耗时秒数，并内嵌对应的「速度加成」徽标（如「炼丹 速度 +5%」）。
   - **次数**：循环轮次选择器（QuantitySelector，支持无限循环与预设倍率）。

### 2.3 非战斗行动五段式结构重构
- 修改文件：`frontend/src/App.tsx` 中的 `ActionModal`
- 结构清晰分为：
  1. **消耗**（dt: 消耗）：材料列表 `inputs`，空时显 `无`；
  2. **产出**（dt: 产出）：物品列表 `yieldPreview.itemOutputs`、灵力收益（`mana` 类 resourceYields）、Buff 收益（若有）；若有产出倍率加成在此处呈现；
  3. **感悟**（dt: 感悟）：修为收益（`experience` 类 resourceYields）、六维经验（`rootExpYields`）、技艺经验（若含已知 `technique`，按基础耗时计算 `exp = durationSeconds` 渲染「{技艺名}技艺经验 ×{exp}」）；若境界圆满待突破挂载底蕴转化徽标；
  4. **耗时**（dt: 耗时）：单轮实际耗时，并紧跟挂载速度加成徽标（`speedBonuses`，如「炼丹 速度 +5%」）；
  5. **次数**（dt: 次数）：统一置于 `.action-detail-list` 网格内作为第 5 项，左侧标签「次数」，右侧放置 `QuantitySelector`；
