## 1. 需求背景与痛点分析

### 1.1 现状痛点
1. **技能（功法/心法/术法）升级进度缺失或与主信息混杂**：
   - 玩家 hover 功法技能时，主卡片仅展示技能名称、五行/类别、招式叙述、加成雷达图与基础词条（等级/冷却/吟唱/灵力消耗）。
   - 功法累计经验到等级的参悟进度（本级当前经验、升下一级所需经验、进度百分比、经验条）缺乏独立的视觉窗口呈现。
2. **左侧技艺栏（炼丹/炼器/符箓/阵法/强化）升级进度直接塞入纯文本 Tooltip**：
   - 左侧侧边栏（Sidebar）展开的技艺二级菜单使用基础的 `FloatingTooltip`，将「技艺名称 · 等级」、「经验进度（如 0 / 100 或已臻化境）」、「行动速度加成」硬编码拼接在同一块长字符串中。
   - 既破坏了主气泡的简洁度，又缺乏修仙风格的进度条与层级分明的视觉体验。

### 1.2 目标效果
1. **技能悬浮联动独立副悬浮窗（升级进度）**：
   - 玩家在斗法装配槽位、已学功法目录、功法选择器以及内视面板中 hover 技能时，在主效果说明卡片旁，自动弹出独立的额外悬浮窗（`FloatingAsideCard`）。
   - 副窗清晰呈现「升级进度」，包含当前等级/参悟阶段、本级经验与升级所需经验数值（`current / max`）、经验百分比，以及具备修仙色彩渐变光效的进度条。
2. **左侧技艺栏悬浮联动独立副悬浮窗（升级进度）**：
   - 左侧导航栏 hover 对应技艺时，主气泡升级为标准的 `FloatingPopover` + `FloatingInfoCard`，展示技艺名称、等级、当前提供的全局行动速度加成说明，彻底移除主气泡内杂糅的经验数字。
   - 在主气泡旁并排显示独立的额外悬浮窗（`FloatingAsideCard`），专门展示该技艺的升级进度（当前经验、所需经验、百分比、满级状态、进度条）。
3. **架构统一与组件复用**：
   - 提炼通用的进度副气泡构建函数与样式（`createProgressAsideCard`），支持百分比、自定义色调（`PillTone` / `FloatingTone`）、满级与未满级态，与项目现有 `FloatingPopover`、`EffectTooltipTarget` 与 `ConditionedTile` 无缝融合。
   - 遵守《前端公共组件与统一模板速查手册》规范，保持零无谓重绘与滚动自适应。

## 2. 技术设计与实施方案

### 2.1 升级进度副卡片通用规范
在 `FloatingPopover` 体系下，拓展标准统一的进度副卡片生成函数 `createProgressAsideCard`：
```ts
export interface ProgressAsideCardOptions {
  id?: string
  mark?: string
  title?: string
  level?: number
  currentExp: number
  maxExp: number
  maxed?: boolean
  maxedLabel?: string
  tone?: FloatingTone
  subLabel?: string
}
```
渲染内容包含：
- 顶部标题行：`mark` 徽记（如「参悟」/「技艺」） + `title`（「升级进度」） + 右侧 `subtitle`（`Lv.X (45.0%)` 或 `已臻化境`）；
- 经验数值行：`当前进度：current / max`（经 `formatNumber` 中文四位分段与格式化）；
- 进度条槽：修仙色调发光槽体与 `compound-stat-progress-fill` 填充条。

### 2.2 技能组件链式接入
1. `EffectTooltipTarget` 与 `ConditionedTile` 增加 `asideCards` 属性透传；
2. 在 `describeAbility` 或调用点处，根据技能累计经验 `combat.abilityExperiences[abilityId]` 经 `calculateAbilityLevelAndProgress` 计算出等级与进度，构造 `createProgressAsideCard` 并传入 `asideCards`；
3. 覆盖范围：
   - `AbilitiesPanel.tsx`：斗法装配槽位、已学功法目录（内功心法、神通术法）；
   - `App.tsx`：下部快捷斗法槽位；
   - `AbilityGridPicker.tsx`：装配选择器列表瓦片；
   - `CombatAttributePanel.tsx`：内视属性面板已装配技能瓦片。
