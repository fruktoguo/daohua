## 报告口径

- `count` 是本测量窗口该阶段实际记录的完成调用数；未观察到阶段为缺失状态与 `null`，不能解释为 0 次。
- `total_ms` 是跨全部调用的累计时长；并发等待、父子计时和跨系统嵌套存在重叠，不可相加得出墙钟或独占 CPU。
- `mean_ms=total_ms/count`，分位来自服务端固定桶的测量窗口差，最大值仅在差分后可确定时输出。
- 同一操作的细分阶段与外层阶段应同时保留，报告应标注父子关系或在解读时明确口径；未测到的内核部分不得作为“剩余耗时”简单归因。
- `--mode replay --target-hours 1` 表示玩家业务时钟推进一小时；`duration`/`measured_wall_ms` 是运行实际耗时。在线墙钟一小时另用 `--mode online --duration-seconds 3600`。
