# TASK-20261005-03 破阵子增伤修正与贯星击杀连锁

## 背景

用户核对现有十门技能的实际实现效果，发现两处与设计意图不符：

- **破阵子**：配表写成 `damageAbsorptionPoints: 15 / 30s`（免伤点数），实际应为**全体友方伤害提升 40%，持续 10 秒**。
- **贯星**：配表只有单体 `300% AD + 50`，缺少**击杀后连锁**——击杀目标后再次对一个单位造成伤害，最多触发两次（总计最多命中 3 个不同目标）。
- **连环**（追加）：配表 `100% AD + 15` 单段，实际应为**对同一目标连续造成 3 段 `80% AD + 10` 物理伤害**。

## 需求确认

| 项 | 结论 |
| --- | --- |
| 破阵子增益口径 | 全体存活友方（`allAllies`，当前友方集合即玩家自身），伤害 +40%，10s |
| 增伤乘区 | 走总增伤 Linear 乘区（`TotalDamageBonusPoints` 同区合并），覆盖普攻与技能伤害 |
| 贯星连锁伤害 | 完整技能伤害再来一次（同面板独立结算链） |
| 连锁次数上限 | 击杀后追加至多 2 次，总计最多 3 个目标 |
| 连锁目标 | 另一存活敌方（威胁轮盘重抽，被击杀目标已离存活池，天然不重复） |

## 实现要点

### 破阵子（战内增伤 Buff）

- `CombatBuffState` 参数表尾部新增 `DamageBonusPoints`（位置构造兼容），`IsValid` 校验有限性。
- `CombatantState.BuffDamageBonusPoints` 聚合 getter（按 Stacks 加权）。
- `DeterministicCombatEngine.ResolveHit` 总增伤乘区：`attack.TotalDamageBonusPoints + context.Attacker.BuffDamageBonusPoints`。
- `CombatActSystem.CastSkill` Buff 授予读取 `damageBonusPoints`。
- 配表：`durationSeconds 30→10`、`damageAbsorptionPoints 15` → `damageBonusPoints 40`（Linear：40 点 = ×1.40）。
- 取舍：雷击符等消耗品打击（`ResolveStrikeDamage`）不接战内 Buff——消耗品评估镜像不携带战内 Buff，道具打击不属于战内输出增益语义。

### 贯星（击杀连锁）

- 配表新增 `chainOnKillCount: 2`（顶层字段，无词汇表校验负担）。
- `CastSkill` 单体分支：主帧结算后，若目标已死则 `SelectTarget` 按威胁轮盘抽下一存活敌方追加一次完整 `ResolveAttack`，至多 2 次。
- 循环终止条件：目标未死（连锁未致死）或无存活目标；死目标不在存活池，天然不重复命中。
- 连锁帧沿用同一施放抽样计数 `count`，命中/暴击掷点继承本次出手（贯穿语义）；随机通道 20/21 避开已占用通道。
- 连锁帧 `AbilityId`/`AtSeconds` 与主帧一致，日志合并自动合成一条多目标行；斗法推演经同一管线自动生效。

### 连环（多段打击）

- 配表新增通用字段 `hitCount`（顶层），连环 `hitCount: 3`、`damageRatio 1.0→0.8`、`flatDamage 15→10`。
- `CastSkill` 单体分支：主帧后对同一目标逐段追加 `hitCount-1` 次 `ResolveAttack`；后续段 `countOverride=null` 沿用普攻计数随机流（`attacker.AttackCount` 自增），各段命中/暴击**独立掷点**；目标中途死亡即终止剩余连段，不转火不空掷。
- 与击杀连锁正交可共存：多段致死目标后仍可触发 `chainOnKillCount` 连锁转火（多段在先、连锁在后）。

### 前端

- `types.ts`：`buff` 定义加 `damageBonusPoints`、顶层加 `chainOnKillCount`/`hitCount`。
- `format.ts` 悬浮卡：新增「伤害提升 {n}」「连击 {n} 段」「击杀后贯穿下一目标（至多 {n} 次）」三行渲染。
- `game.zh.ts`：新增 `buffDamageBonus`、`hitCount`、`chainOnKill` 词条。

### 门禁

- `SkillTriggerEvaluator.ValidateAbility`：Buff 字段清单加 `damageBonusPoints` 有限性校验。
- `DataTool` `AbilityBuffKeys` 授权 `damageBonusPoints`。

## 强度核算（data-designer 口径）

- 破阵子：+40% 总增伤 ×10s / CD60s / 吟唱5s / 耗蓝50。10s 窗口约覆盖 10 次普攻周期（攻速1s），等效增伤约 4 次普攻当量；60s CD 下覆盖率 16.7%，等效常驻增伤 ≈ 6.7%。对比嘲讽（55s CD 纯威胁无伤害），破阵子占模主要来自增益覆盖率与 50 MP 高耗，强度合理。
- 贯星：单体 300%AD+50 斩杀技 + 击杀连锁至多 2 次。上限 3 目标 ×300%AD（900%AD 总量上限），但要求逐次击杀触发——对高血量 Boss 无效，定位「收割链」而非稳定 AoE。36s CD、2s 吟唱、30 MP，相对重云（120%AD 全体、24s CD）上限更高但条件更苛刻。
- 连环：单段 100%AD+15 → 三段 80%AD+10（全中 240%AD+30）。理论上限比重斩（180%+20/CD18s）高约 33%，换取 CD-2s 与分段判定风险（任一段 miss 损失当段）；目标中途死亡截断连段使过量斩杀场景收益递减，定位「对中血量目标的连击压制」而非稳定爆发。
