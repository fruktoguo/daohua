## 需求理解与已对齐边界
1. **特质定义与数值**
   - **标识与名称**：`trait.huoshen` / 「火神」
   - **品阶与消耗点数**：天品（`quality = 5`），`cost = 12` 点，纳入觉醒石全量特质池（`37 -> 38` 项）
   - **成长属性**：提升 `+10%` 火属性增伤（`fireDamageBonusPoints = 10`），按现行统一特质等级系数 `1 + 0.05 * (Lv - 1)` 随特质等级线性提升（Lv.1 = `10%`、Lv.2 = `10.5%`、Lv.3 = `11%`……）
2. **核心机制与已对齐衍生伤害边界**
   - 携带「火神」的单位发起常规攻击（普攻、主动/连锁技能）、雷击符类即时伤害消耗品（单人 `ActionExecutionRules.Resources` 与组队 `ActionParticipationSessionEngine`）、阵盘受击反击（天雷阵盘原木法、血煞阵盘原无属性物理）及「蓄意」触发时的非主目标物理溅射，在**不改变 `CombatDamageKind`（物理/术法/真伤）**的前提下，五行属性统一转化为 `CombatElement.Fire`，按现行管线吃火属性增伤（含火神自身 +10% 起步）与受击方火抗/火减伤，并正常联动「燃魂」（含转火后的阵盘受击反击）。
   - 「蓄意」爆发对主目标造成的真实伤害保持跳过护甲、常规增减伤、暴击与固定增减伤规则不变（仅模拟器 `damageDealtByElement` 统计记为火属性）。
   - 装备反伤（`DamageReflect`）保持直接按受击伤害百分比扣血、不走增减伤且不触发燃魂的原规则。
