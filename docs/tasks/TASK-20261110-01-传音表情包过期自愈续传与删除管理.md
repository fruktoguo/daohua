## 1. 需求背景与核心目标

1. **国内高速图床接入（路过图床 imgchr / ax1x）**：
   - 将聊天图片与表情上传无缝对接至国内老牌 `imgchr.com`，分发直连 `ax1x.com` 全国 CDN（实测国内延迟 500ms~700ms 秒开），全程 0 消耗开发者腾讯云主服带宽；
2. **过期自愈重传机制**：
   - 针对免登录图床 14 天过期（或任何偶发 404）的特性，利用客户端 IndexedDB 永久持久化特性：若用户发送已收藏表情时探测到远端链接失效，客户端静默利用本地持久化 Blob 重新触发上传，获取全新有效 CDN 直链并透明更新收藏夹，实现「只要本地有缓存，外链永久不死」；
3. **表情包删除管理操作**：
   - 在表情选择抽屉（`ChatEmojiPicker`）及聊天流气泡右键菜单（`ChatSticker`）中，为已收藏的自定义表情包提供「从表情包中移除 / 删除表情」的操作选项，解决此前只能收藏无法删除的痛点。

---

## 2. 详细设计与实现方案

### 2.1 上传链路重构 (`chatImageUploadService.ts`)
- 免登录直接对接 `https://imgchr.com/json`；
- 提取首帧 Cookie 与 CSRF `auth_token` 后提交 FormData；
- 成功提取 `image.url`（如 `https://s41.ax1x.com/...`）；
- 兼容 Cloudflare R2 / 路过图床多源，优先使用国内秒开链路；
- 异步向主服登记哈希映射，客户端本地哈希去重秒开。

### 2.2 表情包删除与自愈管理 (`chatStickerService.ts`)
- 增加 `removeCustomSticker(url: string)`：从 IndexedDB 与内存列表中移除，广播状态变更；
- 增加 `ensureValidStickerUrl(url: string): Promise<string>`：
  - 检查远端 URL 可用性（或加载时触发 404 捕获）；
  - 若已失效但本地 IndexedDB 存有原始 Blob，自动重新调用上传服务获取新 URL，原子更新本地映射并返回新 URL。

### 2.3 界面交互完善
- `ChatSticker.tsx`：右键菜单中，如果 `isSaved` 为 true，提供「从表情包中移除」危险动作；
- `ChatEmojiPicker.tsx`：
  - 自定义表情瓦片悬浮提供删除按钮（右上角小叉标或长按/右键菜单）；
  - 点击删除弹出轻量确认或即时移除，通知栏提示「已从表情包中移除」。
