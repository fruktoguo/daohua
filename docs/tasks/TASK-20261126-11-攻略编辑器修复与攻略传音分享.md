## 一、需求概述与确认口径

1. **修复编辑攻略点击工具栏浮层（表情/颜文字/图片/物品）误触表单提交**：
   - `FloatingPopover` 在 `triggerAs="button"` 时显式附加 `type="button"`，避免表单内默认 `type="submit"` 直接保存/发布。
   - `ChatEmojiPicker` 内部添加表情包 `<form>` 的 `onSubmit` 阻止事件经 React Portal 冒泡到外层攻略编辑表单。
2. **修复编辑攻略「物品」选择器列表挤压**：
   - 保留紧凑搜索下拉列表形态；为 `.guide-item-option` 设置 `flex-shrink: 0`、固定可读行高（`min-height: 32px`）、清晰图标与悬停/聚焦态（兼容深浅双主题），解决 Flexbox 结合全局 `button { overflow: hidden }` 导致的纵向塌缩挤压。
3. **修复攻略列表与详情页玩家形象图片过大（并挤没作者道号）**：
   - 改用全站统一的定尺寸外框容器 `.guide-author-avatar-box`（列表 `26×26px` / 详情 `40×40px`，`flex-shrink: 0`）配合更高权重尺寸约束，避免 `.character-avatar { width: 100%; height: 100%; }` 覆盖尺寸撑爆立绘并挤掉 `.guide-author-name`。
4. **新增「查看与编辑攻略发送到聊天」**：
   - 扩展 `chatMarkup.ts` 新增 `{{guide:postId:unlockPrice:title}}` 构建与解析（严格遵守 `200` 字符上限与容错降级）。
   - 扩展 `ChatMessageContent.tsx` 渲染 `.chat-guide-link` 传音攻略超链接胶囊（含免费/灵石价格标识、悬浮提示、深浅双主题适配）；点击调用 `useUiStore.getState().navigateToGuidePost(postId)` 一键切换至「同道 → 攻略」并直达对应攻略详情。
   - **查看攻略时**：详情页顶栏增加「发送到聊天」按钮，复用 `shareToChat` 写入当前激活聊天频道草稿并聚焦输入框。
   - **编辑攻略时**：底部操作区增加「保存并发送到聊天」（编辑已有攻略）/「发布并发送到聊天」（新建未发布攻略），落库拿到权威 `postId` 后自动关闭编辑窗并写入聊天草稿。
