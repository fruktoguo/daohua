## 需求原文

> 运维面板需要增加快捷操作。比如在市场里，我需要能以系统身份添加挂售单和收购单，可以快捷选择某个物品、全部物品，或者某个品类。

## 需求澄清结论

1. 「系统身份」= TASK-20261003-09 种子脚本同一固定身份（账号 `f0000000-0000-4000-8000-000000000001`、
   玩家 `f0000000-0000-4000-8000-000000000002`，道号「系统坊市」，不可登录）；面板下单前确保身份行存在。
2. 「挂售单/收购单」= 坊市 sell/buy 限价单；「某个物品 / 全部物品 / 某个品类」三种范围：
   - 单个物品：目录下拉选择；
   - 按品类：按物品主类型（`ItemDefinition.Category`）过滤；
   - 全部物品：与种子脚本同口径 = `sellPrice > 0` 的非货币可交易物品（当前 54 个）。
3. 默认价格（用户裁定）：**卖买都默认回收价**（`sellPrice`），可手动改；数量默认 1 亿份、可改（对齐种子任务口径）。
4. 配套撤单（用户裁定）：系统下单视图列出当前系统挂单，支持逐条撤销与一键全部撤销。
5. 生效方式：走 `MarketRuntime.PlaceAsync` 正常下单链路，**即时上架，无需重启后端**（区别于种子脚本的落库+重启）。

## 技术方案

### 服务端（`src/Server/Clean/Ops/OpsMarketActions.cs` 新文件）

- `GET /ops/api/market/catalog`：只读物品目录（id/name/category/subCategory/sellPrice），
  数据源 `GameDataCatalog`，口径 = 非货币 + 可交易 + `sellPrice > 0`；同时下发去重后的品类列表。
- `POST /ops/api/actions/market-system-orders`：批量系统下单（side + scope + 可选 price/quantity）：
  1. 前置校验：市场分片就绪（`IsReady`）、品种归属本分片（`Owns`）、价格/数量有限正数；
  2. 每物品先经 `IEconomyTransactionStore` 注入资金（`system-grant` 流水，幂等键 `system-grant:{orderId}`）：
     卖单注入 `quantity` 份物品、买单注入 `price × quantity` 灵石——
     `CommitPlacementAsync` 的冻结扣减（`ChangeBalanceAsync` 余额不足抛异常）因此永远有足够余额；
  3. 再走 `MarketRuntime.PlaceAsync` 正常下单：订单行 + 冻结预留 + 经济流水 + 即时撮合同一 Serializable 事务，
     幂等键 `system-ops:{batchId}:{side}:{assetId}`，订单 UUID 按 (batchId, side, assetId) 确定性生成；
  4. 逐物品返回结果（placed/duplicate/failed + 原因），部分失败不回滚已成功项，如实上报。
- `POST /ops/api/actions/market-system-cancel`：撤销系统挂单（`assetId` 空 = 全部）：
  经 `MarketRuntime.GetOrders(系统玩家)` 取活动订单 → 逐单 `CancelAsync`（幂等键沿用仓储规范格式
  `market-cancel:{系统玩家}:{orderId}`），退款/退货入系统余额（与玩家撤单同路径）。
- 系统身份保障：下单前 `INSERT ... ON CONFLICT DO NOTHING` 补齐 `identity.accounts`/`identity.players`
  （随机口令哈希不可登录），与种子脚本同一固定 UUID。
- 写操作沿用面板安全模型：`RejectWriteRequest`（回环/私网 + `X-Ops-Token`）+ `Ops.Audit` 审计。

### 前端（`frontend/src/ops/`）

- 交易分组新增「系统下单」视图（`views/MarketViews.tsx` 内 `OpsSystemOrderView`）：
  - 方向切换（挂售/收购）+ 范围选择（单个物品下拉 / 按品类 / 全部物品）+ 价格（默认回收价）与数量（默认 1 亿）；
  - 提交经 `ConfirmDialog` 二次确认（展示范围摘要与买单总资金需求）；
  - 结果按物品逐行展示（已挂单/已存在/失败原因）；
  - 下方实时列出系统当前挂单（复用 `/market/orders?playerId=系统玩家`），逐条撤销 + 一键全部撤销（均二次确认）。
- `OpsApp.tsx` 导航登记；类型登记 `opsTypes.ts`。

### 与 TASK-20261003-09 的关系

- 共用同一系统身份固定 UUID；种子脚本保留（一键全量补挂 + 落库口径），面板提供交互式即时下单。
- 面板下单走运行时链路，落库事实链由 `CommitPlacementAsync` 权威保证，不复制 SQL。
