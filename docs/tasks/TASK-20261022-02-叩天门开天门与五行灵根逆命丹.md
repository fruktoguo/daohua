## 需求原文要点

1. 叩天门境界满经验后，突破按钮变为「开天门」；必须开天门取得灵根后，才能继续突破。
2. 开天门后仍可继续洗灵根；逆天改命次数永久保留（累计计数不清零）。
3. 新增道具「逆命丹」，放入炼丹体系，属于特殊配方（解锁条件暂不实现）。
   - 炼制效果：消耗 25% 当前升级所需经验的底蕴，产出 1 颗逆命丹。
   - 逆天改命时可选使用：使用后底蕴消耗 25% → 5%。
4. 开完天门后，「根基」增加一个子 Tab「灵根」，可查看灵根。
5. 灵根基础效果：增加五行对应点数的增伤与减伤（100 点 = 100% 对应属性增伤与减伤；减伤 100% 实际效果是伤害减半，即 NonLinear 曲线）。

## 技术方案

### 领域层（src/Domain）

- `PlayerProgression` 新增五行灵根状态（金木水火土点数、是否已入天门、逆天改命累计次数），随 Progression 分段持久化。
- `PlayerAggregateState.Progression` 增加灵根字段（可缺省解码），`SectionCodec.CurrentSchemaVersion` 37 → 38。
- `PlayerAggregate.Breakthrough` 增加前置：境界 18（叩天门）且未入天门时抛冲突，提示「需先叩开天门取得灵根」。
- 新增 `HeavenGateRules`（纯领域）：抽取灵根、校验五行分配守恒、计算逆天改命底蕴成本、永久累计改命次数。
- `PlayerAttributeResolver` 把灵根五行点数并入对应五行增伤 / 减伤点数乘区（增伤 Linear、减伤 NonLinear，100 点即伤害减半）。

### 服务端（src/Server）

- `EcsPlayerRuntimeAdapter` 新增命令 `progression.heaven_gate`（开天门 / 分配 / 入天门 / 逆天改命，逆天改命支持 `usePill`）。
- 逆命丹炼制接入炼丹行动：配方以「升级所需修为的 25% 底蕴」作为额外成本校验与扣除。

### 配表（config/game-data）

- `items/pills.json` 新增逆命丹道具。
- `actions/alchemy.json` 新增逆命丹炼制配方（标注特殊配方）。

### 前端（frontend）

- `InsightPage` 叩天门满修为且未入天门时，突破按钮改为「开天门」并打开天门阵盘。
- 根基子 Tab 在入天门后新增「灵根」，展示五行灵根雷达与增伤/减伤，并提供「逆天改命」入口。
- 天门阵盘弹窗：开天门、五行重分配、入天门确认、逆天改命（可选逆命丹）。
- 新词条同步 `frontend/public/locales/template.csv` 与中文词典。

## 实现落点

### 领域层

- `src/Domain/Player/PlayerHeavenGate.cs`：`LinggenElement`、`LinggenValues`（五系 0~100 点数）、`PlayerHeavenGateState`（抽取值/生效值/是否入天门/累计改命次数/版本号）。
- `src/Domain/Player/HeavenGateRules.cs`：开天门境界（18）、改命成本（25% / 逆命丹 5%）、逆命丹炼制成本（25%）、通用 `ResolveFoundationCost`、确定性抽取 `Roll`、分配守恒校验、增伤/减伤点数、升级需求乘区（五系齐全 3.0 倍）。
- `PlayerAggregate.Breakthrough`：叩天门满修且未入天门时抛冲突，阻断直接突破。
- `PlayerProgressionState` + `ExportState`/检查点/`Restore`/`RestoreFrom`/`EcsWorldShard.ExportSnapshot` 全链路透传灵根，`SectionCodec.CurrentSchemaVersion` 37→38，`PostgresSchema.Version` 40→41，新增 `migrations/0041_v40_to_v41.sql`。
- `PlayerAttributeResolver`：五行灵根点数并入 `{Element}DamageBonusPoints` / `{Element}DamageReductionPoints` 同键累加，未新造乘区；`AttributeInputRevision` 追加 `HeavenGate.Version` 保证入天门/改命后面板失效。
- `ActionDefinition.FoundationCostRatio` + `ActionExecutionRules.Timed`：炼丹特殊配方的底蕴成本在准入与单轮结算双处校验、在 `CreditExperience` 之前扣除（避免同一份底蕴被花两次）。

### 服务端

- `EcsPlayerRuntimeAdapter` 新增 `progression.heaven_gate` 四步命令（roll/allocate/enter/reroll），种子由 SHA-256 派生保证确定性；逆天改命扣底蕴（25% / 逆命丹 5%），逆命丹消耗走经济事务幂等键。
- `Program.cs` 行动目录下发 `foundationCostRatio`。

### 配表与前端

- `items/pills.json` 新增逆命丹；`actions/alchemy.json` 新增 `alchemy.refine-reverse-fate-pill`（`foundationCostRatio: 0.25`）。
- `frontend/src/game/linggenCalculations.ts`：增伤/减伤/乘区/是否展示开天门按钮的纯函数与单测。
- `HeavenGateModal`：开天门阵盘（抽取、五行重分配、入天门、逆天改命可选逆命丹）。
- `InsightPage`：叩天门满修且未入天门时突破按钮改为「开天门」；根基子 Tab 在入天门后新增「灵根」。
- 行动详情展示特殊配方的底蕴成本；i18n 中文词典与 `template.csv` 同步。
