## 1. 需求背景与核心目标

1. **解答玩家困惑**：当前大地图中「云巅草庐」等首领地点外框为红色，但缺少文字说明导致玩家困惑（其根因为 `node.cloud-peak` 挂载的 `encounter.cloud-peak` 配有妖王 `enemy.chang-tiger` 伥虎，触发了 `.has-boss` 朱红边框）。按用户裁定方案，保留妖王朱红警示边框，并在节点顶部显式展示「妖王」「精英」角标，同时为仅含精英怪的地点增加灵紫描边层次。
2. **节点尺寸翻倍且全缩放比零重叠**：上一版 `WORLD_UNIT_X = 9.6, WORLD_UNIT_Y = 6.4` 在常见视口下 4 字节点实显仅约 `50×17px`、字号约 `9px` 偏小单薄。本任务将基准像素坐标系升级为 `14 × 10`，引入舒适视野（`820 × 560` 基准像素跨度）自动拉近聚焦与焦点边界夹紧，将屏幕实际显示宽高提升约 2 倍，并经真实全量 20 节点碰撞盒验算确保纯牌匾与全带图双模式严格零重叠。
3. **古风牌匾器物质感升级**：强化深/浅双主题下的双层金线内衬、雕纹底色梯度、`--text-xl` 楷体字号、带图切角画框（`96 × 68` 基准像素）与顶部压边「精英 / 妖王」印记角标。

## 2. 技术实现方案

1. **`worldMapVisibility.ts`**：
   - `WORLD_UNIT_X = 14`、`WORLD_UNIT_Y = 10`（`1400 × 1000` 基准像素）；
   - `MAX_RELATIVE_ZOOM = 3.2`，新增 `COMFORT_VIEW_WIDTH_PX = 820`、`COMFORT_VIEW_HEIGHT_PX = 560`；
   - `computeAnchorFitViewport` 支持可选 `focusPoint` 焦点参数及视口半宽高边界夹紧，保持任意 DPI 等比缩放下的齐次构图一致性。
2. **`zongmenMap.ts`**：
   - `ZONGMEN_CANDIDATE_OFFSETS` 升级为 `[11, 10]` 等大间距候选，`MIN_CLEARANCE_PX = 148`，避免翻倍后的宗门牌匾与挂靠节点及邻点碰撞。
3. **`WorldMapPanel.tsx`**：
   - `MapNodeButton` 计算 `hasBoss` 与 `hasElite`，添加 `.has-elite` 类并在顶部渲染 `.world-map-node-badges`（「精英」`combat.nearby.rankElite` / 「妖王」`combat.nearby.rankBoss`）；
   - 同步放大 `getEdgeCurve` 弯曲参数、`framePad`、区域名牌及玩家指针 SVG（含驻留带角标节点时追加 `is-on-badged-node` 防遮挡上移）；
   - `fitToAnchorRegion` 传入选中关口或玩家当前坐标作为聚焦点。
4. **`expedition.css` & `theme.css`**：
   - 全部新增/调整字号严格使用 CSS Design Tokens（`--text-xl` 节点地名、`--text-2xs` 角标、`--text-base` 路程标注、`--text-xl` 区域名牌）；
   - 双主题补全双层金线内衬牌匾、妖王朱红与精英灵紫边框及顶部徽记视觉样式。
