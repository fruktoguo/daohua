## 需求背景与核心目标

在《道化太初》的物品与装备交互中，玩家需要清晰直观地获知物品基础效果、丹药即时/持续增益以及装备完整数值。
当前物品 Hover 气泡将直接恢复数值、冷却时间与复杂 Buff 词条混杂在单一主卡片中，缺乏层级结构。

**本次任务核心目标**：
1. **明确“额外窗口”的架构定义**：即 `FloatingPopover` 体系中的**附属卡片（Aside Card / 独立副面板）**，利用多气泡横向并排贴合（桌面端）/ 垂直堆叠（移动端）规范，实现主干信息与增益/减益 Buff 的清晰解耦。
2. **丹药 Hover 分类解耦展示**：
   - **修炼丹药 / 技艺消耗品**：主卡片展示丹药名称、品级、基础说明与直接修炼/生产增益；附带持续修炼效果时作为 Buff 附属卡片挂载。
   - **战斗丹药 / 恢复药剂**：主卡片展示即时恢复（如气血/灵力回复数值）、使用冷却与触发条件；其附带的战斗增益（如攻击、防御、暴击、攻速等持续效果）提取为独立的 **Buff 附属卡片窗口**！
3. **装备 Hover 完整效果与特殊 Buff 联动**：
   - 主卡片完整展示装备的基础攻防百分比（`baseStatRatios`）、固定数值（`flatStats`）、强化等级动态加成（`enhancementBonus`）与攻速间隔。
   - 若装备带有特殊机制（`specialMechanics`，如威胁值提升、治疗提升）或特技/被动 Buff，自动在右侧挂载独立的 **特殊机制 / 词缀 Buff 附属卡片窗口**。
4. **抽象通用 Buff / Debuff 附属卡片构建器**：
   - 支持所有正向 Buff（`gold`/`jade`/`qi` 主题色）与负向 Debuff（`danger` 朱砂煞红色），统一格式化持续时间、层数与数值高亮（`ValueText`），为全游戏（物品、装备、角色状态栏、战术面板）提供通用 Buff Aside 扩展能力。
