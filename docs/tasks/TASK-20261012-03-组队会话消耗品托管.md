# TASK-20261012-03 组队会话消耗品托管

- **提出时间**：2026-10-12 01:18:45
- **状态**：🧪 验证中（功能实现与专项测试完成；全量门禁被并行任务 TASK-20261012-02 的在途中间态阻塞）
- **分类**：组队讨伐 / 消耗品

## 背景与需求

尐妖（同岳千钧、白青蘅组队挂 `combat.hunt-qi-beast`）配置的聚灵阵盘与顺气丸全部不生效：
- 即时消耗品在 `ActivateInstantConsumables` 中遇 `Participation != null` 直接跳过——共享剧本看不见成员钱包，历史上干脆禁用；
- 持续消耗品只采集「开打时已充能」的槽位进 `SustainedBuffs`，未充能槽（Remaining=0、库存有货）永远不补能。

用户裁定采用**托管（escrow）模型**并直接完整实现：开打定格把槽位对应物品从钱包实扣进会话托管，剧本消耗自己的台账副本（确定性输入闭集），散场退回未用——消灭「副本与真身分叉」的同步难题。

另顺带修复已确诊的前端守卫 Bug：组队中自身倒地（`playerRespawnAtSeconds` 非空）时 `CombatArena` 错误隐藏全部敌方行动条，与引擎「仅全灭才冻结敌方」的语义不符（已改为己方全灭判定）。

## 设计口径（§21.13.1 已同步修订）

1. **冻结采集**：`ActionParticipantSnapshot` 新增 `ConsumableSlots`——启用且适用于战斗栏域的消耗品槽配置（itemId、组、冷却钟、持续槽已充能剩余）。社交层统一读全部成员钱包余额折算托管配额（即时/持续全量、durable 锁 1 件），整池回填首个同物品槽行；托管借记打包为单笔 `EconomyTransactionRequest`（幂等键 `party.escrow:{sessionId}`）**并入 `CreateOrInitializeAsync` 的会话事务**——托管扣款、会话行、初始检查点同一 PostgreSQL 事务原子提交；余额不足整体回滚，重读余额收紧配额重试，无孤儿扣件窗口、无补偿退款路径。
2. **会话台账**：检查点新增 `ConsumableLedger`（每成员每槽剩余托管、冷却钟、持续到期墙钟）。即时消耗品在战斗相位按 5 秒窗口判定（触发器对 canonical 战斗单位求值），恢复/ Buff/雷击伤害直写战内单位；非战斗相位以冻结面板+成员资源池装配只读求值单位，恢复写资源池、Buff 记跨波携带。持续消耗品按墙钟耗竭→冷却→波次入场再充能（与单人同判定，时钟口径换墙钟）。倒地成员整段跳过（与单人 `Hitpoints<=0` 同口径）。实耗记 `LostItem` 账本 + `auto-use.activated` 事件随个人结算下发。
3. **散场退回**：末批结算 `AssetDelta` 返还 `remaining`；配表指纹失配安全收尾同样退回。成员个人槽位时钟不受会话推进。
4. **不可售**：托管量开打即从钱包扣走，战斗中不存在可售的托管物品；散场退回后正常。

## 影响面

- `src/Domain`：`ActionConsumableSlot`、快照 `ConsumableSlots`、`SessionConsumableSlot` 台账行、检查点 `ConsumableLedger`、`CaptureConsumableSlots` 采集。
- `src/Ecs`：`ActionParticipationSessionEngine` 台账生命周期 + 即时/持续判定 + 持续充能注入 + 共享池扣件 + 散场退回；`combat.lost` 倒地事件口径修正为 `combat.downed`（原先被事件过滤吞掉，倒地成员看不到「随队迎战」提示）。
- `src/Server`：`SocialRuntime` 托管计划（`PlanConsumableEscrowAsync`）；`IActionParticipationRuntime.CreateAsync` 与 `IParticipationSessionStore.CreateOrInitializeAsync` 增加 escrow 入参；`PostgresParticipationSessionStore` 在同一事务内 `CommitCoreAsync` 托管扣款。
- `frontend`：无协议变更（余额走既有资产通道，消耗走事件流 + `LostItem` 账本）；`CombatArena.tsx` 倒地守卫已修。
- 测试：`tests/Domain.Tests` 会话引擎消耗品不变量 7 例；`tests/Server.Tests` 托管原子提交集成测试 1 例；替身签名同步。
