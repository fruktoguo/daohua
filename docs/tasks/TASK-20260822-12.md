## 2. 需求背景与核心目标

### 2.1 需求背景
基于 TASK-20260822-10 的全量扫描成果，当前系统在通信协议传输、战斗离散事件推演、数值配置解析与基础设施热路径中存在大量使用 `string` 表示枚举、状态、指令、错误码与槽位的情况。本次任务将全面落地强类型化重构，消除高频堆内存分配，精简 WebSocket 数据包体，建立编译期强类型安全。

### 2.2 核心落地范围
1. **领域枚举体系完善**：
   - 新增 `CombatActionKind` (`Attack`, `Cast`, `Control`, `Wait`, `Respawn`)；
   - 新增 `EquipmentSlot` (`Weapon`, `TwoHand`, `OffHand`, `Head`, `Armor`, `Legs`, `Boots`, `Ring`, `Neck`, `Trinket`, `Talisman`) 与 `[Flags] EquipmentSlotMask`（实现 0-GC 单指令位运算穿戴冲突检测）；
   - 新增 `UnitRank` (`Minion`, `Normal`, `Elite`, `Leader`, `Boss`, `Summon`, `Pet`, `PlayerMirror`, `Npc`)；
   - 新增 `ItemCategory` (`General`, `Material`, `Herb`, `Mineral`, `Pill`, `Food`, `Drink`, `Talisman`, `Manual`, `Equipment`, `Chest`, `Currency`, `Resource`)；
   - 新增 `NearbyEntityKind` (`Npc`, `Building`, `Portal`, `ResourceNode`)；
   - 新增 `VisualRendererKind` (`Text`, `Glyph`, `Image`, `Live2D`, `Model3D`)；
   - 新增 `MarketResultCode` 与 `ExpeditionPhase`。
2. **前后端类型系统与协议映射收拢**：
   - 在前端 `frontend/src/game/types.ts` 中全面收拢所有联合类型与枚举，修正了 `InsightPage.tsx`、`CombatArena.tsx`、`App.tsx` 等组件中的类型与分支比对；
   - 在 `StateMapper.cs` 中实现强类型分发，并在 `Enums.cs` 中实现零堆分配的自定义多语言 JSON 转换器（同时支持中文与 kebab-case/camelCase 序列化/反序列化）。
3. **推演引擎与市场状态机强类型化**：
   - 战斗模拟器（`CombatSimulator.cs`、`CombatGroupSimulator.cs`）全量迁移 `CombatActionKind`；
   - 装备槽位穿戴校验迁移为 `EquipmentSlotMask` 位运算；
   - 市场撮合订单簿（`OrderBook.cs`、`MarketEngine.cs`、`MarketCoordinator.cs`）全量统一返回强类型 `MarketResultCode`。
4. **单测与全量门禁验证**：
   - 135 个领域单测全部 100% 绿灯；
   - 容量门禁（5000 账号 / 500 峰值命令包 / 2000 冷挂机）及前端 `tsc`+`vite build` 全部验证通过。
