1. **背景**：
   - 觉醒石（`item.awakening-stone`）此前在 `materials.json` 中配置为 `kind: "material"`, `category: "consumable"`, `subCategory: "stone"`，在前端物品卡片丝带及 Tooltip 中缺少对应本地化，在储物袋（背包）中被归入「消耗品」分组，容易与常规战斗/修炼消耗品混淆。
2. **目标**：
   - 将觉醒石的类别明确修正为「特殊」（`category: "special"`, `subCategory: "special"`）；
   - 在储物袋（背包）展示中，将觉醒石归入「重要」（`important`）分组；
   - 补齐前端 `game.category.special` 国际化词条（"特殊"）及相关类型定义与元数据兜底；
   - 确保坊市、图鉴、背包使用、商店购买等全链路行为及相关门禁完全正常。
