# TASK-20260919-06 · 统计/记录面板物品得失改为背包式图标瓦片

- 提出时间：2026-09-19 18:32:11
- 状态：🚀 进行中

## 需求

用户反馈：统计（StatsPanel）和历史记录（RecordsPanel）中「物品得失」以横向 `ItemReference` 胶囊（小图标 + 名称 + ×数量）展示，观感不佳。要求改为与背包一致的图标方块——只显示图标与数量角标。

## 方案

1. `frontend/src/components/ItemDisplay.tsx` 新增导出组件 `ItemTileReference`：仅凭 `itemId` + `amount` 自动解析物品/装备目录定义与静态元数据（逻辑对齐 `ItemCard`：`resolveItemMetadata` + `withItemGrade` + `fallbackMetadata`），渲染 `ItemTooltipTarget` + `ItemTile`（图标整块、品质边框、右下数量角标、左上品类丝带、右上等阶、悬浮信息卡片）。
2. `frontend/src/components/reportSections.tsx` 的 `ReportItemsSection`：获得/失去两列改用 `ItemTileReference`，锚点类 `battle-report-item-anchor`。
3. `frontend/src/styles/selection-grid.css`：`battle-report-item-anchor` 加入共享锚点 `:is()` 选择器组（固定槽位尺寸、边缘光线、丝带/角标 hover 高亮）与瓦片 hover 发光列表。
4. `frontend/src/styles/expedition.css`：`.battle-report-items` 由 flex 改为 `--item-slot-size` 网格。
5. `docs/frontend/common-components.md` §6/§24 同步登记新组件与展示口径。

斗法暂存区（StatsPanel `battle-report-staged`）保留 `ItemReference`：每条附带到期倒计时文本，行内胶囊仍是更合适的形式。

## 二次调整（用户验收反馈）

- 瓦片纵向单列问题：`repeat(auto-fill)` 网格在不定宽弹性列中塌缩，`.battle-report-items` 改为 flex 横排换行。
- `ReportBlock` 小节顺序调整为：行动名称（头行）→ 行动信息 → 物品得失 → 获取经验（含等级提升）。
- 三个小节标题（获取经验/物品得失/行动信息）全部移除只留内容，保留「获得/失去」列标签；同步删除 `.battle-report-section-title` 样式与 `expTitle`/`itemsTitle`/`infoTitle` 三条 i18n 死键。
