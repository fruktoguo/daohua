# TASK-20261019-01: 玩家道貌两字道号命名优化

## 1. 任务背景与核心需求

玩家反馈现有 16 款道貌形象名偏「职业说明」，如「冥煞魔修」「幽泉魔女」「九品丹师」，后缀承担了流派解释却削弱了名字本身。本次只针对玩家角色，把显示名统一压缩为两字道号，保留原名的画面感、成对关系与辨识度，去掉「修 / 师 / 子 / 君 / 尊 / 妹 / JK」等通用后缀。

命名原则：

1. 两字必须能独立成象，不依赖后缀说明身份。
2. 同一道统的男女不是同词根换性别，而是两种气质对读。
3. 原名已有强意象的只做减法；核心是品阶或形容词的重新取名。
4. 风潮组保留现代感，但不使用货架标签式直称。
