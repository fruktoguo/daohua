# TASK-20261031-06 组队威胁度与怪物数量动态缩放

## 1. 需求背景与核心目标

- **业务目标**：组队讨伐时，随队伍人数增加动态提高怪物波次的威胁度与怪群规模，强化多修士协同作战时的战术爽感与九宫格同场激战体验，防止多人体量面对单挑怪量导致的瞬秒与无感碾压。
- **核心逻辑预期**：
  1. **威胁度倍率（Threat Multiplier）**：以单人 1 名玩家为基准（100% 威胁度，即 $1.0\times$）。队伍中每多一个玩家（额外成员数 $\Delta N = \max(0, N - 1)$），最终威胁度增加 15%（$+0.15\times$），最多增加至 160%（$1.60\times$ 封顶）：
     - 1人（单人）：$1.0\times$ (100%)
     - 2人队伍：$1.15\times$ (115%)
     - 3人队伍：$1.30\times$ (130%)
     - 4人队伍：$1.45\times$ (145%)
     - 5人队伍（满编）：$1.60\times$ (160%)
  2. **遭遇预算缩放**：遭遇的危险度区间 `[minBudget, maxBudget]` 及 `maxTotalStrength` 强度池上限同等乘以该威胁度倍率，使普通波随机预算与特殊波（精英/Boss）剩余护从预算按比例扩展。
  3. **波次怪量上限扩容**：单人单挑时维持原 `MaxWaveSize = 3`（一行 3 只）不变；组队多名玩家（$N > 1$）时，波次最大怪量上限提升至九宫格上限 9 只（`MaxAlliedWaveSize = 9`），确保增加的威胁度能实际转化为更多的怪物同场激战，九宫格前中后排自适应铺满。
- **影响范围与实现边界**：
  - 核心领域：`src/Domain/Combat/EncounterWaveSelector.cs`（预算推算与怪群轮盘）、`src/Ecs/Systems/CombatActionRules.cs`（行动搜寻入战与波次推进参数接入）。
  - 单人战斗保持 100% 确定性与原有基线不变。
  - 前端渲染已具备 3x3 九宫格 18 角色完全自适应支持，无需前端布局重构。
