# TASK-20261004-02 移除强化护符：强化失败保护改为消耗保护材料

- **提出时间**：2026-10-04 02:00:00（上一轮会话）
- **状态**：✅ 已完成
- **分类**：数值模型调整 / 强化规则 / 全栈

## 需求

用户裁定：移除「强化护符」（`item.enhance-charm`）物品。强化失败保护改为消耗材料——装备配表配置 `enhanceProtectionItems` 列表时可从列表任选其一消耗；未配置时使用同装备的无强化版本（+0 基础件）保护。

## 方案与落点

1. **领域** `src/Domain/Player/EnhancementRules.cs`：删除 `CharmItemId` 常量；`Preparation.UsesCharm` 改为携带 `ProtectionItemId`；`Resolve` 从 `gameData.RawEquipments[targetItemId]` 读 `enhanceProtectionItems` 数组——有列表时 `auxItemId` 必须在列表内，无列表时必须等于目标装备基础 ID；再查钱包持有 ≥1（+0 装备以自身裸件代护时须 ≥2）。
2. **ECS** `src/Ecs/Systems/ActionExecutionRules.Timed.cs`：结算扣件从固定 CharmItemId 改为 `prep.ProtectionItemId`，`itemLosses` 同步；失败维持 `max(0, t-1)`，无保护归零。
3. **协议映射** `src/Server/Clean/StaticGameCatalogMapper.cs`：装备 wire DTO 增 `enhanceProtectionItems` 透传。
4. **配置**：`config/game-data/items/materials.json` 删除 `item.enhance-charm`。
5. **前端**：`EnhancementPage.tsx` 护符 checkbox 换为 `ChoiceMenu` 下拉选择器（选项 = 装备 `enhanceProtectionItems` 列表或默认 `[selected.itemId]` 基础件），经 `auxItemId` 下发；`types.ts` 增 `enhanceProtectionItems?: string[]`；`combatConstants.ts`/`ids.ts`/`game.zh.ts` 删护符残留，`app.zh.ts` `charm*` 键改 `protection*` 键。
6. **测试**：`TechniqueAndEnhancementTests.cs` 新增保护材料裁决用例（白名单/裸件回退/≥2 规则/列表外拒绝）；`EnhancementContractTests.cs` aux 用例改为装备 ID。
7. **文档**：总纲 §20.4.2 与 TASK-20261003-04.md 同步保护材料口径。

## 边界

- 当前没有任何装备配置 `enhanceProtectionItems` 白名单，全部走默认规则：同装备无强化基础件代护。
- 保护材料按裸 `AssetKey` 扣 1，每轮强化消耗 1 个，与原护符口径一致。
