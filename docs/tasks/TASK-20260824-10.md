## 1. 任务背景与核心目标

用户希望拥有一个**十分好看的、契合当前游戏页面暗墨修仙风格的单独 HTML 网页**，无需启动任何开发服务器（直接双击 `file://` 即可打开），能够动态读取或直接浏览《道化太初·总纲》（`docs/design/总纲.md`），并具备极致的视觉质感与交互体验。

### 核心功能与美学要求：
1. **零服务器依赖（Single-File Offline Ready）**：单文件 HTML，内嵌默认的最新主设计文档内容，同时支持本地文件选择、拖拽或 URL 参数动态加载任意 Markdown 文件；
2. **古典暗墨修仙美学**：
   - 暗墨玄石渐变背景（`#0e0c07`）叠加毛玻璃浮层与直角暗金折角纹理（`.daohua-floating-corner`）；
   - 修仙五行色调高亮（暗金 `gold`、苍翠 `jade`、灵虚淡蓝 `qi`、朱砂煞红 `danger`、紫极天道 `purple`）；
   - 标题字体融合楷体/宋体（`"Noto Serif SC", "Kaiti SC", serif`），正文清晰易读；
3. **沉浸式交互功能**：
   - 左侧智能大纲目录树（支持折叠/展开、当前阅读进度高亮、点击平滑滚动、阅读百分比进度条）；
   - 顶部修仙道韵导航栏（太极徽标、实时全局模糊搜索过滤、字体缩放、全屏切换、本地文档拖拽上传切换）；
   - Markdown 高级富渲染（自动将表格美化为玄石暗金网格、LaTeX 数学公式美化、Mermaid 图表、代码一键复制、Callout 卷轴引用框、修仙阶位胶囊徽章自动渲染）；
   - 双端自适应（桌面宽屏多栏与移动端抽屉目录）。
