# TASK-20261009-04 战斗单位详情弹窗「装配」Tab：功法与装备一并可查

## 需求

战场单位详情弹窗（点击角色/盟友/怪物/斗法镜像头像弹出 `CharacterAttributeModal`）此前只展示战斗属性
（+怪物的掉落 Tab）。需要新增一个 Tab 同时展示**功法与装备**；无装备概念的单位（怪物）只显示功法。
Tab 命名自定——取「装配」，与领域 `Loadout` 语义一致。

## 数据源分析

| 单位 | 功法 | 装备 |
| --- | --- | --- |
| 玩家自己 | `state.combat.abilitySlots`（本地常驻） | `state.combat.equipment`（本地常驻） |
| 怪物 | 静态目录 `CombatantDefinition`（原 `abilityIds` 升级为 `skills[]` 带配表等级） | 无——装备分组不渲染 |
| 盟友 | `ActionParticipantSnapshot.Skills`（开打冻结，已持久化） | 新增 `Equipment` 冻结字段（v23） |
| 斗法镜像 | `DuelPlaybackState.OpponentSkills`（撮合冻结，v23） | `DuelPlaybackState.OpponentEquipment`（v23） |

盟友/斗法镜像的技能装备与属性面板同走 `UnitInspect` 按需一次性投影通道，前端按身份键缓存
（与 `inspectedAttributesCacheRef` 同模式），不占常驻快照带宽。

## 改动清单

### 领域 / 服务端

- `ActionParticipantSnapshot` 尾部新增 `IReadOnlyList<PlayerEquipmentSlot>? Equipment = null`，
  `IsValid` 校验；两处采集点（在线 `CaptureActionParticipantSnapshot`、离线 `FromState`）传入冻结装备。
- `DuelCombatant` 新增必填 `Equipment`；`DuelPlaybackState` 新增 `OpponentSkills`/`OpponentEquipment`，
  `ForViewer` 从对手镜像填充，`IsValid` 校验。
- `ToExpeditionAlliesDto`/`ToDuelPlaybackDto`：观察目标命中时同帧投影 `skills`/`equipment`（与 `attributes` 同一交付窗口）。
- `StaticGameCatalogMapper.ResolveMonster`：`abilityIds` → `skills: [{abilityId, level}]`（取 `CombatMonsterDefinition.Skills`）。
- 存档 `CurrentSchemaVersion`/`PostgresSchema.Version` 21 → 23：在飞的 v22（duel `combatants`，
  用户未提交迁移 0022）与本任务 v23 一并落地常量与注释；`migrations/0023_v22_to_v23.sql`（可缺省解码，仅标签推进）；
  `PostgresSchema.Sql` 种子 `schema_version` 行补齐至 23，README 登记表同步。

### 前端

- `types.ts`：`CombatantDefinition.abilityIds` → `skills: CombatAbilitySlot[]`；
  `ExpeditionAlly` 增 `skills`/`equipment`；`ExpeditionDuel` 增 `opponentSkills`/`opponentEquipment`。
- `snapshot.ts`：allies/duel 新字段可缺省解码。
- `CombatAttributePanel`：Tab 组新增 `loadout`（顺序：基础/特殊/装配/掉落），`loadout` prop 驱动；
  功法瓦片复用 `ConditionedTile`+`describeAbility`+`item-tile` 样式（只读、无编辑交互）；
  装备瓦片复用 `ItemTooltipTarget`+`ItemTile`。
- `CombatArena`：`AllyDisplayState` 增 `skills`/`equipment`；新增装配一次性交付缓存；
  `inspectedLoadout` 按 inspected 目标四类来源合成，弹窗透传 `loadout`。
- `CombatEcologyPanel`：`abilityIds` → `skills` 适配。
- `insight.zh.ts`：新词条 `groupLoadout=装配`、`loadoutAbilities=功法`、`loadoutEquipment=装备`、`loadoutEmpty`。

### 测试

- `SkillTriggerEvaluatorTests` 的 `new DuelCombatant(...)` 追加装备参数。
- `InsightPage` 斗法 Tab 的 `CombatAttributePanel` 同步传入本机装配（共享面板口径一致）。
