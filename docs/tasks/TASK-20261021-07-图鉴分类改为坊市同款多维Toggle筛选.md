## 2. 需求与边界

- **诉求**：坊市已有成熟的多维 Toggle 子 Tab 体系，图鉴当前分类「不是很好」，要求把坊市的 Toggle 子 Tab 范式应用到图鉴内。
- **判据**：图鉴每个主分类下都具备「多维度、可叠加、可复位」的筛选项，且选项式样与坊市完全一致；分类真源一律取配表字段，不允许按 ID 硬编码分流。
- **边界**：只做前端图鉴分类与筛选，不改服务端、不改解锁结算语义、不改协议。

## 3. 现状取证（改造前）

| 问题 | 证据 |
| :--- | :--- |
| 图鉴只有「独立子 Tab 条」，一维到底 | `CodexPage.tsx` 三处 `.codex-sub-tabs`：材料（herb/mineral/exotic）、技艺（四技艺）、特质（品阶），无叠加、无收录状态过滤 |
| 材料子分类与配表脱节 | `codexCalculations.isMaterialSubTabItem` 用 6 条物品 ID 特例把 `refinedMaterial`（精材）硬分流进「药材/矿石」，配表实际有四类子分类却展示成三类 |
| 图鉴与坊市两套 Toggle 实现 | 坊市 `MarketOptionToggle` + `.market-toggle-group` 为组件内私有，图鉴无法复用 |
| 筛选状态扁平 | `uiStore` 用 `codexMaterialSubTab` / `codexCraftingSubTab` / `codexTraitSubTab` 三个独立字段，无法承载多维筛选 |

## 4. 实现方案

### 4.1 公共模板抽取

- 新增 `frontend/src/components/OptionToggle.tsx`：坊市私有 `MarketOptionToggle` 提升为全站公共组件，新增可选 `count` 角标（收集度面板用），保留整体置灰语义。
- 样式类名去坊市前缀：`.market-manual-filters` → `.filter-bar`、`.market-filter-label` → `.filter-label`、`.market-grade-field/select` → `.filter-grade-field/select`、`.market-toggle-group/btn` → `.option-toggle-group/btn`，并新增 `.option-toggle-count`；浅色主题覆盖同步改名。
- 坊市 `MarketBrowseGrid.tsx` 改用公共组件与通用类名（行为零变化，已在浏览器逐项复验）。

### 4.2 图鉴分类真源化

新增 `frontend/src/game/codexFilters.ts`（纯函数，无 React/store 依赖）：

| 维度 | 取值 | 真源 |
| :--- | :--- | :--- |
| 材料分类 | 灵材 / 矿石 / 异材 / 精材 | 配表 `subCategory`（四类直取，删除 ID 特例表） |
| 技艺分类 | 炼丹 / 炼器 / 阵法 / 符箓 | 行动配表 `technique`，`craft.refine-*`/`craft.extract-*` 按实际技艺归属 |
| 建造分类 | 生产 / 战斗 | 配表 `group` |
| 功法 | 门类（术法/内功）+ 伤害（物理/法术） | 配表 `discipline` / `category` |
| 妖兽 | 妖兽 / 精英 / 妖王 | 配表 `rank` |
| 特质 | 凡品 ~ 天品 | `TRAIT_DEFINITIONS.quality` |
| 等阶 | 全部 + 1~8 阶 | 材料/功法 `tier`、制造 `resolveActionLevel` |
| 收录 | 全部 / 已收录 / 未收录 | 各分类既有解锁判定 |

`tallyCodexBuckets` 一次遍历产出每个 Toggle 选项的「已收录/总数」角标，与一级页签和总进度胶囊同口径。

### 4.3 状态模型

`uiStore` 三个扁平子分类字段替换为 `codexFilters: Record<CodexCategory, CodexFilterState>` + `setCodexFilters(category, patch)` 逐分类浅合并：切分类只改自己那份，互不干扰；切页离开图鉴后返回，筛选原样保持。

### 4.4 UI 结构

一级页签（六个主分类，右侧带已收录/总数）→ 二级 `.filter-bar` 多维筛选栏（分类 Toggle + 等阶下拉 + 收录 Toggle）→ 条目网格。图鉴顶栏内的筛选栏用 `.codex-filter-bar` 去掉坊市版本的下边框与外边距。
