### 注释规范与详细度基准（中等详细度）
1. **类 / 结构体 / 接口级**：说明所属架构分层、核心职责、所有权模型（如单 Fiber、线程安全约束、纯领域不可变性）。

4. **前端状态 / UI 组件级**：说明组件职责、Props 约束、状态流转意图、精准订阅与 memo 隔离意图。
5. **杜绝无意义机械废话**：不编写单纯复述语法的注释，重点突出业务上下文与技术边界。
