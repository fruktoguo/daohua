# TASK-20261026-02 全量内功被动提升50%与焚血功翻倍乘率到9

## 1. 任务背景与核心需求

用户需求两句话：
1. 「给所有功法的属性加成,提升50% / 给焚血的提升100%」
2. 「然后经验分配,焚血需要总百分比到9」

### 1.1 现状取证与计算

- 内功配表：`config/game-data/abilities/internal_abilities.json`（共 10 门，7 门带 `passive`，吐纳功/炼精化气诀/玄元一气功 3 门无 passive）。
- 属性加成（`passive` 常驻面板点数）：
  - 全部带 passive 的内功基础点数提升 50%（×1.5）。
  - 焚血功单独提升 100%（×2.0）。
  - 成长斜率 `passiveEfficiencyPerLevel: 0.05`（每级 +5% 线性成长）保持不动。
- 六维经验分配（`rootExpMultipliers`）：
  - 焚血功当前配表：`attack: 3.5, stamina: 0.0, consciousness: 0.5`，未列维度（meridians, bone, agility）缺省 1.0，总和为 $3.5 + 0.0 + 0.5 + 3 \times 1.0 = 7.0$。
  - 提升到总和 9.0（增量 +2.0）：遵循「献祭生机气血、换取撼地狂力」的魔道刚猛力修设定，保持 `stamina: 0.0` 终身停长的真代价与 `consciousness: 0.5` 的神智压低，将 +2.0 全部注入主修攻击维度：`attack: 3.5 → 5.5`。
  - 新六维总和 $5.5 + 0.0 + 0.5 + 3 \times 1.0 = 9.0$；基准六维总效率 Lv1 从 117%（7/6）跃升至 150%（9/6），Lv127 参悟终值达 717%（$9/6 \times 4.78$）。
