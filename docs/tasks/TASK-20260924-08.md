- `src/Domain` 保持纯净：不得引入 ASP.NET Core/数据库/网络依赖。
- 每批修改必须通过门禁：`dotnet build` Release 0 警告、`Domain.Tests`、`Server.Tests`（PG 集成用例需 `DAOHUA_MARKET_TEST_CONNECTION`，环境缺失时按既有口径记录）、前端 `build`、契约校验、DataTool strict（涉配表时）。

## 分析维度（首轮并行审计）

1. **服务端运行时**：PlayerRuntime/PlayerActor 单写者模型、WebSocketRuntime 收发管线、MarketRuntime 分区租约、后台 Worker 调度——锁竞争、分配、批量落盘节奏、横向扩展阻塞点。
2. **领域模拟**：SimulationEngine 推进热路径、快照/增量生成成本、每 tick 分配与 LINQ/装箱——计算密度与 GC 压力。
3. **计算节点链路**：compute-link.v1 反向拨入、compute_jobs 派发/回写、批次回退——多节点容量利用、任务粒度、故障半径。
4. **协议与网络**：信封/序列化开销、快照体积、广播扇出、前端解析与渲染节奏——带宽与端到端延迟。
