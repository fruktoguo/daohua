## 1. 任务背景与核心目标

用户希望在单文件主设计文档查看器（`docs/design/master-design.html`）中增加更具修仙沉浸感的阅读交互与排版节奏：
1. **平滑滚动与修仙流光特效**：增强滚动时的动态反馈、细金流光进度条与滚动条微光；
2. **层次化/阶梯式段落缩进（Hierarchical Indentation）**：不同层级与语义的段落拥有分明、规整的层次缩进（篇章导言、H2 小节段落、H3 深层细则、列表、表格各自有节奏不同的左侧缩进和首行排版）；
3. **最下方新进入段落的视口渐显浮现动效（Scroll Reveal Animation）**：
   - 基于 `IntersectionObserver` 实现高性能的进入动效；
   - 当用户向下滚动时，从视口下方新露出的段落、标题、表格、卡片自动执行平滑的“淡入 + 向上浮现 + 灵气虚化聚拢”（`opacity: 0 -> 1; transform: translateY(24px) -> translateY(0); filter: blur(3px) -> blur(0)`）；
   - 首屏元素默认立即可见，避免闪烁；新加载内容级联交错显现。
