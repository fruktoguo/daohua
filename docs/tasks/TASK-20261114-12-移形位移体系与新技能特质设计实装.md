## 需求目标与核准方案

1. **统一位移机制 Buff——「移形」（`buff.yixing`）**
   - 道化太初回合时间轴中，全部位移/闪现效果统一收口为「移形」Buff。
   - 基础时长 5.0s，`resetOnWave: true`；重复授予**叠加层数（上限 99）并刷新到期时间**。
   - **效果不随层数或技能等级叠加**：只要层数 $\ge 1$，固定提供 **+100% 闪避后段乘区**（最终闪避 $\times 2$，`EvasionPostRatio` 收口为 `Instance` / `GrowsWithLevel: false`），且施放**伤害型技能**时攻方命中 $\times 2$。
   - 施放伤害型技能后**按技能次数固定消耗 1 层**（非按命中次数或目标数消耗）；普通攻击与纯治疗/辅助技能既不吃双倍命中也不消耗「移形」。
2. **新增三门主动技能与配套秘籍残卷（暂不配置怪物掉落）**
   - **跃迁**（`ability.yueqian`，T2 叩天门，术法系 `spell` / `talisman` / `none` / `consciousness`）：吟唱 3.0s、冷却 24.0s、耗蓝 50；为全体存活友方施加 1 层 5.0s「移形」（最大 99 层，跨波清除），默认触发 `self buff-stacks equal 0 buff.yixing`。
   - **斩玉 / 踏云**（`ability.zhanyu`，T1 凡胎，物理系 `physical` / `sword` / `metal` / `agility` / `discipline: "spell"`）：吟唱 0.5s、冷却 8.0s、耗蓝 10；常态「斩玉」对单体敌方造成 `100% AD + 10` 金系物理伤害；起手结算时若施法者拥有「移形」，切换为「踏云」对全体存活敌方造成同等伤害，并记为 `{{ability:ability.zhanyu|踏云}}`（悬停仍查「斩玉」、熟练度仍记 `ability.zhanyu`），本技能施放享受 2× 命中并最终消耗 1 层「移形」。
   - **火焰风暴**（`ability.huoyan-fengbao`，T2 叩天门，术法系 `spell` / `fiveElements` / `fire` / `consciousness`）：吟唱 3.0s、冷却 18.0s、耗蓝 30；对全体敌方造成 `100% AP + 50` 火系术法伤害，并对命中且存活的敌方附加 `max(1, floor((max(0, AP) * 技能增幅 * 0.20 + 5) * 等级成长 + 1e-9))` 层既有燃烧 Buff「燃魂」（`buff.ranhun`，持续 5s、每层每秒 1 点火法持续伤害、`ResetOnWave = true`），与特质「燃魂」共用同池叠层与来源归属。
   - **秘籍与残卷**：在 `config/game-data/items/manuals.json`、`frontend/src/game/ids.ts` 与 `game.zh.ts` 补齐 3 套 6 件物品，**不改动任何怪物掉落表**。
3. **新增天品特质——「剑与心」（`trait.jianyuxin`）**
   - Q5 天品（金色），消耗 **12 点**，常驻 **+10% 物理攻击、+10% 术法攻击**（随等级 `1 + 0.05 × (Lv − 1)` 成长）。
   - 机制效果：施法者拥有「移形」时，任何伤害型技能的**主要目标无视仇恨体系，改为从当前存活敌方中等概率随机选取**（单体/多段/连锁与群体技能 `picked[0]` 统一生效，从而连带决定「蓄意」等按主目标判定的效果对象）。
