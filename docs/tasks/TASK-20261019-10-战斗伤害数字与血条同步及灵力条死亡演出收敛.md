## 2. 现象与根因

### 2.1 伤害数字与掉血不同步

1. **血条抢跑、浮字滞后**：快照到达时，`ArenaResource` 的保底路径在 `useLayoutEffect` 中立即把血条落到权威值（只要距上次命中超过 400ms），而事件浮字与切片按击中帧延迟 200ms（普攻）/280ms（施法）才出现。玩家看到的是「条先掉、数字后出」。
2. **致死一击错位**：波次清空切搜寻相位时，尸体阵容合成会把 `hp` 直接置 0；血条在切换帧立即归零，致死一击的数字仍在途中，因果进一步错位。

### 2.2 有时完全没有伤害数字

1. **稳定键缺失**：事件去重签名包含数组下标与 `at.toFixed(2)`。斗法回放窗口滑动时同一事件下标变化，会被重复消费；反之批次重排也可能误判。
2. **浮字队列过短**：`setEffects(current => [...current.slice(-5), effect])` 固定只留 6 条。服务端按 5 秒资源窗口批量结算，一次快照可能携带多次出手；集火或多段连击时，先到的浮字会在同一帧被挤出，永远不可见。
3. **保底被过度抑制**：旧逻辑只要事件数组里存在任意一条命中事件，就不为非事件掉血补数字；DoT、反伤、同批未被事件承接的掉血因此被吞。另有「相同 delta 去重」会把连续等量 DoT 跳字吞掉。
4. **伤害截断**：`formatInteger` 对 `-0.4` 一类小额伤害截断为 `0`，看起来像没有伤害。

### 2.3 怪物死亡后仍播放灵力条消耗动画

1. `combat → search` 合成尸体时显式写入 `mp: 0`，灵力条从当前值掉到 0，触发蓝色切片与负向浮字。
2. 灵力条切片渲染未按 `tone` 限定；设计口径中「血条碎裂切片」只属于气血条，灵力消耗不应产生碎条。

### 2.4 批次节奏

服务端按资源自然窗口（默认 5 秒）批量推进战斗，一次快照同时携带窗口内全部事件。旧实现「收到即播」会让整段伤害在同一帧爆开、攻击方也全部同帧起手，既失去先后节奏，也放大了浮字挤出问题。

## 3. 实施方案

### 3.1 新增纯函数调度模块

`frontend/src/game/combatFeedback.ts`：

- `combatEventBaseKey`：以战斗时钟、攻守、伤害、结算后气血、命中/暴击/破招/拆解与同值事件序号构成**稳定去重键**，不随数组下标漂移。
- `collectScheduledCombatEvents`：只挑出「匹配当前单位且未消费」的新事件，把同一批次的跨度压缩到 `COMBAT_EVENT_REPLAY_BUDGET_MS = 520ms` 内按出手先后重放，同一时刻多段连击按 `COMBAT_COMBO_STEP_MS = 110ms` 错峰；单批次最多重放 `COMBAT_EVENT_REPLAY_LIMIT = 32` 条（离线补算可能一次携带整段战斗事件，避免计时器风暴）。
- 命中帧常量与 `combatHitDelayMilliseconds` 一并收拢，供攻击方起手、受击方反馈与血条落地共用同一时间轴。

### 3.2 `ArenaResource`（气血/灵力条）

- **击中帧锁步**：事件排期时登记 `pendingDropRef`（目标值 + 落地时刻）；保底路径遇到「有事件承接的掉血」只修正目标值，不再抢先落条，等击中帧与数字一起落地。
- **无事件掉血保底**：DoT、反伤、持续扣血等没有事件承接的掉血，仍即时落条并补数字，不再依赖「事件数组中是否存在任意命中」的粗判。
- **浮字容量**：并发浮字上限提升到 `COMBAT_RESOURCE_EFFECT_LIMIT = 24`，解决 5 秒批次与集火时数字被挤出。
- **数值呈现**：伤害数字至少保留 1 点量级（小额伤害不再显示为 0）；横向车道扩展到 5 条。
- **切片条件**：碎条宽度按真实受损比例计算，低于最大值 2% 的持续伤害不再产生切片；灵力条完全不产生切片。
- **灵力条收敛**：只在消耗（负向）时给浮字，自然回复不再刷屏；单位阵亡（`frozen`）后清空浮字与待定状态，尸体只保留定格数值。
- **目标切换**：清空上一单位在途计时器与待定掉血；已消费事件集合跨波保留，避免新一波误重放上一波终局事件。

### 3.3 `ArenaActor`（出手/受击/闪避）

- 攻击方起手、受击方震颤、闪避身法统一改用批次重放时间轴，与伤害数字、血条保持同一因果链。
- 目标切换时清理在途动作/受击计时器，避免旧波次定时器落到新怪身上。
- 记录事件出手排期时刻；行动条倒计时兜底的挥刀在 320ms 内与事件出手重合时跳过，消除同一次攻击挥两刀。

### 3.4 尸体阵容

- `corpseWave` 与相位过渡帧不再把 `mp` 置 0，仅将 `hp` 归零并清空行动条；灵力条保持战斗末值定格。
