# TASK-20260930-11 物品类型两级化：主类型 + 子类型配置，丝带显示子类型

## 需求

- 提出时间：2026-09-30 19:09:24
- 用户反馈：物品本身的类型应分为两个类型配置——主类型与子类型；左上角角标显示子类型。

## 现状问题

- 配表 `category` 单字段混用两级语义：materials.json 中 herb/mineral/material 共存（herb/mineral 实为 material 的细分），manuals.json 全本/残卷同为 manual 只能靠 ID 前缀区分。
- 前端 `resolveItemSubCategory` 上一轮以启发式推导子类型（ID 前缀/装备槽位），缺乏配表权威字段；坊市 `subCategory` 是前端派生字段而非数据。
- `kind` 字段（consumable/material/currency）是功能行为轴，与展示分类轴职责不同，不能直接充当主类型。

## 方案（两级分类模型）

- 配表物品定义新增 `subCategory`（子类型，可选）字段，`category` 归一为主类型：
  - `material`（材料）→ sub：`herb` 药材 / `mineral` 矿石 / `material` 材料（通用）
  - `consumable`（消耗品）→ sub：`pill` 丹药 / `alchemySupply` 炼丹用品 / `explorationSupply` 探索用品（灵食/灵饮/符箓预留键已在词典）
  - `manual`（功法）→ sub：`manualTome` 秘籍 / `manualFragment` 残卷
  - `currency`（货币）→ 无子类型（回落主类型）
  - `equipment`（装备）→ 子类型即 `slot`（weapon/head/armor/legs/boots/trinket），配置不重复字段
- Domain `ItemDefinition` 新增 `SubCategory`；`ParseItem`/`StaticGameCatalogMapper` 全链透传；药品栏门控改判 `SubCategory == 'pill'`。
- 前端：`ItemDefinition.subCategory`、`InventoryItem.category` 更名 `subCategory`（静态元数据表字段同改）；`resolveItemSubCategory` 改为显式字段解析（`eqDef.slot ?? def.subCategory ?? fallback`），移除 ID 前缀启发式。
- 左上角丝带统一显示子类型；悬浮详情「品类」行显示 `主类型 · 子类型`。
- 坊市一级 Tab `pill` 归并为 `consumable`（消耗品），子 Tab 按子类型过滤；材料/功法子 Tab 同样改用权威 `subCategory` 字段匹配。
