## 需求复述与目标

在完成 `TASK-20261024-04` 反多开私有模块化拆分后，将兄弟私有仓库与开源主仓库分别发布至 GitHub：
1. **私有仓库上传**：在 GitHub（账号 `fruktoguo`）创建私有仓库 `daohua-private`，将本地 `D:\Project\Vibe\DaoHua-Private` 推送上去，作为专有的反多开模块与私密扩展资产保管库。
2. **全量历史双备份**：在清洗主仓库前，生成本地不可变全量 Git Bundle 归档（`daohua-full-history-backup-20261024.bundle`），同时将包含全部历史提交的分支推送到私有仓库 `fruktoguo/daohua-private` 作为云端长期灾备，确保自项目创建以来的每一条开发 commit 永不丢失。
3. **主仓库历史清洗与开源**：将主仓库 `DaoHua` 本地历史压缩（Squash/Orphan 分支法）为单条纯净的初始开源提交，彻底消除历史 commit 中曾经存在的反多开代码、指纹算法与敏感记录；强制推送到 `fruktoguo/daohua` 并将其仓库属性由 Private 修改为 Public。

## 详细实施步骤

### 1. 私有仓库创建与推送
- GitHub CLI 创建私有仓库：`gh repo create daohua-private --private --description "道化太初私有扩展模块（反多开子系统与专有门禁）"`
- 本地 `D:\Project\Vibe\DaoHua-Private` 分支对齐为 `main`，配置 remote `origin` 并推送到 `fruktoguo/daohua-private`。

### 2. 主仓库全量历史双重备份
- **本地归档**：使用 `git bundle create` 制作全引用归档包：
  `git bundle create D:/Project/Vibe/daohua-full-history-backup-20261024.bundle --all`
  并使用 `git bundle verify` 校验有效性。
- **云端备份**：在 `DaoHua-Private` 远端仓库中追加推送全量历史备份分支 `history/pre-opensource-daohua`，确保 GitHub 私有端具备云端版本控制历史。

### 3. 主仓库历史清洗（Squash 重发）
- 从当前 HEAD 创建孤儿分支 `clean-main`（`git checkout --orphan clean-main`），保留现有完整源码树与中性扩展点骨架；
- 形成全新的单一初始提交：
  `feat: 道化太初（DaoHua）开源初始发布`
- 本地旧 `main` 留存重命名为 `legacy-history-main`，新分支接管 `main`。

### 4. 泄露扫描与验证
- 扫描确认无任何密钥、私钥、Token、敏感环境变量或私有反多开实现文件遗留；
- 运行开源口径 `npm run build` 与关键单测。

### 5. 强制推送与可见性切换
- 强制覆盖推送到 GitHub `fruktoguo/daohua` 的 `main` 分支；
- 调用 GitHub CLI 将 `fruktoguo/daohua` 可见性设置为 `public`：
  `gh repo edit fruktoguo/daohua --visibility public`
- 验证公开访问状态与 Commit 列表纯净度。
