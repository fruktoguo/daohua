# TASK-20261025-06-物理技能五行属性分配与正交伤害结算

## 1. 任务背景与核心目标

- **任务提出时间**：2026-10-25 18:45:00
- **需求分析完成时间**：2026-10-25 18:52:00
- **任务分类**：数值设计 / 技能配表 / 战斗流派 / 体系对齐
- **业务目标**：
  - 现行配表 `config/game-data/abilities/physical_abilities.json` 中，所有物理技能的属性字段均为 `"element": "none"`，导致物理系无法享受角色的五行灵根增伤、功法词条与装备五行增伤，与术法系（自带水/火/木等五行）形成体验断层。
  - 用户明确要求：“给所有的物理系都加上属性，但还是物理伤害；嘲讽（及纯 Buff 无伤害技能）保持无属性，连环给火，重云给水，重斩与贯星定为金”。
  - 伤害大类依然为 `category: "physical"`（基于 AD 攻击力、对抗护甲防御减伤、吃物理增减伤），但附带五行属性标签，在伤害流水线第二层与第三层激活五行增伤与抗性判定，实现「物理伤害与五行属性正交并存」。
