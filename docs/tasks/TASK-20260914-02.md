## 1. 需求背景与核心目标

用户针对当前的修仙界「坊市」（Market）浏览界面提出了 5 项明确优化需求：
1. **移除状态行**：坊市顶部“共 51 种可交易物品”与后面的“灵石 0”整行移除；
2. **修复网格行高拉伸填充**：坊市物品网格因 CSS Grid 缺少 `align-content: start` 与行高约束，导致物品较少时纵向等比拉伸填充整个容器高度，出现巨大纵向间距，需修复为紧凑行高与顺序排列；
3. **材料分类二级子 Tab 拆分**：将现有一级平铺的“矿石”、“药材”收拢为“材料”大类下的二级子选项卡（全部材料、矿石、药材、通用材料）；
4. **接入装备大类与分类筛选**：原坊市仅读取 `state.items` 导致装备缺失，需将 `state.equipment` 完整接入坊市交易标的与二级子 Tab 筛选（全部装备、武器、防具、饰品）；
5. **功法秘籍悬浮副卡片 (Aside Card)**：技能功法书/残卷物品在悬浮时，右侧联动挂载统一的技能副气泡胶囊窗口，展示技能伤害系数、前摇、冷却、灵力消耗、生效目标与战斗机制。

## 2. 详细技术实现与落地成果

### 2.1 状态行精简与 Header 适配
- 在 `MarketPage.tsx` 中彻底移除了 `<div className="market-status-row">` 及其子元素（“共 xx 种可交易物品”、“灵石 xx”）；
- 错误与同步中状态内联至顶部 Header 右侧操作区（`.market-header-actions`、`.market-header-status`），不侵占主内容纵向视口；
- 清理了 `styles.css` 中 `.market-status-row` 与 `.market-status` 等冗余样式。

### 2.2 网格行高拉伸修复
- 在 `frontend/src/styles/selection-grid.css` 与 `frontend/src/styles.css` 的 `.market-browse-grid` 中增加了：
  ```css
  align-content: start;
  align-items: start;
  grid-auto-rows: var(--item-slot-size);
  ```
- 确保物品网格自上而下顺序紧凑排列，每行方块固定为 64px，间距固定 6px，无论内容多少均不再产生纵向拉伸变形。

### 2.3 分类体系与二级子 Tab 重构
- **一级分类 (Main Tabs)**：`全部` (`all`)、`材料` (`material`)、`装备` (`equipment`)、`丹药` (`pill`)、`功法` (`manual`)。
- **二级分类 (Sub Tabs)**：复用公共组件规范 `.insight-sub-tabs` 与 `.insight-sub-tab-btn`，当选中对应一级主分类时动态展示：
  - 材料大类：全部材料 (`all`)、矿石 (`mineral`)、药材 (`herb`)、通用材料 (`other`)；
  - 装备大类：全部装备 (`all`)、武器 (`weapon`)、防具 (`armor`，含 head/armor/legs/boots)、饰品 (`trinket`)；
  - 功法大类：全部功法 (`all`)、秘籍全本 (`tome`)、招式残卷 (`fragment`)；
- **装备标的完整接入**：在 `MarketPage.tsx` 中从全局 store 读取 `state.equipment`，映射为可交易标的 `MarketInstrument`，透传 `equipmentDefinition` 与 `subCategory`，详情页与购买挂单弹窗完整支持装备属性展示。

### 2.4 功法秘籍技能副气泡窗口 (Aside Card)
- 在 `ItemDisplay.tsx` 中实现了 `resolveManualAsideCard` 解析器；
- 匹配 `item.tome.*` 或 `item.fragment.*` 提取技能 ID，检索全局技能目录 `CombatAbilityDefinition`；
- 调用 `describeAbility(ability, 1)` 构造修仙副气泡卡片（mark 标为「秘籍参悟」或「残卷参悟」，包含流派属性、威力系数、灵力消耗、前摇与冷却时间、战斗释放机制等）；
- 全局所有使用 `ItemTooltipTarget` 的组件（坊市、背包、行囊等）自动生效。

### 2.5 i18n 词条闭环与公共组件手册更新
- `market.zh.ts` 补齐一级与二级 Tab 词条；构建自动同步至 `template.csv`（共 1331 条中文词条）；
- `docs/frontend/common-components.md` 第 1 节与第 5 节同步登记功法书副卡片参悟与坊市二级子导航规范。
