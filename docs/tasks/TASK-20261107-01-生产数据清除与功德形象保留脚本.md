# TASK-20261107-01 生产数据清除与功德形象保留自动化脚本准备

## 1. 任务背景与核心需求

道化太初当前处于内测删档迭代节点。为配合后续新版本上线与删档，需编写数据重置运维脚本 `scripts/reset-player-game-data.sh`。

### 核心规则与业务边界
1. **纯准备，绝不执行**：本次任务只负责完成脚本编写、本地语法测试与逻辑验证，**严禁在生产环境执行删档**；
2. **只清游戏域，保留账号主体**：
   - 保留：`identity.accounts`（账号凭据）、`identity.players`（角色道号与创建信息）；
   - 重置：修为境界（重置为 Lv.1 凡胎）、背包道具与装备实例、功法技能与特质、行动队列、市场挂单与成交记录、社交队伍与消息；
3. **功德资产继承与全额返还**：
   - 继承：玩家当前持有的普通功德（`item.gongde`）与绑定功德（`item.gongde-bound`）；
   - 返还：玩家历史在系统商店（`shop.buy`）消耗的全部功德全额原币种返还回补；
   - 形象解锁消耗不返还（因为已解锁形象终身保留）；
4. **形象终身保留**：
   - 玩家当前装配的形象与已解锁形象列表完整保留，重置后绝不退化回默认双剑修；
5. **范围与安全控制**：
   - 支持 `--dry-run`（只读对账）与 `--apply`（真实执行）；
   - 真实执行前强制触发远端 `/opt/daohua/backup.sh` 热备归档；
   - 执行前强制交互确认（输入 `CONFIRM_RESET_DATA`）；
   - 严格排除 100 个机器人账号（`bot_%`）与 1 个固定烟测账号（`smoke_ci_verifier`）；
   - 支持指定排除管理员账号（如 `yuohira`）以及按注册时间范围筛选（`--older-than-6h` 或 `--all`）。
