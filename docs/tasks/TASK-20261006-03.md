# TASK-20261006-03 坊市物品网格左右留白均衡 + 详情视图整面板滚动修正

- **提出时间**：2026-10-06 14:46:12
- **分类**：前端体验 / 布局优化
- **状态**：🧪 验证中

## 需求分析

1. 用户反馈坊市浏览页物品列表左右边距不一致：容器宽度不是「列宽+间距」整数倍时，网格余量全部堆到右侧，左右空隙差距明显（左 6px padding vs 右 6px + 最多 ~69px 死区），期望宽度铺满、均匀排布。
2. 二轮反馈：坊市详情/委托视图「整体面板」纵向滚动——约定是所有滚动内容应收进子窗口（导航/工具条钉住，仅内容区自滚）。实测 1400×650 下 `.market-instrument-detail-view`（264/346）、`.market-own-panel`（264/264+）整面板滚动，连返回导航条一起滚走。

## 根因

- `.market-browse-grid` 列模板来自 `selection-grid.css` 共享规则 `repeat(auto-fill, var(--item-slot-size))`（64px 定宽列、6px gap），`auto-fill` 空轨道不折叠且不参与分布，`justify-content` 缺省 `start` → 行尾余量单侧堆积。
- 瓦片 `.market-browse-tooltip` 固定 64×64、`justify-self: start`，列轨外的余量无法被吸收。

## 改动点

- `frontend/src/styles/selection-grid.css` `.market-browse-grid`：
  - 保留共享 `repeat(auto-fill, var(--item-slot-size))`——列轨数按满行算，空轨保留列位，非满行/稀疏列表条目仍占满行同列位、不摊开；
  - `justify-content: space-evenly`——余量均分到首列前/列间/末列后每个位置；
  - `styles.css` 该网格左右 padding 调为 `6px`（=gap），使视觉外边距 = 6 + 均分额 = 列间距，逐像素相等；上下保持 8px。
- 共享规则不动：`.inventory-grid` / `.candidate-picker-grid` / `.abilities-learned-grid` 保持原 `auto-fill` 左对齐节奏，仅坊市网格按需覆写。
- `frontend/src/styles.css` 坊市视图整面板滚动改子窗口内滚：
  - `.market-instrument-detail-view` `overflow-y:auto` → `overflow:hidden`；其直接子级 `.market-book-panel`/`.market-enhance` 改 `flex:1; min-height:0; overflow-y:auto`——导航条（返回+物品卡+买卖按钮）钉顶不滚；
  - `.market-enhance-row--header` 改 `position:sticky` 吸顶（不透明底防透出），等级行滚动时列头驻留；
  - `.market-own-panel` `overflow-y:auto` → `overflow:hidden`；`.market-own-orders` 改 `flex:1;min-height:0;overflow-y:auto`；工具条与 `.market-footer` `flex-shrink:0` 钉住。

## 验证

- 前端 `vite build` 通过；
- headless Edge + CDP 在 `daohua.localhost` 真实页面量测（1400×650）：浏览网格仅 `.market-browse-grid` 内滚；详情/盘口视图 `.market-instrument-detail-view` 不再整面板滚动（264/264），`.market-enhance`（166/248）与 `.market-book-panel`（168/271）分别在剩余空间内滚，导航条钉住；委托页 `.market-own-panel` 固定、`.market-own-orders` 内滚。`.main-content` 各 Tab 全视口下均不产生页面级滚动。
- 网格几何实测（1400/1200/1100/1550 宽度 + 分类过滤）：左右视觉边距与列间距逐像素相等（6.00、8.50、16.00、6.83；1550 右侧 0.06px 为亚像素取整），末行首个条目 X 与首行对齐——满行/非满行均按同一列轨排列。
- 待 UI 目检：坊市各分类/搜索结果下左右留白对称；详情页导航条固定、内容内滚。
