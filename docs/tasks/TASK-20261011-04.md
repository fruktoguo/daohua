# TASK-20261011-04 队伍成员角色信息卡

## 需求

在同道页队伍中点击成员，弹出角色信息卡片，包含：

- 昵称（道号）、形象（立绘）、序号（`identity.players.player_seq` 注册序号）
- 境界（RealmBadge 牌匾）、身家（服务端估值口径）
- 六维（等级 + 经验进度）与战斗经验（`Progression.CombatExperience`）
- 装备：战斗装备（六部位）与技艺装备（`tool-*` 工具槽），功法技能
- 详情页：战斗中使用的物品——丹药栏（potion 3 槽）与通用消耗品栏（general 3 槽）配置

## 方案

### 协议（新增一对请求-应答消息，沿用 PartyLobby 范式）

- `PlayerCardRequest = 27`（上行）：`{ requestId, playerId }`
- `PlayerCard = 28`（下行）：`PlayerCardDto`——身份（playerId/displayName/playerSeq/online）、
  境界（realmLevel/experience/experienceToNext）、战斗经验、身家、
  六维（exp+level，与 loadout 分段 coreAttributes 投影同形）、
  功法槽、已学功法 ID 与功法经验、装备（itemId+强化）、战斗栏消耗品槽位、`error` 错误码字段。

### 服务端

- `ISocialRepository.GetPlayerIdentityAsync(playerId)` → `(displayName, player_seq)`，Postgres 实现单查 `identity.players`。
- `SocialRuntime.BuildPlayerCardAsync(viewerId, request)`：
  - 授权边界：目标 == 本人或与本人同队，否则 `error="forbidden"`；身份不存在 `error="not-found"`。
  - 数据源：已装载玩家读运行时内存态（`IPlayerRuntime.TryGetLoaded`），未装载读持久化分段真源
    （`IPlayerStateRepository.LoadAsync` + `SectionCodec.DecodeAggregate`）——展示口径与身家估值一致，
    不投影未消费会话结算。
  - 六维等级经 `PlayerCoreAttributes.Levels(RealmProgression)` 派生（与 loadout 分段投影同口径）；
    `experienceToNext` 取 `RealmProgressionCatalog.ExpCapFor(realmLevel)`。
  - 身家走 `PartyValuationService.ComputeAsync` 实时估值。
  - 消耗品槽位只下发 `ActionType == combat` 的药品栏/通用栏配置。
- `WebSocketRuntime`：`PlayerCardRequest` 校验握手/requestId 后调 `BuildPlayerCardAsync`，
  应答经 `session.SendJsonAsync` 必达投递（弹窗等待态不能靠可丢帧兜底）。

### 前端

- `protocol.ts`：消息枚举 + DTO 类型；`gameClient.requestPlayerCard(playerId)` 返回请求 ID 供配对；
  断线 close 事件统一调 `closePlayerCard` 清理在途请求，避免加载态悬挂。
- `socialStore`：`playerCard`（最近应答，含 error）+ `playerCardRequestId`（在途请求）+
  `requestPlayerCard/applyPlayerCard/closePlayerCard`；应答按 requestId 配对，迟到旧应答丢弃。
- `PlayerCardModal`（新组件，Modal medium 单页滚动）：头部 = 立绘 + 道号 + #序号 + 在线徽 + RealmBadge；
  修为/战斗经验/身家统计行；六维（PillStatLabel 等级 + 本级经验进度，复用内视页词条与曲线）；
  战斗装备/技艺装备分组（`tool-*` 槽位语义切分，ItemTooltipTarget + ItemTile 只读瓦片）；
  功法槽位清单；战斗物品丹药栏 3 槽 + 通用栏 3 槽（ItemReference 胶囊，空槽/停用明示）。
- SocialPage 队伍槽位卡整卡可点击（`role=button` + 键盘可达，踢出 × 与就绪勾选 stopPropagation），
  点击派发 `requestPlayerCard`；加载/错误/成功三态均由 store 驱动。
