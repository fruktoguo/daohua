# TASK-20261016-10 隐藏地图节点与玄元门遗址实装

## 1. 任务背景与核心需求

用户希望在大地图上引入「隐藏地图节点」机制，并在第二张地图「星陨异境」的「冥煞血池」右侧连接一个隐藏节点「玄元门遗址」：
1. **隐藏地图节点机制**：
   - 处于平时状态时：无跨图特殊标记（无绿色菱标），在地图上完全隐藏，不可见、不可寻路；
   - 检定条件简化直观：**神识 > 30**；满足条件时节点与连线直接在地图上显示；
   - 服务端权威校验：在玩家发起 `world.travel` 时做服务端强校验，未达到神识 > 30 时快速失败拦截。
2. **玄元门遗址节点内容**：
   - 地图归属：星陨异境（`map.starfall-domain`，`config/game-data/maps/xingyun_realm.json`）；
   - 节点名称：**玄元门遗址**（`node.xuanyuan-ruins`）；
   - 节点资源：**灵石矿脉**，每次挖掘稳定获得 **10 ~ 40 灵石**，附赠力道/体魄经验；
   - 节点怪物与遭遇战：
     - 普通怪：掠灵邪修（`enemy.plunder-cultivator`）
     - 精英怪：坠魔祭司（`enemy.fallen-devil-priest`）
     - 首领 BOSS：**玄元残魄**（`enemy.xuanyuan-remnant`）
3. **BOSS「玄元残魄」数值与技能**：
   - 等级：**Lv 18**；
   - 乘区权重：**300% 血量**（`hp: 3.0`）、**500% 灵力**（`mp: 5.0`）、**150% 术攻**（`ap: 1.5`）；
   - 技能组顺序严格排列：① 轰炎 → ② 雷光引 → ③ 清平乐 → ④ 掌心雷；
   - 掉落物：仅掉落大量灵石与 5 本功法（《玄元一气功》、《轰炎》、《雷光引》、《清平乐》、《掌心雷》）的全本秘籍与残卷。

## 2. 详细技术方案

### 2.1 数据配置层
1. **怪物配置（`tier2_elites_bosses.json`）**：
   - 新增 `enemy.xuanyuan-remnant`，level 18, rank "boss", tier 2, weights `{ hp: 3.0, mp: 5.0, ap: 1.5 }`；
   - skills 槽位：`ability.blazing-blast`, `ability.lightning-attraction`, `ability.qingping-melody`, `ability.palm-lightning`；
   - dropTable：`currency.spirit-stone`，以及 5 种功法的 tome 和 fragment。
2. **遭遇战配置（`tier2_encounters.json`）**：
   - 新增 `encounter.xuanyuan-ruins`，包含掠灵邪修、坠魔祭司（精英间隔 4）、玄元残魄（BOSS 间隔 12）。
3. **行动配置（`gathering.json`）**：
   - 新增 `explore.mine-spirit-stone`（开采 灵石矿脉），耗时 8 秒，yields 声明 `currency.spirit-stone`（amount: 25, amountMin: 10, amountMax: 40）。
4. **地图配置（`xingyun_realm.json`）**：
   - 新增节点 `node.xuanyuan-ruins`，坐标 `(185, 35)`，标有 `hidden: true` 和 `requirements: { "consciousness": 30 }`；
   - 新增边 `edge.blood-pool-xuanyuan`，从 `node.blood-pool` 到 `node.xuanyuan-ruins`。

### 2.2 服务端与领域层
1. **行动浮动产出**：
   - `ActionYield` 记录扩展 `AmountMin` / `AmountMax`（可空）；
   - `GameDataCatalog.cs` 读取 `amountMin` / `amountMax`；
   - `ActionExecutionRules.Timed.cs` 在产出物品时，若配置了区间，以线程安全随机数取 `[AmountMin, AmountMax]` 整数。
2. **地图隐藏节点与神识校验**：
   - `WorldNode` / `WorldGraph` 支持节点需求或属性；
   - `EcsPlayerRuntimeAdapter.cs` 在处理 `world.travel` 校验目标节点时，若目标节点为隐藏节点且声明了神识要求，检定玩家神识点数 `Levels(gameData.RealmProgression).Consciousness > 30`；不足则返回错误 `CONSCIOUSNESS_TOO_LOW`；
   - `StaticGameCatalogMapper.cs` 透传节点的 `hidden` 与 `requirements` 到前端。

### 2.3 前端地图渲染
1. `WorldMapPanel.tsx` 在计算 `visibleNodes` 时，如果节点声明了 `requirements.consciousness`，检查当前玩家神识等级：
   - 若 `consciousness <= 30` 且玩家当前不在该节点，节点从 `visibleNodes` 中排除；
   - `visibleEdges` 连带过滤；
   - 满足 `consciousness > 30` 时，节点自然浮现，允许交互寻路。

### 2.4 i18n 词条补全
- 补齐行动、遭遇战、BOSS 相关的本地化标签。
