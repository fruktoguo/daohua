## 五大核心不一致性对比

### 1. 交互与触发层级不一致（最大体验断层）
- `CombatEcologyPanel` 采用了**双层嵌套 Popover**：鼠标 Hover 时仅展示只有气血、主攻击力、护甲 3 项属性的极简小卡（`briefCard`），用户必须手动点击瓦片才能看到掉落物、功法与完整属性；
- 其他所有面板（地图、附近、图鉴、日志）均是**单层 Hover 直接展示完整详情**；
- 导致玩家在生态面板悬停无法直接查看掉落与功法，与其他界面的直觉体验产生强烈割裂。

### 2. 描述文本（Description）口径分叉
- `CombatEcologyPanel`：展示战斗流派与属性（如 `体魄型 · 纯阳`、`术法型 · 烈火`）；
- `NearbyPanel`：展示生命层次文学风味描述（如 `寻常出没于此地的精怪生灵` / `领主生灵`）；
- `WorldMapPanel`：**未传入 `description`**，留白；
- `CodexPage`：**未传入 `description`**，在 `footer` 定制图鉴击败状态；
- `LogFeed`：固定展示 `遭遇战` 或 `妖兽敌怪`。

### 3. 品质色调（BadgeTone）与生命层次不一致
- 领主（Boss）徽记色调：
  - `CombatEcologyPanel` 使用 `RANK_BADGE_TONE.boss = 'crimson'`（深赤红）；
  - `NearbyPanel`、`WorldMapPanel`、`CodexPage` 使用 `'danger'`（红）；
  - `LogFeed` 不区分普通/精英/领主，一律统归为 `'gold'`。

### 4. 属性网格（Stats）维度与过滤规则分叉
- **维度数量**：
  - `CombatEcologyPanel`：展示 **7 项**（包含气血、灵力、物攻、法攻、护甲、魔抗，以及**攻击间隔**）；
  - `WorldMapPanel` / `CodexPage`：固定展示 **6 项**（无攻击间隔）；
  - `NearbyPanel`：动态条件展示（当灵力、法攻、魔抗 `<= 0` 时自动隐藏，可能只显 3~5 项；无攻击间隔）；
  - `LogFeed`：仅展示 4 项（伤害类型、五行元素、气血、真元），数值使用纯文本 `formatNumber` 而不是修仙高亮组件 `UnitNumber`。

### 5. 明细行（Lines：出没周期、击杀收益、功法、掉落物）缺失与代码重复
- **出没周期（`intervalHint`）**：`CombatEcologyPanel` 与 `NearbyPanel` 支持并展示；`WorldMapPanel` 遗漏；`CodexPage` 因全局图鉴脱离节点不展示；
- **施展功法（`abilities`）**：`CombatEcologyPanel` 与 `CodexPage` 展示了技能名称列表；而 `NearbyPanel` 与 `WorldMapPanel` **直接遗漏**；
- **掉落物（`drops`）**：前四处均包含掉落胶囊，但各文件重复手写了 15 行完全相同的 JSX 循环（`world-monster-drops-row` + `ItemDropReference`）；`LogFeed` 完全无掉落展示。

## 统一收拢架构方案设计

### 1. 核心设计原则
1. **单一事实真源（Single Source of Truth）**：
   - 提取公共组件 `MonsterInfoCard`（纯内容卡片）与 `MonsterTooltipTarget`（统一 Hover 浮层容器），或在公共模块中提供标准配置构建工厂 `buildMonsterInfoCardProps`；
   - 所有展示怪物悬浮的地方统一接入同一组件，禁止在业务组件内散落拼装。
2. **多态数据源自动适配**：
   - 无论调用方提供的是全量配表 `CombatantDefinition`、服务端轻量快照 `NearbyMonsterDefinition`、还是日志中的 `enemyId`，公共组件均能自动经 `findCombatantInCatalog(encounters, maps, enemyId)` 向上补全静态配表（掉落、功法、经验、完整攻防抗性）；
   - 保证日志胶囊也能展示与大地图同等规格的高品质信息卡。
3. **最高规格统一标准（Golden Standard）**：
   - **头部**：怪物名称、生命层次徽记（普通 `gold`、精英 `purple`、领主 `crimson`）、境界等阶副标（`realm.minorName · Lv.X · Y阶`）；
   - **描述**：统一展示修仙流派与五行属性（`体魄型 · 纯阳`），兼顾信息清晰度；
   - **明细行**：按需可选出没周期（`intervalHint`）、击杀修为收益、施展功法（顿号分隔）、掉落物复合胶囊行（`ItemDropReference`）；
   - **属性网格**：标准 6 维（气血、灵力、物攻、法攻、护甲、魔抗）+ 攻击间隔（若有），数值统一走 `UnitNumber`；
   - **扩展槽**：预留可选 `footer` 槽位供图鉴等特殊场景展示专属标记。
4. **交互规范收拢**：
   - 全局一律以 **Hover 悬停直接弹出完整高规格详情卡** 为基准；
   - 移除 `CombatEcologyPanel` 冗余的 3 属性简卡 Hover 与强迫点击详卡交互，与其他面板完全拉平。
