# TASK-20261015-06 物品与市场排序结构化优化及补全工具部位分类

## 任务背景与核心痛点

1. **修仙品阶排序倒错混杂痛点**：
   - 背包（储物袋）组内物品与坊市（市场）标的列表此前直接按英文字典序或汉字拼音 `localeCompare` 排序；
   - 修仙体系中的品阶词首字（一品、二品、三品……九品）在汉字拼音中声母分别为：y（一）、q（七）、s（三）、j（九）、e（二）、w（五）、b（八）、l（六）、s（四）；
   - 按拼音升序排列导致实际阶位序列被打乱为「一、七、三、九、二、五、八、六、四」，使得高阶、中阶与低阶物品/装备混杂错位，严重违背修仙直觉与玩家查阅体验。
2. **坊市装备二级分类遗漏「工具」**：
   - 坊市装备分类下的二级 Tab 仅硬编码了 6 大战斗部位（武器、副手、头部、衣服、下装、饰品）；
   - 漏掉了 `tool`（7 大技艺法宝/工具：桃木铲、精铁镐、淬灵锤、灵火炉、百炼铁钳、桃木笔、桃晶旗，对应槽位 `tool-gathering`、`tool-mining`、`tool-forging` 等）；
   - 导致玩家在坊市装备分类下无法通过二级部位筛选技艺工具，只能在「全部装备」中翻找。

### 2. 坊市标的结构化定序体系 (`MarketPage.tsx` / `MarketBrowseGrid.tsx`)

- **多级定序权重原则**：
  - **第一级：一级品类权重 (`categoryOrder`)**：
    - 材料 (`material`) -> 消耗品 (`consumable`) -> 装备法宝 (`equipment`) -> 功法秘籍 (`manual`) -> 其他。
  - **第二级：细分部位/子分类权重 (`subCategoryOrder`)**：
    - 装备细分：武器 (`weapon`) -> 副手 (`off-hand`) -> 头部 (`head`) -> 衣服 (`armor`) -> 下装 (`legs`) -> 饰品 (`trinket`) -> 技艺工具 (`tool-*`)；
    - 材料细分：矿石 (`mineral`) -> 药材 (`herb`) -> 通用材料 (`other`)；
    - 消耗品细分：丹药 (`pill`) -> 补给耗材 (`supply` / `alchemySupply` / `explorationSupply`)；
    - 功法细分：秘籍全本 (`manualTome`) -> 招式残卷 (`manualFragment`)。
  - **第三级：品阶梯队 (`tier`)**：
    - 优先按阶位 Tier 降序（或依列表场景规范降序/升序排列，使高阶/同阶装备与材料聚合成梯队，不再受拼音干扰）。
  - **第四级：名称汉字拼音与 ID 兜底稳定定序**：
    - 同一品阶内按名称拼音（`name.localeCompare(..., 'zh-CN')`）和 `itemId` 稳定排序，消除歧义。

---

### 3. 储物袋背包组内排序结构化重构 (`RightSidebar.tsx` / `snapshot.ts`)

- **背包展示组内排序原则**：
  - 维持现有「重要 / 消耗品 / 装备法宝 / 功法 / 材料」5 大分组小标题不变；
  - 针对组内各物品列表 `group.list`，不再仅依赖 `asset_id` 字典序，而进行结构化多级定序：
    1. **品阶梯队 (`tier`)**：按 Tier 降序（T9 -> T1，高阶宝物优先展示）；
    2. **强化等级 (`enhancementLevel`)**：同装备若存在多个变体（如 +10、+5、+0），按强化等级降序；
    3. **名称拼音定序 (`name.localeCompare`)**：同阶同强化下，按汉字拼音平稳排列；
    4. **物品 ID 稳定定序 (`itemId.localeCompare`)**：确保跨渲染帧确定性与无跳动。
