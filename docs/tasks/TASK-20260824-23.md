# TASK-20260824-23 功法槽位重构为横排动态扩展架构（首位内功+后续术法）与战斗详情战备装配同步升级

## 任务背景与核心目标

当前功法槽位固定为 4 个竖格或 2x2 网格，缺乏心法内功与主动术法的语义分界，且槽位数量受硬编码约束不利于后续扩展。
根据用户优化需求：
1. **槽位横排排布**：将功法槽位重构为类似战斗详情中的横向排列（可流动自适应），并提升整体视觉质感与操作便捷度。
2. **5 槽位体系（首位内功 + 4 位术法）**：
   - 槽位 1（Index 0）：标明为「内功」（心法/本命功法），专属内功徽标与金色/紫气流光；
   - 槽位 2~5（Index 1~4）：标明为「术法」（术法 1~4 / 攻击与辅助神通）；
3. **动态非固定可扩展架构**：
   - 服务端领域模型（`CombatLimits.AbilitySlotCount`）、快照自愈规约与前端存储解耦，支持任意槽位数量的动态扩展与优雅降级。
4. **全端同步**：
   - 同步升级右侧栏功法面板 (`AbilitiesPanel.tsx`) 与战斗详情装配面板 (`CombatLoadoutPanel` in `App.tsx`)。
   - 补全 `i18n` 词典与 CSS 横排平滑响应式样式。
