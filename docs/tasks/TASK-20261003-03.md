## 需求

突破原先点击一次即直接发送 `progression.breakthrough` 命令，存在误触风险。要求：

1. 点击突破按钮先弹出独立确认弹窗，确认后才发送突破命令。
2. 弹窗内展示突破后的属性增加：以「当前基础属性 → 箭头(+增量) → 突破后属性」的对比样式逐项展示。

## 设计口径

- 预览计算复用前端既有 `calculateBaseAttributes`（锚点分段线性插值），与服务端 `PlayerAggregate.Breakthrough` 语义对齐：**突破后本层修为清零、境界 +1**，即
  - 突破前：`calculateBaseAttributes(stats.experience, stats.realmLevel)`
  - 突破后：`calculateBaseAttributes(0, realmLevel + 1)`
- 境界跃迁展示复用 `calculateRealmInfo` 的小境界名（如「练气三层 → 练气四层」）。
- 属性标签复用 `insight.base.*` 词典，不新增重复词条；顺序与内视「基础属性」子页一致。

## 修正记录

- **2026-10-03 UI 目检发现「瑶光 → 瑶光」零增益**：初版突破前基准用「当前修为 + 显式境界等级」走前端连续插值，修为圆满时 `totalLevel` 已达 N+1，与突破后完全相同。服务端权威属性解析（`PlayerAttributeResolver` → `BaseAttributes.At(level)`）按**整数境界等级**取锚点，突破即整级跳变。已修正为整级口径：突破前 `calculateBaseAttributes(0, N)`、突破后 `calculateBaseAttributes(0, N+1)`，境界名同步取整级（`calculateRealmInfo(0, N)`），移除不再需要的 `currentExperience` 入参。
- **2026-10-03 零增益行隐藏**：对比列表改为只渲染有增益的属性行（锚点相邻级同值的项不再显示「—」行）；全部无增益时（如最高境界）显示空态提示「本次突破无基础属性提升。」，新增词条 `insight.breakthroughModal.noChange` 与 `.breakthrough-modal-empty` 样式。
- **2026-10-03 行布局改为 X → Y + 增益胶囊**：每行由四列（名称/当前/→+增量/新值）改为三列——属性名、`当前值 → 突破后值`（箭头金色、新值加粗）、行尾独立金色胶囊显示 `+增量`。
- **2026-10-03 色彩对齐内视属性面板**：对比行挂 `pill-tone--{tone}`（每属性专属修仙色调与内视「基础属性」子页一致），箭头/突破后值/增益胶囊复用 `underlined-value` 从同一 `pill-tone` 规则取色（色彩单源），增益胶囊改为中性暗底 + 属性专属色文字。
- **2026-10-03 列对齐优化**：对比列表改为整表共享列轨道——`<ul>` 作五列 grid（属性名 | 当前值右对齐 | 箭头居中 | 突破后值左对齐 | 增益胶囊右贴边），行 `display: contents` 摊平为网格项，各列宽度取全表最大内容宽，所有行的数值与胶囊纵向严格对齐；斑马纹改挂在单元格上保持连续。
- **2026-10-03 右对齐修正**：`underlined-value`（inline-flex）作为网格项被块化为 flex 后 `text-align` 失效，导致「突破后值」实际靠左。改用 `justify-content: flex-end` 使其右贴（与当前值列同为右对齐数字列），箭头列同步改 `justify-content: center`。
- **2026-10-04 确认后弹窗未关闭修复**：`onConfirm` 原先只发送突破命令未关闭弹窗，突破成功后窗口仍停留在旧预览。改为发送命令即关闭（与 `ConfirmDialog` 确认即关的范式一致，突破后预览已失效）。
