# TASK-20261007-08 · 移动端长按显示悬浮详情（触屏 contextmenu 分流）

- **分类**：前端体验 / 移动端交互 / FloatingPopover
- **提出时间**：2026-10-07 23:11:09
- **状态**：🧪 联调/验证中（前端 build 全绿；待 UI 目检）

## 需求分析

用户反馈移动端交互断层：

1. 移动端没有 hover 事件，物品/技能等详情气泡（`ItemTooltipTarget` 等 `trigger="hover"` 浮层）无法像桌面端那样悬停查看；
2. 很多物品格又占用了单击事件（如背包格单击弹操作菜单），详情气泡与业务点击互相挤占；
3. 移动端长按会由浏览器**原生派发 `contextmenu`**（相当于右键），当前该事件被业务右键回调消费——背包格长按直接触发「快捷使用」（穿戴/研读），属于高危误触。

用户明确：**不需要自己做双击/长按手势映射**（浏览器原生长按即右键事件），要做的是把「桌面端 hover 才能触发的详情气泡」绑定到「移动端可以触发的事件（长按 contextmenu）」上。

## 目标交互口径

| 端 | 悬停/长按 | 单击 | 右键 |
| :--- | :--- | :--- | :--- |
| 桌面端 | hover 显示详情气泡（不变） | 业务动作（不变） | 业务右键回调（不变） |
| 移动端 | **长按（原生 contextmenu）→ 显示详情气泡** | 业务动作（不变） | 不执行业务右键回调，系统菜单屏蔽 |

## 实现方案

收拢在 `FloatingPopover` 触发器层统一分流，所有使用点自动生效，业务层零改动：

- 触发器 `onContextMenu` 改经统一处理器：
  - 触屏设备（`isTouchPointerDevice()`）：`preventDefault()`（屏蔽系统右键/长按菜单）+ `stopPropagation()`（阻断冒泡，防止外层业务右键回调——如背包格「快捷使用」——被长按误触发）；若本触发器为 `trigger="hover"`，调用 `handleOpen()` 展示详情气泡（复用既有 openDelay 防抖与视口安全定位）。
  - 桌面端：原样转发业务 `onContextMenu` 回调（回调内自行 preventDefault，语义不变）。
- 关闭路径复用既有机制：点击外部静默关闭、滚动/`touchmove` 收起、Escape 关闭，均无需新增。
- 双击不做特殊处理（用户明确不需要映射）：移动端双击即两次单击，维持现状。
