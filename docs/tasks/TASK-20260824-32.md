## 2. 需求背景与核心问题

1. **右侧三大 Tab 顶栏**：
   - 顶部只要纯文字（“储物袋”、“装备”、“功法”），移除前缀字样/图标。
2. **装备与技艺格子精简与统一**：
   - 装备格子尺寸与普通物品格子完全一致（`64px × 64px`）；
   - 为空时只显示部位/技艺名称（如“头部”、“衣服”、“腿部”、“武器”、“佩饰”、“鞋靴”、“采矿”、“伐木”、“炼丹”、“炼器”），彻底移除“+”号、大水印文字、空置、待扩展等冗余提示。
3. **右侧主栏整体加宽**：
   - 调整右侧列宽度为 `minmax(380px, 440px)`，使物品网格能容纳 5 列、装备与功法排版更舒适。
4. **功法 Tab 两行流式布局与提示精简**：
   - 第一排固定为内功槽位；
   - 第二排为术法槽位，槽位多时自动折行（`flex-wrap: wrap`）展示，不再是横向滚动列表；
   - 下方“已习得”功法列表去除冗长说明与提示文本，保持干净清爽。
5. **战斗底栏功法容纳与国际化修复**：
   - 战斗详情底部的功法栏调整为 `auto auto 1fr` 弹性分配，确保一排内完整正确装下；
   - 修复 `app.combatPanel.chooseSpell` 与 `app.combatPanel.chooseInternal` 国际化缺失问题。

1. **RightSidebar 导航与主栏宽度**：

   - 调整 App 布局中右侧列宽度为 `minmax(380px, 440px)`。
2. **EquipmentPanel 改造**：
   - 将 `.equipment-slot-btn` / `.equipment-tile` 尺寸与标准 `--item-slot-size` (64px) 完全对齐。
   - 空状态组件只渲染居中部位文字，去掉水印和加号。
   - 底部 4 个技艺槽（采矿、伐木、炼丹、炼器）同样对齐 64px 紧凑方块，空状态仅显示技艺名称。

   - 第二排展示神通术法，支持多槽位自动折行排布；
