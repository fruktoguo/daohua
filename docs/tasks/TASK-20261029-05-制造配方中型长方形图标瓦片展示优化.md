## 1. 需求背景与核心目标

### 1.1 现状与痛点
当前技艺面板（炼丹、炼器、符箓、阵法）以及历练面板中的制造配方条目，渲染为 `.action-card.action-card--crafting`：
- 高度仅 44px，内部仅有居中纯文本名称与右上角绝对定位的 `Lv.` 等级角标；
- 尽管游戏底层 93 项制造配方均具备对应产出物品且 100% 配备 48px WebP 高品质手绘图标资产，但配方列表完全未展示任何物品图标；
- 视觉单一、辨识度低，玩家难以一眼根据图标形态认出目标法宝与丹药。

### 1.2 预期形态
- 将所有制造配方升级为**中型长方形卡片**（高度提升至约 56px~60px，比例舒展稳重）；
- **物品图标**：左侧设立中型物品展示框（约 40px~44px），呈现产出物品真实 WebP 图标（有损 48px WebP 原图以 `pixelated` 硬边高清晰渲染），并提供技艺法印首字兜底；
- **配方名称**：右侧主体区域清晰展示物品/配方名称，字体饱满清晰，优雅截断防溢出；
- **等级角标**：右上角严格遵循全站修仙角标规范（`.item-corner.item-corner--top-right`）展示 `Lv. X` 及未解锁 🔒 锁定标识；
- **悬停浮层**：装备产出物同步关联 `equipmentCatalog`，消除原先装备配方 Hover 时丢失属性详情卡片的缺陷。
