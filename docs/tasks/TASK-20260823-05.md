# TASK-20260823-05 战斗怪物显示与数值修复，历练/地图/详情架构重构

## 1. 任务背景与核心目标

- **需求分析完成时间**：2026-08-23 03:02:40
- **完成时间**：2026-08-23 03:08:45
- **当前状态**：✅ 已完成
- **分类**：Bug修复 / 数值平衡 / 架构重构 / 前端交互

### 核心问题与诉求：
1. **Bug 1（怪物与地图名称混淆）**：当前战斗地图显示的是青幽后山，进入战斗后，怪物名称也被赋值为遭遇名“青幽后山”，未正确显示具体的怪物（如“魔化野兔”、“木灵”、“火灵”等），立绘与信息不匹配。
2. **Bug 2（初始怪物数值过高）**：一阶小怪（minion）生命乘区被错误配置为 300% 基础生命，且遭遇生成 3 只怪物群殴玩家，导致 1 级玩家（约 121 HP）面对近 1000 HP 敌群被秒杀。
3. **架构与交互重构**：
   - 现有的“历练”重构拆分为：
     - **地图 (`map`)**：主 Tab，内部包含「地图」和「附近」两个子 Tab。
     - **历练 (`exploration`)**：主 Tab，展示当前地点可选的特殊行动（采集、探索等），有怪物时显示历练行动；点击历练行动弹出独立面板（展示遭遇信息、掉落及重复设置），点击确认进入战斗。
     - **详情 (`combat`)**：主 Tab，承载现在的战斗对决现场（`CombatArena`）与战备配置（`CombatLoadoutPanel`）；确认进入战斗后自动平滑跳转到此界面。

## 2. 技术设计方案

### 2.1 服务端与领域层修复（Domain / Server）
1. **`StateMapper.cs`**：
   - `ToExpeditionProgress` 中修正 `EnemyName`：从实际推演生成的 `activeEnemy?.Name ?? configuredEncounter.Enemy.Name` 获取具体怪物名称，而非使用遭遇名 `configuredEncounter.Name` / `combatEncounter.Name`。
   - 补充 `EnemyId` 字段传递给协议 `ExpeditionProgressDto`，确保前端能够精确加载对应怪物（如 `demonized-rabbit`、`wood-spirit` 等）立绘与图元。
2. **`CharacterStatResolver.cs`**：
   - 校准 `UnitRank` 各生命层次的倍率：
     - `Boss`：(1.50, 6.00)
     - `Leader`：(1.30, 3.50)
     - `Elite`：(1.15, 2.00)
     - `Normal` / `Summon` / `Pet`：(1.00, 1.00)
     - `Minion`：(0.75, 0.50)（一阶魔化野兔生命降至约 45~50 HP，攻击力约 6~8，完全符合新手 1 级玩家单挑通关预期）。
3. **`config/game-data/encounters.json`**：
   - 调整 `encounter.qi-beast`：`maxSpawnCount: 1`, `maxTotalStrength: 25`，避免入门遭遇多怪群殴。

### 2.2 前端主导航与页面拆分（Frontend）
1. **`uiStore.ts`**：
   - 主 Tab 扩展为包含 `'map'`，`TabId = 'insight' | 'market' | 'cultivation' | 'exploration' | 'alchemy' | 'map' | 'combat' | 'inventory' | 'log' | 'settings'`。
2. **`App.tsx` 页面路由与布局重构**：
   - **`MapPage`**：独立地图页面，顶部包含「地图」与「附近」两个子 Tab，分别渲染 `WorldMapPanel` 和 `NearbyPanel`。
   - **`ExplorationPage`（历练）**：展示当前节点的所有可选行动（包含采集、探索以及当前地点的战斗历练行动）。有怪物遭遇时，渲染历练战斗卡片；点击弹出 `ActionModal`。
   - **进入战斗自动跳转**：在 `ActionModal` 中确认开始战斗（或触发 `start_combat` / `enqueue_action` 执行 combat 动作）后，通过 `useUiStore.getState().setActiveTab('combat')` 自动跳转到「详情」Tab。
   - **`CombatDetailsPage`（详情）**：即现在的 `CombatArena` 擂台现场 + `CombatLoadoutPanel` 战备装配。
3. **多语言词典（`app.zh.ts`, `game.zh.ts`）**：
   - 同步更新导航名称：
     - `cultivation`: 修炼
     - `exploration`: 历练
     - `alchemy`: 炼丹
     - `map`: 地图（子 Tab：地图、附近）
     - `combat`: 详情（战斗详情与配置）
