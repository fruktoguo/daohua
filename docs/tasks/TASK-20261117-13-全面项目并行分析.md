## 一、项目整体判断

《道化太初》是服务端权威、行动队列驱动、离散事件推进的修仙放置 RPG，重点不在浏览器逐帧玩法，而在在线、离线挂机、重连及跨玩家资产交互的一致性。成长、战斗、制造、装备、地图建筑、坊市、社交组队、宗门、排行榜、邮件与签到已有相应代码模块；这说明实现范围已超出原型，不代表本轮逐项试玩通过。

实际主链路：

```text
React / Zustand / TypeScript / Vite
  → 同源 HTTP + DHW1 WebSocket
  → ASP.NET Core 10（认证、命令入口、推送）
  → EcsPlayerRuntimeAdapter（玩家 gate、租约、事务边界）
  → EcsGameRuntime / EcsWorldShard（YuoCore Fiber、组件权威状态）
  → Domain（配表、公式、POCO、编解码）
  → PostgreSQL（身份、钱包、分段、市场、队列、日志）

ComputeNode → 反向拨入主服 → 共享 ECS 补算候选
  → 主服独立重演 → 源基线/租约/钱包校验 → 原子写回
```

- `.csproj` 的实际引用总体符合分层：Domain 不反向依赖宿主/Protocol；Ecs 不依赖数据库；ComputeNode 只引用 Domain/Ecs；DataTool 没有项目引用。
