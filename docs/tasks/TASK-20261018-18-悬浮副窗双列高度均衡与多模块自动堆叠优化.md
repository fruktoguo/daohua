# TASK-20261018-18 · 悬浮副窗双列高度均衡与多模块自动堆叠优化

## 1. 任务背景与核心问题

在《道化太初》模块化悬浮气泡体系（`FloatingPopover` + `asideCards`）中，当触发目标（如《清心诀·残卷》等带有丰富衍生信息的秘籍/残卷、可交易多属性装备、长词缀标的）携带多张附属副卡片时，目前全部副卡片均堆叠在右侧单列 `daohua-floating-aside-group`（`flex-direction: column`）中：
1. **左侧空间严重浪费**：左列主卡片（`FloatingInfoCard`，约 300px）下方存在大量（400px~700px）未被利用的空白垂直空间；
2. **右侧单列严重拖地**：副卡片数量较多时（如数量 141 + 功法参悟雷达图 + 心法内功增益 + 六维倾向说明 + 坊市市场价格共 5 张卡片），右列总高度累加达 780px~900px，在主流 1080p 或笔记本屏幕上不仅视觉“头重脚轻”，且容易突破屏幕底部安全边界触发视口夹持（clamp）甚至强行出现纵向滚动条；
3. **视觉对称度缺失**：左列单薄孤立、右侧沉重狭长，缺乏修仙古典界面规整稳重的对称美感。

---

## 2. 技术设计与实施方案

### 2.1 堆叠策略：方案 A（左列吸附填充 + 贪心高度均衡）

1. **分列架构**：
   - 浮层由原本的「主卡片 + 右侧副卡组」重构为「左列（主列，宽 300px） + 右列（副列，宽 220px）」；
   - 左列顶部恒定为主卡片；
   - 当 `asideCards` 总数 $\ge 2$ 时，启动双列高度均衡分发算法；若只有 0 或 1 张副卡，保持经典的左主右副单排，避免不必要的布局扰动。
2. **高度估算与语义权重模型**：
   - 单行数量卡（`quantity`，约 40px）与标的直属市场行情卡（`aside-market-*`，约 160px）属于标的自身交易与持存属性，天然优先吸附于左列主卡下方；
   - 技能参悟与雷达图（`aside-manual-*`，约 340px）等重型外延系统卡片优先归入右列；
   - 剩余描述类（`aside-description-*`）与加成类（`aside-bonus-*`）按估算高度（标题 + 行数 $\times 22\text{px}$ + 内容）贪心分配至高度较矮的一列。
3. **样式与布局统一**：
   - 左列中的副卡片宽度自适应撐满左列（`width: 100%`，即 300px），让胶囊排版更加舒展自然；
   - 右列保持标准副卡宽度（220px）；
   - 响应式兜底：小屏/移动端（`max-width: 768px`）自动降级为单列垂直堆叠（主卡在顶，副卡依次向下）。
4. **性能与零闪烁保证**：
   - 采用纯声明式分发，在浮层展开渲染时基于静态配置即时计算，无需在 DOM 中先挂载再测量，彻底消除双重渲染与布局抖动。
