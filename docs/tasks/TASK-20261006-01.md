# TASK-20261006-01 竖屏物品格子优化

- **提出时间**：2026-10-06 11:27:21
- **分类**：前端体验 / 竖屏适配
- **状态**：🧪 验证中

## 需求分析

用户反馈竖屏（≤960px）下详情页中部使用栏格子过大：

1. 竖屏下 `.auto-use-slot` 被 `flex: 1 1 0` 均分整行宽度，三个槽位被拉成巨型宽条，格子过大。
2. 战斗详情页 `combat-slot-tray` 三组使用栏（消耗药品 / 通用物品 / 功法）当前纵向堆叠成三排；期望两组物品合并到一行，功法技能单独一行。
3. 格子整体缩小 33%，即桌面 64px 的 2/3 ≈ 42px（`--item-slot-size` / `--item-tile-size` 在托盘作用域覆写，内部瓦片/空槽/触发壳均经变量跟随缩放）。

二轮补充需求：

4. 竖屏详情三栏隐藏角标（42px 下数量/消耗/槽位/等级角标过小难辨；丝带保留——色块仍可辨识）。
5. 缩小只限战斗详情页托盘：其他行动页 `.auto-use-tray` 空间够，保持原均分拉伸行为。
6. 技艺页竖屏无法切换模式（炼丹/炼器/符箓/阵法/强化入口只在桌面侧边栏二级菜单，竖屏侧边栏隐藏）：在技艺页底部补一层模式切换页签。

三轮补充需求：

7. 详情页战场内多个角色横向排列站不下：竖屏下改为纵向排列，且每个角色再缩小一档。

## 改动点

- `frontend/src/styles/selection-grid.css` `@media (max-width: 960px)`：
  - `.auto-use-slot` 拉伸与 `.item-use-slot*` 100% 覆写**限定作用域到 `.auto-use-tray`**（行动页托盘保持原均分拉伸；战斗详情页不受影响）；
  - `.combat-slot-section` 不再强制 `width:100%`（改由 expedition.css 按排位分配宽度）。
- `frontend/src/styles/expedition.css` `@media (max-width: 960px)`：
  - `.combat-slot-tray` 改为 `flex-direction: row` + `flex-wrap`，并覆写 `--item-slot-size/--item-tile-size: 42px`（晚于同文件 760px 块中的 64px 声明）；
  - 前两组 `flex: 1 1 0` 均分一行，功法组 `flex: 1 1 100%` 独占第二行，分隔线相应调整；
  - 竖排组标签 `letter-spacing` 收紧防裁切；`.item-corner` / `.abilities-slot-tag-badge` / `.combat-ability-level-control` 角标隐藏。
- `frontend/src/styles/expedition.css` `@media (max-width: 760px)`：移除 `.combat-slot-tray` 上与基础规则重复的 64px 变量声明（960px 块已统一接管）。
- `frontend/src/App.tsx`：新增 `CraftingModeTabs` 组件（复用 `CRAFTING_NAV_MODES` 图标/tone + `calculateTechniqueProgress` 等级，pill-tone 分色），渲染于 `CraftingPage` 底部。
- `frontend/src/styles.css`：`.crafting-mode-tabs` 桌面 `display:none`，≤960px 为横向页签栏（图标+名称+分色等级）；`.enhancement-layout` 竖屏允许内部滚动防挤压。
- `frontend/src/styles/expedition.css` `@media (max-width: 760px)`：
  - `.arena-formation` 由九宫 grid 退化为纵向 flex 角色列，`.arena-slot--empty` 收起，纵列可滚动且按铺位顺序（前排居中槽优先）自上而下排列；
  - `.arena-actor` 保持原版竖向卡片（名条/立绘/出手条自上而下）整体缩小：宽 60px、立绘 48×64、字印 20px、名 9px、条距收紧；
  - 增益方块 `.arena-actor-buff-list` 由卡片底部绝对定位浮层改为卡片流内，避免遮挡下一行角色；
  - 两侧左右对峙与横向位移动画方向不变。
- `frontend/src/styles/expedition.css` `@media (max-width: 520px)`：卡片再降至宽 52px、立绘 40×54、字印 16px，其余沿用 760px 竖列布局。
- `frontend/src/components/CombatArena.tsx`：新增 `measureArenaAim`（仅 ≤760px 纵列生效，量取两端中心连线方位角，钳 ±35°）；攻击播放与受击掉血时分别按「自身→对方首位存活单位」与「对方首位存活单位→自身」写入 `--arena-aim-y/--arena-aim-angle/--arena-hit-y/--arena-impact-angle` 内联变量。协议无目标字段，以纵列首个存活槽位作几何近似。
- `frontend/src/styles/expedition.css`（全局，零值无感）：突进关键帧纵向加 `--arena-aim-y`；弹道容器 `rotate(--arena-aim-angle)` 绕贴近头像边缘摆动（敌方镜像侧角度取反）；受击退散帧带 `--arena-hit-y` 逐帧衰减；刀光容器 `rotate(--arena-impact-angle)`（玩家镜像侧取反）。
- `frontend/src/styles/expedition.css` `@media (max-width: 760px)`：世界地图页改为纵向滚动列表——`.world-map-layout` 改 `display:block` + `overflow-y:auto`（原 grid `auto` 行轨会把详情面板压成剩余空间高度，内容溢出被页面 overflow:hidden 裁掉；块级流按内容自然撑高）；地图高度由固定 420px 降为 `clamp(220px, 36vh, 360px)`，与面板间距 10px；`.world-location-panel` 改为自然高度，内部 `.world-location-sections` 停止自滚动，整页滚动由外层统一负责；520px 断点残留的 `min-height:340px` 死规则同步收敛为 220px。已用 Edge headless 最小静态页复现并量化验证：修复前面板盒子 302px/内容 568px 被裁，修复后面板 582px 全高、滚到底可见底部。
