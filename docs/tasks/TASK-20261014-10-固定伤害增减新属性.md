## 需求背景与核心设计

用户要求增加固定伤害增减的新属性：
1. **固定点数而非百分比**：
   - 包含大类固定伤害增减、固定物理伤害、固定法术伤害；
   - 对应攻方 3 项固定增伤（`FixedDamageBonus`、`FixedPhysicalDamageBonus`、`FixedSpellDamageBonus`）与守方 3 项固定减免（`FixedDamageReduction`、`FixedPhysicalDamageReduction`、`FixedSpellDamageReduction`）。
2. **结算时序与公式规则**：
   - 固定伤害增减不吃任何其他加成（不吃百分比增幅、不吃抗性）；
   - 在伤害计算的最后阶段进行修正（位于抗性平方穿甲、百分比分类增减伤、暴击倍率、免伤百分比收口之后）；
   - 攻方有固定增伤时，即便守方有无限护甲/法抗，也能打出对应的固定伤害；
   - 守方有固定减伤时，在最后的伤害中再扣除，最终承伤最低为 0 点；
   - 若未命中（Miss/闪避），伤害为 0，不触发固定伤害。
   - 攻击类型分类匹配：物理打击只叠加通用固定增免与物理固定增免；法术打击只叠加通用固定增免与法术固定增免。
3. **前端展示规范**：
   - 内视与战斗单位详情属性面板（`CombatAttributePanel`）中参考百分比增减伤的合并形式：
     - `fixedTotalBoostReduce`: 固定伤害增减（格式如 `+10 / 5`）
     - `fixedPhysBoostReduce`: 固定物理伤害（格式如 `+10 / 5`）
     - `fixedSpellBoostReduce`: 固定法术伤害（格式如 `+10 / 5`）
   - 两侧均为 0 时默认隐藏，任意一侧有数值时展示。
   - 装备悬浮（`ItemDisplay`）与多语言模板支持上述固定属性键。
