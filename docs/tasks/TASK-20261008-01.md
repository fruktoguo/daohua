## 需求分析

用户在浏览器预览中提出两点：

1. **去掉「我」标记**：组队讨伐己方阵列中本人位名称后跟随的 `<em class="arena-self-tag">我</em>` 徽标不再需要，按普通单位正常显示即可。
2. **敌方普通攻击弹道方向反了**：竖屏纵列布局下，敌方一号位（右上）打己方三号位（左下），弹道应朝左下方偏，实际却朝左上/右上偏——左右镜像侧的倾斜角符号反了。要求排查是否只有普攻有此问题。

## 弹道方向 Bug 根因

`measureArenaAim`（仅 ≤760px 竖屏纵列启用）量取攻方→目标方位：`angle = atan2(dy, |dx|)`，`angle > 0` 表示目标在攻方**下方**；`--arena-aim-angle` 写入 CSS 供弹道条倾斜。

敌方弹道容器（`expedition.css` `.arena-actor--enemy .arena-action-fx--attack`）：

```css
transform: translateY(-50%) scaleX(-1) rotate(calc(var(--arena-aim-angle) * -1));
```

变换从右向左作用于弹道 streak 本地方向 `+x`（向右展开）：

- `rotate(-a)`：先转到 `(cos a, −sin a)`（向上偏）
- `scaleX(-1)`：再翻成 `(−cos a, −sin a)` = **朝左上**

目标在下方时正确方向应为 `(−cos a, +sin a)` = 朝左下。

**根因**：`scaleX(-1)` 镜像本身已经反转了旋转方向（镜像系中顺时针↔逆时针互换），再手动乘 `−1` 构成双重否定——把「朝目标下偏」错翻成「朝上偏」。正确写法是镜像侧保持正角度，由镜像独立完成左右翻转。

## 其他动画排查结论（只有普攻受影响）

- **施法（cast）**：圆形法环 + 缩放脉冲无方向性，且 JS 仅 `kind === 'attack'` 才量方位；
- **突进位移（lunge）**：`--arena-lunge` 敌我符号相反 + `--arena-aim-y` 共用符号，translate 不涉旋转方向翻转，正确；
- **受击刀光/退散（impact）**：描述的是线斜率而非向量方向，玩家侧 `scaleX(-1) rotate(-a)` 与敌方侧 `rotate(+a)` 经镜像对称性验证正确；
- **VFX 技能特效**（`vfx/engine.ts` 的 `beam`/`projectile`）：按两点真实元素中心坐标 `atan2` 计算方向，无镜像复合变换，不受影响。
