## 需求

用户提出两点：

1. 去除本地 `dotnet run` 控制台的噪声。
2. 新增一个「后台信息」页面，作为**仅本地网络可用**的 Web 面板（完整运维面板：指标、健康、日志、玩家/会话、市场盘口），由 Server 托管独立页。

## 现状分析

- 控制台噪声来源：
  - `MarketRuntime.StartAsync` 在等待旧实例市场分片租约过期时，逐次（最多 39 次）以 `Warning` 打印同一条等待日志。
  - Development 未配置 `Logging:LogLevel`，`Microsoft.AspNetCore` 默认 `Information`，导致 `StaticFileMiddleware` 的 `WebRootPath was not found` 等 ASP.NET 基础设施日志全部输出。
- 现有服务端在 Development 绑定 `http://127.0.0.1:5128`，仅回环；没有运维面板。
- `AGENTS.md` 硬约束：任何 debug/metrics 端点只允许在 `Development` 环境存在，生产 Caddy 必须显式拦截对应路径。

## 方案

### 一、控制台降噪

1. `appsettings.Development.json` 增加 `Logging:LogLevel`：`Microsoft.AspNetCore` 提升为 `Warning`（屏蔽基础设施 `info` 噪声），`Default` 保持 `Information`。
2. `MarketRuntime.StartAsync` 租约重试：首次失败保留 `Warning`，后续重试降为 `Debug`，把 39 行重复告警收敛为 1 行。

### 二、本地运维信息面板（Development-only）

1. 新增配置节 `Ops`：`Enabled` / `Port`（默认 `5129`）/ `ListenAddress`（默认 `0.0.0.0`，即局域网可访问）/ `Path`（默认 `/ops`）/ `LogBufferCapacity`。
2. 仅当 `Environment.IsDevelopment()` **且** `Ops:Enabled` 时装配：
   - 在 `Program.cs` 解析 URL 列表时追加运维端口（主端口保持回环不变）。
   - 端口门禁中间件：请求落在运维端口时仅允许私网/回环来源且仅允许 `Path` 前缀；其它端口访问 `Path` 一律 404。
3. 运维面板端点（`Server.Clean.Ops`）：
   - `GET /ops/`：自包含 HTML 页面（嵌入资源，无外部依赖）。
   - `GET /ops/api/overview`：版本/环境/进程内存/运行时长/协议与 schema 版本/配表指纹/在线会话数/已加载玩家数/市场指标。
   - `GET /ops/api/health`：运行全部健康检查并返回逐项状态。
   - `GET /ops/api/players`：已加载玩家摘要（玩家 ID/账号/道号/版本/在线状态/上次模拟时刻）。
   - `GET /ops/api/sessions`：在线 WebSocket 会话玩家 ID。
   - `GET /ops/api/market/book?assetId=&variant=&depth=`：指定品种盘口。
   - `GET /ops/api/logs?level=&limit=`：进程内日志环形缓冲。
4. 新增 `OpsLogBuffer`（有界环形缓冲 + `ILoggerProvider`），仅在面板启用时注册，避免生产内存与性能开销。
5. `PlayerRuntime` / `SessionRegistry` 增加只读枚举接口供面板使用，不泄露聚合引用。

### 三、安全与运维兜底

- 生产环境（非 Development）不注册任何 `Ops` 端点与中间件；即便配置误开也被环境判定拦截。
- `deploy/xx.yuohira.com.caddy` 的私有路径拦截追加 `/ops/*`，作为生产纵深防御兜底。
- `scripts/dev.sh` 打印运维面板局域网地址。
