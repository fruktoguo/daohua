## 需求与方案

用户希望普通攻击与受伤反馈更丰富，不能花哨，但要有利落、炫酷的打击感。保留现有战斗节奏、状态与布局，采用四种普攻轮廓（掠斩、直刺、回锋、震击）和三种局部受击反馈（裂光、震纹、碎星），每个单位交替播放。普攻粒子上限为 8，不使用全屏爆闪或震屏。设计真源见总纲第十三篇 §13.3。

共享脚本负责普攻视觉，既有 ArenaActor 的气血变化负责正式受击；Demo 保留沙盘结算，并移除同一次命中重复受击。控制台使用既有按钮样式提供七种命名预览。并行分工：主 Agent 实现普攻及画廊入口，子 Agent 负责受击路径与共享样式，统一验证与提交。
