# TASK-20261013-03 记录面板内嵌主页面

- 提出时间：2026-10-13 17:51
- 完成时间：2026-10-13 17:55
- 状态：✅ 已完成

## 需求

用户要求将「记录」（RecordsPanel）由独立弹窗改为内嵌主区页面：点击侧边栏「记录」按钮后切换至记录页面，与其他顶级页签（内视/坊市/历练/技艺/地图/详情/同道/设置）一致，不再弹出 Modal。

## 现状

- `TabId` 无 `'records'`，记录不经 `activeTab` 页面机管理。
- `App.tsx` 桌面 `Sidebar` 底部「记录」按钮以局部 `recordsOpen` 状态开 `Modal.battle-report-modal` 承载 `RecordsPanel`。
- `App.tsx` `CombatDetailsPage` 头部保留移动端 `.records-open-mobile` 入口（侧边栏 ≤960px 隐藏），同样以 `recordsOpen` + `Modal` 承载。
- `RecordsPanel` 根节点为 `.battle-report-panel`（弹窗内排版：grid + 顶部隔线 + 12px 字号），标题为 `.battle-report-title` span，带 `titleId` prop 供 Modal `labelledBy`。

## 方案

1. `uiStore.ts`：`TabId` 增加 `'records'` 并补注释。
2. `RecordsPanel.tsx`：改造为页面外壳——根节点 `panel records-page`，头部改 `panel-header` + `h2`（与其他页一致），删除仅服务弹窗无障碍的 `titleId` prop；内容（离线挂机/今日统计/近期战报）原样保留。
3. `App.tsx`：
   - `Sidebar` 记录按钮改为 `setActiveTab('records')` 并挂 active 高亮，删除 `recordsOpen` 状态与 Modal。
   - `CombatDetailsPage` 移动端记录按钮改为 `setActiveTab('records')`（`.records-open-mobile` 显隐规则不变），删除对应状态与 Modal。
   - `main-content` 增加 `{activeTab === 'records' && <RecordsPanel />}`（按激活挂载，与内视/坊市等轻量页一致；切走时随卸载清理每秒 tick 定时器，语义同原弹窗关闭）。
4. `expedition.css`：新增 `.records-page`（flex 列 + 12px 字号，替代原 `.battle-report-panel` 在弹窗内的排版职责），滚动沿用 `.main-content` 外层滚动（同 settings/social 页）。
5. 同步 `docs/frontend/common-components.md` §24 记录入口描述。
