# TASK-20261114-20 角色名片配装隐私设置与设置「隐私」子页签

- **状态**：✅ 已完成（2026-11-14 领域/服务端/前端全链路实现与验证通过）
- **提出时间**：2026-11-14 20:57:00
- **分类**：全栈功能 / 隐私控制 / 角色名片

## 1. 需求摘要

1. 解除原先对跨队查询角色名片直接返回 `forbidden` 的硬拦截：默认任意修士均可查询他人名片，配合全服排行榜点击行唤起角色名片体验。
2. 在「设置」页面新增「隐私」（`privacy`）子页签：
   - 提供开关调整「是否允许非同队修士查看我的配装」（默认开放 `publicLoadoutVisible = true`）。
   - 明确说明：**对本人及当前同队成员始终保持完全开放**，不受该隐私开关限制。
3. 当目标修士关闭了非同队配装可见性，且查询方既非本人也非同队成员时：
   - 仍可正常打开角色名片弹窗查看不可抄配装的数据（形象、道号、角色序号、在线状态、境界牌匾与修为、总身家及估值分项、六维根骨、战斗基础/特殊属性、生活技艺等级）；
   - 配装相关数据（主动/心法功法槽位、已参悟功法与熟练度、全身装备法宝与技艺工具、领悟特质与等级、战斗消耗品与自动使用槽、当前进行中战报）在服务端裁撤置空并标记 `loadoutHidden = true`，前端在「配装」子页内展示隐私受限说明。

## 2. 技术方案

- **领域与存档**：
  - `PlayerSettingsState` / `PlayerSettingsStateDocument` / `SectionCodec.SettingsDocument` 新增可缺省 `bool PublicLoadoutVisible = true`（`Settings` 载荷向后兼容旧版缺省为 `true`；与 `TASK-20261113-08` 合并推进 `SectionCodec.CurrentSchemaVersion` 至 `43`，`PostgresSchema.Version` 同步推进至 `54`，`MinReadableSchemaVersion` 保持 `41`）。
  - `PlayerAggregate.SetPublicLoadoutVisible(bool visible)` + `EcsPlayerRuntimeAdapter` 新增命令 `player.set_privacy`（payload `{ publicLoadoutVisible: boolean }`）。
- **协议与服务端鉴权投影**：
  - `PlayerCardDto` 新增 `bool LoadoutHidden = false`。
  - `ProtocolSnapshotMapper.ToAttributesDto` 增加 `bool includeTraits = true` 参数，避免关闭配装可见时从 `attributes.traits` 泄露所悟特质配置。
  - `SocialRuntime.BuildPlayerCardAsync`：对同队成员与本人传完整配装；对非同队且目标 `PublicLoadoutVisible == false` 者裁撤配装与特质并置 `LoadoutHidden = true`，仍返回基础属性/六维/身家/境界/技艺等级。
- **前端**：
  - `SettingsPage.tsx` 新增 `'privacy'` 子页签与分组控件（使用 `OptionToggle` / 选项按钮组，`publicLoadoutVisible` 开关 + 同队豁免提示）。
  - `PlayerCardModal.tsx` 在 `card.loadoutHidden === true` 时对「配装」子页签渲染隐私受限占位说明，其他子页（境界/基础/特殊/六维/技艺等级与估值总览）照常展示。
