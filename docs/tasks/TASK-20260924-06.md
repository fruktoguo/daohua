# TASK-20260924-06 木灵/火灵灵力上限收拢至 10 点

## 需求

## 分析
- 怪物属性唯一推导链：`MaxManapoints = 锚点Mp(等级) × 品阶倍率(minion=0.8) × weights.mp`（`GameDataCatalog.ParseMonsterDefinitions`，`GameDataCatalog.cs:847`）；配表无固定值覆写字段，调 `weights.mp` 是唯一手段。

- 其余维度不动：`budgetCost`（15/18）、掉落表、技能槽、`modifiers` 五行减伤均保持原值。
