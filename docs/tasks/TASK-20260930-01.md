3. **技能经验**：每次技能使用 +1（不使用配表掉落收益路径）。
4. 同步领域、ECS、协议、持久化、前端、配表、测试与总纲/对照表/任务文档。

## 方案要点

- `CombatMonsterDefinition`：三奖励字段 → 单 `Experience`；`GameDataCatalog` 只解析 `experience`；
  `StaticGameCatalogMapper` 只下发一个字段；前端 `MonsterDefinition` 同步。
- `SimulationEngine.ApplyCombatRewards`：`CreditExperience(experience, experience, cap)`
  + `DistributeRootExp(player, experience)`；战报记 `Experience`/`Foundation`(净变动)/`CombatExperience`/`RootExp`，删 `Qi`。
- `DistributeRootExp`：无功法声明时六维严格均分（`N/6`）；功法 `rootAttribute` 归属集合作为后续比例调整扩展点。
- `PlayerProgression`/`PlayerProgressionState`/`PlayerComponents`/`EcsWorldShard` 快照：删 `Qi`/`LifetimeQi`（schema v4 内直接改形状，不留兼容）。
- `PlayerBattleReport`/`PlayerBattleReportDocument`：删 `Qi`。
- 前端：`Stats`/`BattleReport`/snapshot 映射/战报分区/怪物奖励展示/i18n `yieldKind.qi` 与战报 `qi` 词条、`actionCalculations` 的 `case 'qi'` 全量删除。
- 配表：`config/game-data/monsters/*.json` 三字段 → `experience`（取原 `experienceReward` 口径）；`cultivation.json` 移除 `kind:"qi"` 收益；前端 `ids.ts` 兜底行动同步。
