## 1. 需求背景与问题定义

### 1.1 现状与疑问排查
1. **线上身家排查**：线上玩家 `anj` 身家高达 53.3 万（533,100 灵石）。
   - **根因取证**：
     - 在今日坊市（市场）中，`item.tome.tide`（潮涌术秘籍）发生两笔高价成交（单价 105,000 灵石），使得 `market.item_stats.reference_price`（滑动平均参考价）被确立为 105,000。
     - 玩家 `anj` 习得潮涌术并参悟至 5 级。根据总纲 §21.3 身家口径，功法价值 = 参悟等级 × 对应秘籍单价 = 5 × 105,000 = 525,000 灵石。
     - 其余 7 门功法（吐纳功15级、掌心雷19级、清心诀17级、烈火咒16级、铁布衫3级、蛮牛劲2级、甘露术9级）按配表回收价各贡献 100~1,900 不等，合计 8,100 灵石。
     - 装备与工具为新手基础产物，回收价为 0，合计 0 灵石。
     - 综上总身家为 525,000 + 8,100 = 533,100 灵石。
2. **交互诉求**：玩家在前端查看身家时，无法知晓这 53 万到底由什么组成。用户明确提出：**希望在鼠标 hover 到身家的时候，能显示具体构成，即：战斗装备、参悟功法、技艺工具**。

### 1.2 改造范围与核心契约
1. **身家口径拆分**：
   - 战斗装备价值：Σ 已穿戴非工具装备（`slot` 非 `tool-*`）单价（含 +N 强化独立变体）。
   - 技艺工具价值：Σ 已穿戴生活技艺工具（`slot` 为 `tool-*`）单价（含 +N 强化独立变体）。
   - 参悟功法价值：Σ 每门已参悟功法等级 × 秘籍/残卷单价。
   - 总身家 = 战斗装备 + 参悟功法 + 技艺工具。
2. **协议与数据流通**：
   - `src/Protocol` 新增 `ValuationBreakdownDto(double Equipment, double Abilities, double Tools)`。
   - `PlayerCardDto`、`NearbyPlayerDto`、`PartyMemberDto`、`PartySeekerDto`、`PartyLobbyMemberDto`、`PartyLobbyDto` 均携带可选 `valuationBreakdown` 字段。
   - 服务端 `PartyValuationService` 改造为支持细分三项独立核算与缓存。
   - 服务端 `SocialRuntime` 在构建名片、附近玩家列表、组队大厅及队伍成员时填充细分数据。
3. **前端全局悬浮展示**：
   - 新建 `frontend/src/components/ValuationDisplay.tsx`，收拢所有身家展示位。
   - Hover 时弹出 `FloatingTooltip`，清晰呈现：总身家估值、战斗装备估值、参悟功法估值、技艺工具估值。
   - 挂接点：`PlayerCardModal`（名片大卡与属性项）、`NearbyPanel`（本人与附近修士）、`SocialPage`（大厅我的身家、散人、队伍成员）。
