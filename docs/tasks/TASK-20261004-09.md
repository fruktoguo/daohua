# TASK-20261004-09 · 坊市装备强化等级盘口与系统挂单装备补齐

- 提出时间：2026-10-04 14:00:00
- 分类：全栈新功能 / 坊市 / 装备变体盘口
- 状态：✅ 已完成

## 需求原文

> 修改：当前系统挂单怎么没有装备啊。而且，装备是有不同强化等级的，不同于其他物品，市场的装备物品点击不应该直接进入买卖界面，而是进入强化等级选择界面（参考 Milky Way Idle 布局：每行一个强化等级，最佳出售价 + 购买按钮 | 最佳收购价 + 出售按钮 | 查看全部）。注意图像只是布局参考，不存在可交易区间。只显示有买卖订单的强化等级，如果都没有，就只显示无强化版本。

## 需求分析

1. **系统挂单无装备的根因**：`scripts/seed-market-system-listings.sh` 与运维面板 `/ops/api/market/catalog` 共用「非货币 + 可交易 + sellPrice>0」口径，装备无回收价被显式排除（TASK-20261003-09 裁定）。
2. **装备变体盘口链路本已存在**：`MarketInstrument(ItemId, Variant)` 中 `"+N"` 即强化等级盘口；钱包以 `(itemId, "+N")` 独立资产行计强化件；落库冻结/成交全链路透传 variant。缺的是「该装备哪些等级有挂单」的查询入口与前端入口。
3. **潜伏 bug**：`fetchMarketBook(itemId, level)` 发送 `variant={level}`（"3"），与服务端强化变体 `"+3"` 不符——此前 UI 永远传 0 未暴露。

## 技术方案

### 契约约定

- 新增 `GET /api/v1/market/variants?assetId={id}` → `[{ variant, bestAsk, bestBid }]`，
  只返回该标的存在活动挂单（买或卖）的变体簿；`variant=null` 表示基础（+0）簿。
- `market.place` 负载 `variant` 口径：`null`/缺省/`""` = 基础簿；`"+N"`（1 ≤ N ≤ `EnhancementRules.MaxLevel`=20）= 强化等级簿，且仅限装备资产。
- `fetchMarketBook(itemId, level)` 修正为 `variant="+N"`。

### 服务端（src/）

- `MarketRuntime.GetVariantSummaries(ItemId)`：扫 `_books` 中同 ItemId 的簿，`Snapshot(1)` 取买一/卖一价，空簿跳过。
- `Program.cs`：挂载 `/api/v1/market/variants`（与 `/book` 同免鉴权口径）。
- `EcsPlayerRuntimeAdapter` `market.place`：variant 经 `EnhancementRules.ParseLevel` 校验——非空必须解析为 1..20 且品种必须是装备；已装备拦截由「同 itemId」收窄为「同 itemId + 同强化等级」（钱包按变体行冻结，不同级变体出售互不影响）。

### 前端（frontend/）

- `apiClient`：修 `fetchMarketBook` 变体格式；新增 `fetchMarketVariants`。
- `MarketPage`：装备选中 → `MarketEnhancementPicker`（强化等级列表视图）；行「查看全部」或购买/出售 → 进入该等级盘口详情/挂单弹窗。非装备维持原有直进盘口。
- `MarketOrderModal`：新增 `enhancementLevel`，`variant` 按等级生成，`selectedAmount` 按变体行计数，已装备拦截同口径收窄。
- `MarketOwnOrders`：挂单名称附 `+N` 显示。
- i18n：`market.enhance.*` 新词条。

### 工具与运维

- `seed-market-system-listings.sh`：装备（28 件）补挂基础变体卖单，定价 = 锻造材料成本价（`actions/forging.json` 投入按物品 `sellPrice` 递归求和，T2 配方含 T1 装备投入递归展开）。
- `OpsMarketActions`：目录口径扩至装备（category=equipment，价格缺省 = 材料成本价），通用化下单目标。

### 文档

- `docs/backend/ops-panel.md` §4.3：目录口径与装备定价基准同步。
- `docs/backend/domain-data-architecture.md`：市场分片写者一节补变体盘口口径。
