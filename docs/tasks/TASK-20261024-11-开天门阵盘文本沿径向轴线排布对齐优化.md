## 1. 需求背景与痛点

用户在开天门阵盘（`HeavenGateModal`）界面中发现当前文本布局存在多处重叠与紊乱：
1. **反向倒灌与重叠**：正上方金轴文本原代码使用垂直固定 offset（`nameDy: -6`, `valDy: 12`, `baseDy: 26`），导致文字由外向内逆向排列，数值 `100` 与 `(初100)` 直接插进圆盘内部，与边缘刻度线和手柄重叠；
2. **中心未对齐**：木、水、火、土四轴由于直接套用垂直 offset，文字的中心并未落在各轴从圆心辐射出来的轴线上，显得错位歪斜；
3. **天灵/地灵徽章碰撞**：品阶标签（「天灵」/「地灵」）原先作为 `hg-handle__badge` 固定在拖拽滑块内部并写死 `translate(0, -22px)`，当灵根数值达到 90~100 时滑块位于外缘，徽章向上弹出直接与五行文本和数值发生严重穿透遮挡。

## 2. 需求理解与实现方案

### 2.1 核心排布顺序与轴线规则
- **轴线方向**：以阵盘中心 $(200, 200)$ 为原点，根据五轴对应的角度（金 -90°、木 -18°、水 54°、火 126°、土 198°）向外延伸发射；
- **排布顺序**：`圆盘边缘 -> 五行文本 -> 五行数字 -> 初始数字`；
- **中心共线对齐**：同一轴上的每个文本图元（五行字、当前值、初始值）的中心坐标 $(x, y) = (200 + R \cdot \cos\theta, 200 + R \cdot \sin\theta)$，全部在对应轴线上对齐，采用 `text-anchor="middle"` 与 `dominant-baseline="central"`；
- **天灵/地灵收拢**：品阶标签作为轴向信息的一部分统一收拢，同样沿该轴线居中对齐（放置在五行文本与圆盘边缘之间，或作为五行文本外侧的冠顶标签），不再随滑块乱漂穿模。

### 2.2 影响范围与实现边界
- 前端组件：`frontend/src/components/HeavenGateModal.tsx`
- 前端样式：`frontend/src/styles/heaven-gate-artifact.css`
- 几何常量/计算（如需）：`frontend/src/game/linggenBoard.ts`
- 不涉及后端、协议、数值公式或底层拖拽逻辑。
