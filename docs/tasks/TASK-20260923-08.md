## 设计

### 模块结构 `frontend/src/vfx/`

| 文件 | 职责 |
| --- | --- |
| `engine.ts` | `VfxEngine`：overlay 坐标系、粒子/弹道/光束/拖尾/发射器原语、注册表 `register/play`、样式注入 `injectStyles`、统一计时器与节点生命周期、`dispose` |
| `feedback.ts` | 通用反馈注册（普攻命中 `feedback.attack`、施法法阵 `feedback.castRing`、通用爆发 `feedback.burst` 兜底）+ 粒子基元 CSS 注入 |
| `abilities/*.ts` ×10 | 每真实功法一个模块：`export default (vfx) => vfx.register('ability.x', ctx => {...})`，自含专属样式 |
| `index.ts` | `import.meta.glob('./abilities/*.ts', {eager:true})` 自动注册；`createCombatVfx(shell)` 工厂：overlay 创建、目标按 `targetType` 从真实 DOM 解析、`play(request)` |
| `useCombatVfx.ts` | React 桥：订阅 store 中 `castingAbilityId` / 敌方 `pendingAbilityId+nextAttackAtSeconds` / 斗法 `events[].abilityId+atSeconds` / 双方普攻时刻，按 signature 防重调度到完成时刻播放 |

### 与画廊版的差异

- 画廊 `ctx.impact/heal/motion` 等沙箱结算回调全部移除——真实结算由服务端快照驱动，`ArenaResource` 自动跳字/碎条、`ArenaActor` 自动 `is-hit`/`is-action-*`，特效脚本只做纯粒子演出。
- 目标元素定位：`side` + `targetType` → querySelector（`.arena-actor--player:not(.is-dead)` / `.arena-actor--enemy:not(.is-dead)`），敌方多单位时 `enemy` 取首个存活、`all-enemies` 取全部存活。
- 时钟域与 `ArenaActor` 一致：`fireAt = serverNow + remaining`，delay 以 `Date.now()` 折算。

### CombatArena 接入点（最小侵入）

- `.combat-arena-shell` 加 `ref`；内部渲染 `<div className="vfx-stage-overlay" />`；
- 一行 `useCombatVfx(shellRef)`。零技能逻辑进组件。

### 样式

- `frontend/src/styles/vfx.css`：overlay/`vfx-node`/震屏 keyframes/粒子基元静态样式，main.tsx 引入；
- 技能专属样式留在各模块 `injectStyles` 自含注入。
