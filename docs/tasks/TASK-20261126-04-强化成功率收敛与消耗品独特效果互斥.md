## 需求背景与目标
1. **高阶强化成功率失控收敛**：
   - 原公式在 `L ≥ t` 时按 `base × (1 + 0.01 × L)` 全等级乘算，且可跨槽同时装备「淬灵粉（+3%）+ 固灵砂（+5%）」叠加 `+8%`，使 `+11~+20` 实际单次成功率逼近 `47%`（接近 `50%` 对称临界点），导致马尔可夫链期望轮次坍塌至数百轮。
   - **新规则**：
     - `L ≥ t` 时仅对**超出目标等级部分**每级乘算提升 `0.5%`：`rate = base × (1 + 0.005 × (L - t))`（如 `L=20` 强 `+20` 无提升，`L=20` 强 `+18` 乘算提升 `1%`）；`L < t` 维持 `base × 0.9^(t - L)`。
     - 成功率上限分段封顶：`t ≤ 10` 维持 `clamp [0, 0.99]`；`t ≥ 11`（`+10 → +11` 及以上）硬封顶为 **`0.45`（`45%`）**，防止未来新增加成突破 `50%`。
2. **自动消耗品独特效果互斥类型（`ConsumableUniqueEffect` / `uniqueEffectType`）**：
   - 物品 `consumable` 配表新增整数枚举字段 `uniqueEffectType`：默认 `0`（`None`，普通类型不互斥）；`1`（`EnhancementSuccess`，强化成功率提升，配置于 `淬灵粉` 与 `固灵砂`），后续特殊不可叠层消耗品可平滑扩展新枚举值。
   - **手动配置顶替**：配置非 `0` `uniqueEffectType` 消耗品时，自动清空全部自动使用槽中同 `uniqueEffectType` 的旧槽位，保留新配置槽位。
   - **存量多槽自动清理**：存档装载水合（主服上线恢复与计算节点离线补算共用 `EcsWorldShard.CreatePlayer`）及结算兜底时，若已装载多个同 `uniqueEffectType`（非 `0`）消耗品，自动移除低等级物品槽位、仅保留最高等级物品并标脏 `Settings`。
