# TASK-20260824-05 游戏配置系统多文件多目录模块化重构

## 任务背景与核心需求

当前游戏配置（`config/game-data`）采用单类型对应单 JSON 大文件设计（如 `items.json`, `monsters.json`, `equipment.json`, `abilities.json`, `actions.json`, `encounters.json`, `maps.json`）。随着游戏内容与阶数扩展，单文件体积持续增大，不便于多人协作、模块化归纳和 Git 差异比对。

本任务目标：
1. **多目录与多文件模块化拆分**：按业务大类拆分子目录（`items/`, `equipment/`, `monsters/`, `encounters/`, `maps/`, `abilities/`, `actions/`），并在各目录下按功能分类/境界划分细分 JSON 文件。
2. **加载器支持递归目录扫描与对象展平**：重构 `Domain.GameData` 中的 `GameDataCatalog.cs`，同时支持外部目录递归加载与内嵌程序集资源加载。支持每个 JSON 既可以是单个对象也可以是对象数组。
3. **适配构建与工具链**：更新 `Domain.csproj`、`ComputeNode.csproj`、`DataTool`、`tools/config-editor` 及 CI 校验门禁 `scripts/verify.sh`。
