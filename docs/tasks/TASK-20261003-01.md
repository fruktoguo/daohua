- 需求：浅色模式下字体加粗，黑字看不清（纸底上 400/500 字重笔画偏细，可读性不足）。

## 设计与范围

仅调整浅色主题字体可读性，不改变配色、字体家族、字号、布局或主题交互。

实现方式（`frontend/src/styles.css` 与 `frontend/src/styles/theme.css`）：

1. `styles.css` 根 `:root` 新增主题字重变量 `--font-weight-regular: 400` 与 `--font-weight-medium: 500`，并以 `font-weight: var(--font-weight-regular)` 让正文全局继承。
2. 四个正式基础 CSS（`styles.css`、`styles/selection-grid.css`、`styles/floating-popover.css`、`styles/expedition.css`）中所有显式 `font-weight: 400`/`normal` 改为 `var(--font-weight-regular)`，所有 `font-weight: 500` 改为 `var(--font-weight-medium)`；仅改值，不改动 600/700/800/900 等更粗字重，不动 `vfx.css` 与 `ops/ops.css`。
3. `theme.css` 浅色 `:root[data-theme="light"]` 将两字重变量覆盖为 600，使浅色正文、辅助文字、表单控件与原 400/500 的标签标题统一至少 600；深色沿用原值不变。浅色补 `font-synthesis: weight`，保证 STSong/SimSun 等单字面字体回退时也能呈现加粗；浅色 `textarea`（未被 `font: inherit` 覆盖）显式声明 `var(--font-weight-regular)`。
4. 设计文档 `13-前端UI设计系统与修仙交互规范.md` §13.1.1 先行更新：主题驱动由「统一配色变量」扩展为配色与字重变量，切换语义同步为主题外观（配色与字重）更新，仍不重新挂载。
