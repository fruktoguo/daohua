## 背景

用户反馈战斗页（详情页）右侧的生活行动总目标卡（`ArenaLifeGoalCard`，修炼/采集/炼丹时替换敌方九宫格）尺寸过大：宽 `clamp(180px, 26vw, 290px)`、`min-height: 200px`、56px 居中大图标，在窄窗口/竖屏下占据右侧大块空间，观感臃肿。

## 需求分析

- 卡片信息量本身合理（类型徽章、行动名、主产物图标与总量、单次产出/剩余轮次、其余产出与材料 chips、轮次进度条、终止按钮），问题在**尺寸规格**而非内容构成。
- 战场为左右两列均分（`combat-arena-field` grid），卡片是右列内的固定宽度块，缩小不影响战场结构。
- 同规格卡片共三张：生活总目标卡（`arena-life-card`）、赶路卡（`arena-travel-card` 复用 `arena-life-card`）、空闲卡（`arena-idle-card`），需同步收拢保持一致。

## 改动方案（仅样式，`frontend/src/styles/expedition.css`）

| 项 | 原值 | 新值 |
| --- | --- | --- |
| 卡片宽度 | `clamp(180px, 26vw, 290px)` | `clamp(160px, 19vw, 224px)` |
| 卡片 min-height | `200px` | 移除（内容自然高度） |
| 卡片 padding / gap | `12px` / `10px` | `10px` / `8px` |

| 竖屏 ≤960px max-width | `290px` | `224px` |

## 需求修正（2026-10-03 09:30）

用户澄清：核心诉求不是尺寸而是**信息冗余**——同一数字（如 1937）在角标、目标产物、计划总量、单次产出四处重复，大图标方块无信息量。改为信息精简：

- **生活总目标卡**：砍掉 56px 大图标方块与「目标产物/计划总量/单次产出/剩余轮次」三行 meta，合并为**一行主信息**（产物名 + 单段明细）：
  - 无限轮：`修为 +1937点/轮 · ∞`
  - 有限轮：`修为 ×1937点 · 剩10轮`
  - 增益主产物：`名称 每轮×2层 · 剩10轮`
  - 「其余产出」「单轮所需材料」chips 仅在存在时保留
- **赶路卡**：砍掉 🧭 图标方块与「目标地点/规划路程/已行路程」三行，合并为一行 `目的地 已行/总里程`（已行里程保留动态刷新）
- 同步清理：`LifeYieldRow` 的 glyph/tone 死字段、`RESOURCE_YIELD_META` 常量、两卡专用 CSS（icon-box/glyph/count-badge/meta/target/subinfo）与浅色主题引用、6 个废 i18n 词条（新增 detailInfinite/detailFinite/detailBuff）
