## 需求理解与实现边界

### 1. 业务目标
在现有坊市浏览网格（`MarketBrowseGrid`）标的卡片右下角的数量模式（「持有 / 在售 / 求购」）基础上，进一步增加「参考价格」显示模式，并严格遵守防回归约束（严防遗漏 `itemId` 导致瓦片图标丢失）。
让玩家在标的网格卡片上能够一键切换并快速查看所有物品当前的全服市场滑动平均成交价（参考价），快速评估商品市面价值。

### 2. 核心逻辑预期
1. **状态模型扩展**：
   - `MarketAmountDisplayMode` 从 `'owned' | 'onSale' | 'bid'` 扩展为 `'owned' | 'onSale' | 'bid' | 'price'`，默认保留 `'owned'`；
   - `toggleAmountDisplayMode` 升级为四态顺次循环：`owned` -> `onSale` -> `bid` -> `price` -> `owned`；
   - `setAmountDisplayMode(mode)` 支持直接赋值指定模式。
2. **数据聚合模型**：
   - 基于 `useGameStore` 中的 `marketStats: Record<string, MarketItemStats>`；
   - 构建 `marketPriceMap`：从 `marketStats` 中按 `itemId` 提取当前有效的 `referencePrice`（最近 10 次成交滑动均价）；优先匹配基础 0 级变体；若无 0 级成交则回退已有变体的参考价；若均无则返回 `null`；
3. **UI 与视觉呈现（防回归关键）**：
   - 顶部选项胶囊扩展为「持有 / 在售 / 求购 / 参考价」四项；
   - 标的瓦片渲染（`MarketBrowseCardItem`）：
     - **严守防回归底线**：显式向 `ItemTile` 传递 `itemId={item.itemId}`，确保瓦片图片图标 100% 正常渲染；
     - 当 `mode === 'price'` 时，通过 `bottomRightLabel` 展示格式化价格（如 `120`，无成交时展示 `-`，避免显示带 `×` 的数量）；
     - 瓦片类名增加 `.is-price-mode`，角标采用琥珀金黄色（`#ffd875` / 浅色模式 `#8c6b12`），象征灵石货币价值；
4. **无障碍与国际化**：
   - 新增 `market.browse.amountMode.price`（'参考价'）；
   - 新增 `market.browse.itemPrice`（'{name}，参考价 {price}'）与 `market.browse.itemNoPrice`（'{name}，暂无参考价'）；
   - 同步维护 `template.csv`。
5. **门禁与测试保障**：
   - 维持并强化 `marketOrders.test.mjs` 中的静态 AST/源码断言，确保 `MarketBrowseGrid.tsx` 中的 `<ItemTile ... itemId={item.itemId} ... />` 永远受代码断言保护；
   - 补充 `marketPriceMap` 取值与文案自洽断言；
   - 跑通 `verify.sh`（前端 191 项单测全绿、后端全测试套 465 项全绿）。
