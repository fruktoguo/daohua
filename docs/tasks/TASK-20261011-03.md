# TASK-20261011-03 特殊属性口径纠偏：玩家取消成长保送、怪物基准保留、杖琴技能增幅

## 需求

用户裁定：特殊属性（攻速/行动速度/冷却缩减/普攻增幅/技能增幅/暴击伤害成长分量等）在玩家基准数值里是**经装备、内功、特质、Buff 等特殊手段获取**的值，不应由境界成长直接赠送；「境界成长保送点数」本质是**怪物同构建模的基准数值**，只对怪物保留。

配套：法杖与琴（治疗琴）两系武器新增技能增幅——T1 +5 点、T2 +15 点；并交付各等阶特殊属性期望值表（等阶 × 特殊属性）。

## 实现方案

1. `PlayerAttributeResolver`：移除 6 项成长注入（攻速/行动/冷却/普攻增幅/技能增幅/暴伤成长 350x²）；暴伤通道保留 50 点基础值（设计默认 150% 暴伤，非成长保送）；`ResistanceScale=Tier` 保留。
2. `GameDataCatalog.ParseMonsterDefinitions`：怪物成长注入不动。
3. `config/game-data/equipment/weapons.json`：九节杖/素心琴 `skillBonusPoints:5`，朝元杖/松风琴 `skillBonusPoints:15`；`frontend/src/game/ids.ts` 兜底镜像同步。
4. 文档先行：`07-战斗数值与内视规约.md` §7.7.5 改写（玩家特殊属性获取途径 + 怪物基准表）、`expected-attributes.json` 说明段、`11-数值量化模型集.md`、`common-components.md`、`CombatGrowthCurve`/`SectionCodec` 注释；`index.html` 经 sync-master-viewer 重生成。
5. 测试：`PlayerAndMonsterShareTheSameGrowthCurve` 玩家侧断言改为「零保送」（仅暴伤基础 50）；怪物侧断言保留。
