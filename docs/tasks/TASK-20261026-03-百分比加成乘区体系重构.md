## 2. 需求背景与核心设计

### 2.1 现状痛点
当前属性解析器（`PlayerAttributeResolver`）中独立乘区过多：
- 六维百分比为独立乘区；
- 装备与灵根百分比累加为独立乘区；
- 战外面板 Buff 百分比为独立乘区；
- 特质（Traits）百分比被单独拆分为第四个独立乘区。
这导致特质与装备、灵根层层连乘，形成了严重的「多系统复合指数级通胀」，随着高阶强化、满灵根与高品特质解锁，属性出现非预期的爆炸增长，同时也增大了玩家心智负担与数值控制难度。

### 2.2 目标模型与乘区规范
根据最新设计意图，百分比加成严格收拢为清晰的三大乘区：
1. **固定值加成**：全部走加算（六维固定、装备/内功固定、节点建筑固定回复、土灵根固定减伤末位直减）。
2. **乘区 1【六维百分比】**：保持独立乘区 $(1 + \text{六维\%})$，代表先天资质底蕴。
3. **乘区 2【常驻基础大乘区（装备 + 特质 + 灵根 + 默认类型）】**：
   - 彻底合并「装备百分比」、「特质百分比」、「灵根百分比」为同一个大乘区；
   - 三者同名属性百分比彼此加算：$\Sigma(\text{装备\%} + \text{特质\%} + \text{灵根\%})$；
   - 后续新增的所有其他类型百分比加成，未显式指定乘区的默认并入此乘区加算。
4. **乘区 3【战斗/状态 Buff 乘区】**：
   - 作为一整个独立的战时状态乘区；
   - 不同的 Buff 之间严格加算（如三个 $+20\%$ 增益 Buff 效果为 $20\%+20\%+20\%=60\%$，乘区为 $1 + 0.6 = 1.6\times$）。

### 2.3 属性解算收口公式
$$\text{FinalStat} = \Big(\big(\text{基础} + \text{六维固定}\big) \times (1 + \text{六维\%}) + \text{装备固定}\Big) \times \text{SoftRatio}(\text{装备\%} + \text{特质\%} + \text{灵根\%} + \Sigma\text{默认\%}) \times \text{SoftRatio}(\Sigma\text{Buff\%})$$
