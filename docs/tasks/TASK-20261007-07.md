# TASK-20261007-07 战斗页队伍面板与参战开关（组队共战 UI 补全 + 快照导出修复）

## 需求来源

2026-10-07 22:20:00 用户反馈：组队共战已在跑（`随队讨伐` 行动中），但战斗界面看不到队友，
也没有明确的「是否参与斗法」入口；要求参考银河奶牛放置的队伍面板（成员卡片阵列 +
本人参战勾选框 + 队伍操作行）。

## 根因定位

- **盟友阵列不渲染根因**：`EcsWorldShard.ExportSnapshotCore` 重建 `QueuedActionState` 时
  漏传 `PartySession`（聚合 `ExportActions` 路径有传，ECS 路径没有）→ 快照 `PartySession=null`
  → `ToExpeditionDto` 的 `spec` 为 null → `allies` 恒 null → 前端盟友九宫格永远不渲染，
  队头条目 `partySession` 标记也恒 null。
- **连带影响**：装载对账的「陈旧绑定识别」读的正是这份导出快照——`PartySession` 恒 null
  导致陈旧会话绑定在装载时永远漏检（只能靠看门狗兜底）。
- **参战入口缺失**：`party.unready` 后端语义本就是「会话中取消参战→散场」，但前端把
  本人开关在会话期间 `disabled` 锁死，用户没有任何退出斗法的途径。

## 语义确认（对齐 §21.13）

- `party.ready`/`unready` 即「参与斗法」开关：全员勾选+槽位占满+同节点 → 服务端自动开打。
- 会话中「退出斗法」= 取消参战 → 名册冻结铁律触发全队散场（确认弹窗明示）。
- 会话中阵容冻结：卡片区不渲染空槽，成员变动入口全部收敛到散场语义。
