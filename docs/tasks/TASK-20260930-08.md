# TASK-20260930-08 物品角标细分类目与装备槽位重复角标清理

## 需求

- 提出时间：2026-09-30 18:23:48
- 用户反馈：物品左上角品类角标理应显示细分类型（如装备应显示武器、衣物等），当前只显示大类型；装备栏位穿戴后左上角额外叠加了槽位类型标签，与装备瓦片自身丝带重复，应改为与背包一致只显示物品自身信息。

## 现状问题（代码分析）

- 背包 `ItemCard` 丝带取 `InventoryItem.category`（`mapAsset` → `resolveItemMetadata` 本地 `ITEM_META_CORES`）：材料一律 'material'→「材料」（配表实为 herb/mineral），功法书一律 'manualFragment'→「功法秘籍」（不分全本/残卷）。
- 坊市已用 `subCategory(eq.slot) || itemDef.category` 展示细分品类；悬浮卡片「品类」行同样用 `itemDef.category`（材料已显示药材/矿石），与背包丝带口径不一致。
- 装备面板 `EquipmentSlotCard` 已装备态叠加 `equipment-slot-badge` 槽位名（如「武器」「腿部」）与瓦片丝带（如「武器」「下装」），双重左上角标签重复。

## 方案

- `ids.ts` 新增 `resolveItemSubCategory(itemId, itemDef, eqDef, fallback)` 统一细分解析：`item.tome./item.fragment.` 前缀 → manualTome/manualFragment；装备 → `eqDef.slot`；其余 → `itemDef.category`；兜底沿用传入值。
- 词典 `game.category` 增补 `manualTome`/槽位细分键（ring/neck/two-hand/off-hand），`manualFragment` 文案改为「残卷」；`ITEM_META_CORES` 修正材料（herb/mineral）与秘籍全本（manualTome）条目。
- 背包 `ItemCard`（新增 `equipmentDefinition` 入参）、`ItemGridPicker`/`ItemUseSlot`、坊市三处、悬浮卡片「品类」行统一走细分解析。
- 装备面板删除已装备态 `equipment-slot-badge` 节点与对应 CSS。

## 范围

- `frontend/src/game/ids.ts`、`frontend/src/i18n/domains/game.zh.ts`
- `frontend/src/components/ItemDisplay.tsx`、`InventoryItemCell.tsx`、`ItemGridPicker.tsx`、`EquipmentPanel.tsx`
