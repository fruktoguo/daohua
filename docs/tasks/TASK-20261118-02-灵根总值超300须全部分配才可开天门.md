## 1. 需求与设计口径

- **业务目标**：防止玩家在开天门或逆天改命抽到总值超过 300 的灵根后，通过「散功 2 返 1」把多余灵根全部弃置只保留单灵根（1.0× 最低修为上限快速破境），升至高级后再改命换回多灵根。
- **核心规则**：
  1. 抽取先天灵根总值 `innate.Total > 300` 时，确认灵根生效（首次入天门 `enter` 与改命采纳 `accept`）**必须把可分配点数全部用完**（`ResolveRemainingPoints(innate, candidate) == 0`），否则拒绝生效。
  2. 先天总值 `≤ 300` 时维持原规则，允许保留未分配点数直接入天门/采纳。
  3. 中间调配保存草稿（`allocate`）只校验不透支（`remainingPoints >= 0`）与至少保留 1 条有效灵根，不阻断分步调配。
