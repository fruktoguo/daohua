## 核心需求与边界

1. 怪物击杀经验层次倍率由「小怪 1× / 精英 3× / 妖王 10×」调整为「小怪 1× / 精英 10× / 妖王 40×」。

4. 不受影响：怪物自身战斗经验（`CumulativeExpFor`）、行动/强化/秘法经验基准（`BaseExperienceForLevel`）、掉落与稀有掉落判定。
