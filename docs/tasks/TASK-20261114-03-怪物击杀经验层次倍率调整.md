- **所属模块**：`src/Domain`（境界进度配表派生）+ 设计文档

## 核心需求与边界

1. 怪物击杀经验层次倍率由「小怪 1× / 精英 3× / 妖王 10×」调整为「小怪 1× / 精英 10× / 妖王 40×」。
2. 唯一实现点：`RealmProgressionCatalog.MonsterKillExperience(level, rank)`（`src/Domain/GameData/BaseAttributeCatalog.cs`）；配表 `monsters/*.json` 无 `experience` 显式覆盖，全量怪物走该派生。
3. 影响口径：击杀收益为单参数 `experience`，同额同时结算修为三池（`Experience`/`Foundation`/`CombatExperience`）与六维经验（归属维度各得全额），三类收益等比放大，不可拆分。
4. 不受影响：怪物自身战斗经验（`CumulativeExpFor`）、行动/强化/秘法经验基准（`BaseExperienceForLevel`）、掉落与稀有掉落判定。
