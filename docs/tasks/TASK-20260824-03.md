## 2. 需求背景与核心目标

### 2.1 现状与问题分析
根据用户明确指令：**所有配置文件都应该默认值不写，而不是写一堆 0 / false / 空集合**。
经全面扫描，当前各配置 JSON 存在严重的冗余默认字段平铺：
1. **`abilities.json`（冗余度 54.4%）**：每个技能均平铺大量 `healingRatio: 0.0`, `flatHealing: 0`, `stunChance: 0.0`, `blindChance: 0.0`, `penetrationRatio: 0.0`, `damageOverTimeRatio: 0.0` 等零值属性。
2. **`actions.json`（冗余度 28.2%）**：大部分行动均平铺 `executionKind: "timed"`, `combatEncounterId: null`, `availableNodeIds: []`, `hiddenFromCatalog: false`, `inputs: {}`, `outputs: {}`。
3. **`monsters.json`**：怪物平铺 `skills: []`, `rareDropTable: []`, `dropTable: []`, `attackIntervalMilliseconds: 1000`, `category: "physical"`, `element: "none"`, `rank: "minion"` 等。
4. **`encounters.json`（冗余度 19.0%）**：平铺大量 `bossEnemyIds: []`, `eliteEnemyIds: []`, `dropTable: []`, `rareDropTable: []`, `enrageTimeMilliseconds: 180000`, `searchMilliseconds: 20000` 等。
5. **`maps.json`**：地图节点平铺 `npcs: []`, `buildings: []`, `cultivationMultiplier: 1`, `availableActionIds: []`, `encounterIds: []`。
6. **`items.json` & `equipment.json`**：平铺 `tier: 1`, `sellPrice: 0`, `isTradable: true`, `category: "general"`, `quality: 1` 等。

### 2.2 核心优化落地
1. **全量配表 Lean 最净化**：
   - 全量精简 `config/game-data/` 下全部 7 个 JSON 文件（`abilities.json`、`actions.json`、`monsters.json`、`encounters.json`、`maps.json`、`items.json`、`equipment.json`），剔除所有无意义默认值。
2. **领域模型与解算兼容性**：
   - 强化 C# 领域 DTO（`AbilityConfig`、`CombatantConfig`、`CombatEncounterConfig`、`WorldNodeDefinition`、`ActionDefinition`、`ItemConfig`、`EquipmentConfig`）与解算器（`DataBudgetResolver.ResolveAbility`、`ResolveCombatant`、`ResolveEquipment`、`ResolveItem`、`ToEncounter`），统一采用属性缺省与可空兜底，100% 保持业务解算行为不变。
3. **DataTool 导出器闭环**：
   - 为所有配置类型实现 Lean 转换器（`ToActionConfig`、`ToAbilityConfig`、`ToEquipmentConfig`、`ToCombatantConfig`、`ToEncounterConfig`、`ToMapConfig`、`ToItemConfig`），使 CLI 工具导出时自动产出最简格式，彻底杜绝后续重导数据引入垃圾字段。
