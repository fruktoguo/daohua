# TASK-20261031-01 市场价格独立悬浮窗顶部完整参考价与布局优化

## 1. 任务背景与核心目标

当前物品/装备 Hover 弹出的「市场价格」独立副卡片（Aside Card）存在以下信息层级与排版缺陷：
1. **顶部缺少核心指标**：副卡头部（Header）右侧重复展示了已在主卡片显著呈现的物品名称（如「乌铁」/「混元巾 +1」），浪费了宝贵的头部黄金区域；
2. **核心参考价格隐藏在底部角标**：公允市场参考价（均价）被挤压在底部的「成交」微型 chip 列表中，字号极小（`text-2xs`），且大数容易被紧凑缩写（如 `1.66万`），无法快速看清真实精确数字；
3. **底部排版臃肿换行**：成交行内同时堆叠了「今日成交」、「本周成交」和「均价」三个条目，在有限卡片宽度下极易折行穿模。

**核心目标**：
1. **顶部直接呈现完整参考价**：在「市场价格」悬浮窗顶部 Header 右侧直接渲染醒目完整的参考价格（千分位精确整数，如 `16,590 灵石`），金色微光高亮；
2. **优雅状态区分**：
   - 有真实市场均价时：呈现 `参考价 16,590 灵石`；
   - 无成交均价回落回收价时：标明 `保底价 432 灵石`（琥珀金回退色）；
   - 均无时：优雅显示 `参考价 -`；
3. **底部布局舒展**：成交区域剥离已提至顶部的均价，舒展展示「今日成交」与「本周成交」两项，杜绝折行拥挤；
4. **组件能力扩展**：扩展 `FloatingAsideCard.subtitle` 支持 `ReactNode`；
5. **主题与 i18n 完备**：适配深色/浅色高对比度主题，闭环 i18n 词条与模板全门禁。

---

## 2. 详细技术方案

1. **组件层（`FloatingPopover.tsx`）**：
   - 将 `FloatingAsideCard` 的 `subtitle` 类型拓展为 `ReactNode`（完全向后兼容 `string`）。
2. **业务呈现层（`ItemDisplay.tsx`）**：
   - 在 `resolveMarketStatsAsideCard` 中，使用 `formatExactNumber` 获取无截断的标准千分位数字；
   - 构造 `.daohua-market-aside-head-ref` 节点填入 `subtitle`；
   - 底部成交统计行（`daohua-market-aside-row--volume`）简化为今日与本周成交量。
3. **样式层（`floating-popover.css` & `theme.css`）**：
   - 增加 `.daohua-market-aside-head-ref`、`.daohua-market-aside-head-ref-val` 等样式规则，设置金色微光阴影与等宽数字；
   - 增加浅色模式（`[data-theme="light"]`）高对比度深金配色。
4. **国际化（`market.zh.ts`）**：
   - 增加 `referencePriceLabel`（参考价）与 `guaranteedPriceLabel`（保底价）。
