## 1. 需求背景与核心问题

用户在游戏过程中发现：按玩法设定，逆命丹是入天门（18 级凡俗 [天] 叩天门开天门）后用于逆天改命的专属丹药，理应只有在 18 级之后才能制作。

经全栈代码与配表核查，证实存在以下根本缺陷：
1. **配表关键字段缺失**：
   - `config/game-data/actions/alchemy.json` 中的 `alchemy.refine-reverse-fate-pill` 未声明 `"level": 18`；
   - `config/game-data/items/pills.json` 中的 `item.reverse-fate-pill` 未声明 `"tier": 2`；
   - `inputs` 为 `{}`（空材料输入，仅消耗底蕴）。
2. **前后端推导规则退化为 1 级**：
   - 服务端 `CraftingRecipeRules.ResolveRequiredRealmLevel` 与前端 `resolveActionLevel` 在缺少 `action.Level`、材料与产物 Tier 时，兜底解析为 1 级；
   - 导致任何 1 级新手玩家在炼丹页面均可直接看到并炼制逆命丹。
3. **严重数值漏洞（跨境界底蕴套利）**：
   - 逆命丹单轮消耗为「当前升级所需修为 25% 的底蕴」；
   - 1 级升 2 级只需 10,000 经验（25% 仅 2,500 底蕴）；
   - 18 级升 19 级需 800,000 经验（25% 需 200,000 底蕴）；
   - 30 级升 31 级需 12,631,000 经验（25% 需 3,157,750 底蕴）；
   - 允许低境界炼制会导致玩家在 1 级以极低代价批量囤积逆命丹，高境界改命时代替数十万至数百万底蕴，彻底击穿改命消耗设计。
4. **历史债务溯源**：
   - 原始任务 `TASK-20261022-02` 明确记录：`新增道具「逆命丹」，放入炼丹体系，属于特殊配方（解锁条件暂不实现）`，彼时遗留未补闭环。

## 2. 核心逻辑预期与实现边界

1. **配表与前端常数拉齐**：
   - `actions/alchemy.json`：`alchemy.refine-reverse-fate-pill` 增加 `"level": 18`；
   - `items/pills.json`：`item.reverse-fate-pill` 增加 `"tier": 2`；
   - `frontend/src/game/ids.ts`：`ITEM_META_CORES['item.reverse-fate-pill']` 对齐为 `tier: 2`；
   - 保持配表 JSON 换行符为 LF，避免跨平台嵌入指纹漂移。
2. **领域不变量收敛（硬约束防偷鸡）**：
   - 普通制造配方遵循「境界达到所需等级 或 对应技艺达到所需等级」二选一；
   - 逆命丹等特殊底蕴配方（`FoundationCostRatio > 0`）：由于底蕴消耗按角色当前境界挂钩，若角色境界未达标，严禁仅凭炼丹技艺等级跨境界放行；
   - 在 `CraftingRecipeRules.IsActionUnlocked`、`EcsPlayerRuntimeAdapter` 入队校验、ECS `TryStartActionCore` 调度准入、以及前端 `App.tsx` / `CodexPage.tsx` 解锁过滤中统一增加硬约束：凡 `FoundationCostRatio > 0`，必须满足 `realmLevel >= requiredLevel`。
3. **全栈门禁验证**：
   - Domain / Ecs / Server 三套测试全绿；
   - 前端单元测试与生产构建通过；
   - DataTool validate 严格校验通过。
