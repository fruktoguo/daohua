## 3. 详细设计方案

### 3.1 地图拓扑：青云古道（4 节点）
- **全局世界坐标**：介于青云仙山 (`x: 60, y: 30`) 与星陨异境 (`x: 115, y: 40`) 之间：
  1. `node.trail-inn`（**离山驿**，`x: 72, y: 32`）：青石古道起点，驿亭客栈，散修汇聚；接青云山门（15s）。
  2. `node.pine-plank`（**古松栈道**，`x: 84, y: 34`）：依山而凿的长路，林木葱郁，偶见野兽；接离山驿（15s）。
  3. `node.rocky-gorge`（**落石险隘**，`x: 96, y: 36`）：峡谷紧缩绝壁，溪流翻滚，伏击险地；接古松栈道（18s）。
  4. `node.boundary-pass`（**断界古关**，`x: 106, y: 38`）：古老边关残垣，关底 Boss 撼地金背猿守关；接落石险隘（20s），接星陨异境裂天界隙（30s）。
- **跨域边调整**：
  - 原 `edge.gate-rift`（青云山门 $\to$ 裂天界隙）退役；
  - 改为 `edge.gate-trail-inn`（青云山门 $\to$ 离山驿，15s）；
  - 新增 `edge.boundary-rift`（断界古关 $\to$ 裂天界隙，30s）。

### 3.2 怪物体系（4 怪）
1. **青脊妖狼** (`enemy.green-wolf`，Lv 10 小怪)：敏捷物理系，掉落【粗韧狼皮】(`item.rough-wolf-hide`) 与【猛兽尖牙】(`item.beast-fang`)；
2. **潮汐之灵** (`enemy.tide-spirit`，Lv 11 小怪)：水系远程施法，施放《潮汐》，掉落【水灵原核】(`item.water-spirit-core`) 与《潮汐》秘籍/残卷；
3. **铁甲岩獠** (`enemy.iron-boar`，Lv 14 精英)：重甲霸体，高护甲高击退，掉落【坚岩獠齿】(`item.rock-fang`) 与【重甲厚皮】(`item.thick-beast-hide`)；
4. **撼地金背猿** (`enemy.golden-ape-boss`，Lv 16 关底 Boss)：肉盾首领，携带技能《碎罡》，掉落【金背猿骨】(`item.golden-ape-bone`) 与【暴猿煞心】(`item.ape-heart`)。

### 3.3 技能体系
1. **《潮汐》(`ability.tide`)**：
   - 0 CD，3.0s 吟唱，耗蓝 10 点，水系全体 60% AP + 10；
   - 对应秘籍 `item.tome.tide` 与残卷 `item.fragment.tide`。
2. **《碎罡》(`ability.sui-gang`)**：
   - CD 60s，3.0s 吟唱，持续 20s，气血 $\le 50\%$ 施放；
   - 自降双抗 80%，获得自身双抗总和 30% 对应层数的碎罡 Buff（每层 +1 AD）；
   - 狂暴被动：血损提供巨幅命中与暴击加成。
