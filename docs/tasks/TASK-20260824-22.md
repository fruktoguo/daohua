# TASK-20260824-22 右侧主栏多Tab重构（储物袋/装备/功法）与角色虚影六部位装备阵列及技艺工具槽位体系开发

## 任务背景与核心目标

当前客户端桌面端右侧栏（`.right-column`）仅固定展示单行囊储物袋网格，缺乏修士个人常驻装备与功法装配的直观操作入口。
本任务旨在将右侧主面板重构为多 Tab 交互体系：
1. **右侧多 Tab 顶层切换**：支持「储物袋 (Bag)」、「装备 (Equipment)」、「功法 (Abilities)」三大核心修仙子面板随时平滑切换。
2. **装备专属面板**：
   - **居中角色虚影**：中间展示当前修士本命立绘虚影/法相（`CharacterAvatar` 结合修仙半透明太虚微光虚影特效与呼吸浮空动效），营造本命法躯临场感。
   - **左右六部位装备阵列**：左侧 3 个槽位（头部、衣服、腿部）与右侧 3 个槽位（武器、饰品、鞋靴）竖排对称环绕角色虚影。
   - **点击装配与穿脱交互**：点击未穿戴/已穿戴槽位可呼出 `ItemGridPicker` 筛选对应部位装备进行穿戴或卸下，支持 Tooltip 悬浮展示装备词条、等阶与属性。
   - **底部技艺工具扩展槽位**：装备面板底部增加一排技艺/生活工具装备扩展槽位（预留如采矿稿、伐木斧、炼丹炉、锻造锤等），展示优雅的未解锁/待装配状态，为后续技艺法宝体系做好协议与视图扩展准备。
3. **功法专属面板**：
   - 常驻展示 4 个战斗功法技能槽（支持等级调整、释放触发条件设置与功法选择）。
   - 聚合展示修士已习得功法与神通秘籍列表，支持即时查看效果、五行分类与灵力消耗。
4. **储物袋面板**：保留并优化原背包网格视图。
5. **规范约束**：
   - 遵循 `docs/frontend/common-components.md` 公共组件规范，复用 `ItemGridPicker`、`FloatingInfoCard`、`CharacterAvatar`、`UnitNumber` 等。
   - 严格遵循国际化 `useT()` / `i18n` 规范，无硬编码中文。
