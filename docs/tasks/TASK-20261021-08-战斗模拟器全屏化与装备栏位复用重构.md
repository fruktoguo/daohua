## 1. 需求背景与核心目标

### 1.1 问题现状
1. **小弹窗局促限制**：当前战斗模拟器作为固定最大宽度 1040px 的 Modal 小窗口居中弹出，在大屏/宽屏设备下两栏信息高度挤压，缺乏推演大盘的开阔视野与沉浸感。
2. **装备部位定义错乱且副手完全缺失**：
   - 现存代码将六大部位硬编码为 `weapon`, `helmet`, `chest`, `legs`, `boots`, `accessory`；
   - 游戏权威 `EquipmentSlot` 为 `weapon`（含 `two-hand`）、`off-hand`、`head`、`armor`、`legs`、`trinket`（含 `ring`/`neck`/`talisman`）；
   - 导致副手（`off-hand`）完全无法读取与配置，头部（`head`）、法袍（`armor`）、配饰（`trinket`）与配表定义键不匹配导致读取失败、全退化为“(未穿戴)”。
3. **装备描述与格式化错乱**：
   - 当前写死在卡片下方以绿色小胶囊逐项输出英文字段（如 `spellAttack: +42 accuracy: +42 skillBonusPoints: +45`），不仅未走多语言本地化和属性翻译，且视觉割裂。
4. **违背 UI 简练红线（AGENTS §8）**：
   - 顶部与消耗品栏含有设计/实现层面的说明性、解释性冗余文本（如“配置六大部位已穿戴装备与强化等级（+0 ~ +20），装备基础属性与强化系数将直接注入战斗推演中。”、“配置战斗自动药品栏（槽位 0~2）与通用栏（槽位 3~5）……”），必须予以彻底清除。
5. **未复用游戏内装备格子规范**：
   - 未遵循前端公共组件规范，未复用游戏内标准 64px 装备格子（`ItemTile`、`ItemTooltipTarget` 悬浮完整属性详情卡与品质边框），而是手写了简陋粗糙的表单。

### 1.2 核心目标
1. **全屏视口沉浸体验**：
   - 模拟器弹窗外壳升级为全屏模式（铺满 100vw × 100dvh），顶部保留统一导航头与关闭按钮，双列布局在大屏下充分舒展自适应。
2. **清除所有说明性冗余文本**：
   - 移除装备 Tab 与消耗品 Tab 中的说明性横条，文案直观简明。
3. **严格对齐权威 6 大装备部位**：
   - 武器（`weapon`）、副手（`off-hand`）、头部（`head`）、衣服（`armor`）、下装（`legs`）、饰品（`trinket`）；
   - 正确导入自身装备并与槽位精准对齐，彻底补齐副手装备与属性生效。
4. **复用游戏内标准装备格子**：
   - 空槽位呈现标准虚线框与槽位名称，已穿戴呈现标准 `ItemTile`；
   - 悬浮通过 `ItemTooltipTarget` 直接呈现游戏权威中文属性卡片与词条详情；
   - 点击格子支持通过装备待选网格（`ItemGridPicker` / 候选流）挑选该槽位全量可用装备或一键卸下；
   - 支持便捷调整强化等级（+0 ~ +20）。

## 2. 详细技术方案

1. **全屏样式重构 (`frontend/src/styles/simulator.css`)**：
   - `.sim-modal` 改造为 `position: fixed; inset: 0; width: 100vw; height: 100dvh; max-width: none; max-height: none; border-radius: 0;`；
   - 优化内部 `.sim-modal-body`、`.sim-config-layout`、`.sim-results-layout` 铺满高度与自适应双栏（左栏人员编辑、右栏地图时长与运行）；
2. **装备部位与映射对齐 (`frontend/src/components/simulator/SimulatorPartyEditor.tsx`)**：
   - 槽位常量对齐 `EquipmentPanel` 中的 `ALL_SLOTS`：`weapon`, `off-hand`, `head`, `armor`, `legs`, `trinket`；
   - 槽位匹配函数复用 `isSlotMatch`（weapon 兼容 two-hand，trinket 兼容 ring/neck/talisman）；
   - 修复读取自身装备逻辑，确保副手及其他部位正确加载。
3. **格子与选择器复用**：
   - 槽位展示采用 64px 标准 `equipment-slot-btn`；
   - 空槽展示 `equipment-slot-empty-label`（武器/副手/头部/衣服/下装/饰品）；
   - 已穿戴展示 `ItemTile` + `ItemTooltipTarget`；
   - 点击格子呼出 `ItemGridPicker`（覆盖全量该槽位装备配表，按等阶/名称排序，支持卸下）；
   - 已装备状态下提供强化等级输入微调（0~20）与快捷卸下按钮；
   - 彻底删除英文属性胶囊输出。
4. **清理冗余说明文案**：
   - 删除 `.sim-equipment-header-hint` 与 `.sim-consumables-header-hint` 等说明性文字。
