# TASK-20261014-07 建筑卡片加成直显与详情三段式重构（信息/升级/负载）

## 1. 任务背景与需求分析

- **提出时间**：2026-10-14 21:55:35
- **分类**：前端交互 / 建筑系统 / 体验重构
- **核心诉求**：
  1. **建筑列表卡片没有直接显示加成**：
     当前建筑列表卡片（`NearbyPanel` 中的建筑项）仅展示了名称、等级、静态效果介绍文字（如「提升此地历练采集行动的收益」）、人数与进度条，缺乏当前等级下的**具体数值加成**（如「历练采集收益 +10%」）。需要在列表卡片中直接明了地展示具体数值加成。
  2. **建筑详情弹窗体验重构，划分为清晰的三大部分**：
     - **信息（Information）**：显示名称、介绍（风味描述）、等级、当前具体加成。
     - **升级（Upgrade）**：显示当前加成和目标等级（升级后/下一级）的加成对比，参考境界突破带箭头的样式（`当前值 → 目标值 (+增量)`）；同时收拢升级操作、工期进度、材料进度与材料交付。
     - **负载（Load & Capacity）**：显示当前使用人数和最大负载人数（明确最大负载是降低加成的阈值，而非硬性人数上限）；未超载显示 100% 效能，超载则显示具体计算后的实际效能百分比（如 `85%`）。

## 2. 技术设计方案

### 2.1 建筑加成解析逻辑（独立通用纯函数）
建筑加成源自 `BuildingDefinition.modifiers`（每级基准效果）。
当建筑有效等级为 `level` 时：
- `level <= 0`：尚未建成（Lv.0），当前生效加成数值为 0。
- `level > 0`：各项加成 = `modifier * level`。
各修饰项定义：
- `explorationSpeedRatio`: 历练采集加速比率（百分比）
- `explorationOutputRatio`: 历练采集收益比率（百分比）
- `alchemySpeedRatio`: 炼丹炼器加速比率（百分比）
- `alchemyOutputRatio`: 炼丹炼器收益比率（百分比）
- `cultivationOutputRatio`: 吐纳修炼灵气收益比率（百分比）
- `combatHitpointRegen`: 战斗气血回复（点数/5秒）
- `combatDamageReductionRatio`: 战斗伤害减免比率（百分比）
- `monsterWeakenRatio`: 怪物削弱比率（百分比，上限 90%）

提供加成解析器，输出格式化文本与标签（如 `历练采集收益 +10%`），并支持计算两级之间的加成增量（`before → after (+delta)`）。

### 2.2 列表卡片展示改造
在 `NearbyPanel` 建筑卡片中：
- 提取并直显当前有效等级的具体加成（或在建中预览加成）。
- 保持卡片紧凑、信息层级清晰。

### 2.3 详情弹窗三段式布局
- **第一部分【信息】**：
  - 建筑名称与等级徽章
  - 建筑背景介绍
  - 当前具体加成项展示
- **第二部分【升级】**：
  - 等级跃迁：`Lv.X → Lv.(X+1)`（或在建中的 `Lv.X → Lv.targetLevel`）
  - 加成对比行：采用参考境界突破的修仙风格对比箭头，展示当前加成 → 目标加成（附带 +增量）
  - 若在升级/建造中：展示工期进度条、材料进度条、所需材料明细、提交材料按钮
  - 若已竣工且空闲：提供发起升级按钮
- **第三部分【负载】**：
  - 当前使用人数 / 承载上限（如 `1 / 110 人`）
  - 运转效能指示：未超载显 `100% 效能`（运转良好/绿色），超载显具体效能（如 `85% 效能`，红色/警告色，并可说明超载人数与衰减幅度）
  - 简明规则提示：超过承载上限后效能开始衰减，最低降至 50%
