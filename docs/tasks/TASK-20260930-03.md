## 需求背景

用户确认斗法暂存区「物品小图标 + 名称 + ×数量」的复合胶囊（`ItemReference`）观感良好，要求统一推广：

1. 行动统计/记录账本的「物品得失」小节：由 `ItemTileReference` 背包式图标瓦片改为同款复合胶囊。
2. 怪物掉落预览：由迷你瓦片 + 下方概率小字改为同款胶囊，形如 `兽皮 ×1-3（20%）`——图标 + 名称 + `×数量区间` + 括号内掉落概率。

## 实施方案

- `ItemDisplay.tsx`：`ItemReference` 新增可选 `value` 值区自定义内容（提供时即便无 `amount` 也渲染复合胶囊）；`ItemDropTile` 改名 `ItemDropReference`，薄封装 `ItemReference`（`value` = `×区间` 下划线值 + `（概率）` 内联 dim 小字）；删除失去唯一调用方的 `ItemTileReference`。
- `reportSections.tsx`：`ReportItemsSection` 获得/失去两列改用 `ItemReference`。
- `CombatEcologyPanel.tsx` / `WorldMapPanel.tsx`：跟随改名。
- 样式：`selection-grid.css` 移除失效锚点类 `battle-report-item-anchor` / `world-monster-drop-anchor`；`expedition.css` 删除迷你瓦片收拢样式，`.world-monster-drop-chance` 改为胶囊内联概率小字。
- 文档：`common-components.md` §6/§24/§28 同步。
