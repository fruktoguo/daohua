- 状态：🧪 验证中（tsc/build/契约全过；待 UI 目检）
- 需求：
  1. 顶栏行动队列的展开下拉当前信息显示过多（序号、名称、次数、进行中/资源不足/斗法徽章、行动描述行），浪费空间。
  2. 下拉宽度与顶栏任务区完整宽度一致，观感不佳。
  3. 改为每条仅展示「行动图标 + 行动名称 + 剩余次数」关键信息，保留下移/上移/移除操作按钮；下拉宽度收拢为任务区宽度的 60%。

## 设计与范围

1. `frontend/src/App.tsx` `QueueCenter`：`.queue-entry` 内移除序号列（`.queue-order`）、描述行（`.queue-sub`）与状态徽章（`进行中`/`资源不足`/`斗法`），剥掉 `.queue-main`/`.queue-title` 双层包裹；阻塞态仍由 `.queue-entry.blocked` 红边框表达，首条仍由 `.active` 高亮表达进行中。
2. `frontend/src/styles.css`：
   - `.queue-dropdown` 由 `left:0/right:0` 改为 `right:0 + width:60%`（60% 宽、右缘与队列展开按钮右缘对齐）。
   - `.queue-name` 直接作为条目 flex 子项承担 `flex:1` 省略截断。
   - 清理死样式：`.queue-order`/`.queue-main`/`.queue-title`/`.queue-sub` 及 ≤960px 下 `.queue-sub`、`.queue-entry > .item-glyph` 隐藏覆盖（图标已成为关键信息，不再隐藏）。
3. `frontend/src/i18n/domains/app.zh.ts`：删除仅被下拉徽章使用的死键 `app.queue.running`（`blocked`/`duelBadge` 仍被当前行动卡等处使用，保留）。
