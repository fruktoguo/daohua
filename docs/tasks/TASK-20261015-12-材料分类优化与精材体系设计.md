# TASK-20261015-12 材料分类优化与精材体系设计

## 任务背景与核心需求

修仙世界中，修仙百业的材料来源清晰明确，原有的物品分类将多种来源的材料笼统混称或简单归为「药材」「矿石」「材料」，导致玩家在储物袋、坊市以及图鉴中难以迅速识别材料的产出途径与应用定位。
用户提出明确的材料分类优化需求：
1. **采集获得**：统一称为「**灵材**」（原药材、灵木、甘露等）；
2. **挖矿挖出**：统一称为「**矿石**」；
3. **战斗掉落**：统一称为「**异材**」（原妖兽皮骨、妖丹妖核、古战场残刃等）；
4. **加工产出**：设计命名方案，建立完备的材料四分类体系。

---

## 加工产出命名设计：【精材】（Refined Material）

### 设计分析与依据

在修仙世界观与玩法闭环中，生活制造（炼器精炼、炼丹萃取）产出的材料（百炼铁、赤铜精、桃木晶、灵松晶、草木精华、伴灵精华）具有以下核心本质：
1. **去粗取精、千锤百炼**：
   - 乌铁经地火千锤百炼去除凡浊 $\to$ **百炼铁**；
   - 赤铜经地火淬炼纯正金泽 $\to$ **赤铜精**；
   - 百年老桃木萃取凝结成琥珀灵晶 $\to$ **桃木晶**；
   - 引灵松树芯凝出清风灵髓 $\to$ **灵松晶**；
   - 灵花仙草与朝露经炉火灵泉淬炼药露 $\to$ **草木精华 / 伴灵精华**。
2. **结构对称与修仙对仗**：
   - 采集自然灵气草木之物 $\to$ **灵材**（天地造化）
   - 采掘地底幽深矿脉之石 $\to$ **矿石**（地脉原胚）
   - 斩获妖魔异兽遗珍之骨 $\to$ **异材**（凶煞灵异）
   - 经由修士真火炉鼎淬纯 $\to$ **精材**（百炼精纯）
   四者双字成列、音律洗练、朗朗上口，契合修真者“去伪存真、采灵炼精”的世界观哲学。
3. **游戏交互与心智闭环**：
   - **灵材**：指引玩家前往大世界节点执行【采集】行动；
   - **矿石**：指引玩家前往矿脉节点执行【挖矿】行动；
   - **异材**：指引玩家前往凶地秘境执行【战斗讨伐】；
   - **精材**：指引玩家前往洞府工坊执行【炼器精炼 / 炼丹萃取】；
   - 坊市二级分类由模糊的 `[全部材料, 矿石, 药材, 通用材料]` 进化为专业的 `[全部材料, 灵材, 矿石, 异材, 精材]`。
