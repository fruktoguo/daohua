## 2. 需求与边界

- **诉求**：竖屏底部页签过多（12 个），改为「点击分组后浮现多个子页签」的二次选择结构。
- **用户初拟分组**：内视/坊市/商店/技艺合一；历练＋地图合一；详情独立；同道/图鉴/日志/设置合一；背包独立。
- **评审结论**（详见交付说明）：内视/坊市/商店/技艺合并不成立（四者语义不相干，且技艺自带 5 项第二层会退化成四级）；历练＋地图、市集（坊市＋商店）、详情独立、背包独立成立；「更多」组漏了「记录」，而它此前竖屏需先入详情页再点头部按钮（2 击），纳入后降为 1 击。
- **硬约束**：日志未读与同道邀请角标必须上提，否则二级沉底会让私聊与组队邀请静默；地图子页签仍为页面内二级导航，不下沉到导航子行。

## 4. 实施方案

### 4.1 分组模型（新文件 `frontend/src/mobileNav.ts`）

- `MOBILE_NAV_GROUP_ORDER` 决定 7 个一级分组的展示顺序（内视/坊市/历练/详情/技艺/背包/更多），`MOBILE_NAV_GROUP_DEFS` 为键即标识的真源表。
- `GROUP_OF_TAB` 用 `as const satisfies Record<TabId, MobileNavGroupId>` 双向约束：漏项或多出键都在编译期失败，是竖屏可达性的编译期兜底。
- 组内构成：坊市＝坊市/商店；历练＝历练/地图；更多＝同道/图鉴/日志/记录/设置；技艺组子行为技艺模式切换条。

### 4.2 状态（`uiStore.ts`）

- 新增 `mobileNavMemory: Record<MobileNavGroupId, TabId>` 与 `activateMobileNavGroup`。
- 任何 `setActiveTab`（含代码直跳、引导驱动）都会写入所属分组的落点，切回分组即回到上次所见子项。
- 已在目标分组时重复点击不改签，避免误触把玩家从子页签踢回首项。

### 4.3 渲染（`BottomNav`）

- 子行在上、分组行贴底；子行高度经 `ResizeObserver` 实测反写 `--mobile-nav-offset`，页面底部占位与 `.notice` 避让统一引用该变量（删除硬编码 `72px`）。
- 角标两级呈现：分组图标合计（日志未读＋邀请），子行各自只显示自己那份。
- `CraftingModeTabs` 由页面内移入技艺组子行，样式类统一为 `.bottom-sub-tab-btn`，删除失效的 `.crafting-mode-*` 全套规则。

### 4.4 联动清理

- `Icon` 从 `App.tsx` 抽到 `frontend/src/components/Icon.tsx`，新增 `more`、`records` 图标。
- 详情页头部的 `records-open-mobile` 入口及其样式删除（更多组已覆盖）。
- 桌面端侧边栏保持扁平不变（桌面空间充裕，二次选择只增加点击成本）。

### 4.5 详情页卡片分层与消耗品格子尺寸全域统一

- **背景框重叠修复**：`App.tsx` 将详情页双组消耗品收拢进 `<div className="combat-slot-row combat-slot-row--consumables">`，与功法组 `<section className="... combat-slot-section--abilities">` 在移动端按垂直 flex 列排布，各自具有独立闭合边框卡片（`border: 1px solid var(--gold-faint); border-radius: 4px; background: rgba(201, 180, 109, 0.025);`），中间留有 8px 垂直间距，彻底消除水平分割线贯穿文字与边框交叉遮挡。
- **消耗品格子统一规范**：详情、历练、技艺三处移动端统一引入 `--mobile-consumable-slot-size: 48px`（≤360px 自适应降至 44px），正方形（`aspect-ratio: 1/1`）。
  - 详情页：双组消耗品（药品 3 格 + 通用 3 格 = 6 格）全部规整并列在第一行，标签左侧居中排列无文字遮挡。
  - 历练页：6 个消耗品槽位由原先 73px 不规则拉伸收敛为 48px 标准正方形，居中排列无横向溢出。
  - 技艺页：3 个消耗品槽位由原先 150px 极端拉伸畸变收敛为 48px 标准正方形。

## 6. 实测记录

- 一级分组 7 项；子行按组切换：历练（历练/地图）、市集（坊市/商店）、更多（同道/图鉴/日志/记录/设置）、技艺（炼丹/炼器/符箓/阵法/强化，含等级）。
- 375px：分组项 54×58px，子行项 72×46px，无横向溢出；320px：分组 46px、子行 61px，无溢出。
- 占位联动：有子行 navH=114px→`--mobile-nav-offset:114px`→`.app-body` padding-bottom=124px；无子行 navH=59px→69px。
- 记忆：历练组切到地图→去市集→回历练，仍落在地图。
- 角标：注入 1 条世界频道未读后，「更多」分组显示 1，「日志」子项显示 1。
- 引导锚点：`[data-tour="nav-map"]` 同时命中桌面侧栏（隐藏）与底部地图子项（可见），`findVisibleTarget` 取可见项。
- 桌面 1440px：`.bottom-nav` display:none，侧边栏 11 项不变，`--mobile-nav-offset:0px`。
