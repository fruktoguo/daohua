## 1. 核心需求与目标

1. **改为独立大尺寸弹窗界面（`HelpModal`）**：原嵌入三栏中间 `<main>` 的 `HelpPage` 空间过窄难以阅读，改用全局 `Modal`（桌面端 `min(1040px, 视口)` × `min(760px, 视口)`，竖屏近全屏覆盖），点击左侧「其他 → 帮助」、竖屏「更多 → 帮助」或引导结束提示的「前往帮助」均直接唤起独立弹窗，不替换底层主界面。
2. **右侧具体教程独立滚动，禁止整页连带滚动**：弹窗壳 `.help-modal.modal-shell` 与内部结构锁定视口高度且 `overflow: hidden`，顶栏与目录固定，仅右侧正文 `.help-content` 启用 `overflow-y: auto` 独立滚动，切换章节或修改搜索关键词时自动滚动归零。
3. **竖屏章节 Tab 置顶（`<= 960px`）**：竖屏断点下 `.help-layout` 切换为纵向弹性排布，左侧章节目录 `.help-sidebar` 收拢为顶部单行横向可滚动胶囊切换条，下方 `.help-content` 占满剩余空间独立滚动。
4. **大幅提升整体信息密度**：
   - 顶栏紧凑单行排布（标题 + 篇数胶囊 + 内联悬浮提示 + 搜索框 + 关闭避让安全距）；
   - 右栏移除占用空间的重复章节大横幅，改为单行轻量章节眉批；
   - 将 14 节冗长自然段重构为简洁短句分点列表（`.help-bullet-list`）+ 紧凑单行「要诀提醒」贴士条。
5. **修正前期讨伐补给品误写**：核查 `config/game-data/items/pills.json` 后，「引气丹（`item.qi-gathering-pill`）」仅用于探索修炼加速；1 级战斗回血药散在配表中的精确名称为「止血散（`item.zhixue-powder`）」，将卷一第 2 节 `earlyRoute` 中的误引用修正为 `{{item:item.zhixue-powder|止血散}}`。
