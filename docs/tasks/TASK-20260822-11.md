## 2. 需求背景与核心目标

### 2.1 需求背景
根据《道化太初》开发规则 [AGENTS.md](../../AGENTS.md)，开发阶段提倡多 Agent 并行开发以最大化研发吞吐与上下文隔离。Antigravity CLI (`agy`) 支持在项目工作区 `.agents/agents/{agent_name}/agent.md` 路径下定义专职 Agent 角色。

### 2.2 核心目标
在 `.agents/agents/` 下构建符合项目架构规范与设计哲学的 5 大专职 Agent：
1. **`domain-dev`**：领域模型与 ECS 架构专家（src/Domain 纯度、确定性、double 精度、测试覆盖）。
2. **`frontend-dev`**：React 19 前端与交互专家（公共组件收拢、TypeScript 严格检查、同源通信）。
3. **`data-balancer`**：数值策划与平衡专家（定量预算论、属性权重、技能/装备/怪物平衡）。
4. **`qa-tester`**：测试与门禁保障专家（领域单测、LoadTests 压测、5000 账号容量门禁）。
5. **`ops-architect`**：容器与运维部署专家（Docker 多阶段构建、非 root 安全、PostgreSQL CAS 账本与备份）。
