## 1. 需求背景与核心目标

当前开天门（叩天门 Lv.18 满修为后触发）产生的五行灵根仅提供：
1. 对应五行属性法术的增伤（Linear 1:1，100 点 = 100%）；
2. 对应五行属性法术的减伤（NonLinear 1:1，100 点 = 承伤减半）；
3. 影响升级所需修为乘区（1 条灵根 1.0x，每多一条 +0.5x，五系 3.0x 封顶）。

**存在痛点**：
- 维度单一：仅在面对具有对应五行属性的技能或怪物时起效；若打物理招式或无五行怪物，灵根几乎零感知；
- 玩法割裂：非战斗场景（大世界历练、修仙七大百艺生活技能）中灵根完全隐形，缺乏修仙小说中“火灵根天生适合炼丹炼器”、“木灵根天生与灵草树木通灵”的修真沉浸感；
- 目标单一：灵根只沦为数值面板上的五行抗性与增伤开关，缺少与暴击、化解、破招、攻速、回灵等丰富战斗流派的深度化学反应。

**设计目标**：
将五行灵根从单一的“五行伤害增减”，升级为包含**【元素法威与护体】、【战斗专精特化】、【百艺洞天加成】**的三维立体增幅体系。

## 2. 五行多维度增幅设计案（初稿）

### 2.1 三大通用维度框架

每系灵根（点数范围 $0 \sim 100$）均统一映射三大维度：

```
五行灵根 (0 ~ 100 点)
 ├── 1. 元素法威与护体：对应五行法伤增幅 (0~25%) + 对应五行减伤 (0~25%)
 ├── 2. 战斗专精特化：按五行特质划分的大幅攻防属性与机制特化
 └── 3. 百艺洞天加成：与游戏内生活技艺及大世界历练深度联动
```

## 3. 数值机制与计算公式

### 3.1 属性映射公式
1. **常规属性与百分比增幅**：按灵根点数 $P \in [0, 100]$ 纯线性折算：
   $$\text{Bonus}(P) = \text{Bonus}_{\max} \times \frac{P}{100}$$
   （如 100 点火灵根 +50% 暴击、50 点火灵根 +25% 暴击）。
2. **五行增减伤害收敛**：
   - 增伤：$\text{ElemDmgBonus} = 25\% \times \frac{P}{100}$
   - 减伤：$\text{ElemDmgReduction} = 25\% \times \frac{P}{100}$
3. **土灵根固定减伤分段公式**：
   $$\text{FlatDamageReduction}(P_{\text{earth}}) = \begin{cases} 0, & P_{\text{earth}} = 0 \\ 1.0 + P_{\text{earth}} \times 0.09, & P_{\text{earth}} \in [1, 100] \end{cases}$$
   - $P=1$ 点时：立即提供保底 $1.0 + 0.09 = 1.09$ 点固定减伤（微末土灵根即刻见效）；
   - $P=100$ 满点时：精确达到 $1.0 + 9.0 = 10.0$ 点固定减伤。
4. **水灵根波间寻怪速度与多人平均算法**：
   - 个人寻怪速度属性：$\text{SearchSpeed}(P_{\text{water}}) = 20\% \times \frac{P_{\text{water}}}{100}$；
   - 战斗推进会话中：单人模式直接使用个人寻怪速度；多人组队模式下，推演共享寻怪速度取全体在场成员寻怪速度属性的**算术平均值**：
     $$\text{TeamSearchSpeed} = \frac{1}{M}\sum_{i=1}^M \text{SearchSpeed}_i$$
     （彻底替代原先「全队取最大值」规则，让队伍中水灵根修士的寻怪增益平滑普惠全队，且防止单人强行拉高整体）。

### 3.2 灵根流派对决：天灵根 vs 混元灵根
- **单系天灵根（如纯金 100 点，其余 0 点）**：
  - 修为突破乘区仅 1.0x（最速升级，一日千里）；
  - 极致特化：+50% 攻击力、+50% 破招、+50% 命中、+25% 强化速度，纯粹杀伐第一；
- **混元五行灵根（五系皆 100 点，总计 500 点）**：
  - 修为突破乘区 3.0x（升级最慢，需 3 倍苦修）；
  - 全能真仙：+50% 暴击、+25% 暴伤、+50% 双攻、+50% 双防、+50% 气血、+50% 灵力、+50% 化解、+50% 破招、+50% 命中、+50% 免爆、+100% 回复、10 点固定减免；四大生活百艺全加速 25%，寻怪加速 20%，成为无死角混元老祖。
