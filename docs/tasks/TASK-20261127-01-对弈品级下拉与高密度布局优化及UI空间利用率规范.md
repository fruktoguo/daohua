## 2. 核心需求与设计目标

1. **对弈八阶品级选择改为下拉框**：
   - 移除原先在顶部 4×2（竖屏 2×4）平铺占屏的 8 张 `.ddz-tier-card` 卡片网格；
   - 收拢为基于 `FloatingPopover` Portal 的紧凑品级下拉选择器（`.ddz-tier-select`），与标题、玩法按钮并排于同一顶栏；
   - 触发器内单行呈现当前选中阶位（凡~帝八品品质色）、灵石小图标 + 底注紧凑数值、当前阶排队人数；当其他阶位存在排队玩家时，触发器旁展示轻量全阶排队提示，无需展开即可感知；
   - 展开下拉列表单行紧凑呈现全部 8 阶：品级名（品质色）、底注（灵石图标 + 紧凑数值）、实时匹配人数胶囊（有人排队或本人匹配中高亮），余额不足阶位轻量置灰标识。
2. **底部指标与操作区高密度收拢（图标 + 极简文本 + 紧凑数值）**：
   - 移除原先 3 张大号独立边框卡片 `.ddz-match-metric` 以及重复 3 次的 `ItemReference`「灵石 × ...」完整胶囊；
   - 改为单行流式高密度微型指标芯片（`.ddz-stat-pill`）：`底注`、`验资`、`可用`，每项仅由 **极简短标签 + `ItemIcon`（显式透传 `itemId="currency.spirit-stone"`）+ `UnitNumber` 紧凑数值** 构成；
   - 十倍底注开局托管说明收进「验资」条目的 `FloatingTooltip` 悬停提示与右上角「玩法」弹窗，移除占用整行的底部长说明文本；
   - 指标条与右侧操作按钮（开始匹配 / 改配此阶 / 取消匹配）同行紧凑合流（竖屏窄视口自适应折行且不浪费纵向高度），消除选中当前匹配阶时的双重「取消匹配」按钮。
3. **沉淀全局 UI「高布局空间利用率 + 横竖屏兼顾」永久规范**：
   - 将高布局空间利用率（多档位优先下拉、微型「图标+短标签+数值」指标项、长说明收进 Tooltip/弹窗、操作与指标合流）与横竖屏双端同步设计写入 `docs/design/总纲/13-前端UI设计系统与修仙交互规范.md`、`frontend/AGENTS.md`、根 `AGENTS.md` 与 `docs/frontend/common-components.md`。
