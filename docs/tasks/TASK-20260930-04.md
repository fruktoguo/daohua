## 需求背景

战斗中点击敌方头像弹出的角色详细信息模态窗（`CharacterAttributeModal`），当前为三个属性分组 Tab（基础/特殊/伤害增减）。用户要求新增第四个 Tab 展示该敌怪的详细掉落信息，复用 TASK-20260930-03 落地的掉落复合胶囊（图标 + 名称 + `×数量区间` + `（概率）`）。

## 实施方案

- `ids.ts` 新增 `findCombatantInCatalog(encounters, maps, enemyId)`：按遭遇主敌 → 刷怪池 → Boss 列表 → 各节点普通/精英/首领生态的顺序查找 `CombatantDefinition`（仅供掉落等静态配表查询；实战数值仍只走 wire 快照）。
- `CombatAttributePanel` 新增可选 `drops` 属性：提供时渲染第四个「掉落」Tab，内容为 `ItemDropReference` 胶囊列表（复用 `.world-monster-drops-row`），空列表展示「没有掉落物」空态；未提供时维持原三 Tab（内视面板、玩家、斗法镜像不受影响）。
- `CharacterAttributeModal` 透传 `drops`；`CombatArena` 按被查看敌怪的 `enemyId` 从静态目录解析 `CombatantDefinition.drops` 传入。
- i18n 新增 `insight.combat.groupDrops`、`insight.combat.dropsEmpty`；`common-components.md` §25 同步。
