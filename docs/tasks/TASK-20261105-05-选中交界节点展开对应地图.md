# TASK-20261105-05-选中交界节点展开对应地图

## 任务背景与核心需求

当前大地图系统中，多个区域（如玄元门、青州等）已共用统一世界坐标系并支持跨区域寻路。但在界面可见性判定逻辑中，只有当玩家角色的物理驻留位置（`world.nodeId`）或当前赶路边（`world.edgeId`）处于跨区域交界节点（拥有通往其他区域的跨域边）时，对侧地图才会被纳入 `visibleMapIds` 并渲染。

如果玩家身处区域内部的普通节点，即便地图上已渲染出带有界门菱标的交界节点，玩家点击选中该交界节点时，对侧地图依然处于收起不可见状态，导致玩家必须消耗时间将角色实体移动至交界节点后才能查看邻接地图的节点布局、资源分布与栖息生灵。

本任务优化目标：
- 当玩家在地图面板中点击选中交界节点（持有跨区域边的关口节点）时，该节点所连接的邻接区域立即展开渲染；
- 其展开表现效果（包括对侧地图节点、跨域连线、区域虚线界框、区域名牌标识以及视口镜头适配包围盒）与玩家实体移动驻留在该交界节点完全一致；
- 展开后允许玩家直接点击查看对侧地图中的节点详情、产出与妖兽，并可直接发起跨区域路线规划；点击回本区域内部普通节点时平滑收起对侧区域。

## 核心实现方案与技术细节

### 1. 区域可见集合 `visibleMapIds` 扩展
在 `frontend/src/components/WorldMapPanel.tsx` 中：
- 保留玩家当前实体位置（`world.nodeId`、`world.edgeId`、`world.mapId`）的权威可见性计算；
- 引入当前选中节点（`selectedNodeId`）的交互探索可见性：
  - 若 `selectedNodeId` 存在，将其自身所在区域纳入可见集合；
  - 若 `selectedNodeId` 存在通向其他区域的跨域边（即属于交界关口节点），将直达的邻接区域全部加入 `visibleMapIds`；
- 依赖项追加 `selectedNodeId`，确保点击关口节点瞬间触发 `visibleKey` 变更。

### 2. 视口自适应锚框 `fitToAnchorRegion` 对齐
当玩家实体移动至交界节点时，视口锚框包含「当前区域全部节点 ∪ 该交界节点的全部相邻节点（含对侧关口节点）」，从而将本区域全貌与对侧门面以最舒展的比例纳入镜头。
- 在 `fitToAnchorRegion` 中：若 `selectedNodeId` 为交界节点且与 `world.nodeId` 不同，同样将其相邻节点（包含跨域对侧关口节点）纳入包围盒计算 `includeNeighbors(selectedNodeId)`；
- 当选中交界节点触发 `visibleKey` 变动时，视口自适应平滑更新，视觉效果与物理移动到交界节点完全一致。

### 3. 选中节点交互状态闭环
- 当对侧区域展开后，对侧区域的所有常规节点及通过神识判定的隐藏节点正常渲染；
- 玩家点击对侧区域中的任一节点时，由于 `selectedNodeId` 处于该对侧区域，`selectedNodeId` 所在区域持续保持在 `visibleMapIds` 中，避免对侧地图发生意外闪退收起；
- 当玩家点回本区域非关口普通节点时，`selectedNodeId` 不再连接对侧，对侧区域自然收起，视口恢复为单区域包围盒。
