## 需求背景与目标
1. **境界驱动的大地图移动速度成长**：
   - 每个中境界阶段晋升提升 `+5%` 大地图移动速度，每个大境界突破提升 `+30%` 大地图移动速度；
   - 采用**线性加算**且**大境界入口仅计 `+30%`（不重复计中境界）**，与根基（`GenjiRules`）、装备固定回血（`EquipmentHpRegenMultiplier`）保持统一境界节点口径：
     - 凡俗段（Lv.1~18）：`武(Lv.1~6)` 0 次中境界（`1.00×`）、`玄(Lv.7~12)` 1 次（`1.05×`）、`天(Lv.13~18)` 2 次（`1.10×`）；
     - 修真段（Lv.19~126 每 12 层一大境界，Lv.127 飞升封顶）：跨入大境界入口（第 1 层 `初` 及 `Lv.127 飞升`）计 1 次大境界突破（`+30%`）；大境界内跨入第 4/7/10 层（`中/后/极`）各计 1 次中境界晋升（`+5%`）；
     - 整数点数公式：`bonusPoints = midBreaks × 5 + majorBreaks × 30`，`speedMultiplier = (100 + bonusPoints) / 100`；飞升满级（29 次中境界 + 10 次大境界）达 `+445%`（`5.45×`）。
   - 实际通行耗时 `duration = baseDuration / speedMultiplier`，在路径规划生成 `TravelPlan` / `TravelActionState` 时一次性折算 `TotalTravelSeconds` 与各段 `TravelSegment.DurationSeconds`（总耗时严格等于折算后各段之和，消除浮点尾差；最短路径拓扑不变，`WorldGraph.Plan` 缓存 O(1) 复用；零持久化 Schema 变更）。
2. **后续新图间距拉长规约**：
   - 既有四图（青云仙山、青云古道、星陨异境、雾梦泽）配表暂保持不变；
   - 在设计总纲第八篇明确记录：自五图（筑基期及更高阶区域）起，新建区域按对应推荐境界的移速基准成比例拉长图内边基础耗时与跨区域关口边耗时（及可选节点空间间距）。
3. **前端大地图展示范围**：
   - 仅在大地图面板（工具栏移速徽章 + 悬浮构成说明）与大地图启程确认弹窗（折算后预估耗时、原耗时对比与当前移速倍率）呈现，不改动境界徽章或突破确认弹窗。
