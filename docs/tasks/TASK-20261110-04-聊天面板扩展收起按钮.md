# TASK-20261110-04 聊天面板右下角扩展/收起按钮

## 一、需求来源与理解

- **提出时间**：2026-11-10 03:06:26
- **用户原始需求**：优化，给聊天框的右下角增加一个扩展的符号按钮，点击后上面会展开覆盖掉中间主要显示内容，要有流畅的过渡动画。
- **需求复述（核心理解）**：
  1. 在桌面端底部传音/日志面板（`.log-panel`）的**顶部标题栏最右侧**新增一个「扩展」符号按钮（采用向外扩展的双箭头符号，展开态切换为向内收拢）；
  2. 点击后该面板向上长开，占满整个中列，把中间主内容区（`.main-content`）完全覆盖/挤出；
  3. 展开与收起两个方向都必须是连续的过渡动画，不能瞬跳；
  4. 按钮同时承担收起（还原）职责，图标随状态切换，需支撑 8 个分组 Tab 全部可用（系统/战斗 Tab 无输入区，不能只挂在输入框里）。
- **边界**：只涉及前端聊天天面板布局与样式，不改动协议、服务端、消息数据结构；移动端（≤960px）底部日志本身就是全屏 Tab，扩展无意义，按钮隐藏。

## 二、现状与设计决策

| 现状 | 决策 |
| --- | --- |
| `.center-column` 为 flex 列：`main-content`（flex:1）+ `desktop-log`（由 `.log-panel` 高度 `clamp(160px,27vh,280px)` 撑开） | 展开时 `.desktop-log` 的 `flex-grow` 0→1、`flex-basis` `clamp(...)`→`0`，主内容 `flex-grow` 1→0；三者均为可插值属性，天然平滑 |
| `.log-panel` 高度写死 clamp，无处填充 | 改为 `.desktop-log .log-panel { height: 100% }`，尺寸单一真源搬到 `.desktop-log` |
| 8 个 Tab 各自渲染，输入框只在部分频道存在 | 扩展按钮挂在 `GameLogPanel` 层的标题栏（`.log-head`），独立于 `role="tablist"` 外，不侵入 `ChatComposer` |
| 移动端 `.mobile-tab.log-panel` 已全屏 | 移动端媒体查询内隐藏按钮，同时 `expandable={false}` |

**按钮落点**：标题栏（`.log-head`）最右侧，`flex-shrink: 0` 固定贴右；Tab 行 `.log-tabs` 设 `flex: 1; min-width: 0` 自行横向滚动，因此 Tab 超宽时按钮不被挤走、也不被滚出视口。

**符号**：常态「向外扩展」双箭头、展开态「向内收拢」双箭头，两套 SVG 直接切换（不依赖旋转，语义与方向都直观）。

**动画参数**：`cubic-bezier(0.22, 1, 0.36, 1)`，320ms；折叠态与展开态对称。

**无障碍**：`aria-expanded`、`aria-label` 随状态切换（`combat.chat.expandPanel` / `combat.chat.collapsePanel`），图标 `transform: rotate` 过渡。
