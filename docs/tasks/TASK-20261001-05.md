用户裁定术语体系：境界展示固定为「大境界 → 境界阶段 → 小境界」三层；数值内容轴游戏内称「等阶」（等阶1~12），「T级/T{N}」为同轴编号写法；怪物档位称「生命层次」（妖兽/精英/妖王）；物品品质八档为「帝圣灵天地玄黄凡」。全部文档与前端展示按此统一。

### 废除/限用词

- 「阶位」「位阶」：从正文中退役——原指 T1~T12 处改「等阶（T级）」，原指武玄天初中后极处改「境界阶段」，原指怪物档位处改「生命层次」。
- 「品阶」：退役——指物品内容档处改「等阶/T级」，指怪物档位处改「生命层次」，指稀有度处改「品质」。
- 「等阶」保留但**专指 T1~T12 数值轴**（等阶1~12 = T1~T12）；原误用于境界等级的「修为等阶/总等阶」改「境界/总等级」。
- 「四阶段/凡俗阶段」：改「修行期/四期」，避免与「境界阶段」撞「阶段」。
- 「第N阶 / N阶 / 12阶」：指 T1~T12 数值轴处改「等阶N / T{N}」。
- 怪物档名「普通妖修/精英大妖/妖王魔尊」：统一为「妖兽/精英/妖王」。
- 品质旧名「灵品Q2/仙品Q6/神品Q7/混沌Q8」：按 Q1~Q8=凡黄玄地灵圣帝 改写（前端 `game.grade` 已是新名，`rarityLabel` 的 X 品形式同步）。
