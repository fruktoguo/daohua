## 1. 需求与裁定口径

1. **12 张全服排行榜专属图标（体系 C：纯白二值镂空图腾）**：
   - 基于本地 ComfyUI MOSS-Image（`/moss-art` 范式 4：纯黑实底 + 纯白硬二值镂空剪影）生成全部 12 榜图标：
     - 5 主榜：`realm`（境界）、`valuation`（身家）、`spirit-stone`（灵石）、`zongmen`（宗门）、`duel`（斗法）
     - 7 技艺子榜：`technique.alchemy`（炼丹）、`technique.forging`（炼器）、`technique.talisman`（制符）、`technique.enhancement`（强化）、`technique.formation`（阵法）、`technique.gathering`（采集）、`technique.mining`（挖矿）
   - 资产落盘：128×128 无损纯白二值 RGBA WebP 母模归档于 `art/glyphs/lb.<boardId>.webp`；64×64 无损纯白二值 RGBA WebP 运行时资产落盘于 `frontend/src/assets/glyphs/lb.<boardId>.webp`，前端采用 CSS `mask-image` 动态单色染色（与 `StatGlyph` 同体系，自适应名次色与深浅双主题）。
2. **聊天频道最高排名徽标**：
   - 玩家在任意传音频道（世界 / 附近 / 宗门 / 队伍 / 好友及综合视图聊天行）发言时，角色道号前展示 `[榜单图腾 #N]` 紧凑徽章：
     - 排版顺序：`[时间] [境界] [宗门] [图标 #N] 道号：`
     - Top 1 / Top 2 / Top 3 对应金 / 银 / 铜微光胶囊，Top 4~50 对应温润道金胶囊，均适配深浅双主题。
     - Hover `FloatingTooltip` 展示完整榜名与名次（如「境界榜 第 1 名」「炼丹榜 第 3 名」）。
   - **取榜规则**：
     - 范围：仅统计 **11 个个人榜**（排除 `zongmen` 宗门榜），仅 **Top 50**（`1 <= rank <= 50`）公开上榜者展示，未进前 50 不显示。
     - 最优裁决：取所有命中个人榜中 `rank` 最小者；同 `rank` 并列时按 **`境界 > 斗法 > 身家 > 灵石 > 七技艺（炼丹/炼器/制符/强化/阵法/采集/挖矿）`** 优先。
   - **架构边界（零 DB Schema 变动）**：
     - 遵循总纲 §26.1「排行榜为只读派生模型」红线，不改 `social.chat_messages` 表结构；
     - `ChatMessageDto` 增可选派生字段 `SenderTopRank`（复用 `GuideRankBadgeDto`）；
     - `ChatRuntime` 在 `SendAsync`、`SendPartyShareAsync` 与 `LoadHistoryAsync` 出口直接调用 `LeaderboardRuntime` 内存快照 O(1) 实时查询（历史消息批量按去重 `senderId` 一次解析）。
3. **前端复用**：
   - 抽出公共组件 `LeaderboardGlyph`（纯图标）与 `LeaderboardRankBadge`（图标 + `#N` 胶囊 + 悬浮说明），统一接入 `LeaderboardPage`（大类 Tab + 7 技艺子榜）、`LogFeed.tsx`（`ChatRow` 头部）与 `GuidePage`（作者上榜头衔）。
