## 需求分析

- **记录主体**：行动实例（actionInstanceId）内的全部战斗单位——本机玩家 `player`、组队盟友 `ally:{i}`、怪物按 `monster:{definitionId}` 聚合同类。斗法段只记本机视角单位，不记对方玩家。
- **指标口径（已确认）**：
  - 伤害（造成）、受到伤害（实收）、减免伤害三项全部按物理/术法分列。
  - 减免伤害 = 命中时原始威力（`CombatHitContext.RawDamage`，减免链前）− 实际落账伤害；未命中不计。
  - 治疗分「自动回复」与「其他治疗」：自动回复 = 战内 5 秒 tick + 行动期间战外自然回复；其他治疗 = 技能治疗、气血汲取、药品瞬回。
  - 倒地复活满血不计入治疗（复活语义非治疗）。
- **生命周期（已确认）**：随行动实例持续累计（跨波次、跨搜寻相位不断账），行动出队时统计丢弃——归档战报不保留战斗单位数据。
- **归属**：挂在行动实例账本 `PlayerBattleReport` 上（既有「行动实例账本」生命周期一致：准入建账、出队归档）。
- **前端（已确认）**：本次连同展示一起做——详情页统计面板新增战斗单位数据表。

## 技术方案

### 领域层（src/Domain）

1. 新增 `src/Domain/Combat/CombatUnitStats.cs`：
   - `CombatStatUnitKind`（Self/Ally/Monster 字节枚举，wire/落库为数字）。
   - `CombatUnitStatEntry`（可变累计行：UnitKey/Kind/DisplayName + Dealt/Taken/Mitigated 各分物理·术法 + HealingRegen/HealingOther）。
   - `CombatUnitStatDocument`（可持久化文档形态，随报表文档落库与下发）。
   - `CombatUnitStatsBook`：有序列表 + 键索引；`KeyOf(CombatantState)` 单位键映射（enemy:{i} → monster:{DefinitionId}）；`Register`/`RecordHit`/`RecordHealing`/`MergeSelf`；`Dirty`/`ClearDirty` 供导出失效检测。
2. `CombatEncounterState` 新增 `internal CombatUnitStatsBook? StatsBook`（运行时挂接，不进快照，与 `TriggerSink` 同模式）。
3. `PlayerBattleReport` 新增 `CombatStats` 簿（恒非空）；`ResetBucket` 清空；`HasContent` 不计战斗统计（即弃语义：战斗统计不构成归档理由）。
4. `ActionReportBook.ArchiveActionReport` 归档前清空 `CombatStats`（行动结束即弃）。
5. `PlayerBattleReportDocument` 新增 `Combatants` 可缺省字段；`PlayerDuelStateCodec` 导出/恢复同步；`IsValidReportDocument` 增补校验。
6. `IPlayerResourceContext` 新增 `DisplayName`（PlayerAggregate 现有属性天然满足；EcsPlayerActionContext 补实现）。
7. `DuelScript` 新增 `InitiatorStats`/`DefenderStats`（推演时经内部挂接簿产出）；`DuelPlaybackState` 新增 `ViewerStats`（可缺省持久化字段）；`ForViewer` 按视角取本方统计；`AttachDuel` 把本方统计并入队首行动账本 `player` 行（对方玩家数据不落账）。

### ECS/引擎层（src/Ecs）

记录点（战内统一走 `encounter.StatsBook?.`，未挂接即零成本旁路）：

| 位置 | 记账 |
| :--- | :--- |
| `CombatActSystem.ResolveAttack` | 攻方 dealt[kind]+=Damage；守方 taken[kind]+=Damage、mitigated[kind]+=（命中 ? RawDamage−Damage : 0） |
| `CombatActSystem.CastSkill.ApplyHeal` | 施放方 healingOther+=实际治疗量（输出口径） |
| `CombatBuffTickSystem.Tick` | 单位 healingRegen+=钳后实际回血增量 |
| `CombatTriggerMath.HpDrain` | 攻方 healingOther+=healing |
| `CombatTriggerMath.DamageReflect` | 反弹方 dealt[kind]+=reflected；攻方 taken[kind]+=reflected（无减免） |
| 雷击符（`ActivateInstantConsumables`） | player dealt[spell]+=damage；目标怪 taken/mitigated[spell] += damage / 原始威力−damage |
| 战外自然回复（`CompleteResourceRegeneration`） | 队首有远征时：player/盟友 healingRegen+=钳后增量 |
| 药品瞬回（同函数即时消耗品分支） | 队首有远征时：player healingOther+=钳后增量 |
| 倒地复活满血 | 不计入（复活非治疗） |

挂接点：`PrepareCombatEntry`（每波开战）、`RestoreCombatBattle`（快照恢复）、`EcsWorldShard.CreateEncounterCore`（手动钉死）。挂接时预注册 player/ally:{i}/monster:{defId} 及展示名。

标脏：`ActionReportBook.FlushCombatStats(player, actionId)`——簿 Dirty 时 `MarkExportDirty` + `MarkDirty(Duel)`；收口于 `CompleteCombatAdvanceCore`、战外回复、消耗品两路径。
