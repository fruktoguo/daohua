### 核心诉求
1. **免罚门槛放宽（取大）**：成员境界低于队内最高 20%（`level × 0.2`）与低于 12 级以内，取更高/更宽容的一方免罚，彻底消除前期低境界玩家组队时因级数低而被重罚 90% 的离谱体验；
2. **超额平滑惩罚**：超出免罚差距后每超 1% 罚 3%（`malus = min(0.9, 3 × (gap - exemptGap) / level)`），封顶 90%；
3. **协议与状态透传**：`PartyMemberDto` 补充 `realmLevel` 与 `levelMalus` 字段，服务端权威下发；
4. **前端卡片角标与提示**：队伍界面的角色卡片右上角增加惩罚角标（如 `-90%` 或类似标识），hover 展示受到等级惩罚的具体说明文案。

## 2. 详细设计与实现方案

### 2.1 领域层等级惩罚公式重构
在 `ActionParticipation.cs`：
- `gap = highest - level`
- `exemptGap = Math.Max(level * 0.2, 12.0)`
- 若 `gap <= exemptGap` 则 `return 0`；
- 否则 `return Math.Min(0.9, 3 * ((gap - exemptGap) / level))`。

### 2.2 协议层与映射
- `PartyMemberDto` 扩展 `int RealmLevel = 1, double LevelMalus = 0`；
- `SocialRuntime.cs` 在构造 `PartyMemberDto` 时，结合当前活跃会话（或各成员当前境界）计算 `LevelMalus` 并透传。

### 2.3 前端卡片与角标
- `protocol.ts` 与 `socialStore.ts` 对齐 `PartyMemberDto`；
- `SocialPage.tsx` 在 `party-slot-card` 右上角渲染角标；
- `social.zh.ts` 与 `template.csv` 添加 i18n 词条。
