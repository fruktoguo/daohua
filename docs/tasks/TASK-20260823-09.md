## 2. 需求背景与核心目标

### 背景与现状分析
当前游戏内物品定义较为零散，部分物品属于早期 DEMO 遗留（如简单的灵草、云糖、兽核），缺乏统一完整的修仙世界观分类分阶（T1~T12）、清晰的产销回路（采集 -> 炼制 -> 消耗/穿戴 -> 挑战更高阶）以及与数值预算量化体系（`DataBudgetResolver`）的严格对齐。

### 核心目标
1. **建立全局物品分类分阶框架 (T1~T12)**：
   - 涵盖四大核心大类：基础材料 (Material)、消耗品 (Consumable)、装备 (Equipment)、特殊/资产 (Currency / Resource / Manual / Chest)。
2. **装备数据模型与预算系统重构**：
   - **分两大部分**：基础 14 属性百分比加成区间 (`BaseStatRatios`) + 额外全属性固定值与特殊机制区间 (`FlatAndSpecialStats`)。
   - **放弃黑盒反推，改用正向预算审计**：属性显式直接配置，预算系统退居为设计校验工具，根据填写的具体加成正向核算装备预算，自动标出脱离预算的装备。
3. **打通闭环产销回路**：
   - 采集/历练产出 -> 炼丹/炼器消耗 -> 持续/瞬发消耗品与装备赋能 -> 挑战更高地图。
4. **与用户协同分步重写设计并落盘配置**。
