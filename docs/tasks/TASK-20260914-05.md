## 1. 现象

生活行动（如「收集 晨露」，本轮 6 秒、剩余 8 轮）执行中：

- 角色立绘下方的行动条倒计时显示「收集 晨露 **50.0s**」；
- 右侧行动卡片显示「本轮进度 **1.7s / 6s (28%)**」，且行动条填充只有约 **10%**。

同一轮行动的剩余时间与进度互相对不上，且倒计时数值随页面停留时长持续增长、永不回正。

---

## 2. 根因

行动倒计时与行动条填充都以「服务端权威时刻 + 本地单调流逝」推算：

```ts
const estimatedClockSkew = serverTimeUnixMilliseconds - clientDateNowAtSync
const estimatedServerNow = Date.now() + estimatedClockSkew
remaining = action.completesAtUnixMilliseconds - estimatedServerNow
```

而 `serverTimeUnixMilliseconds` 只在**全量快照**时才刷新：

1. `PlayerSnapshotDeltaDto` **不携带** `LastSimulatedAt`，增量帧里没有任何权威时刻；
2. 前端 `decodePlayerSnapshotDeltaDto` 因此显式沿用上一次全量快照的旧值：
   `serverTimeUnixSeconds: current.serverTimeUnixSeconds`；
3. `applyPatch` 却每次都把 `lastSyncPerformanceTime` 更新为当前时刻。

于是 `clientDateNowAtSync`（≈ 当前墙钟）与 `serverTimeUnixMilliseconds`（停留在最后一次全量快照）
之差以 **-1 秒/秒** 线性累积。页面自上次全量快照起停留 45.7 秒后，本轮真实剩余 4.3 秒被显示成 **50.0 秒**。

同一根因还让行动条填充每秒被判定为「进入新周期」而重置回 0，使已进行 28% 的轮次只画出约 10% 填充。

（战斗内动作的 `playerAction` 由服务端直接下发、不带 `completesAtUnixMilliseconds`，走的是相对倒计时分支，
因此本缺陷只影响生活行动与赶路。）

---

## 3. 修复内容

### 3.1 协议层补齐权威时刻（根因）

- `PlayerSnapshotDeltaDto` 新增 `LastSimulatedAt`（`src/Protocol/Contracts.cs`）；
- `ProtocolSnapshotMapper.ToDelta` 与 `WebSocketRuntime.BuildDelta` 随每个增量帧下发该字段；
- 顺带清理 `ProtocolSnapshotMapper` 中仅被测试引用、且与新签名产生重载歧义的「兼容旧调用签名」重载
  （符合项目「本地开发不保留历史兼容层」约束）。

### 3.2 前端刷新时钟锚点

- `frontend/src/network/protocol.ts`：增量 DTO 补 `lastSimulatedAt?`；
- `frontend/src/network/snapshot.ts`：增量解码改为按 `lastSimulatedAt` 重建
  `serverTimeUnixSeconds` / `serverTimeUnixMilliseconds`；字段缺失时沿用旧锚点
  （语义等同「本次没有可信的新锚点」），不中断解码、不产生连不上后端的死循环。

### 3.3 补齐「本轮剩余时长」不变量

- `ActionCountdownBadge` 的每帧重算补上 `Math.min(duration, …)` 上界：
  本轮剩余时间不可能超过本轮时长，越界即说明估算时钟不可信（首帧初值此前已有该上界，逐帧重算漏掉了）。

### 3.4 对齐两处进度采样基准

- `CombatArena` 构造 `playerAction` 时改用队列专属锚点
  `lastQueueSyncPerformanceTime ?? lastSyncPerformanceTime`，与右侧卡片刻度所用的
  `useSmoothProgressRef` 完全一致，消除「非队列补丁」（入灵气、掉落、日志等）造成的 0~1 秒显示差。

## 4. 影响面

- 角色行动条倒计时与行动条填充；
- 顶部 Buff 栏与战场 Buff 方块的「剩余时间」提示（同源时钟，此前同样被高估）；
- 战斗内施法/攻击动作特效的排程时刻（依赖 `completesAtUnixMilliseconds`）。
