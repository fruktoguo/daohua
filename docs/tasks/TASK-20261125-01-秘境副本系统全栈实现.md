## 1. 最终锁定需求与裁决

1. **体力制与扣费时机**：上限 `1680`（每 `360s` 回 `1` 点，整点推进守恒，新号/旧档首登默认 `240`）；**进入副本开局直接扣除对应档位体力，团灭或主动撤退不返还**；量词全栈统一使用**「次」**（不用「把」）。
2. **入口与命名边界**：全栈更名为**「追忆副本」**（「秘境」留给后续独立玩法）；**移除大地图角标与节点详情入口**，与「讨伐」同构放入**「历练」**页签（驻留对应节点时展示追忆副本卡片，点击弹出配置窗）。
3. **虚境/现世双下拉 11 档难度（`0..10`）**：
   - 左下拉选模式「虚境 / 现世」，右下拉联动选档位；
   - **虚境（`0..2`）**：普通（30）/ 困难（40）/ 地狱（50），固定配表原等级；
   - **现世（`3..10`）**：凡阶（60）/ 黄阶（80）/ 玄阶（100）/ 地阶（120）/ 天阶（150）/ 灵阶（180）/ 圣阶（210）/ 帝阶（240），阶位双轴倍率自 `d = 3` 继续叠乘（确保凡阶也比虚境地狱难）。
4. **现世动态怪物等级机制（下限保护 + 保差值 + 通用等级加成）**：
   - 取队伍最大玩家等级 $L_{\max}$，下限保护目标等级 $L_{\text{target}} = \max(L_{\max}, L_{\min})$，逐怪等级 $L'_i = \text{clamp}(L_{\text{target}} + (L_i - L_{\min}), 1, 127)$；
   - 怪物面板与通用击杀经验（及通关基准修为/灵石）按动态等级走通用成长曲线重算后再叠乘难度 `d` 倍率；**材料与稀有装备掉率仅按难度等阶增减**，不随动态等级额外增加。
5. **准备弹窗精简与 Hover 具体属性**：移除顶部抽象增幅公式卡片；底部波次改为下拉框，右侧展示所选波次全部怪物瓦片，悬停（Hover）直接展示叠加动态等级与当前难度增幅后的具体实战属性。
6. **收益结算、锻造闭环与等级差惩罚**：逐波独立直发 + 第 10 波通关独占特殊材料与低概率专属成品装备（自 `d=3` 现世凡阶解锁）；复用野外组队通用 MWI 等级差经验折减公式。
