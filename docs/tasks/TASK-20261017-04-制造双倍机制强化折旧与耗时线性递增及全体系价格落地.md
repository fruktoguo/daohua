# TASK-20261017-04 · 制造双倍机制、强化50%折旧与耗时线性递增及全体系价格落地

## 任务背景与核心目标

根据用户指导与总纲经济学规范：
1. **制造产物双倍增值铁律（$\times 2.0$）**：所有制造产物（精炼材料、丹药符箓、阵盘消耗品、装备成品），其系统商店直接回收基础售价（`sellPrice`）严格等于制造投入全部原材料卖店成本总和的 2 倍（100% 净增值率）。
2. **强化装备 50% 额外造价折旧模型**：强化变体装备卖店时白板 100% 绝对保底，高于白板部分按受保强化额外期望造价的 50% 折算返还，杜绝刷钱漏洞并提供换装资金回笼。
3. **行动耗时基准线性累加模型（+30%/阶）**：公式 $T(N) = T_0 \times [1 + 0.30 \times (N - 1)]$，杜绝高阶行动耗时指数爆炸；配合 T2 单价提升 3 倍，单位时间每秒净产出（PPS）提升 2.3 倍。
4. **全量怪物与战利品 100% 真实对齐**：彻底剔除虚构怪物与材料名称，完全对齐系统现存 13 种真实怪物（魔化野兔/木灵/火灵/铁甲熊/魔猿/伥虎/裂齿妖狼/星屑火鸦/掠灵邪修/残刃尸煞/坠魔祭司/玄元残魄/坠星兽）与 12 种真实战利品材料，并严格按 **普通妖兽 20:1 / 精英妖兽 3:1 / 区域妖王 1:1** 期望模型配平。
