## 需求分析

用户反馈现有 TUI 过于简陋，希望把 `dev.sh` 的终端界面做得更清晰、更像可长期使用的开发控制台。问题集中在当前单一日志列表：服务状态、当前阶段、日志来源和快捷键混在一起，信息层级弱，日志区域缺少边框和视觉分区。

## 设计边界

1. 保留现有无第三方依赖、ANSI alternate screen、原始键盘输入和日志文件轮询。
2. 改为固定网格布局：品牌标题栏、阶段/运行时长状态卡、服务状态卡、带活动标签的日志面板、底部快捷键栏。
3. 保留 `q`/`Ctrl+C` 停止、`a` 全部、`b` 后端、`f` 前端、`r` 刷新语义；新增日志级别颜色和空状态提示，不改服务生命周期。
4. 终端较窄或较矮时自动收缩，不能因为中文宽度或日志长行破坏边框。
5. 不引入 npm 依赖、不修改协议和服务端逻辑。
