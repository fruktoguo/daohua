## 一、需求目标与设计锚点

对齐权威设计真源 [31-道友攻略与配装付费查阅规约.md](../design/总纲/31-道友攻略与配装付费查阅规约.md)：

1. **道友 · 攻略子页签（`socialSubTab = 'guide'`）**：
   - 在个人排行榜（除 `zongmen` 外 11 榜）当前整点快照位列 **Top 50** 的非机器人修士获得发帖资格，每日（UTC+8）最多新发布 **1 篇** 攻略（删帖不退当日额度，编辑旧帖不耗额度）。
   - 正文上限 **10,000 字**（Unicode Rune 口径），支持安全 Markdown 块级/行内排版、游戏自带表情（`QqEmoji`）、内置分类颜文字（Kaomoji）快捷插入、图片直链（含 Markdown 图片与个人云表情包/上传图片）自动解析与灯箱放大，以及游戏物品/地点胶囊引用。
   - **独立全功能编辑器**：横屏双栏（编辑 + 实时预览）或切换、竖屏单栏一键切换「编辑 / 预览」，全工具栏与本地草稿自动暂存。
   - **双排序、付费门槛与自由打赏**：支持 **热度排序** 与 **打赏排序**；支持设置 `unlockPrice`（0 免费，或 `1 ~ 100,000` 灵石永久解锁）与自由追加打赏；跨玩家灵石结算走 Serializable 事务 + 10% 系统手续费 + 5 类白名单账本 `'guide.reward'`。
2. **设置 · 隐私付费查看装配**：
   - `Settings` 分段新增 `LoadoutInspectPrice`（存档 `v45 -> v46`，数据库 `v65 -> v66`），支持「公开 / 付费查看 / 完全隐藏」三态。
   - 非同队访客打开 `PlayerCardModal` 时可支付设定的灵石解锁查看目标装配，权限维持至北京时间当日结束零点（次日 `00:00:00+08:00`），走白名单账本 `'privacy.inspect'`（10% 系统手续费，防涨价滑点校验）。
