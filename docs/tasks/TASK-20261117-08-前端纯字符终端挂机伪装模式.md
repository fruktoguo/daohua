## 一、核心需求与设计边界对齐

1. **视觉形态（零图像硬约束）**：
   - 全屏铺满网页视口，采用《Hacknet》/ Linux `tmux` + `btop` / CMD 服务器集群管理终端的硬核纯字符界面；
   - **无任何图像**：严禁使用 `<img>`、`<svg>`、`<canvas>`、Emoji 或背景贴图，所有框线、进度条、波形曲线、集群拓扑与十六进制内存转储均由等宽字符（ASCII / Unicode 制表符、块字符 `█▓▒░`、Braille 点阵波形 `⠁⠃⠇⠏⠟⠿⣿`）构成；
   - **无修仙与中文词汇穿帮**：遮罩内全部使用英文系统监控缩写、十六进制地址与服务器运维日志，开启期间同步将浏览器标签页 `document.title` 与 `favicon` 临时伪装为终端会话标识，退出时完整还原。
2. **暗中映射真实挂机状态**：
   - 仅修改前端显示层，底层 WebSocket、行动队列推进、战斗与采集结算照常运行；
   - 将当前行动队列状态与本轮进度映射至 `JOB_SCHEDULER / WORKER_PIPE` 面板（运行中 `[ RUN ]` 绿灯、暂停/受阻/空队列切换琥珀/红灯告警）；
   - 将当前角色气血（HP）、灵力（MP）占比映射至 `MEM_RESIDENT` 与 `BUF_KERNEL` 资源分配条；
   - 将 WebSocket 连接状态（`online` / `reconnecting` / `offline`）、实时往返延迟 `latencyMs` 与在线节点统计映射至 `NET_MESH` ASCII 拓扑与心跳指标；断线时保持终端遮罩不弹回修仙断线页，并在终端内提供 `[ RECONNECT ]` 重连动作防穿帮；
   - 开启期间压制底层 `Notice` 浮动气泡与自动弹窗（每日签到、更新公告），防止古风弹窗穿透暴露。
3. **入口与退出方式**：
   - 从「设置 → 显示」新增「挂机模式」分组进入；
   - 仅铺满网页视口（不调用浏览器原生 Fullscreen API，避免顶部系统提示条），仅点击终端界面右上角退出按钮（`[ ^C / DISCONNECT ]`）退出（不绑定 `Esc` 键防切屏误触穿帮）。
