# TASK-20260930-06 设置界面游戏化改版

## 需求

- 提出时间：2026-09-30 16:39:53
- 用户反馈：当前设置界面太奇怪，不像正常游戏。

## 现状问题（代码分析）

- 设置页 `.panel` 铺满整个主内容列（约 1000px+ 宽），内容仅数块，大面积留白。
- 账号信息使用 `.stat-row` 标签靠左/值靠右横跨全宽，标签与值视觉脱节，像后台管理表格。
- 「道貌仪容」网格 `minmax(260px,1fr)`，但 `AVATAR_OPTIONS` 当前只有 1 个形象，渲染为一张巨大卡片。
- 界面缩放滑块横跨全宽 + 6 个预设按钮 + 重置按钮，控件无边界感。
- 分类切换是头部右侧两个小按钮（`.settings-sub-tab` 私有样式），未复用统一二级选项卡体系。
- 各功能块为无差别边框块堆叠，没有「设置行（标签+说明 | 控件）」的游戏设置语义。

## 方案

- 布局改为经典游戏设置结构：**左侧竖排分类栏 + 右侧分组设置行**。
  - 左栏竖排分类按钮（账号/显示，含小图标格），视觉对齐既有 `.nav-sub-item` 侧栏菜单体系。
  - 右栏内容限宽（约 640px），分组卡片内使用「标题+说明 | 控件」设置行。
- 账号分组：修士资料卡（立绘缩略 + 道号 + 序号 ID + 修改道号/冷却标签）+ 登录账号/注册时间信息行 + 会话分组（退出登录）。
- 显示分组：界面缩放（滑块+数值徽章+预设档位，限宽）、界面语言（分段按钮）、道貌仪容（紧凑形象卡片网格）。
- 移动端（≤960px）：左栏降级为顶部横向滚动分类条，内容全宽。
- 清理只被设置页独占的过时样式（`.settings-sub-tab`/`.settings-block`/`.stat-row`/`.settings-logout-*` 等）。
