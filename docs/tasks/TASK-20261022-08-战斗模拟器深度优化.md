# TASK-20261022-08 战斗模拟器深度优化：触发器配置系统、图标资产复用与平均场次时长拆分

## 1. 任务背景与核心需求

用户反馈当前战斗模拟器存在以下三方面核心痛点：
1. **技能与消耗品的触发系（Triggers）无法配置与导入**：
   - 战斗模拟器内部技能槽与自动消耗品槽未开放触发器配置通道，无法调校施放阈值；
   - 导入自身配置时未完整导入自身触发器；导入队友时未导入队友自身的触发器与装配条件。
2. **违规使用表情符号（Emoji）**：
   - 战斗模拟器模态框、参战者编辑面板、结果分析卡片及独立推演工具（`tools/combat-simulator.html`）大面积充斥 `⚔️`、`📊`、`📜`、`🛡️`、`🧪`、`🏆`、`💰`、`⚡` 等 emoji 字符；
   - 需彻底移除所有 emoji，规范复用游戏内标准二值矢量/遮罩小图标资产（`StatGlyph`）。
3. **战斗平均场次时长分析与波次类型细分展示**：
   - 缺少单场战斗平均耗时统计；
   - 需深度拆分普通回（Normal wave）、精英回（Elite wave）与 BOSS 回（Boss wave）各自的场次、平均时长及耗时极值范围；
   - 若某地点未刷出精英或 Boss（如纯小怪节点），严格遵照指令动态隐藏，只展示普通回。

## 2. 方案设计与架构落地

### 2.1 触发器配置与双向流转体系
- **数据结构扩展 (`simulatorTypes.ts`)**：
  - `SimulatorCombatantConfig` 新增 `consumableTriggers?: Record<string, CombatTrigger[]>` 字段，对齐现存的 `abilityTriggers`。
- **自身与队友智能导入 (`SimulatorPartyEditor.tsx`)**：
  - `handleImportSelf`：全量提取 `myCombat.abilityTriggers`、`myCombat.abilitySlots` 中的槽位触发器以及 `myCombat.consumableTriggers`；
  - `handleImportTeammate`：优先检索当前活跃探险/战阵 `queue.entries[0].expedition.allies` 中的对应成员，提取开战冻结的真实属性、技能槽条件 (`skills[].triggers`)、独立技能触发器映射与消耗品，缺省时智能对齐玩家战斗配置基线。
- **原位触发器配置与交互组件接入**：
  - 功法技能与消耗品列表在每条记录下方增加触发器配置按钮（`.sim-trigger-btn`）；
  - 点击呼出游戏内统一规范的 `CombatTriggerEditor` 模态窗，支持按目标依赖、判定条件、比较符与数值/百分比阈值进行全功能编辑与保存，并实时回显规则简述摘要（通过 `describeCombatTrigger`）。
- **确定性推演内核求值接入 (`combatSimulatorCore.ts` & `expeditionSimulator.ts`)**：
  - `SimCombatant` 实体扩充 `consumableTriggers` 字段与构造透传；
  - `SimCombatEncounter.applyConsumables` 接入 `SimSkillTriggerEvaluator.matchesAll` 判定：当配置了触发条件时，严格按触发器求值，若为未配置触发器则平滑回退至生命值 < 60% / 灵力 < 40% 默认健康度阈值；
  - `ExpeditionSimulator` 技能槽生成时优先使用 `ally.abilityTriggers?.[abilityId] ?? slot.triggers ?? def?.defaultTriggers ?? []`，使用 `??` 彻底解决空数组（恒可用）被 `||` 错误短路回退的问题。

### 2.2 彻底去表情符号化与游戏资产复用
- 全面清洗 `CombatSimulatorModal.tsx`、`SimulatorPartyEditor.tsx`、`SimulatorResultsView.tsx`、`SimulatorConfigPanel.tsx` 与 `tools/combat-simulator.html` 中的全部 emoji；
- 统一复用前端规范组件 `<StatGlyph glyph="..." />`：
  - 战斗/伤害/攻击：`glyph="attack"`
  - 属性/六维：`glyph="foundation"`
  - 功法/技能：`glyph="skill-bonus"`
  - 装备/防具：`glyph="armor"`
  - 消耗/丹药：`glyph="alchemy"`
  - 战况/妖兽：`glyph="bio-monsters"`
  - 战胜/冠军：`glyph="bio-pvp-win"`
  - 修为/经验：`glyph="experience"`
  - 灵石/收益：`glyph="mining"`
  - 灵气/恢复：`glyph="mp"`

### 2.3 平均场次时长深度分析与动态展示
- **指标抽象 (`simulatorTypes.ts`)**：
  - 新增 `WaveDurationStat`（包含场次 `count`、平均秒数 `averageSeconds`、极小秒数 `minSeconds`、极大秒数 `maxSeconds`）；
  - 新增 `WaveDurationBreakdown`（包含全场均值 `overallAverageSeconds`、普通回 `normal`、精英回 `elite`、BOSS回 `boss`）；
  - `SimulatorReport` 挂载 `durationBreakdown: WaveDurationBreakdown`；
  - `SimulatorNodeComparisonItem` 挂载 `avgDurationSeconds: number`。
- **推演采集 (`expeditionSimulator.ts`)**：
  - 按波次怪物最高品阶（`isBoss` / `isElite` / `normal`）分流采集单场持续时长数组 `bossDurations`、`eliteDurations`、`normalDurations`；
  - 若无精英怪则 `elite: null`，若无 Boss 则 `boss: null`。
- **UI 呈现与动态适配 (`SimulatorResultsView.tsx` & `simulator.css`)**：
  - 战况总览卡片下方新增专属「平均场次时长分析」卡片：全场平均耗时高亮徽章 + 响应式网格布局；
  - 普通回卡片恒显；
  - 精英回与 BOSS 回严格依据 `count > 0` 判定存在性，无精英/Boss遭遇时只展示普通回；
  - 挂机刷图收益对比大表格新增「平均单场」列，直观对比各节点清场速率。
- **独立调参工具同步 (`tools/combat-simulator.html`)**：
  - `simulateTier` 拆分并返回 `avgNormalSec`、`avgEliteSec`、`avgBossSec`；
  - 详表渲染采用 `formatWaveDurationText`，无精英/Boss波次时只显示普通回时长。
