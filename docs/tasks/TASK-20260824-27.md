## 需求背景与核心目标

经过 `/grill-me` 深度访谈，针对《道化太初》正式前端界面交互与修仙美学进行全景重构升级：
1. **视觉美学基调**：**玄门古籍与暗墨金石风**（深邃墨色底、金石篆刻边框、细金线微光、灵气暗纹与沉浸古籍质感）。
2. **架构与布局模式**：**模块化悬浮台型（Island Layout）**，三栏全面去网格线框化，各区域独立悬浮、微光呼吸，支持沉浸自适应与独立收折。
3. **动效与视觉表现**：**丰富仙侠视效**（包含灵气浮游粒子基底、边框金光流转、水墨晕染淡入淡出、浑天仪太极流转与能量涟漪）。
4. **各岛屿交互与收折逻辑**：
   - **左侧导航岛**：支持「64px 图标微缩模式」与「220px 古籍卷轴全展模式」一键切换，自带微缩道号印章。
   - **右侧战备岛**：支持「贴边快捷收折 / 展开三Tab（储物袋/装备虚影/功法槽位）」。
   - **底栏日志岛**：支持「单行快报走马灯」与「展开多行历史面板」一键切换。
   - **中央主视窗岛**：随左右侧边栏收折自动平滑弹性占满空间。
5. **天机顶岛 (Celestial TopBar)**：
   - 左翼：道号、境界玉徽、寿元/精血/灵力微缩胶囊、流光修为灵池进度环；
   - 中央：浑天太极行动总台（八卦灵光流转倒计时环、当前行动徽章、展开悬浮天机册）；
   - 右翼：气运灵牌与灵脉环境增益区。
6. **用户即时指令**：编写独立的单文件纯 HTML 交互 Demo（`docs/design/ui-layout-island-demo.html`），展示全部布局、动态粒子、太极浑天行动台、岛屿收折联动、水墨切换与古籍金石质感，供用户直观预览与验收。
