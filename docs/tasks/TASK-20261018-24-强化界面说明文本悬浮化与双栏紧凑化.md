## 二、问题背景

装备强化页（`frontend/src/components/EnhancementPage.tsx`）采用左右双栏：左栏为目标与方案配置，右栏为实时预览。左栏「保护材料」与「起护等级」两行下方各挂一段说明性长句（`setting-desc`，11px，行高 1.6），在高分屏缩放、浏览器高倍缩放或窄视口下会折成 2~3 行，把双栏整体撑高。

`.panel.skill-page` 为 `height: 100%; overflow: hidden` 的裁剪容器，强化页本身没有任何滚动兜底，超出部分被直接裁掉——玩家看到的现象即「右栏底部的产出预览、单次耗时等信息显示不全」。

同时，右栏 8 条预览行中存在语义重复与冗余信息：

- 「当前等级」与「本轮目标」各占一行；
- 「产出预览」把目标装备全名重复渲染两次（成功/失败），窄栏下各折 2 行；
- 「强化技艺 Lv.N」与「速度加成 +X%」各占一行，可合并为耗时行的副注。

## 三、实现方案

### 3.1 说明文本 Hover 化（本次核心诉求）

- 新增页内 `TermHint` 组件：以现有公共组件 `FloatingPopover` + `FloatingInfoCard` 承载术语卡片，标题为名词本体，描述为原说明长句。
- 触发体为名词标签本身（「保护材料」「起护等级」），采用虚线下划线 + `cursor: help` 提示可悬停，对齐 `.unit-number` 的既有可查询语义。
- 行内不再渲染任何整句说明；「保护材料」缺料时仅在同行的勾选框右侧显示 5 字状态标签「无可用材料」，不新增行高。

### 3.2 左栏紧凑化

- 目标装备瓦片与「目标等级」选择器并排（`.enhancement-target`），窄屏 `flex-wrap` 自动回落为纵向，节省约一行高度。
- 「重复次数」由独立的 `.repeat-row`（13px 上下内边距 + 实线分隔）改为与其余配置同律的 `.setting-row`（6px 内边距 + 虚线分隔），统一节奏。
- 强化页内的 `.setting-row` 内边距由 7px 收到 6px，分组标题下边距 10px 收到 8px。

### 3.3 右栏精简（8 行 → 6 行）

| 原行 | 处理 |
| --- | --- |
| 当前等级 / 本轮目标 | 合并为「等级 +N → +M」单行 |
| 单次费用 | 保留 |
| 成功率 | 保留，数值金色强调 |
| 产出预览 | 保留两行，但去掉重复的装备名，改为「成功 → +M」「失败 → +N（材料代护）/ 归零」 |
| 感悟 | 保留双胶囊 |
| 单次耗时 / 强化技艺 / 速度加成 | 合并为「X 秒」+ 副注「技艺 Lv.N · 加速 +X%」单行 |

### 3.4 溢出兜底

- `.enhancement-layout` 改为 `flex: 1 1 auto; min-height: 0; overflow-y: auto; align-content: start`：内容超高时双栏整体在面板内滚动，不再被 `.skill-page` 的 `overflow: hidden` 裁切；内容吸附顶部，双栏仍等高。
- 删除竖屏媒体查询中重复的 `.enhancement-layout` 滚动声明（已由基础规则覆盖）。

### 3.5 文案与词条

- 新增：`protectionHint`、`protectLevelHint`、`levelFlow`、`techniqueInline`。
- 调整：`protectionUnavailable` 精简为「无可用材料」、`outcomeSuccess` / `outcomeFailProtected` / `outcomeFailReset` 去掉 `{name}` 占位。
- 移除不再使用的 `protectionUse`、`protectLevelDesc`、`attemptLabel`、`techniqueLabel`、`techniqueBonus`。
- 同步重新生成 `frontend/public/locales/template.csv`。
