1. **彻底移除 4 类 MWI 词缀**：

   - 移除 `FuryRatio`（沸血/狂暴）；
   - 移除 `WeakenRatio`（虚弱减伤）；
   - 移除 `PierceChance`（贯穿几率）；
2. **彻底移除 15 秒词缀计时器系统**：
   - 移除 `CombatModifierRuntime` 运行时状态模型；
   - 移除 `ApplyCombatModifierEffects`、`GetNextGroupModifierEventTime` 及相关过期事件调度；
3. **精简领域模型、模拟器计算、协议 DTO 与配置解析器**；
