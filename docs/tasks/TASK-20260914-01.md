## 需求与背景

1. **移除装备攻击间隔**：
   - 装备上不应具备或展示“攻击间隔”属性（修仙战斗规则中角色攻击间隔基础为 2 秒，装备不带攻速间隔词条）。
   - 当前由于后端装备映射默认兜底填充 `attackIntervalMilliseconds: 2400`，且前端强转读取展示，导致所有装备（含防具饰品）错误显示“攻击间隔 2.40 秒”。
2. **装备属性 Hover 色彩与属性面板一一对应**：
   - 当前装备 Hover 面板中的属性数值由于被 `ValueText` 的 `+` 正数规则误判为 positive，在样式中全被渲染为误导性的粉红/暗红色。
   - 期望每个属性加成条目严格对应内视属性面板（`InsightPage`）中的修仙色彩体系（`PillTone`）：
     - 物理攻击: `crimson`（赤红）
     - 术法攻击: `indigo`（靛紫）
     - 生命上限/生命回复/伤害减免: `emerald`（翡翠绿）
     - 灵力上限/灵力回复/冷却缩减: `cyan`（灵气青）
     - 物理护甲/护甲穿透: `bronze`（青铜）
     - 术法抗性: `violet`（紫罗兰）
     - 命中: `sky`（天蓝）
     - 闪避/施法攻速: `teal`（水绿）
     - 暴击率/暴击伤害: `gold`（道金）
     - 免暴/韧性: `slate`（玄岩灰）
     - 破招: `amber`（琥珀橙）
     - 化解: `silver`（银白）
     - 五行: 金 `gold` / 木 `emerald` / 水 `cyan` / 火 `amber` / 土 `bronze`
   - 复用统一公共组件 `PillBonusLabel` 进行胶囊与专属下划线高亮呈现。
