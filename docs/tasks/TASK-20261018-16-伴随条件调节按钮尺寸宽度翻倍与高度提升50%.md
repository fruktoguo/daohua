# TASK-20261018-16 瓦片Hover条件调节按钮尺寸宽度翻倍与高度提升50%

## 1. 任务背景与核心诉求

在功法与战斗消耗品槽位上，鼠标悬停（Hover）在瓦片时会在瓦片上缘（或视口翻转时的下缘）浮现出用于配置触发条件的快捷入口胶囊（`.item-slot-inline-action--condition`，文案如「条件」「条件2」）。

用户针对该悬浮按钮明确指出：
- 需要调整的是**Hover 浮现的那个条件按钮**（而不是点击槽位展开选择弹窗后的弹窗伴随按钮）；
- 将此前误改的弹窗按钮（`.candidate-picker-condition-btn`）恢复原规范；
- 对 Hover 条件按钮实施：**宽度翻倍**、**高度提升 50%**，提供充盈的点击热区。

---

## 2. 技术设计方案

### 2.1 回退弹窗选择器伴随按钮样式 (`selection-grid.css`)
- 恢复 `.candidate-picker-condition-btn` 正常尺寸：高度 32px（触屏 36px），内边距 `4px 14px`，字号 13px；
- 移除 `.candidate-picker-card` 额外的最小宽度限制，保持弹窗随网格内容自然紧凑。

### 2.2 瓦片 Hover 条件调节按钮升级 (`selection-grid.css`)
1. **尺寸精确对齐诉求**：
   - 原尺寸：`padding: 3px 9px`，字号 11px，实际渲染总高度约 20px，总宽度约 38~42px；
   - **高度提升 50%**：设置 `min-height: 30px`（触屏端 `34px`），垂直内边距调整为 `5px`；
   - **宽度翻倍**：设置 `min-width: 80px`（触屏端 `88px`），水平内边距严格翻倍为 `padding: 5px 18px`（触屏端 `6px 20px`），内容通过 `display: inline-flex; align-items: center; justify-content: center` 水平居中；
   - **字号与粗细**：字号由 11px 提升至 13px，字重调整为 600，保证胶囊放大后的视觉重心与饱满度。
2. **热区防脱无缝扩展**：
   - 随按钮尺寸翻倍，`::before` 隐形透明点击热区从 `-6px -8px` 扩展至 `inset: -8px -12px`，保证鼠标从瓦片本体跨移至上方浮现胶囊时 100% 连续不脱触。
3. **居中与位移动画对齐**：
   - 维持 `bottom: 100%; left: 50%; transform: translateX(-50%)` 水平居中基准，在 44~52px 宽的瓦片上居中延伸至 80px 宽度，左右各悬出约 14~18px，对称协调且极易点中。
