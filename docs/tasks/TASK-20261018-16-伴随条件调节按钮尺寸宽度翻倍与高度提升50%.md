# TASK-20261018-16 伴随条件调节按钮尺寸宽度翻倍与高度提升50%

## 1. 任务背景与核心诉求

在待选列表（CandidatePicker，涵盖功法装配与战斗消耗品装配）展开时，顶部 Header 伴随展示了供玩家配置技能/物品触发时机的调节按钮（`.candidate-picker-condition-btn`，文案如「⚙ 触发条件」/「⚙ 条件」）。

用户针对该按钮的点击操控体验提出了明确的尺寸调整诉求：
- **宽度翻倍**：按钮横向感知过窄，操作容错率不够大，要求横向宽度彻底翻倍，提供超宽大热区；
- **高度提升 50%**：原高度为 32px（触屏端 36px），按 +50% 提升至 **48px**（触屏端 **54px**）；
- **字号与图标同比例放大**：齿轮图标由 14px 放大至 18px，文字字号由 13px 提升至 15px（触屏端 16px），加粗居中显示，达到一眼可见、一击即中的顶级点触体验。

---

## 2. 技术设计方案

### 2.1 样式重构 (`frontend/src/styles/selection-grid.css`)

1. **尺寸精确对齐诉求**：
   - 高度：`min-height: 48px`（桌面端，原 32px 的 1.5 倍）；`min-height: 54px`（触屏端，原 36px 的 1.5 倍）；
   - 宽度：设置 `min-width: 150px`（桌面端）/ `min-width: 160px`（触屏端），原宽度约 70~80px，实现严格翻倍；水平内边距加深为 `padding: 6px 24px`（桌面）/ `padding: 8px 28px`（触屏）；
   - 内容布局：`justify-content: center`，图文间距 `gap: 8px`；
   - 字号与图标：`.candidate-picker-condition-icon` 调整为 `font-size: 18px`，`.candidate-picker-condition-btn` 调整为 `font-size: 15px; font-weight: 600`。

2. **卡片容器自适应宽度防护**：
   - 为 `.candidate-picker-card` 配置 `min-width: min(320px, calc(100vw - 24px))`，防止伴随按钮变宽后挤压左侧标题与搜索输入框，保证 Header 在任何分辨率下不拥挤、不换行。

3. **视觉微光与点击反馈微调**：
   - 放大外发光光晕半径（`box-shadow: 0 3px 12px rgba(0, 0, 0, 0.7), 0 0 8px rgba(201, 180, 109, 0.2)`）；
   - `has-triggers` 激活态与 Hover 悬停态呈现更加温润透亮的帝金微光。
