## 1. 任务背景与核心问题

用户反馈在前端界面中，核心修炼行动【**引气入体**】（`cultivation.draw-qi`）的显示存在以下问题：
1. **历史硬编码文案未更新**：前端行动详情弹窗中针对修炼类行动写死展示旧文案 `「每次 +1」`（早期原型残留），未同步至当前的 `+10 修为` 与 `+1 灵力` 真实数值。
2. **产出列表未展示角色内视属性**：角色的修为（`Spirit`）与灵力（`Qi`）已转为角色核心属性，不再作为 `resource.qi` 物品进入背包，导致前端原有的纯物品 `outputs` 遍历在此类行动上显示为空。
3. **缺乏动态加成解算实时预览**：
   - 自动消耗品槽位装配的持续性丹药加成（引气丹 $+30\%$、通脉丹 $+50\%$）未动态计算并直观展示；
   - 世界地图/灵脉加成（`world.cultivationMultiplier`）与实时 Buff 增益未合并计算；
   - 道基底蕴（`foundationExp`）带来的 3 倍修为加速（底蕴化生）以及境界圆满待突破时的底蕴转化未作动态提示；
   - 缺少当前各项加成明细标签与实际单次耗时展示。

## 2. 设计方案与技术实现

### 2.1 动态加成解算工具（`actionCalculations.ts` / 纯函数）
* **加成因子解算**：
  * **丹药加成（Pill Multiplier）**：检查 `autoUseSlots[actionType]` 中已启用的槽位，若槽位有剩余时间或背包有存货，取对应持续消耗品乘率（如引气丹 1.3、通脉丹 1.5）。
  * **世界/灵脉加成（World Multiplier）**：结合 `world.cultivationMultiplier`（如青岚山谷 1.2）。
  * **状态增益（Buff Multiplier）**：计算未过期的生效 Buff 中对应倍率（如 `buff.qiGainMultiplier`）。
  * **综合乘率（Total Multiplier）**：$\text{Total} = \text{Pill} \times \text{World} \times \text{Buff}$。
* **行动产出解算**：
  * **修炼类型（Cultivation）**：
    * 基础值：10.0 修为，1.0 灵力。
    * 加成后：$\text{Exp} = 10.0 \times \text{Total}$，$\text{Qi} = \text{Round}(1.0 \times \text{Total})$。
    * 底蕴化生：若拥有 `foundationExp > 0`，计算消耗底蕴 $\min(\text{foundationExp}, \text{Exp} \times 2)$，预估实际获得修为。
    * 境界圆满：若处于待突破状态，提示修为 100% 自动注入道基底蕴。
  * **通用物品产出（Exploration / Alchemy）**：
    * 支持结合 `gatheringMultiplier` 或 `alchemyMultiplier` 预览动态加成后的产出数量。

### 2.2 前端界面重构
* **行动卡片（`ActionCard`）**：
  * 针对修炼行动，直观展示加成后的修为与灵力产出标签（如 `13 修为 / 1 灵力 (+30%)`）。
* **行动配置与执行弹窗（`ActionModal`）**：
  * **消耗（Needs）**：正常展示材料消耗或「无」。
  * **产出（Outputs）**：
    * 针对修炼类型：清晰展示**修为**与**灵力**（基础值 $\to$ 加成后最终值，附带高亮加成百分比）。
    * 针对底蕴加速/圆满状态：展示专属「底蕴化生 (3倍加速)」或「圆满转化」提示徽章。
    * 针对常规物品产出：展示基础与加成后数量。
  * **耗时（Duration）**：展示单次耗时及速度加成（若有）。
  * **加成明细（Active Bonuses）**：当存在生效加成时，展示清晰的微光胶囊标签（如 `引气丹 +30%`、`青岚山谷 +20%`、`底蕴加速`）。
