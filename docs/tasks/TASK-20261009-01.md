## 设计边界

1. 顶部操作条对齐参考：左侧 `修改队伍`（仅队长）+ 本人参战开关（待命期 confirm-primary，会话中转「退出斗法」danger+确认）；右侧 `离开队伍` + `解散队伍`（仅队长，danger）。
2. 档案区为队名 + `·` 分隔只读信息行（目标/地点/公开性/身价门槛/人数），编辑表单收进 `LeaderProfileModal`（复用 `Modal` + `modal-form` 范式，保存发送 `party.update` 后关闭）。
3. 成员区改为槽位横排卡片：`openSlots` 定列，队长固定首槽，空槽虚线占位；卡内名称+队长标+在线态、立绘（`CharacterAvatar` role=player）、身价、底部本人就绪勾选框（与顶部开关共用 `toggleSelfReady`）/他人只读就绪标签，队长对他人卡有「移出」。
4. 用户二轮反馈：在队态只保留队伍面板——会话横幅、`队伍信息/组队大厅` 页签导航与分享卡全部移除；组队大厅/创建/匹配仅在无队伍态出现。`party-member-list`/`party-header`/`party-card--danger`/`party-session` 等死样式与 `social.members.heading`/`social.tab.overview`/`social.share.*`/`social.session.{banner,encounter,node,startedAt,members,disbandWarn}` 死词条一并清理。
