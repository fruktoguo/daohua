# TASK-20261027-09 全量缺失图标图片AI补全与母模合成落盘

## 任务背景与核心目标

当前游戏内配表与前端实体不断丰富，经全仓扫描比对，除已具备专属图标的 300+ 实体外，共有 14 项物品（三大战术阵盘、百艺加速香品、强化灵粉灵砂、凡人与叩关阶梯丹药膏散、以及最新投放的《碎罡秘籍》与《碎罡·残卷》）在 UI 中因缺少图片资产而回退为纯文本名称渲染。

本任务旨在利用本地 ComfyUI MOSS-Image 生图管线与程序化合成工具，为所有缺失图标的条目补齐高品质仙侠视觉资产，彻底终结纯文本瓦片回退。

## 需求理解与复述

1. **业务目标**：为游戏中当前所有无图片图标的物品/道具补齐专属图标，达成游戏中所有道具、装备、功法与建筑 100% 图标化展示。
2. **核心逻辑与资产范式**：
   - 严格遵循《道化太初》美术双轨制：
     - **体系 B（2D 古典手绘厚涂）**：阵盘、丹药、膏散、线香、粉砂，深墨勾线，古朴色调，45° 对角或 30° 俯角构图；
     - **体系 C（纯白二值镂空矢量图腾）**：针对《碎罡》，生成纯白二值镂空 Stencil 图腾（`emblem.sui-gang.webp`），利用 `composite_manuals.py` 程序化合成至权威线装书与撕裂卷轴母模上。
3. **影响范围与实现边界**：
   - 涉及 14 项物品 ID：
     - 阵盘（3）：`item.tianlei-formation-disk`（天雷阵盘）、`item.mizong-formation-disk`（迷踪阵盘）、`item.xuesha-formation-disk`（血煞阵盘）
     - 阶梯消耗品与丹药（5）：`item.shengji-balm`（生肌膏）、`item.ningqi-powder`（凝气散）、`item.huangya-pill`（黄芽丹）、`item.heqi-pill`（合气丹）、`item.reverse-fate-pill`（逆命丹）
     - 生活百艺香品（2）：`item.dingshen-incense`（定神香）、`item.qingling-incense`（青灵香）
     - 强化辅料（2）：`item.cuiling-powder`（淬灵粉）、`item.guling-sand`（固灵砂）
     - 功法典籍（2）：`item.tome.sui-gang`（《碎罡秘籍》）、`item.fragment.sui-gang`（《碎罡·残卷》）
   - 设计源母模归档于 `art/items/` 与 `art/emblems/`；
   - 生产轻量运行时产物（64×64 RGBA WebP）归档于 `frontend/src/assets/items/`；
   - 不修改底层协议或配表 ID，零破坏性变更。
