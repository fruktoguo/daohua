# TASK-20261015-05 赤军套装生存重构与物理输出新防具设计

## 任务背景与目标

1. **赤军套装（赤金盔、鱼鳞甲、踏阵胫）改版为纯生存/坦克防具**：
   - 定位彻底收拢为主要增加生存能力的坦克/重装防具，配合斩煞刀（+300% 威胁）与赤铜盾（+16 生命，双防各 8%）构成完备的 T2 重装坦克构筑。
   - 物理增伤改为物理减伤（`physicalDamageReductionPoints`: 2，原 `physicalDamageBonusPoints`: 2 移除）。
   - 移除头部原有的攻击属性（命中 `accuracy: 8`），改为纯生存属性（生命/双防），使全套防具无攻击杂质。
   - 额外增加一条威胁增幅（`threatBonusPoints`）：数值为 20% 和两个 15%（胸甲 20%，头与腿各 15%，三件套合计 +50% 威胁值）。
2. **新增一套 T2 物理伤害防具三件套（头、胸、腿）**：
   - 填补物理近战/输出流防具空缺，与破罡剑（纯物攻剑）与赤牙匕（物理输出匕首）形成 T2 物理输出体系。
   - 定位：略微增加物理生存能力，主要增加物理伤害能力（物攻、命中、暴击等）。生存能力主要增加生命值与些许护甲。
   - 严格遵循《道化太初》数值设计规范（`data-designer`）与装备标准化预算体系（Q2 灵品，头 32 点 / 胸 56 点 / 腿 32 点，属性预算严格守恒）。
   - 配置锻造升阶配方（基于 T1 物理防具与赤铜精/兽牙进阶）、前端图标与中英国际化文案。
