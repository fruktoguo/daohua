## 需求

当前讨伐战报被普攻帧刷满（每秒一条「命中/未命中」），且技能行直接漏出功法 ID（`ability.heavy-slash`）。用户要求：

1. 普通攻击伤害帧不再进入日志；
2. 技能行改为功法显示名（走 `{{ability:id|name}}` 引用标记，前端悬浮卡已支持）；
3. 同一次施放命中多个目标时合并为一条：`xxx 施放 xxx，对 xxx 造成 xx 点伤害，对 xxx 造成 xx 点伤害`（参考道劫余生 castId 合并口径）。

## 方案

- 落点只在日志成型层 `CombatActionRules`：战斗引擎 `CombatEvent` 逐帧语义不变，不新增协议字段。
- `CompleteCombatAdvanceCore`：功法经验入账与日志产出拆成两趟；产出趟丢弃 `AbilityId == null` 的帧（普攻与无技能衍生帧），携带 `AbilityId` 的连续帧按（出手方 + 技能 ID + 战斗时刻）合并为一条 `combat.skill`。
- 合并行格式：单子句行内连写 `{出手方}施放 {{ability:id|名称}}，对 {目标} 造成 N 点伤害。`；多子句以 `\n` 分隔逐条开行 `{出手方}施放 {{ability:id|名称}}，\n对 {目标}…\n对 {目标}…。`；妖兽名以 `{{enemy:enemyId|名称}}` 引用落模板，悬停可见敌怪面板；吸血类衍生帧（同施放者+技能+时刻）自然并入同一条。
- 前端多行排版：`gameLogService.splitLogSegmentsByLines` 按 `\n` 把分词切成「前缀行 + 逐条子句行」，`LogRow` 首行渲染前缀+首条子句，续行前置 `visibility:hidden` 的前缀克隆占位（`.log-combat-indent`），各续行「对/为」与首行「对」像素级对齐（对齐语义同 daojie `chat-merged-combat-indent` 方案，服务端模板不含缩进字符）。
- `AdvanceDuelPlayback` 斗法回放同口径：普攻帧不落日志，技能帧按（AttackerIsInitiator + AbilityId + AtSeconds）合并，逐帧血蓝镜像与功法经验记账保持逐帧不变。
- 尾窗 keepFrom 语义不变：同组帧共享 AtSeconds，整组同侧裁剪，无跨边界半组。
- 设计文档第十四篇战斗频道口径同步（普攻逐帧不再落日志）。
