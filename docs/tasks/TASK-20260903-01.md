对《道化太初》服务端（ASP.NET Core / WebSocket / 持久化 / 序列化）、领域层（确定性模拟 / 战斗推进 / 脏数据管理）、协议层以及前端（React 19 / 战报日志高频监听 / 附近生态卡片）进行全方位潜在性能隐患扫描与深度优化。

2. **零 GC 与降低堆分配**：识别热路径上的闭包、LINQ、不必要数组拷贝、重复哈希集合与序列化缓冲分配。
3. **每次修复独立验证与中文 Git 提交**：按模块逐项优化，跑通单测与构建门禁后独立提交。
