## 需求背景（提出 2026-10-03 14:13 前后）

参考《银河奶牛放置》（Milky Way Idle）的组队体验，把现有「邀请制基础队伍」升级为完整组队系统：

- 左侧新增顶级 Tab「同道」，内含子 Tab「队伍」；
- 无队伍时提供 4 入口：自主选择模式（匹配表单）、队伍匹配、组队大厅、创建队伍；
- 队伍匹配：多下拉过滤（去哪个地图 / 干什么目标 / 最低「身价」要求）；
- 组队大厅：同类过滤 + 展示「匹配中」散人与公开队伍列表，可自行加入；
- 创建队伍：填写目标与最低身价门槛；
- 已在队伍中：成员视图 + 队长管理（队名/目标/门槛/公开性/踢人/解散）；
- 不公开队伍不出现在大厅，只能经对话中插入的队伍超链接点击进入；
- 「身价」口径沿用牛牛插件思路：全身装备价值 + 功法参悟等级价值，优先取坊市当前最低挂售价，缺失/不可算时回落回收价；命名不锁死（代码字段 `valuation`，界面词条集中管理）。

## 需求分析结论（完成于 2026-10-03 14:29）

1. 已有基础：邀请制队伍（上限 5 人）、队伍频道聊天、PostgreSQL 持久化、SocialState 推送。本任务是扩展而非新建。
2. 「队伍」本质是**招募组织层**：匹配/大厅/目标字段均为招募标签，本期不含并肩作战的战斗结算。
3. 身价（valuation）必须由服务端统一计算：在线玩家读运行时快照，离线玩家读持久化 loadout 分段；坊市最低挂售价经 `MarketRuntime` 只读盘口查询，非本进程分片或无挂单回落回收价（`ItemDefinition.SellPrice`）。
4. 匹配语义：登记即尝试**自动并入**满足条件的公开队伍；未命中则进入「匹配中」散人池（`social.party_seekers`），供大厅展示与队长邀请。
5. 队伍链接：`social.chat_messages.party_ref` 外键指向队伍；卡片正文由服务端生成，队伍解散后链接自然失效（FK SET NULL，正文仍可读）。
