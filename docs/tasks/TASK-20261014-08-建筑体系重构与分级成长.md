- **核心诉求**：
  1. **建筑体系扩充与重命名（共 11 座建筑）**：
     - **修真营造（8 种）**：
       - `蒲团`（打坐修炼，吐纳灵气收益加成）
       - `丹房`（炼丹技艺，炼丹速度加成）
       - `炼器室`（炼器技艺，炼器速度加成）
       - `衍阵台`（阵法技艺，阵盘制作速度加成）
       - `制符室`（符箓技艺，符箓绘制速度加成）
       - `淬灵室`（强化技艺，装备强化速度加成）
       - `灵材坊`（采集技艺，兼顾采药与砍伐，采集速度加成）
       - `采石坊`（挖掘技艺，采矿挖掘速度加成）
     - **三方战阵（3 种）**：
       - `封魔阵`（削弱此地怪物属性）
       - `回春阵`（战中气血回复）
       - `回元阵`（战中灵力回复）
       - *（原掉落与经验阵法按指示移除）*
  2. **支持配置 1 级效果与每级增幅（Base + Growth）**：
     - 改变原有单值线性倍乘，支持配表中配置 `baseModifiers`（1 级基准）与 `growthModifiers`（每升 1 级增幅）。
     - 计算公式：当有效等级 $L \ge 1$ 时：
       $$Effect(L) = \big( Base + Growth \times (L - 1) \big) \times Efficiency$$
  3. **具体数值规划**：
     - **7 项技艺建筑**（灵材坊/采石坊/丹房/炼器室/制符室/衍阵台/淬灵室）：初始 12%，每级提升 2%。
     - **打坐蒲团**：初始 12%，每级提升 2%。
     - **回春阵**（战斗回血）：初始 2.4，每级提升 0.4（每 5 秒回血）。
     - **回元阵**（战斗回蓝）：初始 2.4，每级提升 0.4（每 5 秒回蓝）。
     - **封魔阵**（怪物削弱）：初始减 6%，每级提升 1%，**无上限**。
  4. **封魔阵双曲阻尼折减公式**：
     - 避免百分比削弱将属性扣到 0 或负数，采用渐进阻尼折减模型：
       $$\text{折减系数} = \frac{1}{1 + \text{weakenRatio}}$$
       $$\text{实际属性} = \frac{\text{原始属性}}{1 + \text{weakenRatio}}$$
     - 样例验证：原值 100 时，50% 衰减到 66.7，100% 衰减到 50，900% 衰减到 10。
