## 需求背景与核心目标

1. **行动卡片极致纯净化**：
   - 彻底移除行动卡片（`ActionCard`）上的详情与相关信息（包括加成/经验徽章、品阶/品质徽章、多行描述文本、右侧箭头等冗余元素）。
   - 卡片仅保留核心内容：行动图标（Glyph）与行动名称（Name）。
2. **右上角 LV 角标系统**：
   - 为所有行动卡片（炼丹、炼器、采集、修炼、历练/战斗等）添加统一的右上角角标（`item-corner item-corner--top-right`）。
   - 角标内部显示行动等阶/等级（如 `Lv.1`、`Lv.2`），等阶根据产出物品/装备等阶、遭遇等阶或输入材料等阶智能解析。
3. **横向大小与网格布局紧凑化**：
   - 调整行动卡片容器（`.action-cards`、`.action-group-list`）的横向尺寸与网格间距，从过去冗长宽大的 `minmax(260px, 1fr)` 重构为紧凑美观的网格排布（`minmax(130px, 1fr)`，移动端自适应 `minmax(105px, 1fr)`）。
   - 调整卡片高度与内边距，使其呈现规整的修仙方块/微型卡片形态，并保持移动端自适应。
