# TASK-20261109-02: 聊天传音表情、表情包（本地离线缓存与右键管理）与复读机（+1）系统

## 任务背景与核心目标

提升道化太初传音聊天的社交趣味性、互动性与表达丰富度：
1. **经典 QQ 风格矢量小黄脸与 Emoji 表情系统**：
   - 内置包含 28 个经典 QQ 小黄脸表情（`[微笑]`、`[呲牙]`、`[偷笑]`、`[滑稽]`、`[再见]`、`[流泪]`、`[发呆]`、`[得意]` 等），采用自包含纯 SVG 矢量图元物理隔离渲染（高光、红晕、渐变脸盘），零外部网络与图片依赖；
   - 聊天消息正文支持智能识别 `[表情名]` 并在行内混排渲染 20px 矢量表情；
   - 支持使用频次自适应排序（高频在先）；
   - 支持网络图片直链解析为图像，未加载前展示精致的修仙风格 `[图片]` 占位符；
   - 加载后结构化缓存至本地 **IndexedDB** 二进制存储，后续遭遇相同链接直接从本地提取秒开，零网络与流量消耗；
   - 聊天流中的所有表情包支持**鼠标右键一键「添加到表情包」**收藏；
   - 表情包具备使用频次自适应排序，且在表情面板中**支持右键「删除」**；
3. **复读机（+1）机制**：
   - 当同一频道/会话中连续出现 **两句及以上完全一模一样** 的消息（纯文本、Emoji、表情包链接均支持）时，在最后一句消息底部呈现 `+1` 图标胶囊；
   - 点击该图标自动替当前玩家向当前频道发送一条一模一样的消息，延续复读；
4. **输入框与表情选择面板**：
   - 底部输入框左侧增设表情入口按钮，点击呼出表情/表情包两级 Tab 浮层面板；
   - 点击表情或表情包可快速插入到输入框光标位置，右键表情包支持删除，并支持手动添加外链表情。

## 详细技术方案

### 1. 本地存储与频次管理 (`chatStickerService.ts`)
- **IndexedDB 图像缓存**：
  - 数据库名：`daohua_image_cache`，仓库名：`images`；
  - 存储对象：`{ url: string, blob: Blob, contentType: string, savedAt: number }`；
  - 优先读取本地 Blob，使用 `URL.createObjectURL(blob)` 渲染；未命中时通过 `fetch` 下载后写入 IndexedDB 并回调。
- **本地频次与元数据存储 (LocalStorage)**：
  - Emoji 使用计数：`daohua_chat_emoji_freq` -> `{ [emoji: string]: { count: number, lastUsedAt: number } }`；
  - 自定义表情包库：`daohua_chat_custom_stickers` -> `Array<{ url: string, count: number, lastUsedAt: number, addedAt: number }>`；
  - 排序算法：$O(N \log N)$ 优先按 `count` 降序，`count` 相同按 `lastUsedAt` 降序。

### 2. 富文本解析与表情包渲染 (`chatMarkup.ts` & `ChatMessageContent.tsx`)
- 扩展 `parseChatMarkup` 或构建专用匹配器：
  - 智能识别消息体内的图片链接（如 `http://...` 或 `https://...` 且包含常见图片后缀，或被特定标记包裹的直链）；
- 新建 `ChatSticker` 组件：
  - 状态流转：`loading`（展示 `[图片]` 修仙徽章占位符） -> `loaded`（展示受控最大宽高的表情图像，且自带圆角微光边框）；
  - 右键交互：绑定 `onContextMenu`，呼出 `FloatingPopover` / 浮层菜单「添加到表情包」。

### 3. 复读机（+1 机制）判定与组件 (`LogFeed.tsx`)
- 在聊天列表渲染管道中，检测相邻消息的重复性：
  - 遍历当前会话消息列表，对 `message.body.trim()` 相同的连续子数组进行折叠统计；
  - 当重复计数 $\ge 2$ 时，在最后一条消息的渲染节点下方追加 `<RepeatPlusOneButton />`；
  - 点击事件：执行 `gameClient.sendChat(channel, message.body, targetPlayerId)`，并累加发送频次。

### 4. 传音输入框与表情选择面板 (`ChatComposer.tsx` & `ChatEmojiPicker.tsx`)
- 输入框左侧放置表情图标按钮；
- 浮层面板（`FloatingPopover` 容器）内包含两个页签：
  - **表情 Tab**：精选修仙/高频 Emoji 网格，点击即插入光标；
  - **表情包 Tab**：已收藏表情包缩略图网格，未加载显 `[图片]` 占位，点击插入链接，右键弹出「删除表情包」菜单；
  - 附带快速「添加表情」输入框（URL 长度限制 200 字符内，符合服务端 `MaxBodyLength`）。
