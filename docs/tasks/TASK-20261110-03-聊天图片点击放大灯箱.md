# TASK-20261110-03 聊天图片点击放大灯箱

## 任务提出
- **提出时间**：2026-11-10 02:24:07
- **提出人**：用户
- **需求**：聊天消息中的图片（表情包/上传图片）左键单击后可放大查看图片细节，手机与 PC 都要兼顾。

## 需求理解与复述
聊天流内贴图当前仅以小图（max-height 88px / max-width 140px）展示，用户希望点按（PC 左键单击 / 移动端触摸点按）后弹出全屏灯箱查看大图细节，交互需同时兼顾桌面（hover 光标反馈、Esc 关闭）与移动端（触摸手势、双指缩放）。表情选择器内的贴图点击语义是「选表情」，不能误触发灯箱。

## 实现方案
- 新增公共灯箱组件 `frontend/src/components/ChatImageLightbox.tsx`（React Portal 全屏）：
  - 打开方式：PC 左键单击消息内贴图；移动端点按。
  - 缩放：PC 滚轮以光标为锚缩放；移动端双指捏合（pointer events 计算两指距离变化）。
  - 平移：缩放 > 1 时拖拽移动，边界钳位。
  - 关闭：Esc / 点击遮罩 / 右上角关闭按钮；双击（1↔2 倍切换）。
  - 复用 Modal 组件标准结构（`modal-backdrop`），灯箱专属样式 `.chat-image-lightbox*`。
- `ChatSticker` 增加 `zoomable` 开关（默认 false）：启用时左键单击/触摸点按打开灯箱，右键菜单（收藏/复制链接等）保持不变；表情选择器内不传该开关，行为完全不变。
- `ChatMessageContent.tsx` 消息正文渲染贴图时传 `zoomable`。
- i18n：`combat.chat.imageLightboxClose` 等新词条登记 combat.zh.ts；灯箱复用 `common.close`。
- 公共组件索引登记 `docs/frontend/common-components.md`。
