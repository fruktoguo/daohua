# TASK-20261110-02 野兔与铁甲熊重斩技能及掉落配置

## 需求分析与核心理解

- **业务目标**：
  为青云山前期核心野怪「魔化野兔」（minion）与精英怪「铁甲熊」（elite）扩充技能体系与掉落收益。使它们在战斗中具备主动释放「重斩」（`ability.heavy-slash`）及同系物理连击技能「连环」（`ability.chain-strike`）的战斗能力，并在战胜后按通用规则概率掉落对应技能秘籍（`item.tome.*`）与残卷（`item.fragment.*`），丰富前期战斗体验与物理剑法类功法获取途径。
- **核心逻辑预期**：
  1. **魔化野兔 (`enemy.demonized-rabbit`)**：
     - **战斗技能 (`skills`)**：新增 `skills` 槽位，配置 `ability.heavy-slash`（重斩，level 1, triggerHpRatio: 0.9）与 `ability.chain-strike`（连环，level 1, triggerHpRatio: 0.6）。
     - **掉落物 (`dropTable`)**：按通用 minion 爆率标准，追加重斩秘籍（`item.tome.heavy-slash`, p=0.001）、重斩残卷（`item.fragment.heavy-slash`, p=0.02）、连环秘籍（`item.tome.chain-strike`, p=0.001）、连环残卷（`item.fragment.chain-strike`, p=0.02）。
  2. **铁甲熊 (`enemy.armored-bear`)**：
     - **战斗技能 (`skills`)**：现有仅有 `ability.taunt`，补充配置 `ability.heavy-slash`（重斩，level 1, triggerHpRatio: 0.9）与 `ability.chain-strike`（连环，level 1, triggerHpRatio: 0.7），并保留 `ability.taunt`（嘲讽，level 1, triggerHpRatio: 0.5）。
     - **掉落物 (`dropTable`)**：现有已有重斩、嘲讽与铁布衫掉落，按通用 elite 爆率标准，补充连环秘籍（`item.tome.chain-strike`, p=0.005）与连环残卷（`item.fragment.chain-strike`, p=0.02）。
- **影响范围与实现边界**：
  - 配表修改：`config/game-data/monsters/tier1_minions.json`、`config/game-data/monsters/tier1_elites_bosses.json`。
  - 任务看板：`docs/tasks.md`、`docs/tasks/TASK-20261110-02-野兔与铁甲熊重斩技能及掉落配置.md`。
