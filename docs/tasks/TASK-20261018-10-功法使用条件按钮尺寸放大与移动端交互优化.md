# TASK-20261018-10 功法使用条件按钮尺寸放大与移动端交互优化

## 1. 任务背景与核心诉求

用户在使用功法面板与战斗配置时提出两点交互体验诉求：
1. **条件悬浮按钮尺寸过小不好点中**：
   - 功法瓦片框外浮现的条件按钮（`.item-slot-inline-action--condition`）目前字号仅 10px、内边距 2px 5px，实际可见尺寸仅约 30px × 18px；
   - 且伪元素扩展热区被 `display: none` 禁用，鼠标从瓦片滑向按钮时极易因 1~2px 的缝隙脱离 hover 链导致闪退，点击容错率极低；
   - 需要将按钮适度放大、优化排版与视觉质感，并通过伪元素建立无缝外扩热区（Hit Target），确保鼠标滑动与触控命中率 100%。
2. **手机端无 Hover 时如何唤出使用条件**：
   - 手机等触屏设备不存在鼠标 `:hover` 事件，导致条件按钮默认隐藏且不可见、不可点；
   - 槽位点击默认行为是挑选/更换功法，导致用户在移动端完全无法配置槽位功法的自动施放条件；
   - 需要设计健全的触屏交互体系：
     - **已装配槽位**：移动端触控模式下条件按钮直接常态显示，一目了然、点击直达；
     - **已学功法网格**：点击瓦片查看详情时，上方条件按钮同步浮现并保持激活可点；
     - **长按极速直达**：触屏长按瓦片（400ms，带滑动取消判定）直接打开触发条件编辑器。

## 2. 技术设计方案

### 2.1 按钮尺寸与热区外扩 (`frontend/src/styles/selection-grid.css`)
- 尺寸放大：
  - 字号提升至 `11px`，字重 `500`，字距 `0.5px`；
  - 桌面端内边距扩大为 `3px 9px`，移动端触屏内边距扩大为 `4px 10px`（最小高度 26px）；
  - 视觉升级为修仙暗金高亮胶囊（`var(--gold-light)`），带有微光边框与暗墨渐变底色；
  - 区分已配置条件（`has-triggers`）视觉：有配置条件时金色微光强调，增强状态感知。
- 命中区域（Hit Target）扩展：
  - 启用 `::before` 伪元素：`inset: -6px -8px;`，可点击命中区扩大至约 34px × 60px，与瓦片上缘无缝重合，滑动绝不失焦。

### 2.2 移动端触屏唤出架构 (`ConditionedTile.tsx` & `selection-grid.css`)
- **槽位移动端常显**：
  - 通过媒体查询 `@media (hover: none), (pointer: coarse)`，槽位卡片（`.abilities-slot-card`, `.combat-slot-card`）上的条件按钮直接常态可见并支持点击。
- **网格点击联动**：
  - `EffectTooltipTarget` 透传 `onOpenChange`，在 `ConditionedTile` 中感知悬浮卡打开状态；
  - 气泡展开期间为容器附加 `.is-tooltip-open` 类，触屏点击瓦片不仅展示技能介绍，其上方放大的「条件」按钮同步浮现可点。
