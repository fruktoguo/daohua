## 1. 需求背景与核心问题

1. **行动完成自动跳详情问题**：
   - 玩家在查看大地图或游历路线时，一旦正在进行的行动完成一次循环（或队列推进），页面会自动强制切换到「详情」（对决擂台）子标签页，打断玩家地图浏览体验。
   - **根因**：`ExpeditionPage` 内部包含对 `activeEntryId` 变动的 `useEffect` 强制调用 `setActiveSubTab('duel')`。

2. **大地图无法拖拽（Pan）**：
   - 当前大地图为固定容器，无法用鼠标或触屏拖拽漫游，大地图内容受限于固定视口。

3. **地点连线 Hover 区域过细且距离文字比例拉伸变形**：
   - 当前连线 Hitbox 较细且 SVG 使用 `preserveAspectRatio="none"` + `viewBox="0 0 100 100"`，导致非正方形视口下文字被横向/纵向拉伸变形，无法保持 1:1 正常视觉比例。

4. **玩家位置标记从“修”改为向下箭头，并默认居中玩家当前位置**：
   - 现存标记为带文字“修”的旋转菱形方块，用户要求改为向下的箭头（指示玩家在此处）；
   - 打开地图及切换位置时，视口中心应默认聚焦于玩家当前所在的地点/位置。

## 2. 技术设计方案

### 2.1 行动子标签页防劫持
- 移除 `ExpeditionPage` 中在 `activeEntryId` 变动时强制覆盖 `activeSubTab` 的逻辑，保持用户的当前选择。

### 2.2 虚拟像素坐标系与 1:1 比例消除拉伸
- 设定大地图虚拟画布标准尺寸（`1200 x 800`）。
- SVG 统一使用 `1200 x 800` 绝对像素坐标系，每个 SVG 单位精确对应 1 CSS 像素。
- 距离文本使用带背景微型胶囊的 `<g>` 标签渲染，居中对齐，字形比例 100% 正常无变形。

### 2.3 宽松 Hover 响应区与动态高亮
- 连线 Hitbox 设置为 32px 宽度的透明拾取层（`stroke: rgba(0,0,0,0.001); stroke-width: 32px; pointer-events: stroke;`）。
- Hover 时触发金色流光高亮与距离数值胶囊清晰显现。

### 2.4 视口漫游拖拽（Pan/Drag）与定位居中系统
- 在 Stage 容器层监听 Pointer 事件（PointerDown/Move/Up/Cancel）配合 `setPointerCapture` 实现平滑拖拽。
- 区分短按点击节点（移动距离 < 4px）与画布拖拽（移动距离 >= 4px）。
- 初始加载、地图变更或点击「定位」按钮时，依据视口宽高自动计算 `pan = { x: stageWidth / 2 - playerPx, y: stageHeight / 2 - playerPy }`，使玩家位置精确处于视口中心。
- 提供浮动快捷控制栏（定位当前位置、缩放微调、重置视口）。

### 2.5 玩家向下箭头指示标
- 采用翡翠/青玉色调的向下箭头矢量标记，带有发光核心与脉冲波纹。
- 在节点停驻时，箭头位于节点上方指向节点；在旅行移动时，箭头尖端直接指示行进轨迹。
- 添加柔和悬浮呼吸动效（Bobbing）。
