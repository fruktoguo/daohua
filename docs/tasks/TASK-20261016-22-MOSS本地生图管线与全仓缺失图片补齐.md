## 2. 核心技术规范与参数标准

- **画风规范**：东方古典修仙 2D 手绘厚涂（Painterly Thick-Coating with Subtle Ink Wash），深墨色外轮廓勾线（RGB ~25），严禁现代 3D 渲染与过度精细杂乱。
- **布局规范**：中心原点绝对坐标（`abs_centralized`，`yxyx`），象限之间预留 260px 以上纯白中缝，严格防跨界污染。
- **推理参数**：Euler + SGM Uniform，Steps 30~35，CFG 3.0~3.5，Shift 5.0，SLG Layer 22。
- **切片标准**：象限物理硬隔离切割 -> 自动去白底 -> 54px 边界等比居中下采样 -> 64×64 RGBA WebP（无损压缩）。
