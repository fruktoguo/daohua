## 一、 设计目标与核心规则

1. **开启时机与常驻养成**：
   - 角色到达 `Lv.30 半步筑基`（练气第 12 层，T3 起点）且本层修为圆满（达到含灵根乘区的升级所需修为瓶颈）时解锁「根基」；已处于 `Lv.31+` 的角色天然解锁。
   - 解锁后作为常驻养成系统保留（`GenjiUnlocked = true`），此后任意境界只要当前层修为足够本次消耗且未达当前境界根基上限，均可随时凝练，无需再次等待修为 100% 圆满。

2. **六维百分比增幅与显示**：
   - 每 `1` 点根基提升 `+1%` 全六维（体魄、经脉、根骨、力道、神识、身法）。
   - 单项根基加成点数向上取整：`bonus = (basePoints * genjiPoints + 99) / 100`（当 `basePoints <= 0` 或 `genjiPoints <= 0` 时为 `0`），有效六维 `effective = basePoints + bonus`。
   - 六维经验等级与升级成本曲线保持按原始经验导出不变；前端内视与名片显示格式为 `力道 96 (+32)`，衍生属性与战斗面板统一按有效六维结算。

3. **筑基突破前置条件**：
   - `Lv.30 半步筑基 -> Lv.31 筑基一层` 突破时，除修为圆满外，要求**任意一项有效六维（含根基加成）达到 `99` 点**（标准六维 `30×3=90` 点角色凝练 `10` 点根基即 `90 + 9 = 99` 可破境）。
   - `Lv.31` 之后的所有境界突破不再硬性要求根基。

4. **累计上限成长曲线（保留在上限池，档位覆盖不叠加）**：
   - `Lv.30 半步筑基`：初始上限 `30` 点。
   - `Lv.31` 起每升 1 级按突破档位覆盖追加上限：
     - 普通小境界突破（每大境 8 次）：`+4` 点
     - 中境界阶段突破（跨入第 4/7/10 层，每大境 3 次）：`+8` 点
     - 大境界突破（跨入筑基一层 `Lv.31`、金丹一层 `Lv.43`……飞升 `Lv.127`，共 9 次）：`+20` 点
   - 每个完整 12 层大境界共 `+76` 点（筑基一层 `50` 点，半步金丹 `106` 点，飞升满级 `658` 点）。

5. **对称守恒修为消耗曲线（受灵根破镜乘区影响，扣当前层修为 `Experience`）**：
   - 设当前境界升级所需修为（含灵根乘区）为 $E$（封顶级 `Lv.127` 回退末档非零修为基数），基准单点成本 $C_0 = 0.50 \times E$，当前境界根基上限为 $M$（恒为偶数，$H = M / 2$），当前根基点数为 $k \in [0, M-1]$：
     - 前 50% 区间（$k < H$）：相对倍率 $m(k) = 0.20 + 0.80 \times \frac{k}{H}$（$k=0$ 最低为正常要求的 `20%` 即 `10% E`）；
     - 达到 50% 后（$k = H + j, 0 \le j < H$）：$j = 0$（恰达 50% 处）相对倍率严格为 `1.00`（即 `50% E`），其后线性递增 $m(H + j) = 1.00 + \frac{0.80(H + 1)}{H(H - 1)} \cdot j$，将前 50% 节省的修为 100% 精确守恒挪至后 50%（最高单点约 `91%~92.7% E < 100% E`）。
