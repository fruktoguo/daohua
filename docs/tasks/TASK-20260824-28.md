## 1. 任务背景与核心目标

用户明确指示：**清理掉此前虚构的推倒性假设，专注完整实现“通用 Buff 实现器（Generic Buff / Modifier System）”**。

目标：
1. **构建通用 Buff 词缀与属性修饰器底层**：
   - 建立标准 `StatKeys` 属性常量池（涵盖气血、灵力、物攻、法攻、双抗、命中、闪避、攻速、移速、修为倍率、采集倍率、炼丹倍率等）；
   - 在 `BuffState` 中引入通用 `Modifiers`（`Dictionary<string, double>`）结构，并保持现有属性字段优雅兼容；
2. **统一领域推进引擎中的 Buff 查询解算器（`BuffEvaluator`）**：
   - 在 `SimulationEngine` 中统一通过泛型/通用查询方法获取修炼、采集、炼丹、移动等各维度的增益倍率；
   - 扩展支持大地图移动速度加成（`StatKeys.MovementSpeed`）等通用增益；
3. **战斗模拟器（`CombatSimulator` / `CombatGroupSimulator`）多维 Buff 提取对接**：
   - 战斗属性构建时全面支持从通用 Buff 提取伤害、攻速、双抗、暴击等词缀；
4. **协议与数据传输对齐**：
   - 更新 `BuffDto` 与 `StateMapper`，支持传输通用修饰器字典，前端展示自适应；
5. **单元测试与门禁验证**：
   - 补充通用 Buff 解析与跨行为增益测试，确保 `scripts/verify.sh` 全量通过。
