   - 新增 `TabId = 'changelog'`，接入桌面端侧边栏「其他（图鉴 / 排行榜 / 更新日志）」折叠分组（`SIDEBAR_OTHER_TABS`）与竖屏底部导航「更多」分组（`mobileNav.ts` `GROUP_OF_TAB` / `TAB_ICON`），共用延迟加载页面 `ChangelogPage`。

   - 玩家登录进入主游戏且目录 `catalogReady` 与首份快照 `hasReceivedSnapshot` 就绪（且非新手引导中 `tutorialStep >= TUTORIAL_DONE`）时，若存在本地未关闭的最新 `noticeId`，自动弹出 `ChangelogNoticeModal` 展示该期日志，并提供关闭（记录已读）与「查看往期日志」跳转按钮。
