## 一、核心需求与确认口径

1. **独立点数通道（每级 +1%）**：
   - 符箓技艺（`talisman`）每级提供 `+1` 点**符箓伤害增幅**（`talismanDamageBonusPoints`，Linear 曲线，100 点 = +100%）；
   - 阵法技艺（`formation`）每级提供 `+1` 点**阵法伤害增幅**（`formationDamageBonusPoints`，Linear 曲线，100 点 = +100%）；
   - 两项通道各自独立、互不交叉，且统一汇聚在属性点数字典中，便于后续符修/阵修流派特质与装备直接加算。
2. **乘区落点（第一层原始威力基数）**：
   - 位于大类抗性平方穿甲之前，与普攻增幅（`BasicAttackBonusPoints`）、技能增幅（`SkillBonusPoints`）完全对等：`RawDamage = 基础威力 × PercentValue.Multiplier(points, Linear)`，天然放大抗性穿透。
3. **严格作用域（仅造成伤害的符/阵）**：
   - **生效**：带 `strike` 打击规格的符箓（如 `item.leiji-talisman` 雷击符）及造成伤害的阵盘触发（`formation.tianlei` 天雷阵、`formation.xuesha` 血煞阵）；覆盖单人 PVE、组队/秘境、PVP 斗法及前端 TS 战斗模拟器。
   - **排除**：非伤害阵盘（聚灵阵回蓝、迷踪阵闪避）、阵盘维持与触发代价（天雷阵耗蓝、血煞阵自损气血）、普攻/功法技能（含 `style: "talisman"` 流派神通）、丹药恢复及装备反伤。血煞阵吸血按实伤结算，随伤害提升自然等比提高。
