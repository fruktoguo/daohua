## 2. 需求背景与核心目标

### 2.1 现状与痛点
- 功法筛选为三组二选一 Toggle（术法/内功、物理/法术、全本/残卷），配合最左侧「全部」开关；玩家必须先取消「全部」才能筛选，且每组只能在两端之间二选一，无法表达「这一维不过滤」。
- 材料、装备、消耗品仍使用单层扁平子 Tab（灵材/矿石/异材/精材、七种装备槽位、丹药/补给耗材），无法组合维度筛选（例如「物理系 + 头部」）。
- 全部品类均无品阶筛选维度。

### 2.2 核心目标与交互规范
1. **每维 Toggle 均含「任意」**：
   - 所有筛选维度统一为「任意 + 互斥选项」的单选 Toggle 组，「任意」等价于该维度不做过滤。
   - 移除功法最左侧「全部」开关及 `manualFilterAll` 置灰联动状态，改由三组各自「任意」表达放行。
2. **功法**：门类（任意/术法/内功）、伤害（任意/物理/法术）、形式（任意/全本/残卷），三组 AND 联合。
3. **装备**：
   - 类型 Toggle：任意/物理/法术/防御。判定以配表 `baseStatRatios` 攻击键为主、`flatStats` 兜底，无攻击键一律归防御（含护甲、减伤、回复、辅助类）。
   - 部位 Toggle：任意/武器/副手/头部/衣服/下装/饰品/工具（六个部位 + 工具）。
   - 勾选「工具」时类型 Toggle 整体置灰禁用（工具无战斗属性），过滤时忽略类型维度；改选其他部位即解除禁用。
4. **消耗品**：任意/战斗药品/战斗通用/技艺。判定以 `usableBars` 是否含 `combat` 为战斗域口径，战斗域内 `subCategory === 'pill'` 为战斗药品，其余为战斗通用；非战斗域（探索/炼丹/炼器等生活技艺栏域）归技艺。
5. **材料**：保留原有四类子 Tab（灵材/矿石/异材/精材），新增稀有度 Toggle：任意/普通/稀有。普通 = 一阶（含未配置 tier 的兜底一阶），稀有 = 二阶及以上。
6. **品阶下拉**：材料/装备/消耗品/功法四类均提供「品阶」原生下拉，默认「任意」，可切至 1~8 阶（与 `ITEM_GRADE_ORDER` 品质档一致）。品阶为跨维度全局过滤，与各 Toggle 取 AND。
7. **状态持久化**：所有筛选状态收拢至 `useMarketStore`，切换分类、进出详情页往返无损记忆。
8. **i18n 闭环**：新增词条纳入 `market.zh.ts`，通过 i18n 键覆盖门禁。

- `frontend/src/styles.css` + `theme.css`：分组标签、品阶下拉、浅色主题覆盖。
- `frontend/src/i18n/domains/market.zh.ts`：新词条。

### 3.2 判定口径
| 维度 | 口径 |
| --- | --- |
| 功法门类 | `ability.discipline === 'internal'` → 内功，否则术法 |
| 功法伤害 | `ability.category === 'physical'` → 物理，否则法术 |
| 功法形式 | `item.tome.` 前缀 / `subCategory === 'manualTome'` → 全本，否则残卷 |
| 装备类型 | `baseStatRatios.spellAttack` → 法术；`physicalAttack` → 物理；否则 `flatStats` 同键兜底；均无 → 防御 |
| 装备部位 | `resolveItemSubCategory` 取槽位，武器含 `two-hand`/`mainHandImplement`/`twoHandImplement`，饰品含 `ring`/`neck`/`talisman`，工具按 `tool-` 前缀 |
| 消耗品三分 | `usableBars` 含 `combat` + `pill` → 战斗药品；含 `combat` 非 pill → 战斗通用；其余 → 技艺 |
| 材料稀有度 | `tier >= 2` → 稀有，否则普通 |
| 品阶 | `max(1, floor(tier))` 与目标阶严格相等 |
