# TASK-20261027-14-悬浮窗超出视口自适应等比缩放

## 任务背景与核心目标

在移动端、竖屏模式（或屏幕高度受限的窗口）下，当物品、装备、功法或状态等同时挂载多个附属气泡（例如：数量副卡、坊市行情价格卡、招式参悟副卡、升级进度副卡、六维倾向说明副卡等）时，悬浮窗在窄屏（$\le 768\text{px}$）下会自动退化为垂直单列纵向堆叠（`flex-direction: column`）。

由于卡片内容较多，单列堆叠的总高度常达到 700px ~ 1000px+，容易大幅超出手机竖屏视口的高度（通常可用视口高度仅 600px ~ 800px），导致下方卡片直接延伸到屏幕之外，无法查看。

本任务的核心目标：
1. **自动溢出检测与等比缩放**：当悬浮窗自然总高度超出视口可用安全高度时，根据溢出比例自动计算整体缩放系数（`scale`），等比缩小整个悬浮窗，确保卡片全部进入视口。
2. **硬性缩放下限**：缩放比例最多缩小到 **50%**（`scale: 0.5`），避免因过度缩小导致文字与图元无法阅读辨识。
3. **定位与视口安全夹持联动**：将缩放后的物理尺寸（`naturalWidth * scale`, `naturalHeight * scale`）纳入视口安全坐标计算（Auto-Flip 与 Viewport Clamp），保证缩放后悬浮窗依然平稳对齐锚点、不偏移不漂移。
4. **内部滚动无缝兜底**：当在极限小屏下即使缩小到 50% 仍有溢出时，保持卡片内部纵向滚动（`overflow-y: auto`）兜底。
