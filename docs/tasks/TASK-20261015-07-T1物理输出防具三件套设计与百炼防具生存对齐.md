1. **补全 T1 物理输出防具三件套（头、胸、腿）**：
   - 解决 T1 阶段只有防御防具（束发巾、百衲甲、扎口裤）而缺乏与青锋剑/兽骨匕匹配的物理输出防具问题。
   - 新增 T1 物理伤害防具三件套：**劲风巾** (`equipment.jinfeng-scarf`)、**轻皮甲** (`equipment.qingpi-armor`)、**疾行裤** (`equipment.jixing-pants`)。
   - 定位：主要增加物理伤害（物攻、命中、暴击），略微生存（生命和些许护甲），每件附带 +2% 物理增伤 (`physicalDamageBonusPoints: 2`)。

2. **百炼防具（束发巾、百衲甲、扎口裤）对齐为纯生存/坦克套**：
   - 物理增伤改为物理减伤（每件 +2% `physicalDamageReductionPoints: 2`）。
   - 增加威胁增幅（`threatBonusPoints`）：胸甲 +15%，头和腿各 +10%（三件合计 +35% 威胁值），与劈山刀（+200 威胁）和精铁盾协同。

3. **锻造升阶链路完美对齐**：
   - T1 劲风巾 / 轻皮甲 / 疾行裤 作为前置材料，升阶为 T2 斩风巾 / 裂罡甲 / 踏风裤（物理输出线）。
   - T1 束发巾 / 百衲甲 / 扎口裤 作为前置材料，升阶为 T2 赤金盔 / 鱼鳞甲 / 踏阵胫（物理坦克线）。
