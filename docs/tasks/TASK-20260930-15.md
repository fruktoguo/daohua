- 分类：服务端架构 / ECS 深化 / 领域模型
- 状态：✅ 已完成（Domain 214/Ecs 39/Server 167 全绿，端到端冒烟验证通过）

## 背景

历史任务书（`equatorial-molybdenum` 会话）要求以 YuoCore ECS 为核心做三版本对比，其中明确列出：

- 玩家一根实体 + 粗粒度业务组件 ✅
- 怪物每怪一实体 + 共用 CombatantComponent ✅
- **地图节点长期实体（MapNodeEntity + NodeBuilding/EncounterProfile/NodePopulation）**
- 行动系统序 `Clock→Queue→行动→Yield→Completion` ✅
- **战斗系统拆分清单（CombatClock/Target/BuffTick/Cooldown/SkillCast/BasicAttack/DamageResolve/Death/Reward/EncounterResolution）**

对照后发现两处结构性缺口：

1. `MutatePlayer` 全量聚合往返（导出快照→Restore 聚合→改→回灌），组件不是命令操作面。
2. Update system 的 Run 体全是 `Pipeline.Find()?.DoX()` 单行转调，规则主体在静态引擎链。
3. 战斗 `AdvanceBoundary` 相位是过程式顺序调用，没走 `RunSystem<tag>` 实体派发。
4. `MapNodeEntity` 四个组件已挂但无消费面（人口/建筑/遭遇池未维护）。

## 阶段交付

### 阶段 1：命令去聚合往返

- 删除 `EcsActionState` 平行类型，统一为 `QueuedAction`。
- `PlayerAggregate` 新增 `Wrap` 视图工厂：分段字段直接引用组件持有 POCO（Progression/World/Resources/Combat/Buffs/Loadout/Settings/Duel/Actions）。
- `MutatePlayer`/`RemoveAction` 直接在组件状态上跑领域方法，只回写标量头字段（DisplayName/Presence/StateVersion/GameDataFingerprint/LastSimulatedAt）。
- 删除属性输入修订号续写 hack（`CaptureAttributeRevisions`/`ContinueAttributeRevisions`）。

### 阶段 2：Update system 工作区组件化

- `EcsActionPipeline` 并入 `EcsActionExecutionComponent`——请求期工作区字段+行为同体驻组件，消灭"组件挂 OOP 会话对象"的伪形态。
- `EcsActionSession` 静态服务承载跨阶段设施（边界求值、批量推进、战斗挂接、提交）。
- 修复 Commit 顺序 NRE（先构造结果再 Detach）。

### 阶段 3：战斗相位 tag 链

- 新增 `CombatPhaseDispatch`（ICombatPhaseDispatcher + Ecs/Inline 双路派发器）。
- 新增 `CombatPhaseSystems`：六个相位 system（ClockBoundary/PlayerRespawn/PlayerDowned/BattleAction/BuffTick/Outcome）经 `YuoWorld.RunSystem<tag>(entity)` 派发。
- `DeterministicCombatEngine` 相位方法抽出为共享实现，公式不复制。
- `CombatEncounterComponent.PhaseContext` 承载相位工作上下文。

### 阶段 4：MapNode 实体化

- `PlayerWorldComponent.CurrentNodeEntityId` 运行时引用 + `NodePopulationComponent.PresentPlayerEntityIds` 驻留集合。
- `EcsWorldShard.SyncNodeMembership` 统一维护点：CreatePlayer/RestorePlayer/MutatePlayer/RemoveAction/RunOnce commit/RemovePlayer。
- `ApplyNodeBuildingProjection` 镜像写节点 `NodeBuildingComponent.Effects/Buildings`。
- `CreateMonsterCore` 维护 `ActiveMonsterCount`。
- `IPlayerResourceContext.NodeEncounterIds` 默认接口成员：ECS 经 `EncounterProfileComponent` 返回，聚合路径回退配表。
- `ResolveCombatEncounterForAction` 遭遇池优先走实体组件。
- 修复 `EcsActionExecutionComponent.Entity` 隐藏 `YuoComponent.Entity` 基类成员的冗余字段。
