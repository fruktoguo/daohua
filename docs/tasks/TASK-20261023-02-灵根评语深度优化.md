## 1. 需求来源

用户要求深度优化开天门灵根评语，给出明确分级框架：

1. 单系顶级 → **天灵根**；
2. 次级纯系 → **真灵根**；
3. 双/三系按纯度分 **上品 / 中品 / 下品**；
4. 超过四系的低数值灵根 → **「X 系杂灵根」**（四系杂灵根 / 五系杂灵根）；
5. 五系皆弱皆全 → **废灵根**。

要求对标小说中公认体系。

## 2. 设定考证（公开设定综述）

- **《凡人修仙传》（忘语）** 是现代修仙灵根分级的事实源头：
  - **天灵根**：单一属性，修炼速度 2~3 倍，结丹无瓶颈，数百年一遇（「上天的宠儿」）；
  - **异灵根**：二/三种五行属性异变升华（雷/冰/风/暗），速度不逊天灵根——本项目五行框架无变异系，等价档位由「双系皆纯」承担；
  - **真灵根**：两或三种属性且每系充裕，修炼较快，自该级起有结丹之望（立足修仙界的资格线）；
  - **伪灵根**：四/五种属性混杂，灵气稀少混沌，基本无望筑基——即俗称的「杂灵根」，五系俱全皆弱的极端形态即通称的**废灵根**（网络修仙语境高度公认，如「我都五行废灵根了」一类作品直接入题）。
- 社区共识谱系（强度降序）：天灵根 ≥ 异灵根 > 真灵根（双 > 三）> 伪/杂灵根（四 > 五）≥ 废灵根；另有上品/中品/下品的传统三档品阶用语用于同级内细分。
- 命名语法公认惯例：`属性前缀 + 条数定性`（如「金木双灵根」「水火木金四灵根」），品阶词紧跟其后。

### 3.5 五系（5 条）——杂灵根与废灵根分界

| 条件 | 名称 | 印章 |
|---|---|---|
| 全 ≥90 | 「五行天灵根」 | 五灵根 · 天品 |
| 全 ≥75 | 「五行上品灵根」 | 五灵根 · 上品 |

### 3.6 评语（desc）写作规范

- 每档一句沉浸式修仙风味评语，25~40 字；
- 用词锚定公认语境：天灵根「上天的宠儿/灵气归一」、真灵根「结丹有望」、杂灵根「灵气驳杂/进境迟缓」、废灵根「五行混沌/仙路无望」；
- 废灵根评语保留一丝「逆天改命」的伏笔感（呼应逆天改命玩法）。
