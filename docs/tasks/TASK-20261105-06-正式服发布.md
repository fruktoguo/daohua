## 任务背景与核心目标

1. **核心缺陷修复**：
   - 角色「無名」及其他拥有生活技艺/装备/建筑加速加成的角色，其实际行动耗时为非整秒浮点数（如 2.00267 秒）。
   - ECS 批量自然边界模拟推进在裁剪出微步时，`AdvanceTimedAction` 错误按整秒量化累加进度（`action.ProgressSeconds += wholeSeconds;`），导致单步累加为 0 陷入不动点自旋，单轮耗时被切成数百个碎片微步，离线补算迅速击穿 `MaxTransitionsPerAdvance = 100_000` 熔断线，抛出 `DomainException: ECS 自然边界推进超过最大转换数。`，造成客户端无限卡在“正在连接服务器”以及冷挂机 Worker 判死。
   - 本次发布将该底层逻辑修复及回归测试更新至生产环境。
2. **发布范围**：
   - 主服（yuohira）：Docker 不可变镜像更新并受控烟测通过。
   - 计算节点（odin）：本次网络未通（Connection refused），经 `--skip-odin` 安全跳过，主服独立计算容器正常运转。
   - 移动端：编译打包带私有反多开保护的 Android 完全版 APK 并上传 GitHub Releases。
