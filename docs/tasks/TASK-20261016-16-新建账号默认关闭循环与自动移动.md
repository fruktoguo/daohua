## 1. 需求背景与目标

### 1.1 需求说明
玩家反馈：对于新建账号，顶部的「循环」和「自动移动」应该默认取消，也就是默认不要开启，因为会引起误导。
- 新建角色进行游戏时，如果「循环」默认勾选（开启状态），玩家添加如单次采集、单次炼丹或引导动作时，动作完成不会排空而是持续循环轮转，导致新手玩家困惑“为什么动作停不下来”、“为什么一直在重复”；
- 「自动移动」开轮地点不符时会自动插队旅行，若默认开启同样容易引发新手脱离当前驻留地的困惑；
- 因此，对于新建账号/默认角色偏好设置，顶部的「循环」（`LoopEnabled`）与「自动移动」（`AutoTravelEnabled`）开关必须统一默认关闭（`false`），由玩家后续按需主动勾选启用。

### 1.2 预期交付物
