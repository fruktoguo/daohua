# TASK-20261104-01 · 道化太初纯文字凌厉叠字图标设计与生成

## 1. 任务背景与核心需求

### 1.1 业务目标
为《道化太初》设计并生成符合官方上架标准（512×512 高清无圆角方图）的纯文字游戏主图标（App Icon），满足 TapTap 平台对正式应用图标的视觉品质与评级要求，同时契合修仙极简折面与冷峻金石美学。

### 1.2 核心布局与艺术设计要求
- **纯文字堆叠排列（叠字印章构局）**：
  - **「道」**：居于最上方，宏伟威严，统摄乾坤；
  - **「太」**：居于左侧，苍劲展开，构筑左翼骨架；
  - **「初」**：居于下方中轴，厚重沉稳，奠定基石；
  - **「化」**：居于右下角，回环收势，浑然天成。
- **线条风格**：
  - 凌厉线条：锋锐硬边折角、刀劈斧凿的几何折面笔画、金石阴刻切口与断笔错位；
  - 拒绝圆润软趴与普通行草，展现古典修仙界生死肃杀、天道无情的硬核质感；
  - 配色方案：玄墨底色（`#070604`）+ 凌厉金刚金石金纹（`#c9b46d` ~ `#f5d580`）与冷峻骨白（`#f5f5f4`）高光点缀。

### 1.3 实施方案（双轨保障）
1. **轨道 1：高精度几何矢量与金石质感渲染管线**：
   - 编写专业级矢量渲染脚本，严格按照用户指定的「道顶、太左、初底、化右下」构架，用多段贝塞尔曲线与锐利折面切割绘制四个核心汉字笔画，辅以先天八卦金框与阴刻呼吸槽，输出 100% 结构准确、毫无错别字变形的 512×512 PNG 工业级母模；
2. **轨道 2：MOSS-Image AI 结构化 Spatial Layout 管线**：
   - 构建 `abs_centralized` 坐标系的四区域精准 Layout JSON，以扩散模型探索更多金石风化与刀痕水墨交融的艺术可能性；
3. **交付与上传**：
   - 将最终母模归档于 `art/` 资产库；
   - 借助 `taptap-cli upload` 直接上传并更新至 TapTap 游戏资料草稿库，替换默认占位图标，消除 `DEFAULT_ICON` 警告。
