## 2. 需求与问题分析

1. **药品效果与持续增益副卡缺乏视觉层级**：
   - 现有的药品附属副气泡（`resolveItemAsideCards`）——包括修炼效率丹药（引气丹、通脉丹）、采集加成（寻灵香）、炼丹加成（地火引）以及战斗丹药持续 Buff（止血散、顺气丸等），依然使用原生的无序列表字符串数组（`ul > li`）平铺；
   - 缺少微光胶囊、色彩分类、粗细对比与修仙水墨微光氛围，视觉简陋，信息穿透力不足。
2. **Buff/Debuff 悬浮窗呈现形式单一**：
   - 全局 Buff 附属副卡（`createBuffAsideCard`）同样为纯文本列表；
   - 战场中的 Buff 小方格浮层（`CombatArena.tsx`）与内视面板 Buff 列表（`CombatAttributePanel.tsx`）将多条效果生硬拼为分号长句（`effectLines.join('；')`），阅读体验割裂；
   - 用户明确要求将市场价格悬浮窗的优质呈现（语义微光胶囊徽章、色调区分、粗体高亮数值、整洁网格布局）推广至药品效果与 Buff 悬浮窗中。

## 3. 实施方案

1. **结构化效果条目解析与组件设计 (`ItemDisplay.tsx` / `floating-popover.css`)**：
   - 提取统一的结构化 Buff / 效果条目模型（`StructuredEffectItem`）：
     - 徽章标签（如「修炼增效」、「气血回元」、「真元滋养」、「护体玄甲」、「疾风神行」等）；
     - 徽章修仙色调（`qi`, `jade`, `gold`, `crimson`, `danger`, `cyan`, `purple` 等）；
     - 高亮数值与单位（如 `+20%`、`+18 / 5秒`、`12.5%` 等）；
     - 辅助副文本（如持续时长、剩余时间、堆叠层数等）。
   - 实现轻量展示组件 `<EffectAsideBody items={...} />`，渲染为标准 `.daohua-effect-aside-row` 网格流；
2. **重构各处挂载点**：
   - `resolveItemAsideCards`：修炼加成、采集加成、炼丹加成、战斗丹药持续效果全面接入结构化内容；
   - `createBuffAsideCard`：实时 Buff 状态全面输出结构化 JSX `content`；
   - `CombatArena.tsx` 战场 Buff 浮层与 `CombatAttributePanel.tsx`：接入微光胶囊化效果列表展示；
3. **样式与主题适配 (`floating-popover.css`, `theme.css`)**：
   - 新增 `.daohua-effect-aside-*` 体系，支持各修仙五行色彩微光胶囊、等宽粗体数值高亮、持续时间专属徽标；
   - 补齐深色与浅色双主题高对比配置；
4. **多语言与契约闭环**：
   - 补齐 `market.zh.ts` 与 `template.csv` 中的效果胶囊词条；
   - 运行全量门禁与构建验证并自动提交。
