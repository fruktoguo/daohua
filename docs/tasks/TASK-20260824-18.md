## 1. 任务背景与核心目标

依据技术栈深度分析与多 Agent 并行审计发现的缺陷，全面实施系统级修复与加固：
1. **玩家最大离线时间（默认 48 小时，可扩展）**：
   - 在 `SystemConstants.cs` 中增加 `DefaultMaxOfflineDuration = TimeSpan.FromHours(48)`；
   - 在 `SimulationEngine.cs` 及 `ActionTransitionSystem.cs` 的离散事件推进中施加 48h 离线截断；
2. **单次任务最小最终耗时 0.1 秒（100ms）**：
   - 非战斗行动单次耗时保底 100ms，内部离散事件边界保持真实毫秒推进；
3. **单 Fiber 调度保护与熔断配额**：
   - 限制批次推演最大耗时与最大步骤，引入超时让出重新入队机制；
4. **确定性与装备排序**：
   - `CombatCatalog.cs` 装备属性聚合并行稳定排序；
   - 浮点数等值容差比较；
5. **存储、市场事务与运维优化**：
   - 市场挂单/撤单/结算内存轻量镜像与落库失败安全回滚机制；
   - CAS 版本冲突 3 次指数退避重试；
   - Durable Outbox 内存快照合并缓冲（Coalescing Buffer）与 autovacuum 优化；
   - WebSocket 断开解耦即时销毁实体，恢复 30s 宽限期；
   - 服务端与前端双向 Ping/Pong 心跳保活机制；
6. **前端状态同步、时钟模型与 UI 规范**：
   - 增量 Delta 版本空洞断层主动拦截并重拉全量快照；
   - 修正时钟静态偏差模型（`estimatedClockSkew`），彻底根治 5 秒突变回退抽搐 Bug；
   - 统一公共组件收拢与国际化词条归集。
