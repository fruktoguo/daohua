1. **核心调整**：暂时将全游戏中玩家「身家」显示、组队门槛与全服排行榜「身家榜」整体切换为**「道行」**（`board_id='valuation'`、协议字段 `valuation` / `minValuation` 保留不变以实现零数据库破坏性变更）。
2. **保留旧身家代码**：[ValuationMath.cs](../../src/Server/Clean/Social/ValuationMath.cs) 中原有的市场/回收价身家计算逻辑 `Compute` 完整保留不删除，仅暂时停用；业务统一调用新道行计算方法 `ComputeDaohang`。
3. **道行计算公式**（总值及各分项保留至多 2 位小数，`MidpointRounding.AwayFromZero`）：
   - **境界与根基**：`RealmLevel * 2 + GenjiPoints * 1.5`
   - **战斗装备**：`Σ 装备配表 level * (1 + 强化等级 * 5%)`（仅统计穿戴的非 `tool-*` 战斗装备；**技艺工具不算**；强化等级向下取整非负）
   - **携带功法**：`Σ 携带槽位非空功法等级`（统计 `Loadout.AbilitySlots` 中 0 号内功心法及 1~4 号主动神通，空槽与「符法·天命」装配的符箓 `item.*` 不计）
   - **携带特质**：`Σ 特质消耗点数 * (1 + 对应特质等级 * 5%)`（统计 `Progression.TraitIds` 激活携带特质，消耗点数取 `CombatTraitRules.AllTraits`，等级取 `Progression.UnlockedTraits`，缺省 1 级）
4. **边界与取舍**：
   - `ValuationBreakdownDto` 兼容追加可缺省字段 `RealmAndGenji`、`Traits`（保留既有 `Equipment`、`Abilities`、`Tools` 字段默认 `0`）。
   - 悬停构成卡片改为展示 **道行构成**：境界根基 / 战斗装备 / 携带功法 / 携带特质 四项（当仅存在旧口径字段且无道行新增项时兼容回退展示）。
   - 追忆副本配表 `recommendedValuation`（`1,500 ~ 4,000万`）沿用旧身家量级，本期暂不改动副本推荐文案与数值，避免量级错位。
5. **额外交付**：改完后基于正式服当前境界排行榜前十玩家最新落盘状态只读核算精确道行。
