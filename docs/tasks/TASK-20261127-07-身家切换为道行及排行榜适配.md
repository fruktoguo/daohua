3. **道行计算公式**（总值及各分项保留至多 2 位小数，`MidpointRounding.AwayFromZero`）：
   - **境界与根基**：`RealmLevel * 2 + GenjiPoints * 1.5`

   - **携带特质**：`Σ 特质消耗点数 * (1 + 对应特质等级 * 5%)`（统计 `Progression.TraitIds` 激活携带特质，消耗点数取 `CombatTraitRules.AllTraits`，等级取 `Progression.UnlockedTraits`，缺省 1 级）
4. **边界与取舍**：
   - `ValuationBreakdownDto` 兼容追加可缺省字段 `RealmAndGenji`、`Traits`（保留既有 `Equipment`、`Abilities`、`Tools` 字段默认 `0`）。
   - 悬停构成卡片改为展示 **道行构成**：境界根基 / 战斗装备 / 携带功法 / 携带特质 四项（当仅存在旧口径字段且无道行新增项时兼容回退展示）。
   - 追忆副本配表 `recommendedValuation`（`1,500 ~ 4,000万`）沿用旧身家量级，本期暂不改动副本推荐文案与数值，避免量级错位。
