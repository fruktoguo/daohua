## 2. 最终效果与属性口径

| 名称 | 品阶 / 点数 | 实现规则 |
| :--- | :--- | :--- |
| 初见 | 玄品 / 8 | 开战获得 2 秒闪避后段 +300% Buff，即闪避面板乘 4；不直接增加闪避概率 |
| 欲速则不达 | 地品 / 10 | 行动速度 +100 点，伤害/治疗增幅各 -100 点；目标生命大于 1 且本次致死时先留 1，后续伤害可击杀 |
| 我要打十个 | 地品 / 12 | 按存活敌人数减 1 叠层，每层总增伤与免伤各 +10 点；人数变化即时更新 |
| 单挑王 | 天品 / 16 | 双方各存活一名单位时，总增伤、免伤、暴击伤害、行动速度各 +20 点；人数变化即时启停 |
| 蓄意 | 灵阶 / 25 | 实际扣血积为层数；下一次命中攻击若层数严格超过最大生命，先全部消费，主目标受等量真实伤害，其余存活敌人以层数为物理威力结算；爆发不再积蓄意 |
| 燃魂 | 天品 / 16 | 直接火伤按实际扣血的 2% 向下取整、最低 1 层；目标存活且实际扣血大于 0 才施加，叠层并刷新 5 秒。每层每秒 1 点火属性术法威力，按常规减免链结算；自身跳伤不自叠或触发命中反应 |
| 看不到我 / 力微饭否 | 玄品 / 各 8 | 保留原效果，隐身时长继续按特质等级成长 |

- 百分比沿用既有点数与乘区：负 100 点对应乘 0.5，负 200 点对应乘 1/3；同通道与其他来源相加。正 10/20 点免伤对应约 9.09%/16.67% 最终减伤。
- 正向数值沿用每级 +5% 线性成长：初见闪避、欲速行动、人数增益、蓄意积蓄速率和燃魂施加比例成长；负面、固定时长、蓄意阈值与燃魂每层威力不成长。
- 新战内 Buff 每波清除。燃魂使用现有整秒自然边界，到期同刻先跳伤再移除；单一状态由最后施加者承担后续归属，来源随快照保存。
- 数值与装配点数按用户给定值锁定；初见基础百分比预算为 300 点、限时 2 秒，持续时间与其余特殊机制按 data-designer 的人工平衡范围处理，未套用装备/技能预算擅自重配。
