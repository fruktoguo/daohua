## 2. 已对齐的核心需求与边界
1. **全局技艺经验翻倍（乘数 ×2）**：
   - 在基于目标行动等级与基础耗时的技艺经验计算公式 `Math.Round(BaseExperienceForLevel(level) × (durationSeconds / 10.0) × multiplier)` 中引入全局乘数 `2.0`。
   - 覆盖全部七项已知技艺的常规计时行动、装备强化与秘法排队操作（化灵/分解/转化）。
   - **神识经验独立保持原倍率不变**：装备强化与秘法操作附带的六维·神识经验维持原公式，不因 `techExp` 翻倍而被连带放大。
2. **消耗上级装备的炼器行动额外再翻倍（总计 ×4 原基线 / ×2 新基线）**：
   - 乘数叠算：全局 `2.0 × 2.0 = 4.0`。
   - 严格判定条件：`action.Technique == "forging"` 且配方 `Inputs` 中包含至少一件数量 `> 0` 的 `equipment.*` 上级装备（即当前 Lv.12/16/18/20/22/24 升阶锻造；精确排除暂无上级装备消耗的 Lv.1 装备/工具、Lv.9 散件及 `item.*` 材料精炼）。
3. **全技艺产出等同技艺经验的「底蕴（Foundation）」**：
   - 每次通过 `GrantTechniqueExperience` 授予技艺经验时，**无论当前修为是否圆满、是否处于瓶颈**，同步向 `Progression.Foundation` 直接累加等额底蕴，并标记 `Progression` 分段脏状态。
   - **不经过 `CreditExperience`**：不会直接转为当前修为 `Experience`、不增加 `LifetimeExperience`（防止后续打坐消耗底蕴放大修为时重复计入）、不增加 `CombatExperience`、不直接触发突破；供生活玩家通过打坐修炼放大突破。
   - 同步记录进 `PlayerStatsDelta.Foundation`（与 `TechniqueExperience` 同条或同轮累计到行动实例/离线/每日三账本的 `foundation` 净变动）。
4. **前后端统一收敛与 UI 预览**：
   - 后端抽拢共享计算入口 `TechniqueCatalog.ComputeTechniqueExperience` 与 `IsEquipmentUpgradeForgingAction`，替换散布在 `ActionExecutionRules.Timed.cs`、`SecretArtRules.cs` 的重复内联公式，并同步 `PlayerAggregate.GrantTechniqueExperience`。
   - 前端抽拢 `calculateTechniqueExperience` 与 `isEquipmentUpgradeForgingAction` 至 `combatConstants.ts`，更新 `calculateEnhancementYields` / `calculateSecretArtYields` 与 `ActionModal`，并在 `ActionModal`、`EnhancementPage`、`SecretArtOperations`（感悟区块）及 `CombatArena`（强化行动目标产出列表）新增「底蕴」预览。
