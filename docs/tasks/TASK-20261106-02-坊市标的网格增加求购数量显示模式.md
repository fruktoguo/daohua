## 需求理解与实现边界

### 1. 业务目标
当前坊市浏览网格（`MarketBrowseGrid`）标的卡片右下角的数量角标仅提供「持有 (owned)」与「在售 (onSale)」两种显示模式。玩家在寻找商机、清仓出售或观察市场流动性时，无法快速直观获知全服有哪些物品存在玩家挂出的买单（求购单）以及需求总量。
本次优化在标的网格的角标数量显示模式中新增「求购 (bid)」选项，形成「持有 / 在售 / 求购」三态切换，使玩家能够一键全局鸟瞰所有物品的全服求购活跃量。

### 2. 核心逻辑与实现方案
1. **状态模型扩展**：
   - `MarketAmountDisplayMode` 从 `'owned' | 'onSale'` 扩展为 `'owned' | 'onSale' | 'bid'`，默认保留 `'owned'`；
   - `toggleAmountDisplayMode` 升级为三态顺次循环：`owned` -> `onSale` -> `bid` -> `owned`；
   - `setAmountDisplayMode(mode)` 支持直接赋值指定模式。
2. **数据聚合模型**：
   - 利用 `useGameStore` 中已持续维护的 `marketStats: Record<string, MarketItemStats>`；
   - 每个变体簿条目具备服务端的权威 `bidQuantity`（当前全服活动买单剩余总量）；
   - 在 `MarketBrowseGrid` 中构建 `marketBidMap`（同 `marketOnSaleMap` 结构：按 `itemId` 累加全部变体级别的 `bidQuantity`，`O(1)` 高性能检索）。
3. **UI 与交互设计**：
   - 顶部胶囊切换控件由两项扩展为「持有 / 在售 / 求购」三项分段控件，无障碍语义升级为 `role="radiogroup"` 与 `role="radio"`；
   - 支持直接点击对应选项直达，按钮 hover 与 active 高对比视觉反馈；
   - 视觉样式区分：
     - 在售模式：暖金/赤橙高亮（`.is-onsale-mode`）；
     - 求购模式：碧青翡翠高亮（`.is-bid-mode`），角标边框与字体采用 `#8fc3a6` / 浅色模式 `#277850`，与坊市悬浮副卡的买盘色调完全一致；
4. **无障碍与国际化**：
   - 新增 `market.browse.amountMode.bid`（'求购'）；
   - 新增 `market.browse.itemBid`（'{name}，求购 {count}'）；
   - 同步更新 `template.csv` 与英文/中文词典，保证无键名裸露，通过 `check-i18n-keys.mjs`。
5. **单测覆盖与门禁验证**：
   - 在 `frontend/src/game/marketOrders.test.mjs` 中补充 `marketBidMap` 聚合逻辑、数量角标映射与 i18n 文案自洽断言；
   - 跑通 `scripts/verify.sh --full` 全量门禁（Release 构建、单元测试、领域测试、ECS 测试、服务端集成测试、前端 189 项单测、生产打包与 Compose 校验）。
