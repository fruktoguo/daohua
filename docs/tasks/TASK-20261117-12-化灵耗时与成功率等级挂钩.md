# TASK-20261117-12 化灵耗时与成功率按物品等级挂钩

## 需求复述与口径确认

- **提出时间**：2026-11-17 20:05:53
- **用户原始需求**：
  1. 化灵基础耗时 5 秒，被化灵物品每提升 1 级，耗时 +0.3 秒，1 级物品仍为 5 秒；
  2. 化灵引入成功率：基础 100%，自身化灵等级低于物品等级时每低 1 级成功率 −5%，下限 20%。
- **裁定口径**（用户确认）：
  - 「化灵等级」= **秘法技艺等级**（`enhancement` 技艺累计经验折算等级，与装备强化共用）；
  - 「物品等级」= 配表显式 `level`（`CraftingRecipeRules.ResolveItemLevel`，缺省 1），**装备强化 `+N` 变体不计入**；
  - **失败后果**：物品照常消耗并焚毁，不产出灵石；技艺经验与六维·神识经验按当次基础耗时照常结算（耗时已真实消耗）。
