# TASK-20261109-07: 聊天传音输入框图片粘贴直传、SHA-256哈希去重复用、账号每日20张配额与图床签名鉴权体系

## 任务背景与核心目标

为《道化太初》传音聊天输入框（`ChatComposer`）提供丝滑、安全、低成本的表情与截图发送体验，杜绝图床被外人恶意滥用与存储膨胀：
1. **输入框剪贴板图片直接粘贴上传 (`Ctrl + V`)**：
   - 玩家在传音输入框中直接粘贴剪贴板截图或图片时，前端自动拦截并识别图片二进制流，展示上传中的轻量反馈；
   - 上传完毕后将生成的直链自动插入光标所在草稿位置，支持即刻回车发送。
2. **完全一致图片客户端与全服级 SHA-256 哈希去重复用**：
   - 上传前计算图片的 SHA-256 摘要；
   - **客户端本地去重**：若本地 IndexedDB/内存已存在该哈希，直接取回已有链接秒开返回，**0 网络请求、0 流量、0 额度消耗**；
   - **全服与图床级去重**：图床对象键基于哈希命名（如 `hash[0..16].ext`）。主服与图床先检查是否已存在同哈希文件，已存在则直接返回既有直链，不重复落盘 R2，**且不扣减当日配额**。
3. **单账号每日最多上传 20 张图片配额拦截**：
   - 由道化主服统一进行账号级每日上限控制（自然日 UTC/UTC+8 00:00 重置）；
   - 超出 20 张后拒绝签发上传凭据，返回友好的业务提示。
4. **自建 Cloudflare 图床防范与道化账号签名鉴权**：
   - 杜绝完全无防范的公开暴露：Worker 上传接口仅接收携带有效道化主服 HMAC-SHA256 签名凭据（Upload Ticket）的请求；
   - 凭据绑定 `accountId`、`hash`、`ext` 与短期过期时间（5分钟），Worker 端校验不通过直接 `401/403` 拒绝；
   - 现有的 Web 上传页面增加防范提示，禁止非鉴权请求随意上传。

## 架构与技术方案

```
[前端 ChatComposer]
    │ 1. 拦截 Ctrl+V 提取图片 Blob，计算 sha256
    │ 2. 查本地 IndexedDB -> 命中则直接返回 URL (0 开销)
    │
    ▼
[道化主服 POST /api/v1/chat/upload-ticket]
    │ 3. 校验 HttpOnly Cookie 会话 (未登录 401)
    │ 4. 查内存/去重表 sha256 -> 命中直接返回已有 URL，不扣额度
    │ 5. 校验该账号当日计数 < 20 (超额返回 429 配额用尽)
    │ 6. 生成 HMAC-SHA256 签名 Ticket (含 accountId, sha256, 5分钟过期)
    │
    ▼ 返回 { ticket, uploadUrl, targetUrl }
[前端向 Cloudflare Worker POST /upload]
    │ 7. Header 携带 X-Upload-Ticket
    │
    ▼
[Cloudflare Worker]
    │ 8. 校验 HMAC 签名与哈希匹配，无效直接 401
    │ 9. 检查 R2 是否已有对应 Key -> 写入 R2 并返回直链
```
