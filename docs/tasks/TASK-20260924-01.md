# TASK-20260924-01 · 总纲拆分为 13 篇文件夹 + 查看器自动拼接与页内跳转

## 需求

1. 将 `docs/design/总纲.md`（13 篇）拆分到 `docs/design/总纲/` 文件夹，每篇一个 md 文件；
2. 查看器 `总纲.html` 改为自动读取文件夹内全部文档、自动拼接组合成一个网页；
3. 网页中点击链接当前新开一页，改为页内跳转。

## 方案

- 拆分：`01-核心哲学与顶层定位.md` … `13-行动统计系统三账本.md`（按 `# 第N篇` 边界切分）；文首标题与目录页落入 `README.md`（目录链接改写为 `./NN-*.md`）；篇内指向 design/ 兄弟文档的相对链接统一加 `../` 前缀。
- 查看器迁入文件夹为 `index.html`：
  - 数据源优先 `fetch('./manifest.json')` → 逐个读取篇目 md → 以 `<!-- FILE:文件名 -->` 哨兵拼接渲染（HTTP 访问时永远读最新）；
  - `file://` 直开时 fetch 不可用 → 回退内嵌快照（由同步脚本生成，取代手工同步），并提供「选择文件夹」按钮（`webkitdirectory`）与拖入文件夹支持读取最新文档；
  - 链接分流：`#锚点` 与指向已加载篇目 `NN-*.md(#anchor)` 的链接 → 页内 `scrollIntoView`（GitHub 风格 slug 映射到标题 id）；外部 http 与文件夹外 md 保持新开页。
- `scripts/sync-master-viewer.mjs`：扫描文件夹篇目 → 重写 `manifest.json` + 内嵌快照块，改 md 后一键同步。
- `design/总纲.md` 保留为指引 stub（指向文件夹 README 与 index.html），全仓既有引用零破坏。
