# TASK-20261016-11 引气入体灵石加速修炼

## 1. 任务背景与核心需求

用户希望在现有基础打坐行动「引气入体」（`cultivation.draw-qi`）中增加灵石加速选项，替代单独拆分新行动的方案：
1. **多档位选项框**：
   - 引气入体行动弹窗中增加灵石注灵选项框，支持选择：`0`（默认）、`1`、`10`、`100`。
   - 基础加成分别对应提升：`+0%`（$1.0\times$）、`+20%`（$1.2\times$）、`+100%`（$2.0\times$ 翻倍）、`+300%`（$4.0\times$ 四倍）。
2. **结算与扣减规则**：
   - 消耗是指每次完成单轮时扣除对应数量的灵石（`currency.spirit-stone`）；
   - 若灵石不足，自动降级为标准行动（不扣灵石，按 $1.0\times$ 产出结算，不中断挂机队列）；
3. **加成性质与收益范围**：
   - 提升基础值（重算逻辑）：直接放大基础值，后续持续消耗品（引气丹等）、灵脉倍率在此放大基数上重算；
   - 收益覆盖范围：仅放大**修为**（`experience`）与**灵力**（`mana`），六维经验（根骨与经脉）保持定额不放大。

## 2. 详细技术方案

### 2.1 契约与协议数据流
- 入队意图：`ActionIntent.Parameters` 原生字典支持，写入键 `"spiritStone": 0 | 1 | 10 | 100`；
- 服务端解析与下发：
  - `action.enqueue` 命令解析 `ActionIntentRequest.Parameters` 并赋值给 `ActionIntent.Parameters`；
  - `ProtocolSnapshotMapper.ToActionQueueSection` 下发 `intent`，前端可从 `action.intent?.parameters?.spiritStone` 直接读取当前执行档位。

### 2.2 服务端与领域层结算 (`ActionExecutionRules.Timed.cs`)
- 在 `CompleteRepeat` 中：
  - 判定当前行动是否为 `cultivation.draw-qi` 且配置了 `spiritStone > 0`；
  - 检查有效资产余额 `EnhancementRulesEffectiveBalances(assets, deltas)` 中的 `currency.spirit-stone`；
  - 若余额 $\ge$ 对应档位：
    - 记录消耗 `spiritStoneDeduction = tierCost`；
    - 在 `deltas` 扣除对应数量灵石，并记录在账本 `itemLosses`；
    - 设定 `cultivationBaseMultiplier = tierMultiplier`（1.2 / 2.0 / 4.0）；
  - 若余额不足或未配置：
    - 不扣除灵石，`cultivationBaseMultiplier = 1.0`；
  - 遍历 yields 收益时：
    - 仅对 `yield.Kind is ActionYieldKind.Experience or ActionYieldKind.Mana` 应用 `yield.Amount * cultivationBaseMultiplier`；
    - 随后与 `autoUseMultiplier` 复合，进入常规修为与灵力入账逻辑；六维经验定额不受影响。

### 2.3 前端交互与产出解算
1. **产出实时预估 (`actionCalculations.ts`)**：
   - `calculateActionYieldPreview` 支持可选参数 `parameters?: Record<string, number>`；
   - 若包含 `spiritStone`，且为修炼行动，计算 `spiritStoneMultiplier` 并加入 `bonuses` 明细标签；
   - `resourceBaseMap` 中 `experience` 与 `mana` 基础值乘上 `spiritStoneMultiplier`。
2. **行动弹窗 (`ActionModal` in `App.tsx`)**：
   - 若 `action.id === 'cultivation.draw-qi'`，在次数选择器上方渲染「灵石注灵」选项组件（4 档胶囊单选：不消耗 / 1 灵石 / 10 灵石 / 100 灵石）；
   - 切换档位时联动更新本地状态 `spiritStoneTier`，并实时反映到顶部的单轮修为、灵力产出预览；
   - 提交入队时，将 `parameters: { spiritStone: spiritStoneTier }` 作为 payload 一同发送给 `action.enqueue`。
3. **队列展示 (`ActionQueue` / `NearbyPanel`)**：
   - 队列卡片上对带有注灵档位的引气入体展示醒目胶囊徽章（如 `💎 10/轮`），增强挂机感知。
