## 2. 需求背景与核心设计

用户要求整合原本零碎细分的单技艺消耗品，改为全百艺通用的技艺加速物品，并保留强化成功率专属物品：
1. **通用技艺加速物品**：
   - 1级（凡人巅峰）：**定神香**（`item.dingshen-incense`），通用百艺行动速度 **+30%**。
   - 18级（炼气期·叩天门）：**青灵香**（`item.qingling-incense`），通用百艺行动速度 **+50%**。
   - 覆盖范围：采药、采矿、炼丹、锻造、制符、布阵等全部有耗时的生活技艺行动。持续时间 300 秒（5分钟），配置在对应栏位自动维持生效。
2. **强化专属成功率消耗品**：
   - 1级（凡人巅峰）：**淬灵粉**（`item.cuiling-powder`），强化单次判定成功率 **+3%**。
   - 18级（炼气期·叩天门）：**固灵砂**（`item.guling-sand`），强化单次判定成功率 **+5%**。
   - 持续时间 300 秒，配置在强化自动栏位（AutoUseBar.Enhancement），生效期间强化成功率直接加算。

## 3. 技术落地规划

1. **领域模型扩展**：
   - `ConsumableDefinition` 新增 `TechniqueSpeedRatio` 与 `EnhancementSuccessBonus`。
   - `TimedActionDurationRules.cs` 在技艺耗时除数中引入 `EffectiveConsumableSpeedRatio`：
     $$\text{Duration} = \frac{\text{BaseDuration}}{1 + \text{技艺等级} + \text{装备工具} + \text{灵根加成} + \text{消耗品速度加成}}$$
   - `EnhancementRules.cs` 在成功率结算中接入消耗品加成 `consumableBonus`。
2. **配表与白名单**：
   - `config/game-data/items/pills.json` 录入定神香、青灵香、淬灵粉、固灵砂。
   - `src/DataTool/Program.cs` 授权键支持 `techniqueSpeedRatio` 和 `enhancementSuccessBonus`。
3. **前端对齐**：
   - `frontend/src/game/ids.ts` 登记元数据。
   - `frontend/src/i18n/domains/game.zh.ts` 与 `market.zh.ts` 补充词条，导出 `template.csv`。
