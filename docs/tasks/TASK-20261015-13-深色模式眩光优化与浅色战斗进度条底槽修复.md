# TASK-20261015-13 深色模式眩光优化与浅色战斗进度条底槽修复

## 1. 任务背景与核心需求

### 1.1 现状与问题归因
1. **深色模式眩光与光晕效应（Halation Effect）**：
   - 物品槽位底色接近纯黑（`#070604`、`rgba(0,0,0,0.5)`），外框使用了高明度冷银白（`rgb(194, 207, 220)`，加粗 1.5px）和高饱和荧光绿（`rgb(69, 179, 107)`）。
   - 暗光下瞳孔放大，人眼中约 30%~40% 散光人群在纯黑底与高对比亮细线交界处产生强烈散射重影。
   - 每个物品格子内部叠加了左上角丝带、右上角 Lv.X 胶囊与右下角 ×0 胶囊，胶囊均带 `border: 1px solid 66% 亮线` 与 `box-shadow: 0 0 7px` 外发光，4×5 网格一屏塞入 80+ 条高频发光细线，引发视网膜视觉噪点与赫曼方格交点闪烁疲劳。
2. **浅色模式战斗进度条可读性漏洞（黑字叠黑底）**：
   - “讨伐 青云山门”等战斗行动卡片下方的敌我双血条（`.queue-combat-vital`）在 `styles.css:1071` 底槽固定为纯黑 `#090805`，但在 `theme.css` 中完全缺失浅色模式重写。
   - 浅色模式下，条内文字（“己 131/220”、“敌 751/2380”）跟随浅色主题变为深墨色 `--text: #2b2417`，未填充区域直接形成黑字叠黑底，彻底丧失可读性。

### 1.2 改造目标
根据用户指示修复问题 1 与问题 2（零库存降权等其他后续项暂不涉及）：
- **目标 1（深色眩光与光晕优化）**：
  - 抬升深色大背景与面板底色（`#070604` → `#151412`、面板 → `#1b1a17`），压缩极限黑白对比度。
  - 物品瓦片底色提亮至阶梯暗灰（RGB 28~36 ≈ `#222120`），用面明度差取代硬亮线。
  - 削弱品质边框锐度：凡品取消 1.5px 粗线改为 1px、使用低透明度柔和灰白；黄阶压暗降饱和为沉稳暗翠色 `#2b6e46`。
  - 削弱胶囊 `.item-corner` 锐度：移除亮色描边与 `0 0 7px` 外发光，仅保留半透明深色底衬，文字改为柔和浅灰 `#c5bfb0`/`#c8c3b7`。
- **目标 2（浅色进度条可读性修复）**：
  - 在 `theme.css` 中补齐 `.queue-combat-vital` 与 `.progress` 浅色模式适配，底槽改为温润浅米褐色，文字保持深墨色并辅以全向柔和白光晕描边，确保填充与未填充区域均清晰可辨。
