# TASK-20261001-09 顶栏太极主题快捷开关与圆形扩散换色过渡

- 提出与需求分析时间：2026-10-01 21:58:00（北京时间）
- 状态：🚀 进行中
- 需求：顶栏放置可旋转的太极图，点击快速切换浅色/深色并伴随旋转；切换时从点击点（右上角区域）做全屏圆形扩散过渡——扩散区内呈现目标主题、区外保持旧主题，动效要丝滑。

## 设计与范围

1. `game/themeStore.ts`：`setTheme(theme, origin?)` 支持扩散圆心参数，新增 `toggleTheme(origin?)`；切换经 `document.startViewTransition` 快照新旧主题，`::view-transition-new(root)` 上做 `clip-path: circle()` 从圆心扩散动画（`cubic-bezier(0.22,1,0.36,1)` ~680ms）；不支持 View Transitions 或 `prefers-reduced-motion` 时直接切换。
2. `components/TaijiToggle.tsx`：新组件——阴阳双色 SVG 太极图（阳面浅黄纸 #f8f4e4、阴面玄墨 #12100b，固定取两主题底色），常态静止（2026-10-02 起取消自转），点击经内层 `--taiji-spin` 变量追加 180° 旋转并把按钮中心作为扩散圆心调 `toggleTheme`；盘底取偏差中间色（浅 `#e7dcba` / 深 `#252017`）避免双鱼与底色融没。
3. `App.tsx`：顶栏末尾挂载 `<TaijiToggle />`；`.topbar` 栅格增一列 `auto`；移动端（≤960px）顶栏第二列自然落于右上角。
4. `styles.css`：`.taiji-toggle`/`.taiji-spin`/`.taiji-icon` 样式与 `taiji-drift` 关键帧；`::view-transition-old/new(root)` 关闭默认交叉淡化并固定层级（new 在上）。
5. `SettingsPage` 分段主题按钮透传点击坐标为扩散圆心；i18n 增加 `app.topbar.themeToLight/themeToDark`。
6. 设计文档 §13.1.1 补充快捷开关与过渡动效描述。

## 验证

- `npm --prefix frontend run build`
- 目检：顶栏太极常旋、点击旋转 + 圆形扩散换色、设置页切换同样触发扩散
