# TASK-20261015-03 行动感悟技艺名称精简

## 1. 任务背景与核心意图

- **提出时间**：2026-10-15 13:05:00
- **需求分析完成时间**：2026-10-15 13:06:00
- **完成时间**：2026-10-15 13:12:00
- **任务分类**：前端交互 / 文案润色 / 体验优化
- **背景**：
  在非战斗行动弹窗五段式规范（消耗/产出/感悟/耗时/次数）中，第 3 段「感悟」呈现了行动涉及的经验类收益。目前修为主属性显示为「修为 × 10」，六维根基显示为「神识 × 10」，而生活技艺却拼接了「技艺经验」后缀，呈现为「炼丹技艺经验 × 10」。
- **问题与诉求**：
  在「感悟」这一明确的经验分类下，强调「技艺经验」四个字属于冗余说明性文本，不仅占用胶囊横向空间，且与同级修为主属性和六维属性格式不统一。根据 AGENTS.md §8「UI 文本简练红线」，生活技艺经验收益应通用精简为「{技艺名} ×{经验点数}」（如「炼丹 × 10」、「采集 × 8」），去除无意义的「技艺经验」后缀。
