# TASK-20261017-02 装备出售强化等级选择与持存动态读取

## 1. 任务背景与核心需求

### 1.1 背景分析
在坊市（Market）挂单出售与物品交易体系中，装备支持 `+0` ~ `+20` 的强化等级变体（资产键为 `(itemId, "+N")`，基础无强化变体为 `(itemId, "")`）。
此前，挂单模态弹窗（`MarketOrderModal`）接收外部固定的 `enhancementLevel` 属性（默认 0 或由外层盘口列表选定），弹窗内部并未暴露强化等级的选择或调节控件。当修士在装备详情页点击「发起挂售」（出售界面）时，无法在弹窗内直接切换所要出售的具体强化等级，且库存数量与最大可挂售数量被锁定在初始传入的等级上。

### 1.2 核心需求解析
用户指令：
> “优化一下：当前装备出售时，没有办法选择出售的装备强化等级。在出售界面上增加一个强化等级：如果是装备，就显示一个强化等级。然后物品的数量可以根据选中的强化等级再去读取。你能理解吗”

需求明确拆解为三项核心能力：
1. **出售界面支持强化等级切换**：如果是装备标的（`isEquipment` 为真），在交易表单（`MarketOrderModal`）中渲染强化等级字段，支持修士自由切换/选择强化等级（0 ~ 20 级）。
2. **快捷持有等级点选**：表单头部智能呈现修士背包中实际持有的该装备强化等级列表（如 `+0 (2件)`、`+3 (1件)`），点击即可一键秒选切换。
3. **物品库存与可支配量动态重读**：选中强化等级切换后，即时重新读取背包中该等级对应的变体持存行（`selectedAmount`）、扣除同等级已穿戴数量（`equippedCount`），动态更新可挂售上限（`availableAmount` / `quantityLimit`）、库存提示、物品瓦片预览（`ItemTile` 强化等级徽标）与提交载荷（`variant: "+N"`）。

## 2. 详细技术方案

### 2.1 标的类型判定与状态机
- **装备判定**：复用既有标的判定逻辑 `isEquipment = Boolean(instrument.equipmentDefinition || instrument.category === 'equipment' || instrument.itemId.startsWith('equipment.'))`。
- **等级状态**：在 `MarketOrderModal` 内部引入 `level` 局部状态，以入参 `enhancementLevel`（缺省 0）为初始值；并在 `open` / `enhancementLevel` 变更时自动重置。
- **盘口深度异步更新**：引入 `activeBook` 状态，当修士在弹窗内切换 `level` 时，调用 `fetchMarketBook(instrument.itemId, level)` 异步拉取对应等级的买一/卖一与深度，动态刷新快捷填价（`买一`、`卖一`）档位。

### 2.2 变体持存与穿戴拦截动态读取
- **背包持存**：
  ```ts
  const selectedAmount = instrument
    ? (inventory.find(item => item.itemId === instrument.itemId && parseEnhancementVariant(item.variant) === level)?.amount ?? 0)
    : 0
  ```
- **已穿戴件数**：
  ```ts
  const equippedCount = useGameStore(
    state => state.combat?.equipment?.filter(
      entry => entry.itemId === instrument?.itemId && Math.floor(entry.enhancementLevel) === level
    ).length ?? 0
  )
  ```
- **可支配挂售上限与数量钳位**：
  `availableAmount = Math.max(0, selectedAmount - equippedCount)`。
  当 `level` 切换导致可用量缩减时，若当前填写的 `quantity > availableAmount`，自动下调并钳位至 `availableAmount`（最小为 1）。

### 2.3 UI 布局与组件集成
- **组件复用**：强化等级选择器复用统一模板 `QuantitySelector`（`min={0}`, `max={20}`, `leadingPresets={[0]}`），完全契合公共组件与视觉规范。
- **持存快捷芯片**：在字段标签右侧输出 `.market-order-quick-prices` 胶囊按钮组，罗列玩家持有的该装备全部等级与件数（如 `无强化 (2)`、`+3 (1)`），选中等级高亮；无持存时显示基础预设。
- **图元与标题联动**：
  - `displayName = level > 0 ? `${instrument.name} +${level}` : instrument.name`
  - `ItemTile` 传入 `enhancementLevel={level}` 与更新后的 `name={displayName}`。
- **协议提交**：
  - 发送 `market.place` 时携带 `variant: level > 0 ? `+${level}` : null`。
