# TASK-20261109-11: QQ动态表情扩充至两百个与页面空闲全量预加载系统

## 任务背景与核心目标

满足修仙玩家对更丰富社交表达与无感秒开体验的需求：
1. **表情库全面扩充至 ~200 个常用动态表情**：
   - 从 QFace 官方动图库中完整筛选约 200 个经典动态 GIF 表情（涵盖人脸情绪、肢体手势、常用生活物品与动物符号等）；
   - 本地前端全量打包作为坚实底座，单张 ~8KB，总资源约 1.5MB；
   - 同步通过 Cloudflare R2 自愈缓存实现边缘加速。
2. **页面初始化低优先级全量预加载机制 (Idle Preload)**：
   - 玩家进入页面（App 挂载后），在网络和 CPU 处于空闲时（`requestIdleCallback` + 分批滑动窗口并发控制），静默并发预热全部表情；
   - 优先通过 CF 图床拉取并解包沉淀到本地 IndexedDB (`daohua_image_cache`)；
   - 确保玩家在任何时刻打开传音频道或呼出表情面板时，所有表情均为已解码的本地 Blob 状态，实现 100% 真正的零延迟、零白块秒开。

## 详细技术设计

### 1. 表情数据契约升级 (`qqEmojis.ts`)
- 收录 200+ 个动态表情条目，清洗并规范化中文别名；
- 维护 QSid 与表情名称的高效双向 Map，支持快速匹配富文本短码。

### 2. 动图资源归档 (`frontend/public/emotes/`)
- 自动抓取并归档全部 200+ 个动态 GIF 文件；
- 保留原有命名规范 `s${qsid}.gif`。

### 3. 空闲预加载管线 (`chatStickerService.ts` & `App.tsx`)
- 新增 `preloadAllEmotes(concurrency = 6): Promise<void>` 方法：
  - 采用滑动窗口 Promise 池控制并发度，避免冲击游戏主网络连接（WebSocket 握手与快照同步）；
  - 若已在 IndexedDB / 内存缓存中则跳过；
  - 优先从 `https://img.yuohira.com/emotes/s${qsid}.gif` 拉取并写入 IndexedDB，失败回退 `/emotes/s${qsid}.gif`；
- 在 `App.tsx` 挂载后的空闲时段触发调度。
