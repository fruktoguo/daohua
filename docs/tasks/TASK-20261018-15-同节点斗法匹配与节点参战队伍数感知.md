# TASK-20261018-15 同节点斗法匹配与节点参战队伍数感知

## 1. 任务背景与核心目标

- **当前痛点与自洽性问题**：
  1. 原斗法撮合（`EcsPlayerRuntimeAdapter.MatchDuelsOwned`）仅基于全服已加载在线活跃玩家的实力带（±30%）进行初选与撮合，完全未考虑玩家当前所在的地图节点（`CurrentNodeId`），导致不同大区/节点的玩家跨图遭遇，割裂了修仙世界同区域历练探索的空间沉浸感，并使得暂存区掉落掠夺的区域资源生态失衡。
  2. 玩家在历练战斗确认面板及队伍管理面板勾选「斗法」选项时，无法得知当前地图节点是否有其他开启斗法的对手正在交战，处于完全的信息黑盒中，难以评估进场遭遇预期。
- **核心目标**：
  1. **严格同节点撮合**：斗法撮合（`MatchDuelsOwned`）强制要求双方处于同一地图节点（`candidate.NodeId == seeker.NodeId` 且均未处于移动边中），并在单写者门禁内复核原子预约，杜绝跨图斗法。
  2. **当前节点斗法队伍数感知**：服务端实时统计当前地图节点开启斗法并且正在战斗的队伍数量（含单人单位与组队讨伐会话，每队计 1），随握手与心跳 Pong 响应轻量同步至客户端，并在行动确认弹窗与队伍斗法开关旁清晰呈现。

## 2. 需求拆解与技术方案

### 2.1 撮合层：严格同节点过滤 (`src/Server/EcsPlayerRuntimeAdapter.cs`)
1. 候选池收集阶段：
   - 提取候选人时同步提取其当前有效地图节点 `aggregate.World.NodeId`（需满足 `aggregate.World.EdgeId is null` 且节点非空）。
2. 寻求者匹配阶段：
   - 寻找 seeker 对应的候选对手池时，强制约束 `candidate.NodeId == seekerNodeId` 与实力带双重条件。
3. 预约回滚与原子防御：
   - 在门禁内执行双方 `TryReserveDuel` 时，复核候选者与发起方所在节点未发生位移变更，确保撮合与挂载期间位置绝对一致。

### 2.2 状态感知层：节点参战队伍数纯内存统计
1. **统计口径**：
   - 目标节点：`nodeId`；
   - 遍历 `_loaded.Values` 内存快照（0 锁、0 数据库开销、0 聚合阻塞）；
   - 满足条件：
     - 玩家停留在该节点（`state.World.EdgeId is null && state.World.NodeId == nodeId`）；
     - 队首行动处于运行态（`Actions.Count > 0 && Actions[0].Status == Running`）；
     - 队首行动属于战斗远征（`Actions[0].Expedition is not null`）；
     - 勾选了斗法开关（`Actions[0].Intent.PvpEnabled == true`）；
   - **队伍粒度去重**：单人玩家独立计 1 队；组队讨伐会话（`Participation.Reference.SessionId`）按会话 ID 去重后计 1 队，严格符合总纲 §7.10.4 队伍单位规约。
2. **协议与通信通道 (`src/Protocol/Contracts.cs`, `WebSocketRuntime.cs`)**：
   - 在 `PresenceStatsDto` 与 `PongResponse` 中补充 `NodeDuelCombatTeamCount` 字段；
   - 客户端心跳 Pong 请求由服务端实时解析当前连接玩家所在节点并返回该节点斗法中队伍数；
   - 握手 `HelloAck` 携带初值，后续随心跳每 5 秒自动平滑同步。

### 2.3 前端呈现层 (`frontend`)
1. **Store 与网络层**：
   - `gameStore.ts` 登记 `nodeDuelCombatTeamCount: number | null`；
   - `gameClient.ts` 在 `HelloAck` 与 `Pong` 响应中解析并写入 store；并在打开行动确认弹窗时调用 `pingNow()` 触发即时测速与队伍数刷新。
2. **UI 挂载**：
   - `App.tsx` 中的 `ActionConfirmModal`：在 `duel-option-status` 中展示当前节点斗法中队伍数量；
   - `SocialPage.tsx` 中的队伍讨伐面板：在队伍斗法开关旁同步展示队伍数量；
   - 补齐 i18n 模板词条（`app.action.duel.nodeTeams`）与修仙微光样式。
