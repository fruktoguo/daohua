# TASK-20260825-03：战斗场景纯 HTML 实机画面 Demo

## 1. 任务背景与需求分析

用户希望在 `docs/design/` 下新增一个**纯 HTML 单文件战斗场景 Demo**，用于快速验证当前游戏画面的视觉效果。参考画面为用户提供的 1568×804 战斗截图，要求：

- 使用纯 HTML、CSS、原生 JavaScript，不引入 React、Vite 或第三方运行时；
- 页面可直接双击或通过静态文件服务器打开；
- 允许加载仓库现有角色立绘等图像资源；
- 重点复刻截图的黑金暗墨面板、顶部状态栏、左侧导航、中部战斗场景、底部战报日志、右侧储物袋/装备/功法 Tab；
- 保留足够的演示交互，用于快速验证战斗画面：切换右侧 Tab、点击角色查看信息、触发攻击/终止行动、更新战报与进度条；
- 以桌面目标视口 1568×804 对齐截图，同时在较窄视口下保持可用，不影响正式 `frontend` React 入口。

现有实现边界：正式前端的战斗组件与公共视觉规范已查阅；本任务只新增离线设计 Demo，不修改 `src/Domain`、`src/Protocol`、`src/Server` 或正式前端运行时代码，不承担历史兼容。

## 2. 视觉与技术方案

### 2.1 视觉基准

- 颜色：`#070604` 暗墨底、低饱和金色边框与标题、蓝色灵力条、红色气血条、青绿色行动条；
- 架构：68px 顶栏 + 三列主体（左侧导航 / 中央战场与日志 / 右侧装备信息）；
- 中央区域：战斗标题条、带细网格底纹的双阵营战场、底部消耗品/功法快捷槽；
- 图像：复用 `frontend/public/avatars/player.svg` 与 `frontend/public/avatars/wood-spirit.webp`，通过 CSS 处理方向、暗化与光晕；
- 所有样式与脚本内聚到单文件，避免打开 Demo 时依赖开发服务器。

### 2.2 交互边界

- 左侧导航点击切换选中态并写入演示日志；
- 右侧三 Tab 切换储物袋、装备、功法内容；
- 点击战场角色显示轻量属性卡；
- 点击技能/物品槽触发演示伤害、读条与日志；
- 点击「终止当前行动」切换停止/继续状态并追加战报；
- 不接入服务端，不伪造网络协议，不改变正式游戏状态。
