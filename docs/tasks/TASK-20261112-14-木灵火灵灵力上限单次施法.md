# TASK-20261112-14 木灵火灵灵力上限下调至单次施法

## 需求分析与核心理解

- **业务目标**：延续前期怪物配平——法术固伤上调（TASK-20261112-07）后，灵体系法术已成主要威胁；用户要求收敛木灵、火灵的法力池，使其在默认难度（difficulty=0）满蓝状态下**只能释放一次技能**。
- **核心逻辑预期**（用户原话拆解）：
  1. 仅调整 `enemy.wood-spirit`（木灵）与 `enemy.fire-spirit`（火灵）的 `weights.mp`；
  2. 「默认难度满蓝只能放一次」= `floor(MaxManapoints / manaCost) == 1`，即 `manaCost ≤ MP < 2×manaCost`；
  3. 怪物无灵力回复（`MpRegen` 恒 0）、开战满蓝（`CombatantState` 构造 `Manapoints = MaxManapoints`）、灵力上限不受封魔阵削弱影响，故该约束对整场战斗恒成立。
- **影响范围与实现边界**：仅改 `config/game-data/monsters/tier1_minions.json` 两处 `weights.mp` 与 `MonsterDropTableValidationTests` 新增契约断言；不动技能、等级、其他权重；水灵（甘露耗蓝 20，MP 26 本就只能放一次）与潮汐之灵（T2 段）不在本次范围。

## 数值推导

怪物灵力上限公式（`GameDataCatalog.ParseMonsterDefinitions`）：

```
MaxManapoints = ceil( 期望面板MP(含Diff修正) × 层级属性倍率 0.8 × weights.mp )
```

默认难度 `AttributeMultiplier(0) = 1.25^0 = 1.0`，不再放大。

| 怪物 | 等级 | 期望面板MP | 技能耗蓝 | 旧 weights.mp → 旧 MP → 旧可放次数 | 目标 MP 区间 | 新 weights.mp → 新 MP → 新可放次数 |
|---|---|---|---|---|---|---|
| 木灵 | 2 | 126.0376 | 掌心雷 4 | 0.2 → 21 → 5 次 | [4, 8) | **0.06** → ceil(100.83×0.06)=**7** → 1 次 |
| 火灵 | 3 | 172.4949 | 轰炎 10 | 0.3 → 42 → 4 次 | [10, 20) | **0.12** → ceil(137.996×0.12)=**17** → 1 次 |

取值取各自合法窗口中部，规避取整边界敏感；水灵对照：0.25 → MP 26 / 甘露 20 → 本就 1 次。
