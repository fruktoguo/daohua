## 设计要点

- **取证可复现**：所有判据由脚本输出，阈值集中在该脚本 `THRESHOLDS`，`SKILL.md` 阈值表与之逐项对应，改一侧必须同步另一侧。
- **归档豁免**：`docs/archive/` 是时点证据快照，源码路径与行号允许失效，只参与「索引可达性」判据，不参与重复度、路径引用与形态判据。
- **索引唯一入口**：撤回「逐目录 README」判据——本仓以 `docs/README.md` 为唯一入口，再造目录索引与「DESIGN.md 不是第二真源」冲突。
- **退出码语义**：硬缺陷（坏链/看板编号重复/详情死链）返回 1，软指标超限返回 0。脚本不进门禁，故不阻塞提交。
