# TASK-20261109-08: QQ经典动态表情精选与Cloudflare图床双源梯级分发系统

## 任务背景与核心目标

提升道化太初传音聊天的社交体验与生动度，彻底淘汰手绘静态矢量 SVG 图元，全面实装腾讯 QQ 官方经典动态 GIF 表情库：
1. **精选 QQ 经典动图表情库**：
   - 收录玩家最熟悉、高频使用的 50~60 个经典 QQ 动态表情（如微笑、呲牙、发呆、得意、流泪、害羞、调皮、大哭、抓狂、滑稽、抱拳、点赞等）；
   - 单张 GIF 动图体积仅 ~15KB，兼顾生动趣味与微小包体。
2. **Cloudflare R2 + 本地游戏服务器双源梯级分发**：
   - 一级优先源：Cloudflare Worker + R2 自建图床（`https://daohua-emotes.fruktoyao.workers.dev/emotes/...`），全球 Anycast 边缘缓存与免流分发；
   - 二级兜底源：前端本地静态资源（`/emotes/s${id}.gif`），当 CF 访问受限、404 或超时时平滑无感回退；
   - 客户端离线缓存：结合已有 IndexedDB（`daohua_image_cache`），单次拉取后永久本地二进制复用，零重复流量。
3. **架构重构与死重清理**：
   - 彻底删除 `QqEmoji.tsx` 中近 400 行临时手绘静态 SVG 图元；
   - 重构 `QqEmoji.tsx` 为动态表情组件，支持动态图渲染、Loading 占位与双源自愈加载。

## 详细技术设计

### 1. 表情契约与映射表 (`qqEmojis.ts`)
- 包含 `qsid`（QFace 官方 ID）、`name`（中文识别名，如 `微笑`）、`id`（英文标识，如 `smile`）；
- 提供 `getQqEmojiUrl(qsid, preferCf)` 函数：优先生成 CF 图床 URL，并提供本地静态 URL 作为备选。

### 2. 动图静态资产 (`frontend/public/emotes/`)
- 抓取并存储精选经典 50+ 个表情的真实动态 GIF 文件，命名为 `s${qsid}.gif`；
- 作为前端自带本地兜底源，断网或 CF 故障时仍能完整展示。

### 3. CF 图床增强 (`tools/cf-uploader/src/index.js`)
- 支持 `GET /emotes/:filename` 路由；
- 命中 R2 直接返回；未命中时可透明回源或由上传脚本统一推送。

### 4. 动态表情渲染器 (`QqEmoji.tsx`)
- 引入图片加载双源状态机：
  1. 查 IndexedDB 本地缓存；
  2. 若无缓存，优先从 CF Worker 加载；
  3. 若 CF 触发 `onError` 或超时，无缝切换为本地服务器源 `/emotes/s${id}.gif`；
  4. 成功拉取后沉淀至 IndexedDB。
