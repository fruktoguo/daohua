## 需求理解与边界

1. **业务目标**：显著缩短 `scripts/verify.sh --full` 交付/发布前全量门禁的墙钟耗时，消除纯 CPU 空转、重复全量重编译与测试内硬编码长等待。
2. **安全与覆盖边界**：
   - **生产零退让**：`PostgresAccountRepository` 生产默认 PBKDF2 迭代数必须保持 `600_000` 不变，且不允许通过外部配置文件或环境变量降低。
   - **真实逻辑不降级**：前后端契约脚本继续执行同一份 TypeScript 源码的真实解码逻辑；WASM 模拟器缓存仅在源码与配表指纹完全一致且产物完备时跳过重编，洁净构建/环境变量强制重建不受影响。
   - **不碰无关脏改动**：工作区既有的模拟器同源改造文件（`src/Ecs/*`、`src/Simulator*`、`tests/Ecs.Tests/CombatSimulatorParityTests.cs` 等）保持原样。
