## 2. 视觉与技术方案

- **单画布粒子调度**：新增共享 `particle-stage.js`，创建固定粒子池、单 `requestAnimationFrame` 循环、DPR 与视口缩放适配；采用高亮硬芯 + 克制外辉光，不用贴图、大面积模糊烟雾、全屏白闪或长时残留。

- **明确时间轴**：约 80~260ms 起手，清楚可见的命中帧，定向碎光和冲击环在约 0.6~1.15 秒内收尾；保留配表真实吟唱时长，不用拉长技能后摇制造气势。
- **逐技能剪影**：重斩斜落金刃、连环三段火影斩、嘲讽怒纹、重云压顶、贯星穿刺、掌心雷闪电链、轰炎扇形爆裂、清平乐青叶回春、雷光引分叉天雷、破阵子金符护阵、碎罡碎甲化煞、甘露灵露汇聚、潮汐推进浪锋。
- **预览控制**：演武页提供主动/内功筛选、独立重播、暂停/继续与速度控制；可关闭环境普攻，避免验收时被杂项反馈干扰。
- **确定性及性能**：演出使用可播种随机数；单个战斗舞台只有一个动画循环，隐藏页冻结；停止/重置/卸载能清理动画、画布和旧定时任务。
