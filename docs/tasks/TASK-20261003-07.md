# TASK-20261003-07 · 技艺界面优化：导航技艺等级前缀 + 内视技艺 Tooltip 精简

- 提出时间：2026-10-03 15:50:22
- 分类：前端体验 / 技艺展示
- 状态：🧪 验证中

## 需求原文

> 优化
> 所有的技艺的分组前面应该显示对应的技艺等级
> 内视的技艺里面，hover 不要显示后面的什么共用同一个曲线，改为就开头的两句

## 需求澄清结论（用户确认）

1. 「技艺的分组」= 左侧导航「技艺」分组展开后的二级菜单项（炼丹/炼器/符箓/阵法/强化），每项名称前显示对应技艺等级。
2. 「开头的两句」= 各技艺 Tooltip 的第一行诗意描述（如「草木入炉，凝液成丹。」），移除「技艺经验与修为共用同一曲线…」整段机制说明。

## 实现方案

### 1. 左侧导航技艺子菜单等级前缀

- `frontend/src/App.tsx`
  - 导入 `calculateTechniqueProgress`（combatConstants）与 `CraftingMode` 类型。
  - 新增模块级常量 `CRAFTING_NAV_MODES`（五项，采集/挖掘无技艺页签入口不入导航）。
  - `Sidebar` 组件订阅 `state.combat?.techniqueExperiences`，`useMemo` 导出五技艺等级映射（0 级起步，等级 = 修为曲线导出级 - 1，与内视技艺 Tab 同一公式）。
  - 五个重复的 `nav-sub-item` button 重构为 `CRAFTING_NAV_MODES.map`，名称前插入 `nav-sub-level` 等级 span（`app.crafting.navLevelLabel` → `Lv.{level}`）。
- `frontend/src/styles.css`：新增 `.nav-sub-level`（`min-width: 38px` + `text-align: right` + `tabular-nums`，等级位数变化时各子项名称起始位置稳定；11px 暗金色作次要信息）。
- `frontend/src/i18n/domains/app.zh.ts`：`app.crafting` 新增 `navLevelLabel: 'Lv.{level}'`。

### 2. 内视技艺 Tooltip 精简

- `frontend/src/i18n/domains/insight.zh.ts`：七技艺 `*Tooltip` 仅保留第一行诗意描述，删除「技艺经验与修为共用同一曲线，每级提升 5% …」机制说明（速度加成机制已由同行「行动速度 +X%」胶囊的 `speedBonusTooltip` 承载，强化成功率说明在强化工作台展示，信息不丢失）。
- `frontend/public/locales/template.csv`：由 `scripts/export-i18n-csv.mjs` 随构建自动重导出。

## 二轮调整（2026-10-03 15:55 用户反馈）

用户目检后要求：
1. 等级不要「Lv」前缀，直接「炼丹 3」——名称后跟纯数字。
2. 子项底下加一条很细的经验条，且不同技艺不同颜色。

实现：
- `App.tsx`：`CRAFTING_NAV_MODES` 增加 `tone` 字段（与内视技艺 Tab 分色一致：炼丹 emerald / 炼器 crimson / 符箓 amber / 阵法 purple / 强化 gold）；`techniqueLevels` 升级为 `techniqueStates`（等级 + 本级进度比例，满级恒显满格）；子项改两行结构——主行「图标 + 名称 + 等级数字」，底边 `nav-sub-progress` 细经验条。
- 数字与经验条取色复用现有 `pill-tone` 体系：数字挂 `underlined-value` 类从 `.pill-tone--{tone} .underlined-value` 规则取色（去下划线/加粗），经验条 fill 直接复用 `compound-stat-progress-fill` 类命中 `.pill-tone--{tone} .compound-stat-progress-fill` 分色规则——零新增色值，色彩单源。
- `styles.css`：`.nav-sub-item` 改纵向两行布局，新增 `.nav-sub-main` / `.nav-sub-level.underlined-value`（覆盖去下划线）/ `.nav-sub-progress`（2px 细条 + 底槽）及 fill 块化规则。
- `app.zh.ts`：删除不再使用的 `app.crafting.navLevelLabel`（纯数字无需模板）。

## 三轮调整（2026-10-03 16:20 用户反馈）

用户要求：导航技艺子项 hover 应显示经验值，或技艺相关信息 + 经验值。

实现：
- `App.tsx`：`techniqueStates` 扩展本级经验（current/max）、满级标记与速度加成百分比；子项包 `FloatingTooltip`（`displayContents` 保持 flex 布局透明、`placement="right"` 贴右侧不遮挡导航），气泡三行文本——「炼丹 · 3 级 / 经验 5,800 / 2.71万 / 行动速度 +15%」，满级经验行改显「已臻化境」。
- `app.zh.ts`：新增 `app.crafting.navTooltipLevel`（'{level} 级'）/ `navTooltipExp`（'经验 {current} / {max}'）/ `navTooltipMaxed`（'已臻化境'）/ `navTooltipSpeed`（'行动速度 +{value}%'）。App.tsx 无跨域引用 insight.* 词条的先例，跟随惯例在 app.crafting 域内新增。
