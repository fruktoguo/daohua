     - 制造型：递归原料树，逐项支持「自采」（自动前置单轮采集）或「求购」（向市场挂买单）；
     - 商贸型：抓取低价流通品类，维护双向买卖盘口；
     - 装备型：穿戴指定装备。
  4. 动态概率定价：卖价硬性 $\ge \lceil \text{回收价} \times 1.10 \rceil$；1~2小时成交抽样提价，滞留抽样降价（不低于底线）；买单受灵石与预算限制。
  5. 托管订单隔离：仅调整与撤回机器人自身托管的订单，不碰真实玩家原有挂单。
- 实现边界：
