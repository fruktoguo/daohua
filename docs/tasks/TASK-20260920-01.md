# TASK-20260920-01 · 移除地图节点纯采集提示建筑

- 提出时间：2026-09-20 00:04:50
- 状态：✅ 实现完成，待验收

## 需求

用户反馈：当前地点的物品采集总伴随一个「XX 采集点」的静态地标建筑，有物品即可采集，纯提示建筑多此一举，要求全部移除。

## 方案

地图节点内嵌 `buildings` 为纯展示实体（`ProtocolSnapshotMapper.ReadEntities` 透传，前端 NearbyPanel「地标与设施」与 WorldMapPanel 地点详情消费），与玩家可建造的 `NodeBuildingRegistry` 建筑无关。仅删除 effect 为「X 采集点/采摘点/采伐点/开采点」的纯采集提示条目，其余功能/叙事地标保留。

删除清单（均为所在节点 `buildings` 唯一条目，连同 `buildings` 属性一并移除）：

- `qingyun_mountain.json`：`building.shuyu-stones`（漱玉跳岩/晨露采集点）、`building.herb-rack`（晾药竹架/灵草采摘点）、`building.peach-bridge`（断木古桥/桃木采伐点）、`building.mining-shed`（淘石草棚/乌铁开采点）
- `xingyun_realm.json`：`building.carrion-monument`（残破古冢/伴灵花采摘点）、`building.scorched-branches`（枯焦残木/引灵松采伐点）、`building.copper-chasm`（荧光地缝/赤铜开采点）

保留：古井/古槐（叙事）、茶棚（灵市）、山门牌坊/道庐/石台（修炼与试炼）、界碑（边界）、血坛/骨堆/星核（巢穴）。
