# TASK-20261014-03 · 顶栏连接状态灯悬浮测延迟

- 提出时间：2026-10-14 14:47:48
- 状态：✅ 已完成（2026-10-14 14:49）

## 需求

左上角绿色连接状态灯（`connection-dot`）：hover 后触发一次 Ping，悬浮信息显示当前往返延迟，文本保持简洁。

## 方案

1. `gameStore` 新增 `latencyMs: number | null` 与 `setLatencyMs`（登出重置归 null）。
2. `gameClient`：
   - 抽出 `sendPing(socket)`，发送时按 `requestId` 登记发送时间到 `pendingPings`；
   - 心跳 25s Ping 与新增的公开 `pingNow()`（1s 最小间隔防抖）共用该路径；
   - `Pong` 帧独立 case：按 `envelope.requestId` 回查发送时间，`Date.now() - sentAt` 写入 `latencyMs`；
   - `open()` 时清空 `pendingPings`（旧连接的 Pong 永不回包）。
3. `TopBar` 连接灯 `onMouseEnter` → `gameClient.pingNow()`；tooltip 文案为 `已连接 · 在线 · 24ms`（未测得前不显示延迟段）。
4. i18n：`app.topbar.latency = '{ms}ms'`。
