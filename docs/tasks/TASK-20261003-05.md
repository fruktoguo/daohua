# TASK-20261003-05 大世界地图区域化显示

- **提出时间**：2026-10-03 14:13:44
- **状态**：🧪 验证中（2026-10-03 14:20 前后完成实现）
- **分类**：前端体验 / 世界地图 / 配表坐标

## 需求

用户提出：

1. 地图按「区域」显示——当前初始地图（青云仙山）为一个区域，T2 地图（星陨异境）为另一个区域。
2. 正常情况下只显示一个区域。
3. 部分节点可前往其他区域；玩家站在该类节点上时，同时显示当前区域与可前往的目标区域。
4. 整个大世界本质是一张大地图，按区域拆成小地图，所有区域**共用一个坐标系**。
5. **青云山门（`node.cloud-gate`）作为连接二图的节点**（原跨图边挂在云巅草庐 `node.cloud-peak` 上）。

## 现状分析

- `config/game-data/maps/qingyun_mountain.json`（8 节点，x∈[10,88]）与 `xingyun_realm.json`（7 节点，x∈[15,88]）各自使用独立 0-100 局部坐标。
- 跨图边 `edge.peak-rift`（草庐→裂天界隙，60s）登记在星陨配表内；服务端 `GameDataCatalog.BuildWorldGraph` 先全量登记节点再解析边，跨图寻路本来可用。
- 前端 `WorldMapPanel.tsx` 仅取 `maps.find(m => m.mapId === world.mapId)` 单图渲染 → 跨图边两端不在同图，永不绘制；也无法选中他图节点。

## 方案

### 配表

- 节点 `x/y` 语义升级为**全局世界坐标**（1 单位 = 视口宽/高的 1%）。
- 青云仙山保持原点不动；星陨异境整体平移 `x+100, y-10`：裂天界隙 (115,40)、腐生古冢 (132,65)、畸木焦林 (135,15)、荧石铜渊 (160,70)、冥煞血池 (155,35)、白骨荒坑 (175,55)、坠星天坑 (188,25)。
- 跨域边 `edge.peak-rift` → `edge.gate-rift`：`node.cloud-gate` → `node.astral-rift`，60s。

### 前端 WorldMapPanel

- `maps` 合并为全局索引：`nodeOwner(nodeId→mapId)` + 全节点/全边列表；路径规划与玩家位置插值统一跑合并图。
- 可见区域集合：
  - 驻留节点 → 所在区域 + 该节点跨域边直达的邻接区域（关口双显）；
  - 行进在边上 → 两端点所属区域（跨界路途中双显，图内边单显）；
  - 兜底 `world.mapId`。
- 画布改为世界包围盒尺寸（`width: worldW%`，1 世界单位 = 1% 视口），节点/边/玩家坐标统一按 worldW/worldH 归一化。
- 可见集合变化时自动 fit 可见区域 union bounds（zoom≈min(92/W,92/H)，居中）；滚轮/按钮最小缩放放宽至 0.3。
- 视觉：每个可见区域绘虚线圆角界框 + 区域名牌；跨域边虚线样式 `is-crossing`；关口节点 `is-gateway` 描边提示。

### 工具链

- `tools/config-editor` MapsEditor：边端点下拉改为全图节点（`lookups.nodeList`，标注所属地图），兼容跨域边编辑。
