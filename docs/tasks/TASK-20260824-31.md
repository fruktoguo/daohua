## 2. 需求背景与核心问题

### 2.1 用户原始诉求
> “调整,我希望item的边距小一些,现在间隔太大了,”

### 2.2 根本原因定位
1. **槽位与瓦片内衬差值过大**：
   - 历史样式中定义 `--item-slot-size: 79px`，而内部 `--item-tile-size: 63px`，导致每个物品外层容器（`.inventory-item-anchor`, `.item-grid-picker-tooltip`, `.item-use-slot-tooltip` 等）上下左右各有 `8px` 的隐形透明边距。
2. **多重间距叠加**：
   - 网格本身设置了 `gap: 7px`（甚至 `styles.css` 历史遗留了 `gap: 14px`），叠加两边各 `8px` 的透明边距后，视觉上方块与方块之间的实际空隙高达 `23px`，造成非常松散、空旷、同屏容纳量过低的视觉体验。
3. **装备/快捷栏/选择器各处间距不统一**：
   - 部分位置写死较大 min-height/min-width，需全面对齐紧凑修仙风格。

---

## 3. 详细设计与调整方案

1. **尺寸收拢与内衬精简**：
   - 将 `--item-slot-size` 与 `--item-tile-size` 统一调整为 `64px`，外层 padding 归零。
   - 丝带 (`.item-type-ribbon`) 与角标 (`.item-corner`) 依赖 `overflow: visible` 自然展示，无需多余透明占位。
2. **网格间隙紧凑化**：
   - `.inventory-grid`、`.item-grid-picker-grid`、`.market-browse-grid` 统一定义 `gap: 6px`，紧凑排布。
   - 清理 `styles.css` 遗留的 `.inventory-grid { gap: 14px; minmax(124px, 1fr); }` 冗余覆盖。
3. **战斗槽位与快捷栏同步适配**：
   - 同步调整 `expedition.css` 中 `.combat-slot-tray` 的 `--item-slot-size` 与 `--item-tile-size`，保持全站一致。
4. **文字与动效微调**：
   - 优化 `.item-tile-name` 的内边距（`padding: 6px 3px 4px`），确保 2~6 字物品名称在紧凑格内居中自然、字体清晰。
   - 微调 Hover 动效（缩放幅度由 2.08 降为 1.22），保证放大与光晕精致且不会产生遮挡。
5. **多端与门禁验证**：
   - 全量门禁脚本 `scripts/verify.sh`（包含 Release 构建、187 项领域测试、23 项服务端测试、容量门禁、前端构建与类型检查）全部通过。
