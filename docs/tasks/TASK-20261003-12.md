## 需求

在保留 YuoCore ECS Tag System 实体派发路径的前提下，为无实体战斗路径增加一个更轻量的触发器处理流程：处理器通过继承基类和实现固定事件接口自动被反射收集，启动时完成实例化与排序，战斗热路径只执行缓存后的接口调用。

## 设计边界

- 轻量处理器不继承 `ISystemTag`，不创建 `YuoSystem`、组件或实体信箱。
- 事件接口按触发器种类固定方法和参数；新增同类效果只新增处理器类，不修改派发器。
- 反射仅限启动收集阶段；派发使用按事件类型缓存的接口数组，不使用 `MethodInfo.Invoke`。
- 处理器只接收 `PendingCombatTrigger` 等领域上下文，不持有 `YuoEntity` 或 `YuoWorld`。
- 同一条 pending trigger 只能由一个 sink 消费，避免轻量路径和 ECS 路径重复结算。
- 处理顺序必须显式、稳定；同一事件类型按顺序号升序、处理器全名 `Ordinal` 二次排序。
