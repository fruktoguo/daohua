## 需求与提示词分析

- **核心诉求**：增加常量文件夹（`Constants/`），将全项目中分散在 `Simulation/`、`Models/`、`GameData/`、`Market/` 等各处的静态常量、标识符常量、系统硬限制与公式计算系数全面收拢集中管理。
- **梳理与收拢规划**：
  1. **新建常量目录**：创建 `src/DaoHua.Domain/Constants/` 作为领域静态常量唯一根目录。
  2. **战斗与公式常量收拢** (`DaoHuaCombatConstants.cs`)：将原位于 `Simulation/` 的战斗数值、基础属性锚点、境界突破经验表、六维根基折算系数、公式平滑常数等纯常量全面迁移至 `Constants/` 目录。
  3. **原型标识符常量收拢** (`DaoHuaIdConstants.cs`)：将动作 ID (`DaoHuaActionIds`)、物品与装备 ID (`DaoHuaItemIds`)、Buff ID (`DaoHuaBuffIds`)、遭遇副本 ID (`DaoHuaCombatEncounterIds`)、大地图与节点 ID (`DaoHuaWorldMapIds`, `DaoHuaWorldNodeIds`) 统一归入 `Constants/`。
  4. **系统限制与领域常量收拢** (`DaoHuaSystemConstants.cs`)：收拢战斗槽位限制 (`DaoHuaCombatLimits`)、模拟引擎运行参数与事件上限 (`DaoHuaSimulationConstants`)、数据版本号与市场硬限制规则 (`DaoHuaMarketConstants`)。
  5. **模型与枚举纯粹化**：`Models/` 仅保留纯粹的数据结构、枚举（`DaoHuaEnums.cs`）与值对象（`PercentValue` 等），不混杂静态常量子类。
