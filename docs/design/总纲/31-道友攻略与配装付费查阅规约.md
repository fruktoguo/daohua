# 第三十一篇 道友攻略与配装付费查阅规约

> 状态：实装中（TASK-20261124-02，Schema v66 / 存档标签 v46）。本文是「道友 · 攻略」板块与「隐私 · 付费查阅配装」系统的唯一权威设计真源。

## 31.1 定位与核心目标

1. **道友攻略沉淀**：将排行榜荣誉转化为受控的高质量内容发言权——凡跻身全服个人排行榜（除宗门榜外共 11 榜）前 50 名的修士，均可每日撰写 1 篇万字长文攻略，通过富文本、内置表情、颜文字、图片直链与游戏物品引用传道授业，并支持设置灵石付费解锁门槛与自由打赏。
2. **配装隐私知识变现**：扩展「设置 → 隐私」角色名片配装可见性，支持在公开与完全隐藏之间设置「支付灵石查阅装配」，付费后权限维持至北京时间当日结束零点（次日 `00:00`），兼顾流派保密与合理的配装参考变现。
3. **跨玩家经济安全**：所有付费解锁、攻略打赏与配装查阅均走权威 PostgreSQL Serializable 事务与第⑤类持久化流水白名单，统一征收 **10% 系统手续费**（向下取整）并设定单笔额度上限，杜绝小号零成本定向倒金。

## 31.2 攻略发帖资格与频次边界

### 31.2.1 排行榜准入规则
- **有效榜单范围**：读取 `LeaderboardRuntime` 当前生效的整点快照（冷启动尚未驻留内存时回退读取 `game.leaderboard_ranks`），在除宗门榜（`zongmen`）外的 **11 张个人榜**（`realm` 境界榜、7 张 `technique.*` 技艺榜、`valuation` 身家榜、`spirit-stone` 灵石榜、`duel` 斗法榜）中，只要玩家在任意一榜位列 **Top 50**（`1 <= rank <= 50`），即视为**上榜修士**，获得攻略发帖权限。
- **荣誉头衔投影**：帖子列表与详情页实时附带作者当前最优个人榜名次徽标（如「境界榜 #2」）；作者掉出 Top 50 后头衔自动隐去，但**历史已发布帖子继续保留展示、点赞、付费解锁与打赏**。
- **掉榜与作者自治**：未上榜时仅拦截「发布新帖」；作者本人对本人历史已发帖子始终保有**编辑更新**与**删除**权限。机器人账号（`identity.accounts.is_bot = true`）永久禁止发帖、点赞、付费解锁与打赏。

### 31.2.2 每日额度与篇幅约束
- **每日发帖上限**：按北京时间（`UTC+8`）自然日计，每位上榜玩家每日最多新发布 **1 篇** 攻略（`social.guide_daily_quotas` 记录当日累计发布次数）。**删除已发布帖子不退还当日发布额度**，防止反复删发刷屏。
- **编辑不耗额度**：修改已发布帖子的标题、导语、正文或解锁门槛不消耗当日新发帖额度。
- **字数与字段约束**（统一按 Unicode 标量值 / Rune 计数，前后端同口径）：
  - 标题 `title`：必填，去除首尾空白后 `1 ~ 60` 字；
  - 导语/摘要 `summary`：选填，去除首尾空白后 `0 ~ 200` 字；免费帖未填导语时列表截取正文纯文本前 `120` 字作摘要，**付费帖在未解锁态严格只展示 `summary`，绝不自动截取或下发 `body` 正文**；
  - 正文 `body`：必填，去除首尾空白后 `1 ~ 10,000` 字；
  - 解锁价格 `unlockPrice`：整数，`0`（免费公开）或 `1 ~ 100,000` 灵石。

## 31.3 富文本能力与独立编辑器交互

### 31.3.1 安全富文本语法（零 HTML 注入）
攻略正文以纯文本标记存储，前端解析为受控 AST 节点渲染，严禁 `dangerouslySetInnerHTML` 或任意脚本协议：
1. **块级排版**：支持一至三级小标题（`# ` / `## ` / `### `）、引用块（`> `）、无序列表（`- ` / `* `）、有序列表（`1. `）、分割线（`---`）、多行代码块（` ``` `）与自然段落换行。
2. **行内样式与标记**：
   - 加粗 `**文本**`、行内代码 `` `文本` ``；
   - **游戏自带表情符号**：完整复用 `[微笑]`、`[呲牙]` 等 `QQ_EMOJI_MAP` 标记，渲染为 `QqEmoji`；
   - **颜文字（Kaomoji）**：原生支持任意 Unicode 颜文字，编辑器内置多分类颜文字快捷插入面板；
   - **图像链接自动解析**：支持 Markdown 图片 `![说明](https://...)`、`{{img:https://...}}` 以及正文直接粘贴的 `http(s)://` 图片直链（`.png/.jpg/.jpeg/.gif/.webp/.svg/.avif`，长度 ≤ 500 字符），自动解析为自适应内嵌图片，点击唤起 `ChatImageLightbox` 缩放查看；支持在编辑器中直接选取个人云同步表情包或本地上传图片生成安全直链插入；
   - **游戏实体胶囊**：兼容传音同源标记 `{{item:itemId}}` / `{{item:itemId:enhancementLevel}}` 与 `{{location:nodeId}}`，行内渲染图标与悬浮详情卡片（严格显式透传 `itemId`）。

### 31.3.2 独立编辑器横竖屏适配与传音分享
- 攻略编辑采用独立全视口级工作台弹窗（`Modal` large 全幅扩展），不挤压侧栏与底栏：
  - **横屏（桌面/宽屏）**：顶部元数据栏（标题、导语、付费灵石门槛）+ 多功能排版工具栏（标题/加粗/引用/列表/分割线/内置表情/颜文字/插图/物品引用）+ **左右分栏（左侧源码编辑区 + 右侧实时排版预览区）**，亦支持切换单栏专注写作；底部实时显示 `当前字数 / 10,000` 与本地草稿保存状态。
  - **竖屏（移动端）**：紧凑可横滑工具栏 + **「编辑 / 预览」顶部分段一键切换**，全高自适应避让虚拟软键盘，保证手机端长文撰写与排版预览同样完整顺畅。
  - **本地草稿防丢**：未发布的新帖草稿按玩家 ID 自动暂存 `localStorage`，意外关闭后重开自动恢复。
- **攻略传音分享与一键直达**：
  - **查看攻略时**：详情页顶栏提供「发送到聊天」入口（面向全部可读/付费攻略），点击后经 `shareToChat` 将 `{{guide:postId:unlockPrice:title}}` 超链接胶囊填入当前激活聊天频道草稿并聚焦输入框，允许玩家补充文字后发送。
  - **编辑攻略时**：编辑器底部操作区提供「保存并发送到聊天」（编辑已有攻略）/「发布并发送到聊天」（新建攻略），先完成校验与保存/发布拿到权威 `postId`，再自动关闭编辑器并将攻略链接填入聊天草稿。
  - **传音胶囊直达**：传音消息中的 `{{guide:...}}` 渲染为带免费/灵石价格标识的交互胶囊，点击自动切换至「同道 → 攻略」并直达对应攻略详情页。

## 31.4 攻略排序、付费解锁与打赏结算

### 31.4.1 观看者双排序口径
观看者可在攻略列表顶栏自由切换两种主排序，并支持按「全部攻略 / 我的发布」过滤：
1. **热度排序（`hot`，默认）**：
   $$\text{HotScore} = \text{ViewCount} + 5 \times \text{LikeCount} + 10 \times \text{TipperCount} + 8 \times \log_{10}(1 + \text{TotalRewardStones})$$
   次序裁决：`HotScore DESC → created_at DESC → post_id DESC`。
   - `ViewCount`：打开可读正文详情的独立玩家去重计数（每帖每玩家至多计 1 次）；
   - `LikeCount`：玩家免费点赞去重计数（支持点赞/取消赞切换）；
   - `TipperCount`：对该帖发生过付费解锁或额外打赏的独立玩家去重人数。
2. **打赏排序（`reward`）**：
   按帖子累计获赏灵石总额（解锁支付灵石 + 额外打赏灵石之和）降序：`total_reward_stones DESC → tipper_count DESC → created_at DESC → post_id DESC`。

### 31.4.2 付费可见与打赏经济流转
- **付费解锁**：
  - 作者本人查阅自己的帖子恒定免费可见；`unlockPrice == 0` 的帖子对全服玩家免费可见。
  - `unlockPrice > 0` 时，未解锁读者请求详情仅获元数据与 `summary`（`locked = true, body = null`）；支付当前 `unlockPrice` 灵石后写入 `social.guide_post_unlocks` **永久解锁**（后续作者调价不再重复收费），所付灵石计入帖子 `total_reward_stones`。
- **自由打赏**：
  - 读者可向非本人帖子任意次追加打赏 `1 ~ 100,000` 整数灵石（已可阅读正文的读者均可打赏），计入 `total_reward_stones` 与 `tipper_count`。
- **手续费与实时入账**：
  - 付款方实扣 `amount` 灵石（`currency.spirit-stone`），系统收取 **10% 手续费** `tax = floor(amount * 0.10)`，作者实时入账 `netAmount = amount - tax` 灵石（写入 `economy.player_asset_balances` 并在提交后热刷新双方在线钱包，规避邮箱 100 封容量挤兑风险）。

## 31.5 隐私设置：付费查阅装配（维持至当日零点）

### 31.5.1 三态隐私模型
在 `PlayerSettingsState` 新增 `LoadoutInspectPrice`（`double`，缺省 `0`），与既有 `PublicLoadoutVisible`（`bool`，缺省 `true`）组合表达三种状态：
1. **免费公开**：`PublicLoadoutVisible = true`（任何人点开角色名片均可查看完整配装、特质与战斗消耗品）。
2. **付费查阅**：`PublicLoadoutVisible = false` 且 `LoadoutInspectPrice > 0`（`1 ~ 100,000` 整数灵石）——非本人、非当前同队队友点开 `PlayerCardModal` 时默认隐藏配装（`loadoutHidden = true`），但名片下发 `loadoutInspectPrice` 供访客一键付费解锁。
3. **完全隐藏**：`PublicLoadoutVisible = false` 且 `LoadoutInspectPrice <= 0`——非本人、非同队队友隐藏配装且不开放付费解锁。

### 31.5.2 当日零点过期契约
- 访客调用解锁接口支付 `LoadoutInspectPrice` 灵石（同样征收 10% 系统手续费，被查阅方实时入账 90% 税后灵石）后，写入 `social.loadout_inspect_grants(viewer_id, target_id, access_date, paid_stones, target_received_stones, expires_at, created_at)`。
- **有效期边界**：`access_date` 取北京时间（`UTC+8`）当前自然日，`expires_at` 钉死为北京时间**次日 `00:00:00+08:00`**（即当日结束的零点 / 24:00）。
- **已购权益保护**：在当日 `expires_at` 到期前，访客重复打开目标玩家名片均可实时查看其最新配装（名片附带 `loadoutUnlockedUntilUnixSeconds` 提示有效期），即使目标玩家在当日内后续调高价格或切回完全隐藏，当日已付费访客的查阅权仍维持到当日零点。跨过零点后自动失效。
- **防涨价滑点**：解锁请求必传客户端看到的 `expectedPrice`；若目标玩家在访客点击瞬间刚上调价格（`actualPrice > expectedPrice`）或切为完全隐藏，服务端拒绝扣款并返回明确状态码提示刷新名片。

## 31.6 持久化结构与白名单治理（Schema v66 / 存档 v46）

1. **玩家分段存档**：
   - `settings` 分段新增可选字段 `loadoutInspectPrice`（缺省 `0`），推进 `SectionCodec.CurrentSchemaVersion` `45 -> 46`（可缺省解码，`MinReadableSchemaVersion` 保持 `41` 不抬）。
2. **新增 `social.*` 关系表**：
   - `social.guide_posts`：攻略主表（`post_id uuid PK`, `author_id uuid`, `title`, `summary`, `body`, `unlock_price`, `view_count`, `like_count`, `tipper_count`, `total_reward_stones`, `created_at`, `updated_at`, `deleted_at`）；
   - `social.guide_daily_quotas`：每日发帖计数表（`player_id uuid, post_date date, post_count integer, updated_at timestamptz, PK (player_id, post_date)`）；
   - `social.guide_post_views`：独立阅读去重表（`post_id uuid, player_id uuid, viewed_at timestamptz, PK (post_id, player_id)`）；
   - `social.guide_post_likes`：攻略点赞表（`post_id uuid, player_id uuid, created_at timestamptz, PK (post_id, player_id)`）；
   - `social.guide_post_unlocks`：付费帖永久解锁表（`post_id uuid, viewer_id uuid, paid_stones double precision, author_received_stones double precision, unlocked_at timestamptz, PK (post_id, viewer_id)`）；
   - `social.guide_post_tips`：攻略打赏累计表（`post_id uuid, tipper_id uuid, total_tipped_stones double precision, tip_count integer, updated_at timestamptz, PK (post_id, tipper_id)`）；
   - `social.loadout_inspect_grants`：配装付费查阅当日授权表（`viewer_id uuid, target_id uuid, access_date date, paid_stones double precision, target_received_stones double precision, expires_at timestamptz, created_at timestamptz, PK (viewer_id, target_id, access_date)`）。
3. **5 类持久化白名单与定期排空**：
   - 经济事务类型 `'guide.reward'` 与 `'privacy.inspect'` 纳入第⑤类跨玩家资产交互白名单（`PersistLedger = true`），并在 `PostgresRetentionWorker` 登记入 30 天流水保留集合。
   - `PostgresRetentionWorker` 定期清理过期超过 7 天的 `social.loadout_inspect_grants`、超过 7 天的 `social.guide_daily_quotas` 以及软删除超过 30 天的 `social.guide_posts`（级联清理附属互动行）。
