## 19.7 命名约定

1. **修仙难译词用拼音**：`Qi`/`Linggen`/`Gongfa`，禁止生造英文近义词（`spirit` 修为是教训）。
2. **可直译词用准确英文**：`Foundation` 底蕴、`CombatExperience` 战斗经验、`Experience` 修为。
3. **同构双名已冻结**：战斗面板 `AttackPower`/`Defense`/`CriticalResistance`/`ParryResolve` ↔ 玩家属性 `PhysicalAttack`/`Armor`/`CriticalAvoidance`/`Parry`，不再造第三名字。
4. **死契约不保留**：废弃键直接删并记入 §19.6，不留兼容路径。
5. **特质 ID 前缀 `trait.`**：特质拼音连写（`trait.liweifanfou` 力微饭否、`trait.bukandaowo` 看不到我、`trait.zhenfadashi` 阵法大师、`trait.fufaji`/`fufapozhen`/`fufatiangang`/`fufatianming` 符法四式、`trait.yangjianshu` 养剑术、`trait.cangfeng` 藏锋、`trait.xueqihuadun` 血气化盾、`trait.shanshenbu` 闪身步）；特质/技能衍生 buff 按 buff 惯例拼音（`buff.yinshen` 隐身、`buff.jianyi` 剑意、`buff.tiangang` 天罡、`buff.shenxing` 神行）。
