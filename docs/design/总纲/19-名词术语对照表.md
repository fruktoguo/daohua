## 19.1 成长四池与境界（`PlayerProgression`）

| 中文名 | 变量名 | 一句话 |
| :--- | :--- | :--- |
| 修为 | `Experience` | 顶部进度条，本层突破计量条，满层截断、突破清零 |
| 底蕴 | `Foundation`（新） | 修为满层后沉淀；未满层消耗它放大修为获取至最多 3 倍；突破不清空 |
| 战斗经验 | `CombatExperience`（新） | 修为收益按增幅前基础量等额入账；命中/闪避对抗素材（§7.7.6） |
| 总修为 | `LifetimeExperience`（新） | 历史修为收益累计，永不归零，悬浮条用它 |
| 六维经验 | `StaminaExp`/`MeridiansExp`/`AttackExp`/`BoneExp`/`AgilityExp`/`ConsciousnessExp` | 体魄/经脉/力道/根骨/身法/神识，等级 `floor(cbrt(exp/100))`，初始 0 级 |
| 功法经验 | `AbilityExperiences` | 按功法 ID 聚合，导出演练等级 |
| 境界（小境界等级） | `RealmLevel` | Lv1~127，每级一个小境界名号，突破 +1 |
| 小境界 | `RealmInfo.MinorName`（前端 `game.realm.mortal/layer/peak/…`） | 每级名号：凡胎…叩仙门、X一层~X大圆满、半步X、飞升 |
| 大境界 | `RealmInfo.StageName`（前端 `game.realm.major.*`） | 11 个：凡俗→练气/筑基/金丹/元婴/化神/炼虚/合体/大乘/渡劫→飞升 |
| 境界阶段 | `RealmInfo.PhaseName`/`RankChar`（前端 `game.realm.phase*`） | 徽章单字：凡俗段 武/玄/天，修真段 初/中/后/极 |
| 等阶（T级） | `Tier` | T1~T12 数值/内容轴（装备套/技能/丹药/怪物分档），`BaseAttributeCatalog.TierAt` 锚点推导；半步X/叩仙门计入下一等阶 |
| 本层修为上限 | `RealmProgressionCatalog.ExpToNext` / `ExpCapFor` | Lv.127 返回 0 |
| 修为结算单点 | `CreditExperience(base, amp, cap)`（新） | `credited=min(3·amp, amp+Foundation, cap−Experience)`，三条收益路径共用 |
| 寿元 / 道龄 | `AgeSeconds` / `LifespanYearsFor(tier)` | 道龄累积；寿元按等阶配表 |
| 品质（八品） | `quality`/`rarity`（前端 `game.grade.*`） | Q1凡品/Q2黄品/Q3玄品/Q4地品/Q5天品/Q6灵品/Q7圣品/Q8帝品 |
| 修行期（四期） | —（文档分组） | 前期凡俗(T1~T2)/中期气基丹(T3~T5)/后期婴神虚体(T6~T9)/大后期仙道真源(T10~T12) |

## 19.7 命名约定

1. **修仙难译词用拼音**：`Qi`/`Linggen`/`Gongfa`，禁止生造英文近义词（`spirit` 修为是教训）。
2. **可直译词用准确英文**：`Foundation` 底蕴、`CombatExperience` 战斗经验、`Experience` 修为。
3. **同构双名已冻结**：战斗面板 `AttackPower`/`Defense`/`CriticalResistance`/`ParryResolve` ↔ 玩家属性 `PhysicalAttack`/`Armor`/`CriticalAvoidance`/`Parry`，不再造第三名字。
4. **死契约不保留**：废弃键直接删并记入 §19.6，不留兼容路径。
5. **特质 ID 前缀 `trait.`**：特质拼音连写（`trait.liweifanfou` 力微饭否、`trait.bukandaowo` 看不到我）；特质衍生 buff 按 buff 惯例拼音（`buff.yinshen` 隐身）。
