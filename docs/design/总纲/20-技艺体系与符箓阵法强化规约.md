## 20.1 技艺等级体系

### 20.1.1 技艺清单

七项生活技艺，独立存储、独立升级：

| 技艺 | `TechniqueId` | 关联行动域 |
| --- | --- | --- |
| 炼丹 | `alchemy` | 炼丹、药材萃取 |
| 炼器 | `forging` | 装备精炼/锻造 |
| 符箓 | `talisman` | 符箓绘制 |
| 强化 | `enhancement` | 装备强化 |
| 阵法 | `formation` | 阵盘部署 |
| 采集 | `gathering` | 采集/砍伐/拾取 |
| 挖掘 | `mining` | 采矿 |

### 20.1.2 经验与等级

- 每项技艺持有**累计经验**（`TechniqueExperiences[id]`），初始为空即 0 级。
- 升级曲线与修为完全一致：复用 `RealmProgressionCatalog.ExpToNext` 逐段推进，`exp >= expToNext[0]` 升 1 级，溢出经验连续升级直至 `expToNext` 表耗尽（封顶）。
- 技艺经验授予：每完成一个有效行动轮次，入账对应行动等级的 100% 单轮基准经验（`Math.Round(BaseExperienceForLevel(行动等级) × 基础耗时秒 ÷ 10)`，不含速度折减，1 级基础耗时每秒折合 1 点经验；强化按被强化装备等阶换算等级与当次实际基础耗时动态计算）。
- 升级记录走 `LevelUp` 账本（kind `technique`）。

### 20.1.3 行动速度加成

- 每级技艺 +5% 对应行动速度：`实际耗时 = 基础耗时 / (1 + 0.05 × level)`。
- 作用于**该技艺对应**的行动耗时（`ActionDefinition.Technique`），不跨技艺叠加，不作用于修炼/探索/战斗/赶路主行动。
- 与节点建筑速度乘区同点结算（`TimedActionDuration`），保持确定性。

### 20.1.4 非战斗行动六维经验

非战斗行动在完成轮次（或赶路行进）时向六维定向发放经验，定位为「以行养形」的缓慢根基积累，与击杀收益的全归属全额口径（§7.10.3）完全独立。

- **收益声明与百分比配置**：`yields` 中 `experience`（修为）与 `rootexp`（六维经验，须带 `aspect`）支持直接配置百分比 `"percentage": N`（如 `100` 表示 100%、`50` 表示 50%）或比率 `"ratio": R`（如 `1.0` 或 `0.5`）；总百分比之和支持超过 100%（例如引气入体为 100% 修为 + 50% 经脉 + 50% 根骨 = 200%）。
- **行动等级**（公式基准）：优先读取行动配置的显式 `"level"`；未显式声明时按产物物等阶换算（`CraftingRecipeRules.ResolveRequiredRealmLevel`：tier≤1→Lv1、tier 2→Lv18、tier N→`18+(N−2)×12`；无产出物时回退输入材料最大等阶，再缺省 Lv1）；装备强化按**被强化装备**的等阶换算。
- **通用基准推导**（与怪物基础经验共用等级曲线计算规则）：以对应境界等级的基础经验 `BaseExperienceForLevel(行动等级) = expToNext[等级] / 1000 × 0.9^(等级-1)` 为基座（1级为 10 点，18级为 133.4 点）；10 秒行动对应 100% 基准：`单轮基准经验 = BaseExperienceForLevel(行动等级) × 基础时长秒 ÷ 10`。各项经验收益装配时按自身百分比自动推导实际点数 `amount = round(单轮基准经验 × ratio)`。
- **定额口径**：六维收益为固定入账，**不吃**持续消耗品/灵脉/建筑产出等收益倍率，速度类加成亦不改变每轮额度（更快 = 单位时间更多轮）。
- **强化特例**：不走静态 yields——每完成一个强化轮次，入账 `神识 = round(BaseExperienceForLevel(目标装备等阶换算等级) × 当次基础耗时(5+t) ÷ 10)`（相当于 100% 神识）。
- **赶路特例**：`world.travel` 声明 `per: second` 身法收益（每秒基准 = 10s 基准 ÷ 10），抵达终点按实际行进总秒数一次性取整入账，中途弃行不补发。

| 归属映射 | 六维 |
| --- | --- |
| 采集 `gathering` | 身法 agility |
| 挖掘 `mining` | 力道 attack + 体魄 stamina（平分） |
| 制造（炼丹/炼器/符箓/阵法）+ 装备强化 | 神识 consciousness |
| 修炼 `cultivation` | 经脉 meridians + 根骨 bone（平分） |
| 赶路 `world.travel` | 身法 agility（按秒） |

## 20.2 符箓 —— 雷击符

- 制造行动 `talisman.draw-leiji`（技艺=符箓）：消耗 `桃木晶×3`，20 秒/张，产出 `item.leiji-talisman`。
- 雷击符为**战斗通用栏即时消耗品**：`usableInActionTypes=["combat"]`，支持触发器条件与 60 秒冷却，无吟唱。
- 触发即扣 `manaCostRatio(5%) × MaxManapoints`；灵力不足则本次不激活。
- 打击 `raw = manaDamageRatio(20%) × MaxMana + spellAttackRatio(200%) × SpellAttack`，元素 Wood、大类 Spell；走守方减伤链（抗性平方穿甲→攻方增伤 Linear→守方减伤 NonLinear→免伤收口），物品打击不参与命中/暴击掷点。
- 目标语义与普攻一致（最高有效威胁，回退首个存活敌人）；伤害直接写入战斗实体或波次快照，胜负判定交回战斗边界。

## 20.3 阵法 —— 聚灵阵盘

- 制造行动 `formation.deploy-juling`（技艺=阵法）：消耗 `桃木晶×6 + 破碎灵核×6`，30 秒/盘，产出 `item.juling-formation-disk`。
- 聚灵阵盘为**战斗通用栏持续消耗品**（`isContinuous` + `durationSeconds=300` + `cooldownSeconds=300`）：每次遭遇入场自动消耗 1 件充入 300 秒，按战斗存活时钟扣减；耗竭时刻起算 300 秒冷却，冷却走完后的下一次入场才重新扣件补能。
- 效果：每 5 秒回蓝 `(原回蓝 + 5) × 1.3`（例：原 5 → 13）。
  - 实现为 buff 双通道：固定 `mpRegen=5` 与前段合并，`mpRegenPostRatio=0.3` 在所有固定加成合并后再乘。
  - 战斗中经由 `CombatBuffState` 同构字段作用于战内 5 秒回蓝格，Buff 时长对齐槽位剩余时长，耗尽即自然过期。
- 回复收口公式（全域同构）：`regen = (Stats.Regen + Σbuff.RegenFlat) × (1 + Σbuff.RegenPostRatio)`。

## 20.4 装备强化

### 20.4.1 物品与等级模型

- 强化等级存于**资产变体**：`AssetKey(itemId, "+N")` 为独立余额行；已装备槽位仍记录 `PlayerEquipmentSlot.EnhancementLevel`，装备校验按变体键核对余额。
- 每级强化使装备 `flatStats`/`baseStatRatios` ×1.05（指数成长，+20 满级约 ×2.653）；增幅类 `*Points` 键同样经 `flatStats` 承载并随强化缩放。
- 强化行动 `enhance.equipment`（`ActionKind.Enhancement`，技艺=强化）：按目标物品与当前等级动态结算，不走静态 inputs/yields。

### 20.4.2 单次强化结算

- 目标等级 `t = 当前等级 + 1`；`t > 20` 拒绝开轮。
- 耗时：`5 + t` 秒/次，再受强化技艺速度加成。
- 成本：`灵石 × t×10`。
- 成功率：基础成功率全阶查表（+1 为 50%，+2~+3 为 45%，+4~+6 为 40%，+7~+10 为 35%，+11~+20 统一为 30%）；技艺等级 `L≥t` 线性乘算 `×(1+0.01×L)`，`L<t` 乘性衰减 `×0.9^(t-L)`；终值 clamp `[0,0.99]`。
- 判定走确定性随机（种子=行动实例 Id 前 8 字节，channel 独立不扰战斗种子）。
- 成功 → 资产键升至 `+t`（已装备者同步槽位等级）；失败：启用保护材料（每轮消耗 1 个）则维持当前等级（`max(0, t-1)`），无保护归零（回到基础键）。保护材料由 `AuxItemId` 指定：装备配表 `enhanceProtectionItems` 非空时取列表内任一物品，未配置时以同装备无强化基础件（裸 `AssetKey`）代护；保护材料与本体共用裸键时（+0 装备以自身裸件代护）须持有 ≥2。
- `targetLevel` 意图参数到达后行动提前完成出队；余额不足/物品不存在 → 阻塞语义无产出。
- 每完成一个强化轮次（无论成败）入账六维·神识：`round(MonsterKillExperience(目标装备等阶换算等级) × 当次基础耗时(5+t) ÷ 10)`，定额不吃收益倍率（§20.1.4）。

## 20.5 内视「技艺」Tab 与前端页面

- 内视页新增 `technique` Tab：七技艺列表，每项展示等级、经验进度（本级累计/下一级需求）、+5%×等级 行动速度加成。

## 20.7 技艺工具

### 20.7.1 物品模型

- 七技艺各配一件可装备工具，以**装备目录条目**落地（`equipment.` 前缀、进 `RawEquipments`），不参与物品目录登记。
- 装备槽位：`slot = "tool-<techniqueId>"`（`tool-alchemy`/`tool-forging`/`tool-talisman`/`tool-enhancement`/`tool-formation`/`tool-gathering`/`tool-mining`），七个专属槽位随装备槽位唯一互斥校验天然互斥，同技艺至多一件。
- 加成声明：`techniqueBonus = { technique, speedRatio }` 绑定技艺与速度加成数值；`speedRatio` 配表化为后续高品阶工具留空间，本批（tier 1）恒为 `0.10`。
- 工具不配置 `flatStats`/`baseStatRatios`，对战斗属性零贡献；命名遵循「本名不拼品阶前缀」，高阶工具以新 id 承载。
- 首批工具：桃木铲（采集）、精铁镐（挖掘）、灵火炉（炼丹）、百炼铁钳（炼器）、桃木笔（符箓）、桃晶旗（阵法）、淬灵锤（强化）。

### 20.7.2 速度加成结算

- 行动 `Technique` 命中已装备工具的 `techniqueBonus.technique` 时，其 `speedRatio` 与技艺等级加成**同除数加算**：`实际耗时 = 基础耗时 / (1 + 0.05×技艺等级 + Σ工具speedRatio)`。
- 不跨技艺叠加、不乘产出倍率；与节点建筑速度乘区同点结算（`TimedActionDuration`），保持确定性。

### 20.7.3 制造与获取

- 工具由炼器产出：炼器页新增「技艺」子分组，7 条 `forge.tool-*` 配方（`technique=forging`），产出对应 `equipment.tool-*`。
- 工具**可强化**：强化规则同普通装备（指数成长 1.05^强化等级，未配置保护材料时以同装备基础件代护）；强化后其 `techniqueBonus.speedRatio` 随强化等级等比缩放（`有效速度加成 = 基础加成 × 1.05^强化等级`），与技艺等级加成同除数加算，进一步提升对应生活生产行动速度。

### 20.7.4 前端槽位

- 装备面板底部「技艺工具」区为七个可交互槽位（每技艺一格），点击弹网格挑选器按 `tool-<techniqueId>` 过滤，穿脱复用 `loadout.replace` 通道。
