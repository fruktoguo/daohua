# 第二十篇 技艺体系、符箓/阵法制造与装备强化规约

> **篇目定位**：生活技艺等级/经验/速度加成、符箓与阵盘制造、装备强化的唯一设计真源。
> 实现契约字段名以 `docs/tasks/TASK-20261003-04.md` 为准；本篇约束设计意图与结算语义。

## 20.1 技艺等级体系

### 20.1.1 技艺清单

七项生活技艺，独立存储、独立升级：

| 技艺 | `TechniqueId` | 关联行动域 |
| --- | --- | --- |
| 炼丹 | `alchemy` | 炼丹、药材萃取 |
| 炼器 | `forging` | 装备精炼/锻造 |
| 符箓 | `talisman` | 符箓绘制 |
| 强化 | `enhancement` | 装备强化 |
| 阵法 | `formation` | 阵盘部署 |
| 采集 | `gathering` | 采集/砍伐/拾取 |
| 挖掘 | `mining` | 采矿 |

### 20.1.2 经验与等级

- 每项技艺持有**累计经验**（`TechniqueExperiences[id]`），初始为空即 0 级。
- 升级曲线与修为完全一致：复用 `RealmProgressionCatalog.ExpToNext` 逐段推进，`exp >= expToNext[0]` 升 1 级，溢出经验连续升级直至 `expToNext` 表耗尽（封顶）。
- 技艺经验授予：每完成一个有效行动轮次，入账 `definition.DurationSeconds`（基础耗时秒数，不含速度折减）；强化按当次实际基础耗时。
- 升级记录走 `LevelUp` 账本（kind `technique`）。

### 20.1.3 行动速度加成

- 每级技艺 +5% 对应行动速度：`实际耗时 = 基础耗时 / (1 + 0.05 × level)`。
- 作用于**该技艺对应**的行动耗时（`ActionDefinition.Technique`），不跨技艺叠加，不作用于修炼/探索/战斗/赶路主行动。
- 与节点建筑速度乘区同点结算（`TimedActionDuration`），保持确定性。

## 20.2 符箓 —— 雷击符

- 制造行动 `talisman.draw-leiji`（技艺=符箓）：消耗 `残魄灵符×2 + 桃木晶×1`，20 秒/张，产出 `item.leiji-talisman`。
- 雷击符为**战斗通用栏即时消耗品**：`usableInActionTypes=["combat"]`，支持触发器条件与 60 秒冷却，无吟唱。
- 触发即扣 `manaCostRatio(5%) × MaxManapoints`；灵力不足则本次不激活。
- 打击 `raw = manaDamageRatio(20%) × MaxMana + spellAttackRatio(200%) × SpellAttack`，元素 Wood、大类 Spell；走守方减伤链（抗性平方穿甲→攻方增伤 Linear→守方减伤 NonLinear→免伤收口），物品打击不参与命中/暴击掷点。
- 目标语义与普攻一致（最高有效威胁，回退首个存活敌人）；伤害直接写入战斗实体或波次快照，胜负判定交回战斗边界。

## 20.3 阵法 —— 聚灵阵盘

- 制造行动 `formation.deploy-juling`（技艺=阵法）：消耗 `灵松晶×2 + 破碎灵核×2`，30 秒/盘，产出 `item.juling-formation-disk`。
- 聚灵阵盘为**战斗通用栏持续消耗品**（`durable`）：部署后槽位启用且钱包持有即生效，不消耗物品、不耗竭时长。
- 效果：每 5 秒回蓝 `(原回蓝 + 5) × 1.3`（例：原 5 → 13）。
  - 实现为 buff 双通道：固定 `mpRegen=5` 与前段合并，`mpRegenPostRatio=0.3` 在所有固定加成合并后再乘。
  - 战斗外经由 `ActiveBuff`（无限期、随槽位状态注入/清除）作用于资源 5 秒回复边界；
  - 战斗中经由 `CombatBuffState` 同构字段作用于战内 5 秒回蓝格。
- 回复收口公式（全域同构）：`regen = (Stats.Regen + Σbuff.RegenFlat) × (1 + Σbuff.RegenPostRatio)`。

## 20.4 装备强化

### 20.4.1 物品与等级模型

- 强化等级存于**资产变体**：`AssetKey(itemId, "+N")` 为独立余额行；已装备槽位仍记录 `PlayerEquipmentSlot.EnhancementLevel`，装备校验按变体键核对余额。
- 每级强化使装备 `flatStats`/`baseStatRatios` ×(1+0.02)（既有公式，+20 满级合计 +40%），`specialMechanics` 不缩放。
- 强化行动 `enhance.equipment`（`ActionKind.Enhancement`，技艺=强化）：按目标物品与当前等级动态结算，不走静态 inputs/yields。

### 20.4.2 单次强化结算

- 目标等级 `t = 当前等级 + 1`；`t > 20` 拒绝开轮。
- 耗时：`5 + t` 秒/次，再受强化技艺速度加成。
- 成本：`灵石 × t×10`。
- 成功率：`t≤10` 查表 `[0.5,0.45,0.45,0.4,0.4,0.4,0.35,0.35,0.35,0.35]`；`t≥11` → `0.3×0.95^(t-11)`，clamp `[0.01,0.5]`；技艺等级 `L≥t` 加性 `+0.01×L`，`L<t` 乘性 `×0.9^(t-L)`；终值 clamp `[0,0.99]`。
- 判定走确定性随机（种子=行动实例 Id 前 8 字节，channel 独立不扰战斗种子）。
- 成功 → 资产键升至 `+t`（已装备者同步槽位等级）；失败：启用保护材料（每轮消耗 1 个）则维持当前等级（`max(0, t-1)`），无保护归零（回到基础键）。保护材料由 `AuxItemId` 指定：装备配表 `enhanceProtectionItems` 非空时取列表内任一物品，未配置时以同装备无强化基础件（裸 `AssetKey`）代护；保护材料与本体共用裸键时（+0 装备以自身裸件代护）须持有 ≥2。
- `targetLevel` 意图参数到达后行动提前完成出队；余额不足/物品不存在 → 阻塞语义无产出。

## 20.5 内视「技艺」Tab 与前端页面

- 内视页新增 `technique` Tab：七技艺列表，每项展示等级、经验进度（本级累计/下一级需求）、+5%×等级 行动速度加成。
- 技艺导航组在 炼丹/炼器 之外新增 符箓/阵法/强化 三个子页；符箓/阵法复用行动卡网格；强化为独立页面（物品格+目标等级+保护槽+重复控件 / 费用·成功率·产出·经验·耗时面板）。

## 20.6 持久化与协议

- `PlayerLoadoutDocument.TechniqueExperiences` 随 Loadout 分段持久化；`ActionIntent` 增 `targetItemId`/`auxItemId` 入队载荷。
- `SectionCodec.CurrentSchemaVersion` 与 `PostgresSchema.Version` 同步 +1，新增字段全部可缺省解码。
