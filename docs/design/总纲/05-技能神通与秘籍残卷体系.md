## 5.2 完整技能书与残卷体系 (23 门功法配套书对 = 46 种专属道具)
1. **完整技能书 (`item.tome.<ability_id>`)**（掉率 0.1%）：
   - **首次研读**：直接领悟并解锁该技能（初始 Lv.1，0 经验）；
   - **学会后再次使用**：为该技能直接增加 **10,000 点技能经验**。
2. **技能书残卷 (`item.fragment.<ability_id>`)**（掉率 2.0%）：
   - **使用前置条件**：必须先学会对应技能，未领悟前无法研读；
   - **使用收益**：为对应技能增加 **500 点技能经验**。
3. **秘籍覆盖面守恒律（硬约束）**：**每一门 `abilities/*.json` 中定义的功法都必须同时存在 `item.tome.<id>` 与 `item.fragment.<id>` 两条物品定义**，不得存在无秘籍可学的功法，也不得存在无对应功法的秘籍。服务端 `ability.learn` 靠 `item.tome.` / `item.fragment.` 前缀反推 `ability.<x>`（`EcsPlayerRuntimeAdapter`），缺任一侧都会让掉落变成死物品或功法永远无法习得。新增功法时必须同批补齐秘籍、残卷、`frontend/src/game/ids.ts` 静态元数据与 `game.zh.ts` 词条（`check-i18n-keys.mjs` 会对缺失硬失败）。
   - **当前覆盖**：23 门功法 × 2 = 46 件；`碎罡`（`ability.sui-gang`）由二图关底首领 **撼地金背猿**（`enemy.golden-ape-boss`）掉落补齐，秘籍 1%、残卷 5%，与该首领既有「重斩/连环」书对同档。
4. **批量研读**：秘籍与残卷属手动即时消耗品，支持一次选择多本（`ability.learn` 携带 `quantity`）。
   - 语义与逐本重复点击等价：未习得功法时使用 N 本秘籍，第 1 本领悟解锁，其余 N-1 本各 +10,000 经验；已习得则 N 本各 +10,000；残卷 N 本各 +500。
   - **结算代价与数量解耦（硬约束）**：等级只由累计经验经立方曲线派生，故服务端按 `总量 = 本数 × 单本经验` **一次注入、一次跃迁判定**，禁止按本数循环。日志账本把批量折叠为一条 `起始等级 → 最终等级` 跃迁记录，经验总量与逐本累加同值。
   - 命令在玩家所在 ECS 世界分片的所有权门闩内执行，客户端可控的 `quantity` 绝不允许决定循环次数或迭代规模；任何批量入口（研读/回收/丢弃/挂售）都必须是 O(1) 或 O(固定槽位数)。
   - 一次批量只针对同一种 `itemId`；**扣减前先按钱包快照校验持有量**，不足整笔拒绝并返回 `INSUFFICIENT_ITEM`（扣减与习得在同一经济事务中原子提交或整体回滚）。
   - 单次 `quantity` 上限 1e12 本且不得超过当前持有量；超出按 `INVALID_QUANTITY` 拒绝。
5. **等级成长推导规则**：
   - 全部技能数值项每级 **+2.0% 线性成长**：`LevelGrowth = 1 + 0.02 × (Lv − 1)`——伤害倍率、固定伤害、治疗量与支援数值（`threatGain`、Buff 增伤/免伤/威胁增幅/每秒威胁等点数及固定回复）同式；
   - 时长与叠层上限不成长。

## 5.3 内功心法体系（10 门内功心法）

**定位**：内功是常驻被动的心法基座——装配 0 号内功位即生效，**不进入施放序列**（无冷却/吟唱/耗蓝/触发器）；其权威定位是**经验获取调整器**：按 `rootExpMultipliers` 对六维经验做**非守恒乘率重分配**（提升某一维度、压低另一维度，达成个性化养成），并可携带修为增减点与常驻面板效果。

### 5.3.1 心法配表字段与结算公式

- `discipline: "internal"`：只入 0 号内功位（槽位双向互斥，术法位只收 `spell`）；internal 功法不配 `defaultTriggers`/`manaCost`/`castMilliseconds`/`damageRatio` 等施放字段，战斗施放管线对 `internal` 一律跳过。
- `rootExpMultipliers`：六维乘率表，键为 `stamina`/`meridians`/`attack`/`bone`/`agility`/`consciousness` 子集，未列维度缺省 `1.0`，允许配 `0`（献祭归墟——该维终身停长，为真代价）。
- **六维入账公式**：`share_i = experience × mult_i × eff`（每个归属维度各得全额乘以自身乘率）；非守恒——六维总效率 = `eff × Σmult/6`，允许偏离 100%（总量是内功强度的定价旋钮：偏科越狠/总量越高，代价越硬）。
- `rootExpEfficiencyPerLevel`：参悟等级每级提升六维总效率，`eff = 1 + perLevel × (参悟Lv − 1)`；参悟等级与术法同口径由功法经验立方曲线导出，内功不施放、参悟经验唯一来源为秘籍/残卷研读（§5.2）。
- `cultivationExpBonusPoints`：修为类收益增减点（1 点 = 1%），作为独立乘区乘在增幅后收益量 `amp` 上，对全部修为类收益路径生效（击杀/行动收益/冥想，见 [第七篇](./07-战斗数值与内视规约.md) §7.11.1）；负值为「弃道从武」型内功的代价。
- `passive`：常驻面板效果块，复用装备 `flatStats` 同族点数字段汇入 `PlayerAttributeResolver`；基础数值按现行口径配置，并随参悟等级线性成长，每级提升 +5%（`passiveScale = 1 + 0.05 × (Lv − 1)`）。
- `rootAttribute`：保留为主修维度标识（UI 归属展示/设计语义），不再承担分配计算——分配唯一由 `rootExpMultipliers` 决定。
- 未装备内功时六维全归属、各得全额（每维 `experience`，总量 6×）；神通/外功声明 `rootAttribute` 不参与分配。

### 5.3.3 内功六维总额度双轴量化模型与设计原则

为确保未来全等阶（T1~T12）与八大品质（Q1~Q8）内功数值秩序井然，建立**双轴量化参考模型**：

1. **等阶轴（Tier，T1~T12）**：T1 凡品基准为 $600\%$，T 级每提升 1 级，基础总额度 $+100\%$：
   $$\text{Base}(T) = 600\% + (T - 1) \times 100\% = (500 + T \times 100)\%$$
2. **品质轴（Quality，八品 Q1~Q8）**：品质每提升 1 级，总额度提升 $20\%$（指数型，四舍五入取整）：
   $$\text{Cap}(T, Q) \approx \text{round}\Big( \text{Base}(T) \times 1.20^{Q - 1} \Big)\%$$
3. **宏观设计矩阵标尺（T1~T4 × Q1~Q5 理论基准）**：
   - T1 凡俗：Q1 600% / Q2 720% / Q3 864% / Q4 1037% / Q5 1244%
   - T2 练气：Q1 700% / Q2 840% / Q3 1008% / Q4 1210% / Q5 1452%
   - T3 筑基：Q1 800% / Q2 960% / Q3 1152% / Q4 1382% / Q5 1659%
   - T4 金丹：Q1 900% / Q2 1080% / Q3 1296% / Q4 1555% / Q5 1866%
4. **具体功法落地取整原则**：
   - 上述公式为设计总纲的**宏观基准锚点（Anchor）**，用于规划产出梯队与成长天花板；
   - 具体功法落地时**以整洁好记、符合玩家心智为最高优先级**，可在理论基准上下适度取整，不机械死抠零头（例如 T3 Q3 玄阶玄品理论标尺为 1152%，首门玄门正宗心法《玄元一气功》采用六合同修全维均等方案，直接整洁取整为六维各 200% / 总和 1200% 翻倍，且无常驻 passive 效果，纯粹以强大的潜能倍率彰显高阶底蕴）。
5. **秘籍/残卷物品**：每门内功按 §5.2 同规范配 `item.tome.<id>` / `item.fragment.<id>`；投放途径（掉落/坊市/引导）由后续任务统一规划。
6. **历史归类清理**：嘲讽/清平乐/破阵子三门曾以 `internal` 过渡归类，随真内功落地统一改回 `discipline: "spell"`——`internal` 门类自此只收经验调整型被动心法。
7. **文案纯仙侠风味红线（严禁带出游戏术语）**：所有功法、心法、秘籍、残卷的剧情介绍与悬浮描述，必须保持纯正沉浸的仙侠世界观风味，**绝对禁止出现“六维”等现代游戏系统术语**；统一使用“周天百骸、形神兼修、内外浑融、根基道基”等修仙语境进行沉浸表达。
