# 第二十二篇 新手引导系统（服务端权威任务链式导览）

> **定位**：新玩家首次进入后的线性任务链引导，覆盖采集 → 炼丹 → 炼器 → 地图移动 → 修炼 → 战斗六条核心玩法通路；表现层沿用「遮罩镂空 + 高亮描边 + 气泡卡 + 步骤进度」的引导范式，步骤权威由服务端持有。

## 22.1 设计目标与红线

- **服务端权威**：引导步骤（`TutorialStep`）持久化在玩家 `settings` 分段，材料赠送与完成奖励在行动结算管线内随模拟事务入账。清理浏览器缓存不得重置进度或重复领取奖励；断线重连后按快照恢复到当前步骤。
- **前端只表现**：前端按快照里的 `tutorialStep` 渲染当前里程碑的引导 UI（准备页签、高亮真实控件、气泡文案、跳过），不在客户端判定完成条件、不发放奖励。
- **严格单向**：步骤只能前进（`0 → … → 7`），不存在回退或分支；跳过收敛到终态并补发剩余未领奖励；唯一的「重来」是显式 `tutorial.restart`（重置步骤但不动奖励游标）。
- **不过度防御**：引导不阻断玩家自由操作；玩家在引导外自行完成的同种行为不计入步骤（每步只认对应行动的完成事件）。

## 22.2 里程碑状态机

`TutorialStep` 为 `int`，挂在 `PlayerSettingsState`（settings 分段），随全量/增量快照以 `settings.tutorialStep` 下发。缺省解码为 `0`。

| 值 | 里程碑 | 推进条件（服务端） | 推进时入账 |
| --- | --- | --- | --- |
| 0 | 采集 | `explore.gather-ningxue-grass` 完成一轮（出生点云溪村就地可采） | 凝气草 ×3（炼丹材料） |
| 1 | 炼丹 | `alchemy.refine-qi-pill` 完成一轮 | 百炼铁 ×7 + 兽骨 ×1（炼器材料） |
| 2 | 炼器 | `forge.qingfeng-sword` 完成一轮 | — |
| 3 | 前往云巅草庐 | 旅行到达 `node.cloud-peak`（或激活本步时已驻留该节点） | — |
| 4 | 修炼 | `cultivation.draw-qi` 完成一轮（云巅草庐修炼加速 1.25×） | — |
| 5 | 返回云溪村 | 旅行到达 `node.yunxi-village`（或激活本步时已驻留该节点） | — |
| 6 | 战斗 | `combat.hunt-qi-beast` 完成一轮（一波清空，即 `combat.won` 口径，而非进入战斗阶段） | **功德 ×1000 + 灵石 ×10000** |
| 7 | 完成 | 终态；跳过引导同样收敛到本值 | — |

规则细节：

- 行动型里程碑只认「该行动 ID 完成一轮」的结算事件，驻留型里程碑只认「当前驻留节点 = 目标节点」。
- 驻留型里程碑在进入该步骤的同一结算窗口内立即重估：若玩家激活旅行步时已驻留目标节点，直接续推进，避免「先旅行后补步骤」造成的卡死。
- 赠送与奖励经结算窗口的 `deltas` 增量通道写入资产钱包，与行动产出共用同一事务与资产差量推送；同一迁移只发生一次（步骤不可逆天然幂等）。
- **奖励游标** `TutorialRewardsStep`（settings 分段，缺省 0）：记录奖励已发放至第几里程碑；里程碑推进仅当 `nextStep > 游标` 才入账该步赠送并推进游标，重学路径不重复发放已领奖励。
- `tutorial.skip` 命令把 `TutorialStep` 置为 7 并**补发剩余未领奖励**（游标+1..7 的赠送/终奖合并入账，走命令经济事务 + 资产差量推送 + 结构化入账日志）；重复跳过幂等空转。
- `tutorial.restart` 命令把 `TutorialStep` 重置为 0（奖励游标不动）：供「重新学习引导」；重走流程可再完成全部交互步骤，但已领过的阶段奖励与终奖不再重复发放，未领过的里程碑走到时仍照常入账。

## 22.3 结算挂钩点

推进器为 ECS 层静态规则 `TutorialRules`，在三处结算边界内嵌调用：

1. `CompleteRepeat`（`ActionExecutionRules.Timed.cs`）：计时行动每轮完成（`action.completed`）后，按行动 ID 匹配里程碑 0/1/2/4。
2. `CompleteCombatAdvanceCore` 波次清空分支（`CombatActionRules.cs`）：`combat.won` 计一轮完成后，匹配里程碑 6。
3. `FinishTravel`（`ActionExecutionRules.Travel.cs`）：`world.arrived` 后按驻留节点匹配里程碑 3/5。

所有钩子只携带「玩家上下文 + 触发事实 + 增量字典/事件尾」参数，无状态、无分配扩张，不在热路径引入集合重建。

## 22.4 前端导览层

React 组件 `TutorialOverlay`（`frontend/src/tutorial/`）按 `tutorialStep` 渲染当前里程碑的 UI 子步骤序列：

- **视觉**：四块半透明暗色遮罩围出目标元素镂空（外扩数像素），金/红描边高亮框脉冲；气泡卡含里程碑 kicker、标题、正文、`n/m` 进度条与「跳过 / 上一步 / 下一步」按钮；箭头小方块指向目标；卡片按剩余空间自动选择方位并 clamp 进视口。
- **子步骤推进模式**：
  - `button`：点「下一步」；
  - `target`：点击高亮目标本身推进（遮罩镂空放行真实点击，先教后做）；
  - `server`：等待型卡片（无推进按钮），服务端里程碑翻转后自动进入下一里程碑。
- **prepare**：子步骤激活时先驱动真实 UI（切页签、切技艺模式/子页签），再轮询等待目标元素出现后再测量定位；目标缺失时卡片降级为居中提示。
- **弹窗治理**：业务弹窗（`Modal`/`ConfirmDialog`，z-index 低于引导层）在引导期间只允许「当前目标所在的弹窗」存在；定位轮询对每个 `.modal-backdrop` 判定——不含当前目标的游离弹窗一律程序化点击其 `.modal-close` 收拢（覆盖「上一步」回退残留弹窗、跨页签 portal 残留等死锁路径）；目标元素 `disabled` 或被遮挡时按定位失败计数，超时出现逃生「下一步」。
- **等待步展示聚焦**：`server`/`arrive` 等待子步骤经 `focusSelector` 镂空聚焦一块「可看不可点」的详情区——行动类等待切「详情」页签聚焦行动实况面板，旅行类等待切「地图」页签聚焦节点地图本体；镂空区上盖透明拦截层吃掉点击（中止按钮等原可交互控件在引导期不可操作），气泡卡以实测尺寸避让到聚焦区外悬浮。
- **锚点**：行动卡片带 `data-action-id`，导航带 `data-tour="nav:*"`，行动模态提交钮、地图「规划路线」「启程」钮带专用 `data-tour`；地图节点沿用既有 `data-node-id`；详情页主面板 `data-tour="combat-detail"`，节点地图 `data-tour="world-map"`。
- **生命周期**：`hasReceivedSnapshot` 且 `tutorialStep < 7` 时挂载；里程碑翻转为 7 时展示一次完成卡（含奖励文案），「完成」后卸载。
- **跳过二次确认**：点「跳过引导」先弹引导层内确认卡（业务 `ConfirmDialog` 层级低于引导层不可复用），文案明确「跳过后剩余奖励将直接发放，之后可在设置→引导重新学习」；确认才发送 `tutorial.skip`。
- **重学入口**：设置页「引导」分类提供「重新学习引导」（发送 `tutorial.restart` 后引导层自动重新挂载）与当前进度说明。

## 22.5 「功德」物品

引导终奖使用既有占位物品 `item.gongde`（名「功德」，见 §21.12.3）：`kind/category = currency`、`sellPrice=0` 不可系统回收、可进坊市挂单，新手引导是其首个产出入口。绑定变体 `item.gongde-bound` 仍归邀请系统独占，引导奖励不涉足。赠送与奖励均为普通资产增量，无独立货币通道。

## 22.6 存档与兼容

- `PlayerSettingsStateDocument` 与 `SectionCodec.SettingsDocument` 新增 `TutorialStep`（缺省解码 `0`）与 `TutorialRewardsStep`（缺省解码 `0`）；schema 版本推进至 15，`migrations/0015_v14_to_v15.sql` 仅做标签推进。
- 旧存档解码 `tutorialStep = 0`：既有内测账号登录后会看到一次引导，可跳过，语义可接受且便于验收。
- v14 载荷无奖励游标：解码时按 `tutorialStep` 回填「必然已领过」的游标下限（已进炼丹 ⇒ 游标≥1，已进炼器 ⇒ ≥2，已 Done ⇒ 7），防止升级后重学/跳过路径重复领取阶段赠送。

## 22.7 验证口径

- 领域/ECS 测试：新建玩家 `tutorialStep = 0`；逐里程碑驱动采集/炼丹/炼器/修炼完成一轮与两次旅行到达、一波讨伐胜利，断言步骤推进、材料与终奖精确入账且不重复；跳过补发清单按物品合并、跳过后游标至 Done 幂等；重学重置步骤不动游标、跳过后重学全程不再入账；编码→解码往返后步骤保留。
- 前端：`tutorialStep` 全量/增量快照链路、各里程碑锚点选择器可解析。
