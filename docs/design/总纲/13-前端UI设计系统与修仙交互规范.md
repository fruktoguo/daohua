# 第十三篇 前端 UI 设计系统与修仙交互规范

## 13.1 暗墨玄石美学与色调规范
- **材质底色**：`rgba(14, 12, 7, 0.96)` 高透明度深黑底色 + `backdrop-filter: blur(14px)` 毛玻璃效果。
- **古典修仙色调 (`FloatingTone` / `PillTone`)**：
  - `gold` (暗金/极品/破招)、`jade` (苍翠/生命/木行)、`qi` (灵虚淡蓝/灵力/神识)、`danger` (朱砂煞红/负伤/削弱)、`purple` (紫极天道/仙品)、`muted` (玄灰幽暗/背景注记)。

### 13.1.1 深色与浅色显示主题

- 设置 → 显示提供「浅色 / 深色」分段选择，默认浅色；选择在当前浏览器保存，刷新后在首屏恢复。
- 浅色采用稍暗的暖灰纸底、古铜金边框和深墨文字，保留现有字体、布局、间距、图标、品质层级、修仙色相、角纹、内描边、渐变、法阵及交互动效；深色延续暗墨玄石风格。
- 主题由根节点 `data-theme` 与统一配色、字重变量驱动，悬浮 Portal、弹窗、登录/连接屏幕、地图与战斗信息使用同一主题；物品图像与技能特效不做整体反色。
- 两套主题分别提供正文、次要文字、语义色、面板、输入框与交互状态配色。浅色普通文本对实际底色的对比度至少 4.5:1，焦点与必要控件边界至少 3:1；不能直接把深色高亮文字复用于浅色底。
- 浅色正文、辅助文字、输入控件与原 400/500 字重的标签和标题统一提升至至少 600 字重（由 `--font-weight-regular`/`--font-weight-medium` 主题字重变量驱动），原有 600 及以上字重保留不变；深色沿用原有字重。
- 切换只更新主题外观（配色与字重）与浏览器主题元数据，不重新挂载游戏界面，不触发网络命令，不改变输入值、滚动位置与游戏状态。

## 13.2 核心公共组件速查 (强制收拢规范)
1. **`FloatingPopover` / `FloatingInfoCard` / `FloatingTooltip`**：基于 React Portal 挂载至 `#daohua-floating-root`，自动计算视口翻转（Auto Flip）与边界夹持（Viewport Clamp），标准宽度 `medium` (300px)，支持 `quantity={amount}` 独立中文四位分段副气泡；桌面 Hover 防抖、移动端 Touch 0 阻碍穿透底层。
2. **`RealmBadge`**：大境界牌匾框 + 位阶棱形框 + 小境界胶囊框，Hover 展示精准等级与属性。
3. **`PillStatLabel` / `PillBonusLabel`**：复合修仙胶囊，内置图标、专属下划线数值、内联进度条与 Tooltip。
4. **`ItemTile` / `ItemGridPicker`**：标准物品方块，品阶光晕色、品质边框、旋转填充倒计时遮罩。
5. **`QuantitySelector`**：数量输入、常用预设按钮与 `∞` 无限循环按键。
6. **`UnitNumber`**：万进紧凑展示（最多6位数字、2位小数、向下取整），Hover 弹出中文四位分段对照（如 `1234亿 7777万 5211`）。
7. **`CharacterAvatar`**：角色/妖兽立绘，WebP/PNG/SVG 智能降级，敌方自动镜像翻转（`scaleX(-1)`）。

## 13.3 普攻与受击反馈层级

- 普攻采用「掠斩、直刺、回锋、震击」四种短促演出，同一出手单位交替使用；变化只影响画面，不改变攻击时刻、目标、伤害或次数。
- 受伤采用「裂光、震纹、碎星」三种局部反馈，同一受击单位交替使用；正式前端由权威气血下降触发，画廊由沙盘扣血触发，一次伤害只启动一次受击动画。
- 普攻主色限于骨白与淡金，受击用克制的暖白与朱砂；禁止普通命中引发全屏闪白、震屏、大范围烟雾或长尾粒子。每次普攻最多 8 枚小粒子，主体轨迹在约 0.4 秒内收束，所有残留在 0.8 秒内清理。
- 光痕与震纹集中在立绘身位，尺寸跟随立绘台缩放，不触碰名字、资源条与行动条布局；连续攻击时保留目标轮廓与数值可读性。
- 画廊与正式前端共享普攻脚本和受击样式；画廊提供命名变体按钮供逐项查看，环境普攻自动交替。技能、暴击、阵亡仍保持独立演出层级。
