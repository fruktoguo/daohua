# 第二十三篇 万象图鉴与解锁机制

> 状态：随 TASK-20261013-02 落地；TASK-20261021-07 重构为多维 Toggle 筛选体系。本文档为《道化太初》图鉴系统（Codex）与解锁机制的唯一权威设计真源。
> 前端页面：`frontend/src/components/CodexPage.tsx`，对应主界面顶级页签 `codex`（图鉴）；分类与筛选纯函数：`frontend/src/game/codexFilters.ts`。

---

## 23.1 核心定位与设计哲学

图鉴是修士在大千世界历练、探索、修习与百工营造过程中的见闻典籍。
其核心定位为：
1. **收集与索引真源**：聚合修仙世界中的五大维度——**天地材料、制造配方、节点建筑、功法神通、妖兽精怪**，提供直观的收集进度与详情总览；
2. **能力与玩法解锁的闸门**：
   - **天地材料**：展示大千世界中的草木药材、矿石矿脉与妖兽异材，提供产出来源、基础用途与市场行情指引；
   - **制造配方**：玩家未解锁对应图鉴前，在制造交互列表中**彻底隐藏**，不可见且服务端拒绝执行；
   - **节点建筑**：玩家未解锁对应图鉴前，在地点建造候选列表中**彻底隐藏**，不可见且服务端拒绝发起；
   - **功法神通与妖兽**：记录修士已学神通与已降服妖兽。

## 23.2 五大分类与解锁规约

### 23.2.1 天地材料（Materials）

涵盖修仙界百工炼造与历练采集的基础材料，居于万象图鉴首位。材料子分类**直取配表 `subCategory` 字段**，共四类（互斥且完备，禁止按物品 ID 写特例分流）：
1. **灵材 (spiritMaterial)**：野外采集之草木灵材（凝气草、桃木、晨露、伴灵花、引灵松等）；
2. **矿石 (mineral)**：矿脉采掘之原矿（乌铁、赤铜等）；
3. **异材 (exoticMaterial)**：妖兽讨伐掉落之奇珍残蜕（兽皮、兽骨、破碎灵核、妖丹、煞齿、兽牙、火羽、残魄灵符、残刃、煞骨、妖核、陨星破片等）；
4. **精材 (refinedMaterial)**：经萃取与精炼所得的精料（草木精华、伴灵精华、桃木晶、灵松晶、百炼铁、赤铜精）。

> 配表新增材料若缺 `subCategory` 或取值不在上述四类内，图鉴材料页会整条缺失，由 `frontend/src/game/codexFilters.test.mjs` 与 `codexCalculations.test.mjs` 的配表完备性断言强制拦截。

- **解锁规则**：
  - **T1 材料**（等阶 Tier 1）：默认 1 级自动解锁并收录图鉴；
  - **T2 材料**（等阶 Tier 2，对应 18 级）：
    - **境界或技艺双重解锁（或关系）**：修士角色境界达到 18 级（凡俗 [天] 叩天门），**或者**对应生活技艺等级达到 18 级，均可自动解锁收录图鉴：
      - **药材 (Herb)**：草木灵材与百草精粹关联**采集技艺 (gathering)**；
      - **矿石 (Mineral)**：采掘原矿与金铁精材关联**采矿技艺 (mining)**；
      - **异材 (Exotic)**：妖兽讨伐残蜕因无专属生活技艺，由境界等级裁决；
    - **持有直接点亮**：玩家背包当前或曾持有该材料时亦即刻点亮收录。
- **图鉴展示**：
  - 无论是否解锁，在「材料」分类及其子 Tab 下均列出所有已知材料；
  - 未解锁状态以暗墨虚影及锁头标记，Hover 悬浮卡内清晰标注双重解锁条件（如【解锁条件：境界达到 lv18 或 采集达到 18 级解锁】）；
  - 已解锁状态以标准 `ItemTile` 瓦片全彩呈现，悬停展示完整品类标签、等阶、风味描述及坊市行情副卡片。

### 23.2.2 制造配方（Crafting）
涵盖修仙四大技艺生活制造：**炼丹 (Alchemy)、炼器 (Forging)、阵法 (Formation)、符箓 (Talisman)**；子分类取行动配表 `technique` 字段，精炼与萃取类 `craft.*` 行动按实际技艺归属（`craft.refine-*` 属炼器、`craft.extract-*` 属炼丹）。

- **解锁规则**：
  - **T1 配方**（等阶 Tier 1）：默认 1 级自动解锁并收录图鉴；
  - **T2 配方**（等阶 Tier 2，对应 18 级）：
    - **境界或技艺双重解锁（或关系）**：角色境界达到 18 级（凡俗 [天] 叩天门），**或者**对应制造技艺等级（炼丹 alchemy、炼器 forging、阵法 formation、符箓 talisman）达到 18 级，满足其一即自动领悟并解锁图鉴；
    - 配方 T 级由产出物（Yields）或输入物（Inputs）的最大 Tier 裁决（`convertTierToLevel(tier)`）。
- **交互与拦截**：
  - **前端交互**：技艺制造页面（`CraftingPage`）只展示当前玩家已解锁图鉴的配方（境界达到或对应技艺达到）；未解锁配方不出现在列表中。
  - **服务端拦截**：`action.enqueue` 针对制造类及探索采集行动，严格校验 `RealmLevel >= requiredLevel || TechniqueLevel >= requiredLevel`；双重等级均不足时拒绝入队，错误码为 `RECIPE_LOCKED` 或 `ACTION_LOCKED`。
- **图鉴展示**：
  - 无论是否解锁，在图鉴「制造」分类下均列出所有已知配方；
  - 未解锁状态以暗墨剪影/锁头标记，Hover 悬浮卡内清晰标注【解锁条件：境界达到 lv18 或 {技艺名}达到 18 级自动领悟】。

### 23.2.3 建筑图谱（Buildings）

涵盖大世界节点公共建筑（采葛营帐、携行丹灶、聚灵蒲团、淬火铁砧、护阵石龛、养脉泉眼等）。

- **解锁规则**：
  - 根据建筑配表中的 `requiredRealmLevel` 境界等级自动解锁图鉴（如 1 级、19 级、31 级、43 级）。
- **交互与拦截**：
  - **前端交互**：地图附近面板（`NearbyPanel`）的建筑候选弹窗中，只展示当前玩家已解锁图鉴的建筑；未解锁建筑不出现在列表中（隐藏）。
  - **服务端拦截**：`building.build` 校验 `RealmLevel >= definition.RequiredRealmLevel`，不足时拒绝发起（`BUILDING_LOCKED`）。
- **图鉴展示**：
  - 图鉴展示全部建筑条目；
  - 未解锁状态显示虚影暗淡，Hover 悬浮卡内清晰标注【解锁条件：境界达到 X 级自动解锁图鉴】。
- **效果文案规范**：建筑效果必须按 §9.4 的成长模型给出**完整公式**，即「Lv.1 基准值 + 每级增幅」两个数值（如丹房显示 `炼丹行动速度 +12%`、`每级 +2%`），禁止只列 `modifiers` 静态基准——图鉴无等级上下文，单值会被误读为恒定加成。属性名一律走 `PillBonusLabel` 胶囊高亮（属性小图标 + 名称微胶囊 + 色调下划线数值），条目取自 `BUILDING_BONUS_DESCRIPTORS` 全量描述表，新增修饰项字段时只需在此表登记即自动出现在图鉴。

### 23.2.4 功法神通（Abilities）

涵盖心法、剑诀、五行术法、体术与符箓法术等主动与被动技能。

- **解锁规则**：
  - 修士首次通过研读完整技能书（`ability.learn`）领悟该神通后，自动解锁并收录对应图鉴（依据 `learnedAbilityIds`）。
- **交互与状态**：
  - 第一期作为纯收集体系；
  - 未学会的技能显示暗淡问号/虚影；Hover 悬浮卡内注明【解锁条件：研读对应秘籍领悟】。

### 23.2.5 大世界怪物（Monsters）

涵盖各境界区域的普通妖兽、精英怪与世界妖王。

- **解锁规则**：
  - 修士在讨伐遭遇中击败该妖兽（波次胜出清空），即视为降服并解锁收录对应图鉴；
  - 服务端在 `PlayerProgression.DefeatedMonsterIds` 集合中持久化记录所有已击败怪物的 `EnemyId`，并通过快照协议下发至前端。
- **交互与状态**：
  - 第一期作为纯收集体系；
  - 未击败的妖兽显示迷雾剪影，已击败显示全彩；Hover 悬浮卡内注明【解锁条件：在野外讨伐并击败该妖兽】。

## 23.3 视觉与交互规范

1. **顶级入口**：位于左侧主导航栏（PC）及移动端快捷导航中，标识符为 `codex`，图标采用典籍卷轴。
2. **两级导航**：
   - 一级：六大主分类页签（材料 / 技艺 / 建造 / 功法 / 妖兽 / 特质），页签右侧常驻「已收录/总数」角标；
   - 二级：**与坊市同款的多维 Toggle 筛选栏**（公共模板 `OptionToggle` + `.filter-bar`），取代旧的独立子 Tab 条。每个维度为一组「全部 + 互斥选项」单选按钮，首项「全部」表示该维不过滤，维度之间 AND 联合；每个选项右挂「已收录/总数」角标，与一级页签及总进度胶囊同一口径。等阶维度项目较多，使用原生下拉（`.filter-grade-select`，`全部` = 不过滤）。
3. **各分类的筛选维度**：

| 主分类 | 分类维度 | 其余维度 |
| :--- | :--- | :--- |
| 材料 | 灵材 / 矿石 / 异材 / 精材（配表 `subCategory`） | 等阶、收录状态 |
| 技艺 | 炼丹 / 炼器 / 阵法 / 符箓（配表 `technique`） | 等阶、收录状态 |
| 建造 | 生产 / 战斗（配表 `group`） | 收录状态 |
| 功法 | 门类（术法 / 内功）+ 伤害大类（物理 / 法术） | 等阶、收录状态 |
| 妖兽 | 层次（妖兽 / 精英 / 妖王，配表 `rank`） | 等阶、收录状态 |
| 特质 | 品阶（凡品 ~ 天品，`TRAIT_DEFINITIONS.quality`） | 收录状态 |

4. **筛选状态常驻**：每个主分类各自持有一份筛选状态（`useUiStore.codexFilters`），切换到其它页签或其它分类后返回，原分类的子分类、等阶与收录过滤 100% 保持；不同主分类之间互不干扰。
5. **收集进度指示**：主分类页签与每个筛选选项均展示「已收录/总数」角标，顶部另设全库总进度胶囊（`收录进度：56 / 187 (30%)`）。
6. **悬浮卡片规约**：遵循 `FloatingInfoCard` 公共组件规范，卡片主体展示条目属性与材料；并在显要位置渲染专属胶囊或说明行标记【解锁条件】。
