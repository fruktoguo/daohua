# 第一篇 核心哲学与顶层定位

## 1.1 产品定义
《道化太初》是一款以**服务端权威、高确定性离散事件推进（DES）、长线挂机放置**为核心的修仙 RPG 游戏。玩家绝大多数成长行为通过行动队列驱动，离线挂机与在线游玩具有完全等价的确定性数学模拟结果。

## 1.2 核心设计铁律
1. **怪我完全同构 (Monster-Player Isomorphism)**：怪物在领域模型中与玩家完全同构，共享同一套 14 基础属性池、技能装配逻辑、暴击破招对抗与抗性减伤公式，杜绝给怪物编写特殊隐藏补正。
2. **数值全域使用 `double` 精度**：所有属性、收益率、倍率、战斗伤害、时间与计数，计算与存储一律采用 IEEE 754 `double` 精度（百分比存储为 `double` 点数，1 点 = 1%），杜绝整数截断与精度损失。
3. **离散事件飞跃推进 (Discrete Event Simulation)**：游戏推进不依赖固定帧逐秒轮询，而是跳跃至下一个行动或战斗阶段的到期时间戳进行原子状态跃迁。
4. **长线数值闭环量化**：杜绝拍脑袋配表，全量技能、装备、丹药与怪物属性均由顶层数学模型（期望属性池、部位权重、质量预算）确定性推导。
5. **玩家三态生命周期（核心主旨，不可变更）**：角色在任意时刻仅处于以下三种状态之一，状态语义不再谈判——
   - **在线**：行动、战斗、旅行等全部运算在服务端实时进行，事件消息实时推送；
   - **离线挂机**：断线未达离线时长上限（收益封顶线）。收益按确定性规则持续产生，但实时调度降级为批量冷算——队伍中有人在线时全员强制实时（在线成员须收到真实事件推送）；全员离线时不再实时推进，可按小时级批次统一结算，批算任务在主服与计算节点之间按负载分配。未轮到批算即回线的玩家，由主服即时完全补算到当前时刻；
   - **彻底离线**：断线超过离线时长上限。有队伍者直接退队、行动队列整体暂停；进入该状态时完成一次覆盖「断线→上限边界」的收益补算（补算本身可走非实时派发），省得下次登录再即时补算；
   - **切换阈值**：在线 → 离线挂机存在连续离线宽限（当前口径 5 分钟），断开瞬间不得立即按离线挂机处置。离线时长上限（当前 48 小时）自断线时刻起算，服务端执行口径见总纲18 §14。
6. **本地开发兼容清零**：在内测开发期直接废弃历史兼容包袱，不保留双读双写与兼容适配器，以代码精简、架构清晰为第一原则。
