# 第一篇 核心哲学与顶层定位

## 1.1 产品定义
《道化太初》是一款以**服务端权威、高确定性离散事件推进（DES）、长线挂机放置**为核心的修仙 RPG 游戏。玩家绝大多数成长行为通过行动队列驱动，离线挂机与在线游玩具有完全等价的确定性数学模拟结果。

## 1.2 核心设计铁律
1. **怪我完全同构 (Monster-Player Isomorphism)**：怪物在领域模型中与玩家完全同构，共享同一套 14 基础属性池、技能装配逻辑、暴击破招对抗与抗性减伤公式，杜绝给怪物编写特殊隐藏补正。
2. **数值全域使用 `double` 精度**：所有属性、收益率、倍率、战斗伤害、时间与计数，计算与存储一律采用 IEEE 754 `double` 精度（百分比存储为 `double` 点数，1 点 = 1%），杜绝整数截断与精度损失。
3. **离散事件飞跃推进 (Discrete Event Simulation)**：游戏推进不依赖固定帧逐秒轮询，而是跳跃至下一个行动或战斗阶段的到期时间戳进行原子状态跃迁。
4. **长线数值闭环量化**：杜绝拍脑袋配表，全量技能、装备、丹药与怪物属性均由顶层数学模型（期望属性池、部位权重、质量预算）确定性推导。
5. **本地开发兼容清零**：在内测开发期直接废弃历史兼容包袱，不保留双读双写与兼容适配器，以代码精简、架构清晰为第一原则。
