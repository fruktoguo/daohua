# 第三篇 修仙境界与四乘区数值底座

## 3.1 境界三层轴、等阶与品质架构
游戏建立**横向等阶（Tier T1~T12，四修行期）**与**纵向品质（Quality 八品）**交织的修仙体系。

### 3.1.1 境界三层展示轴（大境界 · 境界阶段 · 小境界）
- **小境界**：境界等级轴 Lv.1~127，每级一个名号，是突破进度的最小单位；
- **境界阶段**：大境界内的分段徽章单字——凡俗段为「武（Lv1~6）/ 玄（Lv7~12）/ 天（Lv13~18）」，修真段每个大境界 12 层内分「初（1~3 层）/ 中（4~6 层）/ 后（7~9 层）/ 极（10~12 层）」；
- **大境界**（共 11 个）：凡俗（Lv1~18）→ 练气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫（各 12 层，Lv19~126）→ 飞升（Lv127）。凡俗段 18 级的小境界名依次为：凡胎、炼皮、锻骨、易筋、洗髓、养气、通脉、瑶光、开阳、玉衡、天权、天玑、天璇、天枢、宗师、大宗师、临渊、叩仙门；修真段每大境界 12 层命名为「X 一层~X 九层 → X 巅峰 → X 大圆满 → 半步 Y」（半步 Y 为下一大境界的破境过渡档）。
- **一体化徽章表现**：`[大境界牌匾框] ◇境界阶段棱形框◇ (小境界胶囊框)`（如 `[练气] ◇极◇ (练气巅峰)`，悬浮展示精准等级 Lv）。

### 3.1.2 等阶（T级）数值内容轴
等阶 T1~T12 是装备套、技能、丹药与怪物的数值底座与产出分档轴，锚点等级为 `1/18/30/42/54/66/78/90/102/114/126/127`（`BaseAttributeCatalog.TierAt`：不超过当前等级的锚点个数即等阶）。等阶边界与大境界错开一层：每个等阶以「破境过渡小境界」开篇——叩仙门开启 T2，半步筑基开启 T3，……，半步飞升开启 T11——覆盖到对应大境界大圆满为止。即 T2 对应练气内容档、T3 对应筑基档、T10 对应渡劫档、T11 半步飞升、T12 飞升。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        全 12 等阶四修行期全景架构                       │
├────────────────────────────────────────────────────────────────────────┤
│ 前期 (凡俗期)   : T1 (Lv1~17) ──> T2 (叩仙门 + 练气档 Lv18~29)          │
│ 中期 (气基丹期) : T3 (筑基档) ──> T4 (金丹档) ──> T5 (元婴档)           │
│ 后期 (婴神虚体) : T6 (化神档) ──> T7 (炼虚档) ──> T8 (合体档) ──> T9 (大乘档) │
│ 大后期 (仙道真源): T10 (渡劫档) ──> T11 (半步飞升) ──> T12 (飞升真仙)   │
└────────────────────────────────────────────────────────────────────────┘
```

- **八大品质等级**：Q1 凡品 (白 1.00x) $\to$ Q2 黄品 (绿 1.15x) $\to$ Q3 玄品 (蓝 1.35x) $\to$ Q4 地品 (紫 1.60x) $\to$ Q5 天品 (金 1.90x) $\to$ Q6 灵品 (橙 2.30x) $\to$ Q7 圣品 (红 2.80x) $\to$ Q8 帝品 (彩 3.50x)。
- **怪物生命层次**：妖兽 (Minion 80%) / 精英 (Elite 120%) / 妖王 (Boss 150%)，作用于同级怪物相对**期望玩家面板**（`levelExpected[].finalExpected`，每级锚点）的全属性倍率，非裸 `baseAttributeAnchors` 底座（详见第七篇）。
- **系统与世界观解耦说明**：12 等阶是底层数值、内视面板与装备穿戴的统一系统模型；剧情对白与世界观文案使用“未入门/引炁/炼炁/凝炁”沉浸式口径，两者各司其职。

## 3.2 核心属性四独立乘区归一化数学模型
$$\mathbf{最终面板属性} = \mathbf{(基础数值池 (BaseFlat) + 六维固定值 (RootFlat))} \times \mathbf{(1 + 六维\%)} \times \mathbf{(1 + 装备\%)} \times \mathbf{(1 + Buff\%)}$$

> 六维每点**同时**提供固定值与百分比（§3.2.2）：固定值并入基础池后先被六维%独立乘区放大，再叠装备 `flatStats`、被装备%/Buff% 乘区放大。

### 3.2.2 基础六维资质换算规约 (初始 0 点，每点提供固定值 + 百分比双加成)
六维等级由境界修为表派生的**单点成本表**导出（0 级起算，初始经验 0）：每维上限 **381 点**（127 级境界 × 3 点/级）。记 `B[i] = expToNext[max(0, i−1)]`（跨入第 i+1 级消耗的那格修为条，`B[0]` 取第一条），升到第 p 点（1≤p≤381）所需经验 = `B` 在 `t=(p−1)/3` 处的线性插值 `lerp(B[⌊t⌋], B[⌈t⌉], frac(t))`——一级境界对应三点、三点合计约三倍该级修为条，相邻档间平滑过渡不出现三连同价。单维累计至 3Lv 点 ≈ `3×ΣexpToNext[1..Lv−1]`（境界累计修为的 ~3.1 倍，Lv127 收敛 3.05×），使六维成本与修为通胀永远同节奏。每点六维为映射属性**同时**提供固定值与百分比加成：
- **体魄 (Tǐ Pò)**：`1% +12 生命上限`、`1% +1 物理护甲`、`1% +1 生命自动回复`
- **经脉 (Jīng Mài)**：`1% +7 灵力上限`、`1% +1 法术抗性`、`1% +1 灵力自动回复`
- **根骨 (Gēn Gǔ)**：`1% +12 生命上限`、`1% +7 灵力上限`、`1% +1 化解`
- **力道 (Lì Dào)**：`1% +1 物理攻击`、`1% +1 暴击等级`、`1% +1 破招等级`
- **神识 (Shén Shí)**：`2% +2 术法攻击 (术法×2)`、`1% +1 命中等级`
- **身法 (Shēn Fǎ)**：`1% +1 闪避等级`、`1% +1 免爆等级`、`1% +1 化解`

### 3.2.3 双流派对偶配点法则
1. **🗡️ 物理系 (Physical)**：走 **`1 AD : 1 暴击 : 1 破招`**，破招触发**双倍暴击与双倍命中**；普攻为全流派统一物理模型（1.0s 基准 ×(1-ATR)×(1-攻速成长)，满成长 0.25s 极限间隔、`100%→200%` AD），结合重斩/贯星等高倍率单体绝技，主打极致 Boss 斩杀。
2. **🔮 法术系 (Magic)**：**AP 仅供技能结算**（普攻与物理系完全统一）；高法攻面板在平方减伤公式下**天然强势破防**，配合 AP 群攻技能与掌心雷（0CD 填充技）主打范围清场。
