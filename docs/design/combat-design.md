# 道化太初 · 战斗数值与内视设计规约

本文档记录角色内视体系、双数值类型定义规范、统一基准数值底座、非玩家单位（怪物）全量量化设计模型、六维根基换算规则、普通攻击规则、全量战斗属性分类、抗性减伤与对抗计算公式，以及核心生平记录规范。

## 1. 强制数值类型架构规范 (全量使用 double)

根据系统与领域核心架构规则：
- **全部数值计算与储存一律使用 `double` 精度**（前端对应 JavaScript/TypeScript `number` 即 IEEE 754 double）。
- 杜绝任何整数截断导致的非预期突变，百分比结构体内部存储同样采用 `double` 点数。

### 1.1 固定数值类型 (Fixed Value / Flat Value)
- **底层表示**：直接使用 `double` 存储与结算。
- **涵盖属性**：全部基础战斗属性均为此类型。
  - 生命值 (HP)、灵力值 (MP)
  - 物理攻击、术法攻击
  - 护甲 (物防)、法抗 (法防)
  - 命中、闪避
  - 暴击、免爆
  - 破招、拆招 (化解)

### 1.2 统一百分比数值类型 (Percent Value)
- **底层表示**：内部统一存储为 `double Points`（点数），以 **100 点 = 100% 当量 (1 点 = 1%)** 作为基准缩放常数 $K = 100$。
- **支持曲线模式 (Curve Mode)**：
  - **`Linear`（线性模式）**：适用于增伤、免伤、仇恨增加、各类属性伤害增免。
  - **`NonLinear`（非线性/速率倒数模式）**：适用于冷却速度 (CDR)、行动速度 (攻速)、灵力消耗减少。

#### 百分比类型双模式换算模型对比表

设属性底层点数为 $x$：

| 点数 $x$ | 模式 (Mode) | 实际战斗乘区倍率 (Multiplier) | 面板展示百分比 (DisplayPercentage) | 业务行为说明 |
| :--- | :--- | :--- | :--- | :--- |
| **0** | Linear | $1.0\times$ | **0%** | 无增益 / 无减益 |
| **+100** | **Linear** | $1 + \frac{x}{100} = \mathbf{2.0\times}$ | $\mathbf{+100\%}$ | 增伤 100 点，伤害翻倍 ($2\times$) |
| **-100** | **Linear** | $\frac{100}{100 + \|x\|} = \mathbf{0.5\times}$ | $\mathbf{-50\%}$ | 负向除法软着陆，伤害减半 ($0.5\times$) |
| **0** | NonLinear | $1.0\times$ | **0%** | 基础冷却 / 消耗时间 |
| **+100** | **NonLinear** | $\frac{100}{100 + x} = \mathbf{0.5\times}$ | $\mathbf{50\%}$ | 冷却速度 100 点，CD 缩减 50% |
| **-100** | **NonLinear** | $1 + \frac{\|x\|}{100} = \mathbf{2.0\times}$ | $\mathbf{-100\%}$ | 冷却减速 100 点，CD 延长一倍 |

## 2. 统一基准数值底座 (Baseline Attributes)

全系统单位（包括默认玩家角色、所有怪物、首领、NPC）**均采用同一套基准数值底座**，所有后续成长、装备、功法、Buff 以及怪物强度，均在基准数值上进行量化百分比缩放与增量叠加。

| 基础属性 | 符号/简写 | 基准默认数值 (double) | 说明 |
| :--- | :--- | :--- | :--- |
| **最大生命值** | HP | **100.0** | 基础仙躯气血 |
| **最大灵力值** | MP | **50.0** | 基础气海容量 |
| **物理攻击** | AD / PhysAtk | **10.0** | 基础体魄杀力 |
| **术法攻击** | AP / SpellAtk | **5.0** | 基础术法灵威 |

| **法术抗性 (法抗)** | MagicRes | **0.0** | 基础法御抗性 |
| **命中点数** | Accuracy | **1.0** | 基础对抗命中 |
| **闪避点数** | Evasion | **1.0** | 基础对抗闪避 |
| **暴击点数** | Critical | **1.0** | 基础对抗暴击 |
| **免爆点数** | CritAvoid | **1.0** | 基础对抗免爆 |

| **所有百分比属性** | PercentPoints | **0.0 点 (0.0%)** | 基础增免伤、加速、穿透均为 0 |

## 3. 全量量化平衡与非玩家单位（怪物）设计模型

### 3.1 量化设计理念 (参考 mud-mmo-next)
系统杜绝“拍脑袋填表、来回人工调参、牵一发而动全身”的落后配表方式。整个数值体系是**完全参数化、闭环量化**的：
1. **玩家标杆量化**：对于任意目标境界等级 $L$（如炼气九层、筑基初期、金丹大圆满），系统可精确计算出该境界玩家的：
   - **基准状态数值**：$\text{Base}(L) = \text{Baseline} \times (1.1)^{L-1}$
   - **极限养成数值**：$\text{Peak}(L) = \text{Base}(L) \times (1 + \text{六维加成} + \text{极品装备加成} + \text{丹药加成})$
2. **怪物量化生成**：怪物无需人工填独立数值，直接按照**品阶倍率（Tier Multiplier）**和**属性倾向（Tendency）**在目标境界基准上自动百分比缩放生成：

| 怪物层级 (Tier) | 全属性缩放比例 | 生命值 (HP) 缩放比例 | 战术定位与平衡标杆 |
| :--- | :--- | :--- | :--- |
| **普通妖修 (Normal)** | **100%** 基准 | **100%** 基准 | 对齐标准基准玩家，单体击杀平稳，挂机历练核心 |
| **精英大妖 (Elite)** | **120%** 基准 | **300% ~ 360%** 基准 | 对齐中高练度玩家，需配合控制或续航技能 |
| **妖王魔尊 (Boss)** | **150%** 基准 | **1000% ~ 1400%** 基准 | 对齐极限养成玩家或组队挑战，需策略破招与战煞抗伤 |

### 3.2 怪物属性倾向量化微调
在品阶倍率之上，可通过倾向配置快速派生特色怪物：
- **玄甲巨兽型**：护甲 $\times 1.5$、生命 $\times 1.3$、攻速 $\times 0.8$
- **影蝠刺客型**：闪避 $\times 2.0$、暴击 $\times 1.5$、生命 $\times 0.7$
- **炽炎法王型**：术法攻击 $\times 1.6$、法穿 $\times 1.5$、护甲 $\times 0.6$

## 4. 普通攻击机制 (Basic Attack)

当修士在战斗中不使用或未就绪任何功法技能时，触发普通攻击：
- **行动速度**：默认为 `0` 点（对应 `0.0%`，无增减）。
- **伤害倍率**：造成 **100% 物理攻击伤害**（`1.0 * PhysicalAttack`）。
- **冷却时间 (CD)**：`0.0s`。
- **引导施法时间**：`1.0s`。
- **灵力消耗**：`0` 灵力。

## 6. 核心生平记录规范 (全量使用 double)

内视【生平】页面精炼为四大核心道果记录：

1. **斩妖**：击杀妖修怪物的数量，分别按三个级别统计：
   - 普通妖修数量 (`double normalKills`)
   - 精英大妖数量 (`double eliteKills`)
   - 妖王魔尊数量 (`double bossKills`)
   - 诛灭妖邪总计 (`double totalMonsters`)
2. **破敌**：击败其他修士玩家的数量 (`double playersDefeated`)。
3. **败走**：在任何战斗模式中被击败的次数 (`double totalDefeats`)。
4. **苦修**：进行修炼的累计总时长 (`double cultivationSeconds`，以小时/秒展示)。

## 7. 战斗伤害与对抗计算公式

### 7.1 抗性减伤公式
伤害计算公式（参考 mud_mmo_next 体系）：
$$\text{实际伤害} = \text{原始伤害} \times \left( \frac{\text{原始伤害}}{\text{原始伤害} + \text{有效抗性} \times \text{抗性减伤系数} + \text{基础常数}} \right)$$

- **抗性减伤系数**：常量为 `5.0`。
- **基础常数**：常量为 `1.0`。
- **有效抗性**：计算穿透比例后实际起效的护甲或对应属性抗性。

### 7.2 技能消耗换算
技能配置的消耗数值经独立方法 `CalculateManaCost` 换算：
$$\text{最终灵力消耗} = \text{基础消耗} \times 10$$

### 7.3 三大对抗概率计算公式
对抗基础概率公式：
$$\text{实际概率} = \frac{\text{自身属性}}{\text{自身属性} + \text{对方对抗属性} \times 1.0 + 1.0}$$

1. **命中 vs 闪避**：未命中则完全不造成伤害。
2. **暴击 vs 免爆**：暴击时伤害乘以暴击伤害倍率。
3. **破招 vs 拆招（化解）机制**：
   - **破招触发**：攻击者破招 > 被攻击者拆招时判定，成功时**命中值与暴击值实际计算效果翻倍**。
   - **拆招触发**：被攻击者拆招 > 攻击者破招时判定，成功时**双抗（护甲/法抗）与闪避实际计算效果翻倍**。

## 8. 威胁（仇恨）与技能目标选择机制

### 8.1 威胁（Threat / 仇恨）定义与累积规则
- **定义**：单位在战斗中对敌方全体造成的总伤害，统一称为**“威胁”**（`double Threat`）。
- **持续累积**：在整场战斗过程中持续累加，全部计算与存储均采用 `double` 精度。
- **嘲讽技能即时加成**：
  - 嘲讽类技能或 Buff 提供的威胁加成效果为**即时生效（Real-time Applied）**；
  - 在计算有效威胁值时，直接按该百分比放大：
    $$\text{有效威胁值} = \text{基础累积伤害威胁} \times (1 + \text{嘲讽/仇恨增加百分比})$$

### 8.2 技能目标选择与命中概率分配规则
战斗中，除全体技能或明确锁定特殊类型（如生命最低友方、自身、特定指定单位等）的技能外，其余所有单体与非全体范围技能**均按候选目标的威胁值比例进行目标选择**。

#### 1. 单体技能 (Single-Target Ability)
- **总池计算**：将当前全体可选存活目标的有效威胁值求和作为总池值 $S$：
  $$S = \max\left(1.0, \sum_{i \in \text{可选目标}} \text{Threat}_i\right)$$
  *(设置保底值 $S_{\min} = 1.0$，防止除零异常)*
- **命中概率**：每个候选目标被选中的概率为其威胁值占总池的比例：
  $$P_i = \frac{\text{Threat}_i}{S}$$
- **全零回退规则**：当所有候选目标的威胁值均为 $0.0$ 时，退化为**完全等概率随机**选择其中一个目标（每个目标概率为 $1 / N$）。

#### 2. 非全体群攻技能 (Non-Full AoE Ability / Multi-Target)
根据技能机制设定，分为**可重复命中**与**不可重复命中**两种模式：

1. **可重复命中模式 (Repeatable Multi-Hit)**：
   - 技能进行的每一次打击判定，均独立在全体可选目标中按单体威胁权重概率池完整抽取一次；
   - 同一个目标可能在同一次技能中被连续命中多次。
2. **不可重复命中模式 (Unique Multi-Target)**：
   - 采用**动态缩减概率池（Sequential Elimination）**算法：
     1. 第一段在当前全体候选目标中按威胁比例抽取目标 $T_1$；
     2. 命中后将目标 $T_1$ 从候选池中剔除，剩余目标构成新的总池 $S' = \sum_{j \neq 1} \text{Threat}_j$；
     3. 后续攻击依次在剩余目标池中按更新后的威胁比例继续抽取，直至达到技能目标上限或候选池耗尽；
     4. 保证单次群攻中每个目标至多受到一次命中。
