# 战斗流派设计思路

> **文档定位**：仅沉淀各战斗流派的仙侠意境、核心体验、正负取舍与「特质 × 技能 × 装备 × 器物」构筑思路，**不记录具体代码、字段与底层实现细节**。每敲定一个新流派即追加收录。

---

## 一、流派设计通用心法

1. **鲜明的仙侠身份感**：每个流派都应对应修真界一种辨识度极高的斗法路数（如瞬影剑仙、离火焚天、执掌阵眼的奇门阵师、掷符如雨的符箓宗师、十年养剑的拔刀剑痴等），一眼就能想象出修士在战场上的出招画面。
2. **单一清晰的桥梁机制**：每个流派围绕一个核心状态或规则改写运转——由部分特质/技能「造势」，另一部分特质/技能/装备「借势」或「收势」，避免杂乱堆砌零散词条。
3. **敢给上限，也敢下重手做取舍**：高阶流派核心特质遵循「重收益、真代价」原则，通过极致偏科封堵平庸万金油，逼出截然不同的配招与配装。
4. **重势不重碎频**：多用「蓄势一击、周期落雷、单发增威」来表现威力，避免靠无意义的超高频碎伤刷屏，既保留大数字破防的爽快感，也维持战场节奏凝练。

## 二、既有成熟流派

### 1. 御风移形流（位移流）
- **仙侠意境**：身剑合一，踏虚无痕；一动避万法，一击斩敌首。
- **运转核心**：围绕短时身法状态**「移形」**展开循环——处于移形中时身法飘忽、闪避倍增；一旦出招攻敌，便借势打出双倍命中的必杀一击并消耗一层移形。
- **构筑拼图**：
  - **特质**：**【剑与心】**——双攻小幅精进；身处移形之中出招时，剑锋无视前排嘲讽牵制，直取敌阵随机目标要害（可跨前排斩后排，亦可联动重击爆发）。
  - **技能**：由【跃迁】（全队起势）、【破军】（冲阵起势并获递减罡气护体）与未起势时的【瞬闪】负责赋予移形；再由【斩玉→踏云】（借移形化单体为横扫群敌）或已起势的【瞬闪】（借移形斩杀目标后立刻重整冷却）完成收割。
  - **装备倾向**：偏重高物攻/双攻、暴击暴伤与闪避身法，追求「避实击虚、一剑破点」。

### 2. 离火焚魂流（灼烧流）
- **仙侠意境**：万法归炎，薪火不绝；初触微温，转瞬焚骨成灰。
- **运转核心**：围绕可无限叠层并刷新存续的火毒状态**「燃烧」**运转——每一次火系创伤都在往敌人神魂上添柴加薪，只要攻势不断，积攒的业火便会每秒烧穿敌方防线。
- **构筑拼图**：
  - **特质**：
    - **【燃魂】**：一切直接火伤皆可按创伤轻重引燃敌方，化直伤为绵延火势；
    - **【火神】**：将自身拳脚、刀剑、术法乃至符阵之威尽数化为离火真炎，并增幅火威——打通门户之见，令剑修、多段连击与阵盘皆可入火道。
  - **技能**：【火焰风暴】群体铺火并压低血线，【灼心】舍弃直伤、专为强敌种下巨量火毒层数，辅以【连环】等多段招式高频添薪续火。
  - **装备倾向**：偏重术法威力、火系增伤、冷却流转与生存续航，拖入中盘即是焚天绝境。

## 三、全新拓展流派

### 3. 奇门阵修流（阵盘杀伐流）
- **仙侠意境**：不逞匹夫刀剑之勇，盘坐阵眼执掌乾坤；挥袖间天雷勾地火，入阵者寸步皆杀机。
- **运转核心**：彻底废去修士本体的拳脚与术法直伤杀力，将一身修为与资源全部倾注于**杀伐阵盘（如天雷阵、血煞阵及后续高阶奇阵）**，走纯粹的「器物借法、以阵诛邪」路线。
- **核心特质**：
  - **【阵法·敛】**：将原本全队触发式的阵盘收束归于自身触发，其余规则不变。阵师收拢四散阵机独归己身，身即阵枢，不再依赖旁人交锋引阵，独行或组队皆能自成完备杀阵。
  - **【阵法大师】**：阵法造成的伤害大幅提升 **200%**；代价是自身技能增幅减少 **500%**、普攻伤害减少 **500%**。本体招式化作毫无杀力的引阵手印与护道法诀，杀伐输出完完全全交由大阵承担。
- **后续技能与装备延展思路**：
  - **技能侧**：配套不依赖直伤的奇门护道、聚灵维阵、镇压敌军抗性等辅助法门。
  - **装备与阵盘侧**：扩充更多品阶与五行特性的杀伐阵盘，以及强化阵威与灵气/气血续航的阵旗、罗盘法器。

### 4. 天罡符修流（灵符轰炸流）
- **仙侠意境**：懒习贴身剑术，不诵冗长咒文；袖藏乾坤万道符，抬手雷火覆千军。
- **运转核心**：与阵修并称器道双绝——同样舍弃本体普攻与常规神通直伤，将**符箓消耗品**从辅助添头彻底升格为主战核心；通过打破槽位桎梏，将多种不同灵符直接装入术法栏位，如普通消耗品般瞬发轮番轰炸，以海量灵力与符纸储备倾泻狂暴火力（同时深度盘活修真百艺中的制符产销链）。
- **核心特质**：
  - **【符法·疾】**：降低自身 **500%** 的技能增幅与 **500%** 的普攻伤害；使符箓冷却时间减少 **80%**（按 400 点冷却加速计，特质升级每级 +5% 提升该加速值，如升至 420 点），代价是激发符箓消耗的灵力提升 **300%**（变为原有的 **400%**）。高频掷符伴随巨量气海倾泻，迫使符修极致堆叠灵力上限、回灵速率与聚灵阵盘。
  - **【符法·破阵】**：赋予符箓**暴击**能力，并常驻提升 **10% 暴击率** 与 **10% 暴击伤害**，打开符修会心一击的爆发上限。
  - **【符法·天罡】**：符箓造成的伤害直接提升 **30%**，夯实符道基础杀力。
  - **【符法·天命】**：自身的**术法槽位可以直接装配符箓**（而不再局限于术法神通），并提升 **10% 符箓伤害**。装配与触发规则与普通战斗物品栏完全一致——**同名符箓全栏互斥**（不可多槽重复装同一种符箓，引导收集搭配诸般异种灵符），且冷却就绪、条件满足时**无吟唱瞬发**并扣除对应库存与灵力。由此解放通用消耗品栏专心挂载聚灵阵盘供蓝。
- **后续技能、符箓与装备延展思路**：
  - **符箓谱系扩充**：在现有雷击符之外，按等阶与五行扩充不同定位的灵符（如离火符、玄冰符、庚金剑符、破甲符等），支撑多术法槽位的异种符箓联轰。
  - **技能与内功侧**：搭配纯粹提升气海容量、周天回灵速率及护身保命的心法与辅助秘术。
  - **装备侧**：设计符笔、符袋、通灵玉佩等专属装备，围绕最大灵力、回灵、暴击暴伤与符威增幅展开。

### 5. 藏剑养剑流（蓄势拔刀流）
- **仙侠意境**：十年藏锋匣中鸣，一朝出鞘鬼神惊；不争朝夕碎刃，只求一剑开天。
- **运转核心**：反高频之道而行，封住日常平庸碎招，在静默与长吟唱蓄力中逐秒积攒**「剑意」**，待重剑绝学出鞘瞬间倾泻全部剑意，借恐怖的物攻、暴击与暴伤一击洞穿强敌重甲。
- **核心特质**：
  - **【养剑术】**：未造成伤害期间每秒获得 **1 层「剑意」**；剑意持续最多 **10 秒**，每次获得新层数时刷新持续时间；每层提升 **30% 物理攻击力**、**30% 暴击率** 与 **30% 暴击伤害**，出剑造成伤害结算后散去重蓄。
  - **【藏锋】**：战斗中**不再进行普通攻击**（技能冷却期间收剑入鞘专心养剑，绝不因平 A 泄去剑意），并提升 **20% 技能增幅**（随特质等级同步成长，放大出鞘绝技威力）。
- **后续技能与装备延展思路**：
  - **技能侧**：天然契合长吟唱、长冷却、高单发倍率的重剑杀招（如《贯星》《重斩》及后续拔刀斩仙剑诀），蓄力读条本身亦在持续叠高剑意。
  - **装备侧**：偏重高基础物攻、技能增幅、破招与暴击伤害的重剑/剑匣法宝。
